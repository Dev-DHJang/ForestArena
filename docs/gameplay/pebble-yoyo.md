# 조약돌 요요

2026-10-30 사용자 승인 계획의 능동 장신구(버튼을 눌러 사용하는 장비)다. 자현·나비의 로컬·LAN 전투에 적용한다. 캐릭터의 새 사용 모션은 별도 독립 검토와 모션별 명시 승인 뒤 등록한다. 승인 상태·검사 증거는 [_workspace/pebble-yoyo](../../_workspace/pebble-yoyo/00_request.md)를 따른다.

## 획득과 편성

상점에서 조약돌 요요를0원으로 획득한 뒤 장신구 목록에서 장착·해제한다. 장착은 로컬·DB 저장과 프리셋에 남는다. 저장 ID는 `pebble-yoyo`다. 기존6장신구의 보유 기록은 보존하지만 현재 경기에서는 계속 비활성이다.

대전 준비에서 내 장비와 AI별 장비를 고른다. AI 선택지는 미장착 또는 내가 소유한 활성 장신구다. 기본값은 미장착이며 준비 화면·재대전에서 유지하고 앱 재실행 시 초기화한다. AI는 장착한 장비를 사람과 같은 사용 조건으로 사용한다. 연습 허수아비는 자동 사용하지 않는다.

## 사용과 판정

- 오른쪽 `장비` 버튼 또는 키보드 `E`로 사용한다. 지상·공중 대기/이동 중 가능하며 공격·가드·피격·다운·공중 행동 제한 중에는 거부한다.
- 준비6틱 → 발사18틱 → 회수18틱 → 회복6틱이다. 초당60틱 기준 팔에서 전방180까지0.3초, 돌아오는 데0.3초이며 전체 행동은0.8초다. 방향은 시작할 때 고정한다.
- 사용 중 수평 속도를0으로 하고 좌우 이동·새 점프·가드·공격을 잠근다. 중력·낙하·지형 충돌은 유지한다. 공중에선 사용 중 착지해도 동작 진행을 유지한다.
- 유효한 사용 시작부터600틱(10초) 대기한다. 빗나가거나 피격으로 중단돼도 유지한다. 거부된 입력은 시간을 소비하지 않는다. 목숨을 잃어도 쿨타임은 유지하고 새 경기·재대전에서는 초기화한다. 경기 일시정지 중에는 진행하지 않는다.
- 발사 중 요요 본체28×28만 적중하며 직전 위치부터 현재 위치까지 검사한다. 실·회수·회복은 무판정이다. 적마다1회, 여러 적에게 적중 가능하며 자신·팀원은 제외한다. 단단한 지형을 만나면 조기 회수한다. 통과형 발판은 기존 통과 방향을 따른다.
- HP 피해·추가 넉백 없이 정확히30틱(0.5초) 경직을 준다. 무게·일반 경직 배율은 적용하지 않고 이미 더 긴 경직을 줄이지 않는다. 남은 공중 행동 기회는 바꾸지 않는다.
- 가드는 내구도 소모 없이 막는다. 무적·기상·다운 보호와 면역 규칙은 유지한다. 시전자가 피격·탈락·사망하면 남은 요요 판정을 제거하고 쿨타임은 유지한다.

동시 입력은 아래+점프 → 일반 공격 → 장비 → 아래 가드 → 점프 순이다. 장비 누름만 사용 입력이며 길게 누르기로 자동 반복하지 않는다. UI는 미장착·준비·사용 중·대기시간·행동 불가를 권위 상태에서 읽는다.

## 데이터·LAN과 확인

`AccessoryData.active_ability`는 선택형 `AccessoryAbilityData`이며 장신구별 시간·거리·효과를 데이터로 정의한다. 기존 schema2 장신구와 schema3 프로필을 유지한다. 소스 Resource는 바꾸지 않고 한 판용 복사본을 쓴다. 이미지 논리 ID는 `fa.accessory.pebble.yoyo`, 전투 본체는 `fa.accessory.pebble.yoyo.combat`다.

LAN은 protocol5이며1~4는 명시적으로 거부한다. 서버가 실제 사용·쿨타임·피격을 결정하고 클라이언트는 입력과 표시만 맡는다. 남은 대기·단계·단계 경과틱·위치·방향·활성화 번호를 전달하며 재접속에서도 복원한다. 정식 인터넷 온라인 범위는 확대하지 않는다.

자동 검사: `tests/pebble_yoyo_combat.gd`, `tests/pebble_yoyo_ui.gd`, `tests/two_fighter_product.gd`, 프로필·프리셋·LAN 실제 연결 회귀. 이름 있는 수동 재검사: **요요 팔 연결과 왕복**, **128px·좌우 반전 모션**, **장비 버튼 엄지 접근**, **실기기 중단·복귀**. 실제 Android 미실행 항목은 기기 통과로 기록하지 않는다.
