# 장신구 설정 v01

2026-10-09 사용자 승인 방향: 추가 피해·부활을 제외하고 공격 방식 변경이나 기타 특수 옵션을 제공하며 과도한 우위를 만들지 않는다. 반사 피해도 추가 HP 피해이므로 제외한다. 장신구에는 등급·희귀도가 없다.

현재 적용한 값은 균형 검증을 시작하기 위한 조정 가능한 기본값이다. 작은 수치와 불리한 점이 있다고 해서 공정성이 입증된 것은 아니다.

| 표시 이름 | 실제 효과 | 불리한 점・제한 | 보존하는 저장 ID |
| --- | --- | --- | --- |
| 철갑옷 | 무게 +5% | 지상 속도 -5%, 슈퍼아머 없음 | fixture-iron-armor |

상품 이름과 옛 저장 ID는 다를 수 있다. 기존 보유・선택・API 허용 ID는 유지하고 새 설정을 적용한다. 추가 피해와 부활을 선언한 옛 AccessoryData 정의는 검사에서 거부한다. 일반 전투 효과 처리기의 직업용 기능은 삭제하지 않는다.

복싱 글러브는 기존 기술 목록 교체 예시를 유지한 것이며 새 글러브 전용 공격・모션 제작은 아니다. 다른 캐릭터의 기본 피해를 바꾸는 기술 교체와 적중 후 별도 추가 피해는 구분한다. 기술 교체만으로도 우위가 생길 수 있어 모든 캐릭터에서 확인해야 한다.

## 확인과 미확인

- 자동 확인: 4캐릭터×6장신구의 조합・실제 적중・효과 금지・마지막 stock・재대전・원본 데이터 보존.
- 장신구 없는 상태와의 승률・실제 사람의 조작 감각・Android 기기별 최신 옵션 검사는 아직 수행하지 않았다. 밸런스 완료로 표시하지 않는다.
- 향후 비교: 같은 캐릭터・경기장・상대 조건에서 미장착과 각 옵션을 번갈아 플레이하고 승패・공격 성공・복귀 성공・불리한 상황을 기록한다. 우세가 반복되면 값이나 기술 교체 범위를 조정한다.
- 조약돌・무지개돌 정책은 [재화 문서](../product/economy-pricing-v01.md)에서 구분한다. 이번 전투 설정 변경은 결제・재화 차감・가격 적용을 포함하지 않는다. 유료 전용 특수 옵션의 경쟁 공정성은 별도 검증 대상이다.
