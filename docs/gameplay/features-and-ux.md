# 03. 기능과 UX

UX는 사용자가 조작을 배우고 목표를 달성하는 전체 경험이다. 화면 관련 용어는 [용어 가이드](../GLOSSARY.md#화면과-그래픽-용어)를 참고한다.

## 화면과 입력

- Android 가로 화면의 왼쪽 이동 영역과 오른쪽 행동 버튼을 기본 방향으로 삼는다.
- Phase 1 입력 UX는 왼쪽에 상·하·좌·우 방향패드, 오른쪽에 약·강·특수와 별도 점프 버튼을 두며 구현·검증됐다. 이 배치는 후속 범위 승인 없이 바꾸지 않는다.
- 현재 대시 입력은 호환 행동으로 유지하며, 가드·회피·궁극기는 전투 명령으로 해석한다. 잡기 기술과 Android 보조 버튼은 제공하지 않으므로 동작하지 않는 버튼을 미리 표시하지 않는다.
- 터치 영역은 손가락으로 안정적으로 누를 수 있어야 하며 운영체제 제스처, 노치와 안전 영역(safe area)을 침범하지 않는다.
- 멀티터치 이동·공격, 버튼 경계 이탈, 포커스 손실과 복귀 뒤 입력 고착이 없어야 한다.
- 구체 터치 크기, 배치 프리셋과 사용자 조정 범위는 실제 기기 검증 뒤 ADR로 확정한다.

## 프로토타입 흐름

    앱 실행 → 연습 또는 AI 대전 → 캐릭터·직업·장신구·경기장 선택
    → 전투 → 링아웃/복귀 또는 결과 → 재시도/선택 화면

승인된 모드는 Story, Solo, Team, AI, Practice다. 전체 참가자는 최대 8명이며 Team은 팀당 1~4명, 전체 최대 8명이다. Phase 6 오프라인 모드 선택과 실제 경기 생성은 구현됐지만 Story 대화·보상·성장·획득은 아직 구현하지 않았으며 선택 화면과 성장 저장을 혼동하지 않는다.

Story 버튼과 준비 화면에는 `프롤로그`를 함께 표시한다. 현재 Story는 보상·성장 없이
기존 전투로 이어지는 도입 흐름이며 완성된 이야기 모드로 표현하지 않는다. 별도 `LAN 1:1`
메뉴에서는 방 만들기·참가, 한 줄 코드, 대기, 결과와 재대전만 노출한다. 로그인·결제·랭크·
친구·채팅 버튼은 표시하지 않는다.

## 비전투 화면 설계 계약

- Penpot 기준 프레임은 1920×1080 가로 화면이고 Godot 런타임 논리 해상도 1280×720은 유지한다.
- 고정된 24개 `SCR_*` 화면 이름과 `IMG/*` 이미지 자리는 [비전투 UI 데이터](../ui/non-combat-ui-v01.json)를 프로그램이 읽는 최종 기준으로 사용한다.
- 밝은 비픽셀 판타지 숲을 기본 시각 방향으로 삼고 `SCR_01_Splash`에는 캐릭터를 배치하지 않는다.
- 장신구 UI는 기능 범주와 궁합을 표현하되 희귀도·등급으로 오인될 별·색상 테두리·티어 라벨을 사용하지 않는다.
- 빠진 이미지는 정확한 `IMG/...` 이름의 임시 이미지(플레이스홀더)로 남기고 Penpot의 `MISSING ASSETS` 목록에서 보이게 기록한다.
- 24개 화면의 Godot 구현, 이미지 생성과 외부 Penpot 파일 편집은 이 설계 기반과 별도의 후속 작업이다.

## 카메라와 전투 정보(HUD)

- 로컬 AI 전투 카메라는 플레이어를 가운데 목표로 따라가며 고정 줌 1.25를 사용한다. 현재 네 캐릭터의 평균 실루엣 기준으로 가로에 약 10개가 들어오는 크기이며 경기장 전체를 한 번에 보여 주지 않는다.
- 상대 스프라이트가 화면에 조금이라도 보이면 별도 표시를 숨기고, 완전히 화면 밖일 때만 HUD 아래·터치 조작 위의 가장자리에 방향 화살표를 표시한다. 이름과 거리 숫자는 표시하지 않는다.
- HUD는 전투 중 현재/최대 HP와 남은 stock을 보여 주지만 그 값이나 승패를 직접 계산하지 않는다.
- 궁극기 게이지와 막기 내구도는 전투 코드가 계산한 값을 표시만 한다. 터치 UI가 충전, 소모나 막기 실패를 계산하지 않는다.
- 개발 오버레이는 상태, 공격 단계와 성능 정보를 릴리스 UI와 분리한다.
- 카메라, 화면 밖 화살표와 지형 그림은 전투 snapshot, 적중, 링아웃과 승패를 변경하지 않는다.

## 대전 미니맵

- 대전 화면 우측 상단에 240×150 사각형 미니맵을 둔다. 화면 안전 영역 안에서 경기 정보·대전 버튼·터치 조작과 겹치지 않게 배치한다.
- 경기장 전체의 간단한 지형과 현재 참가자 위치를 실시간으로 보여 준다. 카메라 이동과 확대에 따라 미니맵의 지도 범위를 바꾸지 않는다.
- 기본 표시는 승인 캐릭터 이미지의 작은 얼굴과 사용자명이다. 내 위치는 작은 삼각형으로 구분한다. 탈락하면 숨기고 재등장하면 다시 표시한다. 경기장 범위를 벗어나면 가장자리에 표시한다.
- 팀전은 내 팀의 이름·얼굴 테두리·점을 파란색, 상대 팀은 빨간색으로 표시한다. 개인전과 팀 구분이 없는 1대1은 모두 흰색으로 표시한다.
- 접근성 설정에서 얼굴/점, 이름 켜기·끄기, 미니맵 전체 투명도 0~90%를 바꾼다. 기본은 얼굴·이름 켜기·투명도 30%다. 배경·지형·얼굴·이름 전체에 같은 투명도를 적용한다.
- 닉네임은 기본 `플레이어`이며 앞뒤 공백 제거 후 1~12자다. 줄바꿈과 제어 문자를 허용하지 않고 중복은 허용한다. AI는 `AI 1`처럼 참가자별 이름을 쓴다. 미니맵에서 긴 이름은 말줄임 처리하고 겹친 이름은 가까운 빈 공간에 배치한다.
- 설정은 기기 또는 개발용 DB에 저장하고 다음 경기부터 적용한다. LAN 닉네임은 방 생성·참가 시 확정하며 재접속·재대전에도 유지한다. 저장에 실패하면 기존 값을 유지하고 재시도를 안내한다.
- 미니맵은 지형과 전투 상태를 읽어 표시만 한다. 판정·승패·전투 상태를 변경하지 않는다.

## Android 생명주기

- 중단·백그라운드 진입 시 오프라인 전투를 일시정지하고 입력과 오디오를 정리한다.
- 복귀 시 중복 진행 없이 명시적 재개 흐름을 제공한다.
- 앱이 입력 초점을 잃으면 눌린 입력을 모두 해제하고 화면 안전 영역을 다시 계산한다.
- 초기 Phase에는 저장되지 않은 매치 복원을 약속하지 않는다.

## 접근성

- 위험, 피격과 상태를 색상 하나에만 의존하지 않는다.
- 화면 흔들림, 번쩍임, hit-stop과 진동의 조절 가능성을 설계한다.
- 텍스트, 아이콘과 핵심 조작이 작은 화면과 손가락에 가려지지 않게 한다.
