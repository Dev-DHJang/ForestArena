# 같은 Wi-Fi LAN 1대1 플레이

macOS 한 대가 대전을 계산하고 Android APK 두 대가 같은 Wi-Fi에서 접속한다. 로그인,
결제, 데이터베이스와 인터넷 매칭은 사용하지 않는다. 이 기능은 신뢰할 수 있는 사설
Wi-Fi에서 한 경기만 운영하는 사용자 시험용이다.

## 준비

- Mac과 Android 기기 두 대를 같은 Wi-Fi에 연결한다. 공유기의 기기 간 통신 차단 기능이
  켜져 있으면 해제한다.
- 두 Android 기기에 같은 debug APK를 설치한다.
- Mac에 이 저장소에서 사용하는 Godot 실행 파일이 있어야 한다.

## 서버와 방 시작

1. Mac 저장소 최상위에서 `./scripts/lan-host.sh start`를 실행한다.
2. 출력된 `FAH1|ws://...|1` 한 줄을 방을 만드는 사용자에게 전달한다.
3. 첫 Android에서 `LAN 1:1 · 같은 Wi-Fi` → `방 만들기`를 누르고 `연결 코드 붙여넣기`를 누른다.
4. 캐릭터와 장신구를 정하면 앱이 `FA1|ws://...|<방 코드>|1` 초대 코드를 보여 준다.
   `초대 코드 복사`를 눌러 두 번째 사용자에게 전달한다.
5. 두 번째 Android에서 `참가하기` → `초대 코드 붙여넣기`를 누른 뒤 로드아웃을 정한다.
6. 두 사용자가 연결되면 자동으로 대전이 시작된다. 결과 화면에서 양쪽이 재대전을 누르면
   새 경기로 초기화된다.

서버 상태는 `./scripts/lan-host.sh status`, 로그는 `./scripts/lan-host.sh logs`, 종료는
`./scripts/lan-host.sh stop`으로 확인한다.

## 연결과 종료 규칙

- 서버가 60Hz로 HP·stock·링아웃·승패를 계산하고 APK는 20Hz 상태를 표시한다.
- 연결이 끊기면 해당 사용자의 입력을 즉시 풀고 최대 60초 동안 재접속을 기다린다.
- 60초 안에 돌아오지 않으면 이탈 패배다. 결과 뒤 재대전 선택은 20초 동안 기다린다.
- 방을 나가면 상대의 승리로 경기를 끝낸다. 한 서버에는 세 번째 사용자가 들어올 수 없다.
- 한 줄 코드는 비밀번호가 아니다. 공용 인터넷에 포트를 공개하거나 신뢰하지 않는 Wi-Fi에서
  사용하지 않는다.

## 자동 검사

`./scripts/verify-lan-runtime.sh`는 방 생성·참가, 잘못된 입력 거부, 세 번째 참가 거부,
연결 해제·복귀, 이탈 결과, 재대전과 앱 화면 연결을 실제 WebSocket 두 클라이언트로 검사한다.
물리 Android 두 대의 터치·Wi-Fi 전환·중단/복귀는 자동 검사와 별도로 기록한다.

## 미니맵의 사용자명

로비의 `접근성 설정`에서 닉네임을 저장한 뒤 방을 만들거나 참가한다. 입장할 때 정한 이름은 재접속·재대전에도 유지된다. 닉네임을 보내지 않는 이전 클라이언트는 `참가자 1`·`참가자 2`로 표시한다. 미니맵 표시 규칙은 [기능과 사용자 경험](features-and-ux.md#대전-미니맵)을 따른다.
