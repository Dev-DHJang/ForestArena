# 같은 Wi-Fi LAN 1대1 플레이

현재 데모는 기존 LAN 기반에 게스트 인증・서버 닉네임・v2 연결 코드를 추가했다.
[무료 APK 데모 설치와 서버 실행](demo-install.md)을 현재 사용법으로 따른다.

- Mac 한 대의 API・PostgreSQL・Godot LAN 서버가 같은 네트워크 1대1 한 경기를 처리한다.
- 서버가 60Hz로 판정하고 클라이언트에 20Hz 상태를 보낸다. 두 물리 Android 검사는 별도 기록이다.
- 기기 저장의 보유・선택・접근성을 유지하며 게스트 ID・닉네임은 서버에 저장한다.
- 경기 재접속은 60초, 결과 후 재대전은 20초다. v1 코드・APK는 업데이트 안내로 거부한다.
- `./scripts/verify-lan-runtime.sh`는 독립 인증 fixture와 두 실제 WebSocket 클라이언트로
  인증・동일 ID 중복・다른 ID 복귀・취소・재대전・표시 UI를 확인한다. 실제 API/DB 통합 검사는 별도로 실행한다.
