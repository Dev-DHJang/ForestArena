# 자현·나비 전투 v2

2026-10-19 승인된 현재 제품 전투 기준이다. 오프라인·연습·Solo·Team·LAN은 같은 규칙을 쓴다. 기존 네 캐릭터·장신구 조합은 기반 검사와 보유 기록에 남기고, 새 경기에서는 자현·나비와 장신구 미장착만 제공한다. APK 배포와 스토어 출시는 이번 작업 범위가 아니다.

새 안무에 필요한 모션은 별도 시안 검토와 모션별 사용자 승인이 필요하다. 승인 전 시안을 게임 자산으로 등록하지 않으며, 기존 모션을 연결한 개발 화면을 전투 완성으로 기록하지 않는다. 전투 v2 시작 기록은 [기존 작업 요청](../../_workspace/two-fighter-combat-v2/00_request.md), 2026-10-29 전투 조작·장외 개선은 [현재 작업 요청](../../_workspace/combat-input-ringout/00_request.md)을 따른다.

## 조작과 연계

왼손 방향패드와 오른손 점프·약·강·특수 네 버튼을 쓴다. 아래 단독 유지로 가드하고 아래+점프로 통과형 발판을 내려간다. 기본 대시·회피·차지·필살기는 제공하지 않는다. 방향을 함께 누른 지상 공격도 같은 기술을 사용한다. 지상 강은 버튼을 누를 때 단타가 시작되며 해제나 유지로 위력이 변하지 않는다.

| 캐릭터 | 지상 약 연계 | 지상 강 | 지상 특수 |
| --- | --- | --- | --- |
| 자현 | 왼손 → 오른손 → 왼손 → 킥(다운) | 먼 상대를 긴 목도리로 끌어온다 | 목도리를 좌·우·위로 1초간 휘두른다 |
| 나비 | 왼손 앞으로 → 오른손 위로 → 양손 X자 할퀴기(다운) | 어퍼로 띄운다 | 앞으로 돌파하여 첫 적 뒤에서 1회 타격하고 멈춘다 |

약 중간타는 준비8·판정4·회복18 tick, 피해4·기준 경직16 tick이다. 피격 경직은 무게와 기존10~36 tick 상·하한을 적용한 최종값을2배로 늘려20~72 tick을 사용한다. 마지막은10·4·22 tick, 피해7이다. 전투는 초당60 tick으로 계산한다. 다음 약공격의 누름 입력은 준비 시작부터 회복 마지막까지30 tick(약0.5초) 동안 하나만 예약한다. 유지 입력으로 자동 연계하지 않으며, 예약한 공격은 현재 회복이 끝나야 시작한다. 공격 취소는 공격 후 대기의 허용 구간에서만 처리한다. 마지막 타격은 취소할 수 없고 피격 중에는 공격할 수 없다. 취소 뒤에도 원래 남은 회복 시간이 끝나기 전에는 새 공격을 시작할 수 없다.

강공격은12·5·20 tick, 피해10이다. 자현의 전방 리치는180이며 끌기는 실제 지형 충돌을 따른다. 피해자를 벽 너머로 순간이동하지 않는다. 신체 이미지를 확대하여 리치를 표현하지 않고 목도리·발톱 효과를 별도로 그린다. 그림은 적중 계산에 영향을 주지 않는다.

아래 단독 유지를 해제할 때까지 승인된 가드 고정 자세를 유지한다. 방향 변경·터치 해제·중단·접속 해제로 입력이 초기화되면 실제 방어와 모션도 함께 해제한다. 가드 붕괴 경직은60 tick이며 기상 보호12 tick과 공중 행동 제한120 tick은 유지한다.

## 공중 공격과 착지

체공마다 약1회·강1회를 각각 쓴다. 공격이 유효하게 시작될 때 해당 기회를 사용하며 빗나가거나 중단돼도 돌려주지 않는다. 약 두 번 또는 강 두 번으로 대체할 수 없다.

- 공중 약은 긴 리치의 단타다.8·4·18 tick, 피해5이며 피해자의 추가 점프와 공격을 제한한다. 일반 경직이 끝나면 좌우 이동은 가능하다.
- 공중 강은12·5·22 tick, 피해9다. 자현은 목도리를 위에서 아래로 내려쳐 **피해자**를 초기 아래 속도900 이상(전체 낙하 상한1000)으로 떨어뜨린다. 시전자가 강제로 급강하하지 않는다. 나비는 위로 쳐올리며 피해자의 모든 행동을 제한한다.
- 공중 행동 제한은 첫 적용부터 최대120 tick(2초)이다. 다시 맞아도 시간을 늘리거나 같은 체공에 다시 시작하지 않는다. 제한이 풀려도 이미 사용한 공중 공격·점프는 복구하지 않는다. 일반 피격 경직과 경기장 밖 탈락은 별도로 적용된다.
- 일반 바닥과 통과형 발판 윗면 착지가 공중 상태를 끝낸다. 벽 접촉은 착지가 아니다. 피격 중에도 이동 뒤 착지를 확인한다.
- 착지 다운과 지상 연계 마지막 타격은 다운36 tick 뒤 기상 보호12 tick을 적용한다. 다운 중 일반 공격으로 다시 띄우지 않는다. 본인이 공격을 시작하면 기상 보호가 끝난다.

## 특수기

특수는 지상 전용이며 유효한 시작부터300 tick(5초) 대기한다. 빗나가거나 준비 중 맞아 중단돼도 대기시간은 유지한다. 거부된 입력은 대기시간을 만들지 않는다. 가드할 수 있고 무적·슈퍼아머를 주지 않는다. 시전자가 맞으면 남은 타격을 중단한다.

자현 특수는 준비12·판정60·회복24 tick이다. 활성6·12·18·24·30·36·42·48·54·60 tick에 정확히10회 타격한다. 좌·우·위 영역이 겹쳐도 같은 상대에게 한 시점에 한 번만 맞는다. 처음9회는 피해1과 끌기, 마지막은 피해5와 바깥 방향 밀어내기다. 늦게 들어온 상대도 전체 기술의 마지막 시점에 밀려난다. 아래 방향 공격 영역은 없다.

나비 특수는 준비10 tick 뒤 속도1200으로 최대320 거리를 탐색·이동한다. 경로에서 처음 만나는 적 뒤64를 도착점으로 고정하고 단타 피해12 후 회복20 tick으로 들어간다. 빈 공간에서는320을 이동하고 멈춘다. 상대를 계속 추적하지 않으며 여러 명을 연속 공격하지 않는다. 뒤 공간이 벽으로 막히면 안전하게 멈추고 뒤 공격은 실패한다. 이동 구간에만 캐릭터 몸 충돌 분리를 생략하며 지형 충돌과 피격은 유지한다.

## 화면과 AI

카메라는 로컬 파이터를 추적하는1.50배 줌과 화면 밖 상대 화살표를 유지한다. 작은 얼굴 카드에는 얼굴·이름·HP·남은 기회만 표시한다. 내 가드 내구도는 방향패드 옆, 특수 대기와 공중 공격 사용 가능 여부는 조작부에 표시한다. 필살기 게이지와 원시 프레임 숫자는 표시하지 않는다. UI는 받은 상태를 표시하며 피해·경직·승패를 계산하지 않는다. LAN은 실제 로컬 파이터 ID를 사용한다.

AI는 접근·거리 유지·짧은 후퇴·공격 대기·가드를 섞고, 기본 판단18 tick·전술36~72 tick·목표 유지90 tick을 사용한다. 죽거나 탈락한 목표는 다시 고르고 팀원은 제외한다. 공격 준비를 보면 방어, 회복 중이면 접근·반격 비중을 높인다. 점프·약·강·지상 특수를 섞되 삭제된 대시·회피·필살기·차지 명령은 생성하지 않는다. 낭떠러지 복귀와 발판 이동이 우선이며 위험 방향으로 후퇴하지 않는다. 같은 초기값과 입력이면 같은 결과가 나와야 한다.

## 장외와 임시 디버깅

좌우·위 경계를 넘는 동안은 계속 조작하고 복귀할 수 있다. 아래 경계를 넘으면 조작·공격·피격·몸 충돌을 종료하고 중력으로 낙하한다. 카메라는 주 바닥 높이 아래로 따라가지 않는다. 아래 경계보다256px 아래의 공통 비표시선을 통과하면 캐릭터를 숨기고60 tick(1초) 뒤 기회를 한 번 차감하며 승패를 판정한다. 남은 기회가 있으면 기존 부활 대기를 사용한다. HP 소진 사망은 기존 흐름을 유지한다.

설정의 디버깅 분류에서 실제 공격 영역은 빨강, 피격 영역은 파랑으로 표시한다. 다단 공격도 해당 시점에 활성인 모든 영역을 표시한다. 체크는 실행 중에만 유지하며 재실행하면 꺼진다. 적용·취소·기본값을 제공하고 전투 결과에는 영향을 주지 않는다.

## 저장·통신과 확인

전체4캐릭터·6장신구 ID와 보유·전적·프리셋 기록은 보존한다. 비활성 캐릭터가 선택돼 있으면 보유한 활성 캐릭터로 바꾸고, 둘 다 없으면 자현을 무료 추가한다. 실행 장신구는 미장착으로 바꾼다. DB 모드는 기존처럼 서버 저장 성공 후 변경을 확정한다.

`AttackData` v4와 `CombatRules` v5는 기존 v3/v4 기반을 명시적으로 읽는다. 새 경기의 기술 목록은 별도 파일이며 기반 자료를 덮어쓰지 않는다. LAN 통신은 protocol4이며 이전1·2·3과 섞어 실행할 수 없다. 상태 전송에는 남은 경직·다운 시간, 낙하 비표시·대기 상태와 실제 공격·피격 사각형을 포함한다. 서버와 클라이언트 모두 활성 캐릭터·미장착·허용 입력을 확인한다. 인터넷 온라인 범위는 확대하지 않는다.

자동 검사는 두 캐릭터 기술·행동 복구·다단 적중·벽·발판·동일 입력 재현과30초 무진행 금지·5분 내 경기 종료를 확인한다. 화면은16:9·20:9, 글자1.0·1.3,2·4·8명과 LAN 양쪽을 확인한다. 터치 경계·멀티터치·크기 변경·중단/복귀도 포함한다. 실제 물리 Android가 연결되지 않았으므로 엄지 접근성·가독성·중단/복귀·성능은 별도 수동 재검사로 남긴다.
