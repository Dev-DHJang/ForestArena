# 메뉴의 실제 기록·친구·순위 v01

프리미엄 v07 화면에서 기기 경기 기록과 개발 서버의 실제 데이터를 연결한다. [ADR-033](../product/decisions.md#adr-033-메뉴-기록친구순위와-통합-개발-프로필)에 따른 제한된 서버 확장이며 Story·보상·재화·공용 인터넷 서비스는 포함하지 않는다.

## 프로필 하나로 연결하기

프로필 메뉴에서 서버 주소와 중복 없는 닉네임을 입력해 통합한다. 기존 DB 프로필을 우선하고, 없으면 LAN 게스트, 둘 다 없으면 새 게스트를 사용한다. 두 계정이 있으면 각각의 인증으로 본인임을 확인한다. 서버가 다르면 자동으로 합치지 않는다.

보유 캐릭터·장신구는 합치고 현재 선택·접근성·미니맵·기기 프리셋 4개·조작 설정을 유지한다. 원래 사용자 ID와 기록은 삭제하지 않는다. 서버가 통합을 끝냈으나 응답이나 기기 저장이 실패하면 같은 요청을 다시 확인한다. 이때 기존 계정을 초기화하거나 대체 게스트를 자동으로 만들지 않는다.

프로필 v3, 프리셋·조작 파일 v1은 유지한다. 새 통합 정보·진행·전송 대기 파일은 버전1이다. 임시 파일과 백업으로 보호하며 Android QA에서는 실행별 저장 폴더를 사용한다. 통합 후 두 인증 클라이언트가 별도로 refresh token을 회전하지 않도록 DB 프로필 연결의 한 인증 경로를 사용한다.

## 기록과 미션

AI·Solo·Team 정상 종료는 기기에 즉시 기록한다. 연습·Story·포기 경기는 제외한다. 서버 연결이 되면 전송하지만 출처는 계속 오프라인이며 LAN 순위에 들어가지 않는다.

LAN 정상 결과는 경기 서버만 등록한다. 실제 참가자·캐릭터·장신구를 보내고 매 재대전에 새 경기 ID를 쓴다. 결과와 진행 기록은 DB에서 함께 저장한다. API가 멈춰도 경기를 계속하고 경기 서버의 전송 대기 파일에서 재시도한다. 결과 화면의 대기·실패를 저장 성공으로 표시하지 않는다. 같은 요청은 한 번만 집계한다.

| 분류 | 조건 | 기간 |
| --- | --- | --- |
| 일일 | 정상 경기 1회 완료 / 1승 | 한국 시간 자정부터 다음 자정 |
| 주간 | 정상 경기 5회 완료 / 3승 | 한국 시간 월요일 자정부터 다음 월요일 |
| 누적 | 첫 완료 / 10회 완료 / 네 캐릭터 각각 완료 | 전체 기록 |

보상 받기와 재화는 없다. LAN은 서버의 종료 시각, 오프라인은 기기의 종료 시각을 쓴다. 프로필은 모드별 승·패·무승부와 최근 50건, 동기화 상태를 보여 준다.

## 친구와 초대

중복 없는 온라인 닉네임을 정확히 검색한다. 친구 요청의 수락·거절·취소와 친구 삭제를 제공한다. 반대 방향의 요청이 있어도 자동으로 친구가 되지 않는다. 본인 요청과 중복 요청을 막는다. 최근 상대는 실제 LAN 참가 기록에서 읽는다.

앱을 사용하는 동안 30초마다 접속 상태를 보내고, 90초 동안 갱신이 없으면 오프라인으로 표시한다. 친구 화면은 10초마다 갱신한다. 연결 실패는 친구 없음과 구분하고 마지막 확인 정보를 남긴다.

친구만 실제 대기 중인 LAN 방으로 초대할 수 있다. 초대는 120초 뒤 만료하며 방이 닫혔으면 참가할 수 없다. 수락은 기존 LAN 참가 절차를 사용하고 진행 중인 전투를 자동으로 중단하지 않는다. 채팅은 제공하지 않는다.

## 순위

전체·이번 달·친구 탭에서 실제 LAN 정상 종료만 비교한다. 전투 종료와 무승부만 포함하며 연결 이탈·포기·개발용 duel_dev 경기와 같은 통합 사용자의 두 계정끼리 한 경기는 제외한다.

승수 내림차순, 승률 내림차순으로 정렬한다. 승률은 승/(승+패+무)이며 두 값이 같으면 공동 순위(1,1,3)다. 동점 표시 순서는 사용자 ID로 고정한다. 0경기는 순위가 없다. 한 페이지는 50명이고 내 순위는 따로 표시한다. 월간은 한국 시간의 현재 월, 친구는 현재 상호 친구와 본인을 포함한다.
