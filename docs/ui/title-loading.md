# 타이틀과 화면 이동 로딩

앱 시작 장면은 `scenes/startup_title.tscn`이다. 먼저 타이틀을 보여주고 메뉴에 필요한
자산과 기본 데이터를 준비한다. 첫 화면의 하단 로딩바는 실제 준비 진행률을 표시하며,
필수 준비가 끝난 뒤 중앙 하단의 `게임 시작` 문구로 바뀐다.

## 시작 입력과 정보

- 준비가 끝난 뒤 화면 어디든 새로 터치하면 한 번만 진입한다. 준비 중 누르고 있던
  터치는 시작 입력으로 처리하지 않는다. 데스크톱의 확인 키도 개발용으로 제공한다.
- 첫 실행은 첫 캐릭터 선택, 기존 저장은 로비로 이어진다. 저장 오류 안내와 개발용 DB,
  demo의 기존 경로는 유지한다. 네트워크 연결은 시작 터치 후 실행한다.
- 버전은 `application/config/version`을 읽는다. 기본은 `0.0.1`, demo 빌드는
  `config/version.demo`의 `0.1.0-demo`다. Android 내보내기의 `version/name`과 일치해야 한다.
- 저작권 문구는 `© 2026 Forest Arena. All rights reserved.`다.
- 캐릭터 없는 전용 숲 배경은 `fa.background.title.forest`로 읽는다.
  [배경 제작 기록](../../assets/ui/title-v01/manifest.json)에 원본·크기·파일 확인값을 둔다.

## 화면 이동

화면 준비가 150ms 이내에 끝나면 로딩바를 표시하지 않는다. 더 오래 걸리면 화면 중앙에
진행률을 표시하고 준비된 화면이 표시될 때 제거한다. 보기 좋게 보이려고 별도 대기 시간을
추가하지 않는다. 진행률을 알 수 없는 준비 단계는 진행 중임을 표시한다.

로비·하위 메뉴·대전 준비·경기 진입·결과·재대전·뒤로 이동에 적용한다. 같은 화면의 옵션
변경과 일시정지·계속하기는 화면 이동에 포함하지 않는다. 경기 진입에서는 해당 캐릭터의
모션을 먼저 준비하고, 로딩 중 경기 시간이나 입력 처리가 시작되지 않게 한다.

준비 중 중복 이동 요청은 막는다. 실패한 자산은 완료로 취급하지 않으며 재시도와 이전
화면 복귀를 제공한다. 종료된 작업의 늦은 결과가 새 화면을 바꾸지 않아야 한다.

## 확인

자동 검사와 전체 검사 결과는 [작업 마무리 기록](../../_workspace/title-loading-proportions/04_closeout.md)에
남긴다. 수동 화면 확인 이름은 `TITLE_LOADING_LAYOUT_R01`이다. 16:9·20:9에서 배경 잘림,
하단 정보·시작 문구 가독성, 빠른 이동의 표시 생략과 느린 이동의 중앙 표시를 확인한다.
Android 실제 기기에서 실행하지 않았다면 기기 통과로 기록하지 않는다.
