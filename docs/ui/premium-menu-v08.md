# 로비와 메뉴 시안 v08

2026-10-20. 로비와 13개 하위 메뉴를 어두운 숲 공간과 큰 승인 원화로 재구성하는 Penpot 설계다. [기존 v07](premium-menu-v07.md)과 공식 화면 ID를 보존한다. Godot 메뉴 배치·저장 형식·API·게임 규칙은 변경하지 않는다. 앱 아이콘은 별도 묘령 상반신 v02를 실제 프로젝트·Android 내보내기에 적용한다.

## 구성

로비는 중앙 대표 캐릭터, 오른쪽 편성 요약, 아래 캐릭터·장신구·프리셋·미션·친구·상점과 가장 큰 플레이 행동을 둔다. 프로필·설정은 위에 있고 도감·랭크는 전체 메뉴에서 연다. 캐릭터 목록은 초상 갤러리, 상세는 초상 목록·큰 원화·기술 정보로 나눈다. 장신구는 기능 필터·4열 진열·장착 비교, 프리셋은 네 슬롯과 선택 편성 미리보기다. 상점은 분류·추천 이미지·상품 진열이며 개발용 0원 획득을 명시한다.

미션·친구·랭크·프로필은 현재 구현된 조건과 조회 상태를 표현한다. 빈 목록·미연결·로딩·오류·이전 데이터와 정상 빈 결과를 구분한다. 설정은 실제 소리·화면 효과·접근성·미니맵·조작 항목을 표시하고 분류별 적용·취소·복원을 연결한다. 도감 상세는 읽기 전용이다. 미승인 가격·보상·성장·장신구 등급은 추가하지 않는다.

## 제작 기준

- 설계1920×1080, 축소1280×720, 로비·캐릭터·상점·친구·설정의20:9 비교.
- Noto Sans KR, 제목48–56px·본문30–34px, 보조 안내24–28px, 8px 간격.
- 안전 여백 좌우96px·상하48px, 주요 조작72×72px 이상, 전환200ms.
- 바탕#10181C·패널#1C282C·글자#F2F3ED/#BBC6C6·주요 행동#D9C58E·보조 강조#8CBFB2.
- 선택은 선·체크·문구를 함께 사용한다. 원본 UI 글자는 Penpot에서 편집 가능한 텍스트로 유지한다.

## 전달과 확인

[Penpot 파일](https://design.penpot.app/#/workspace?team-id=40e06342-8830-80d6-8008-9c1bc3d57d29&file-id=d8ac01df-6646-81d2-8008-a3696fea940e)과 [v08 작업 기록](../../_workspace/premium-menu-v08/00_request.md), [UI 제작 기록](../../_workspace/premium-menu-v08/02_ui.md), [마무리 기록](../../_workspace/premium-menu-v08/04_closeout.md)을 함께 본다. 실제 저장·출력·프로토타입 검사 결과는 마무리 기록에 기록한다. 정적 명세 검사만으로 실제 Penpot 또는 기기 통과라고 말하지 않는다.

장면 명세·상태표·클릭 좌표·이미지 연결표·PNG·검사는 v08 작업 폴더에 둔다. 기존 v07의6개 숲 배경·승인 원화4개·벡터 아이콘16개를 재사용하며 원본 파일은 변경하지 않는다. 출처·해시는 v08 자산 manifest와 이미지 기록에서 추적한다. 새 Godot 논리 자산 등록은 없다.

묘령 아이콘은 얼굴·목·어깨·분홍/흰 상의가 이어지는 첨부 구도다. 일반1024/192px, 적응형432px 전경·배경과 원형·둥근 사각형48/72/192px 미리보기를 제공한다. Godot 시작 로고 숨김은 유지한다. APK 검사와 실제 Android 기기 결과는 [아이콘 기록](../../_workspace/myoryung-app-branding-v02/04_closeout.md)에서 구분한다.
