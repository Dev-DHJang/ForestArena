# Forest Arena 숲빛 UI v06 전달

`Forest_Arena_UI`를 밝은 숲 배경, 굵은 입체 아이콘, 작은 어두운 유리 구획으로 재구성했다. 승인 캐릭터를 중앙에 크게 배치하고 로비 하단의 6개 메뉴와 오른쪽 아래 플레이 버튼을 유지했다. 기존 v02–v05 컴포넌트와 변경 전 Penpot 버전은 보존했다.

이번 결과는 Penpot 설계와 자산·개발 전달 자료다. Godot 화면, API, 입력, 저장 형식, 런타임 자산 등록은 변경하지 않았다. 상용 게임의 내부 제작 사양과 동일하다고 주장하지 않는다.

## 화면 배치와 이동

로비는 프로필 왼쪽 위, 설정 오른쪽 위, 큰 투명 자현 중앙, 현재 편성 왼쪽, 보조 콘텐츠 오른쪽, 캐릭터·장신구·프리셋·미션·친구·상점 하단, 가장 큰 플레이 오른쪽 아래다. 선택 화면은 왼쪽 목록·필터, 중앙 미리보기, 오른쪽 상세와 확정 버튼을 사용한다. 선택은 테두리와 체크로 표시한다.

실행 → 로비 → 모드 → AI/연습 조건 → 캐릭터 → 직업 → 장신구 → 경기장 → 로딩 → 전투 → 결과 → 재시도/로비를 기존 목적지로 연결했다. 일반 설정, 취소·뒤로·나가기 확인, 선택 누락·빈 목록·연결 실패, 오프라인 정지와 온라인 메뉴, 피격·링아웃·복귀·탈락·승패 상태를 포함한다. Splash에는 캐릭터가 없고 장신구에는 희귀도·등급을 표시하지 않는다.

보존된 공용 Pause/Leave 프로토타입의 복귀 목적지는 1대1 대표 화면이다. 구현 시 실제 경기 모드·선택 내용을 가지고 원래 경기로 돌아가야 한다. 프로토타입은 상태 예시이며 AI 경기·저장·네트워크 실행을 구현한 결과가 아니다.

## 좌표·안전 영역·조이스틱

설계 좌표는 1920×1080, Godot 논리 좌표는 모든 위치·크기에 2/3를 곱한 1280×720이다. 20:9 비교는 2400×1080 보드의 중앙 x240–2160에 같은 콘텐츠를 두고 배경만 옆으로 확장한다. PNG는 각각 1280×720, 1600×720로 제공한다. 전달표의 좌표는 보드 내부 기준이다.

최소 하단 안전 여백은 플로팅 활성 영역 아래 54px다. 조이스틱은 최초 4방향 패드 계획을 변경한 별도 승인 설계이며 v05 좌표·동작을 유지한다. 고정은 중심 312,850에 복귀한다. 플로팅은 중심 x304–480, y802–866으로 제한하고 입력 해제 시 숨긴다. 링은 시작 위치에 머물며 손잡이 최대 이동 반경은 44px다. 자유 이동 편집과 아날로그 속도는 추가하지 않는다.

이동 손가락은 해제까지 소유권을 유지하며 두 번째 이동 손가락이 빼앗지 않는다. 공격·점프·대시는 다른 손가락으로 동시에 입력한다. 버튼 밖 이탈 시 위치만 제한하며 입력 소유권은 유지한다. 해제·pointer cancel·앱 중단·메뉴 전환 시 입력을 비운다. 오프라인 재개는 확인 후 카운트다운, 온라인 메뉴는 경기 계속 상태를 표시한다.

## 캐릭터 투명 PNG와 호흡

기존 승인 투명 자현 PNG를 유지했다. 네 모서리 알파 0, 검은 사각 배경 없음, 귀·꼬리·리본 가장자리를 확인했다. PNG 자체는 정지 파일이다. Penpot의 rest/inhale 두 상태가 4초 주기로 dissolve 전환하며 움직임 의도를 보여준다. 기본 위치 648,124 / 552×736, 최대 호흡 646.344,117.584 / 555.312×740.416이다. 캐릭터 사각 영역은 메뉴 시작 y864보다 최소 6px 위다. 자세한 기록은 `motion-alpha-review.json`에 있다.

## 검증과 남은 결정

55개 전체 PNG와 호흡 2개를 내보냈다. 14개 검토 이미지와 주요 단독 화면에서 한국어 대비·잘림·겹침, 아이콘 식별과 버튼 위계, 8인 P1–P8 HUD·남은 기회·피해율·A/B 팀 표시, 최대 줌아웃, 16:9·20:9 안전 영역을 검토했다. 상세 카드와 상태 패널의 낮은 글자 대비, Splash 로고와 나가기 위험 버튼을 수정했다. `screen-review.csv`는 시각 검토, `delivery-audit.json`은 파일·ID·연결 검사를 각각 기록한다.

실제 Penpot 뷰어에서 로비→모드→선택→전투, 나가기 취소·확인, 앱 복귀 확인, 일반/조작 설정, 고정↔플로팅, 복원 취소·확인, 뒤로·로비 복귀를 클릭했다. 기록은 `manual-flow-review.md`에 있다. 문서·기본·Godot 리소스 검사 결과는 작업 마무리 기록에 남긴다.

47개 기존 `IMG/*` 콘텐츠 자리는 제작하지 않았으며 `missing-assets.csv`에 정확한 이름을 유지한다. UI 자산 93개로 이 목록을 자동 충족 처리하지 않는다. 온라인·경제·Story는 미래 설계다. 직업 능력·해금, Story 대화/보상, 성장·구매 수치, 온라인 재접속·시간 제한, 조이스틱 무입력 범위·방향 임계값·설정 상하한은 아직 확정하지 않았다. 재화 이름 등 이미 승인된 제품 결정은 [결정 기록](../product/decisions.md)과 [가격 제안](../product/economy-pricing-v01.md)을 따른다.

Android 실제 검증은 하지 않았다. 구현 후 `TOUCH_SIMULTANEOUS`(이동과 공격), `TOUCH_LEAVE_BOUNDS`(버튼 밖 이탈과 해제), `FLOATING_ORIGIN_CLAMP`(첫 위치·경계), `APP_INTERRUPT_RESUME`(입력 초기화·재개 확인), `ORIGIN_MODE_RETURN`(실제 시작 모드 복귀), `SAFE_AREA_16_20`(기기 비율·손가락 가림)를 수행해야 한다.
