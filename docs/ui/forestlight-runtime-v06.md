# 숲빛 v06 실제 게임 화면 연결

승인된 숲빛 v06 PNG 93개와 기존 투명 자현 로비 이미지 1개를 실제 Godot 화면에 연결했다. 이미지 원본은 변경하지 않았다. 복사된 PNG와 승인 SVG 또는 배경의 해시는 [출처 기록](../../_workspace/android-current-device-fixes/forestlight-runtime-provenance.json)에 남겼다.

`fa.ui.forestlight.*` 논리 ID로 이미지를 찾는다. UI는 공통 고품질 이미지여서 `high`, `medium`, `low`에서 같은 승인 파일을 사용하며 기존 품질별 24개 자산은 유지한다. 일반 문구는 Godot의 네이티브 글자이고 각 메뉴·선택·구매는 기존 저장과 경기 설정을 실제로 호출한다.

- 로비: 밝은 숲 배경, 중앙 투명 자현, 현재 편성, 설정, LAN, 플레이와 하단 6개 메뉴. 화면 비율이 늘면 가운데 1280×720 내용과 배경을 함께 유지한다.
- 첫 선택·준비: 네 캐릭터 카드와 선택 체크. 준비의 캐릭터는 왼쪽 2×2 목록, 모드·장신구·AI 선택은 오른쪽, 로비·시작은 아래에 둔다.
- 상점·설정·LAN: 승인 카드와 버튼을 사용하고 기존 0원 구매·저장·오디오·진동·접근성·연결 기능을 유지한다. 긴 내용은 스크롤한다.
- 전투·정지·결과: 승인 버튼 스킨과 고정 조이스틱을 사용한다. 전투는 실제 snapshot의 닉네임·캐릭터·P번호·A/B팀·HP·기회·궁극·가드 카드를 표시하며 8명은 왼쪽 4×2 카드로 미니맵을 피한다. 화면 표현은 전투 피해나 승패를 계산하지 않는다.

프리셋·미션·친구는 현재 단계에서 제공하지 않는다고 안내한다. 미래 경제·Story 보상·정식 인터넷 온라인·플로팅 조이스틱의 미승인 설정을 추가하지 않았다. 같은 Wi-Fi 연결과 현재 오프라인 흐름은 계속 사용할 수 있다.

`FORESTLIGHT_RUNTIME`은 실제 화면 생성, 세 품질에서 자산 읽기, 메뉴 연결, 기존 선택 목록, 전투에 새 터치 스킨 활성화, 결과 표현의 전투 데이터 보존을 검사한다. `--ui-capture`를 주면 실제 Godot 렌더러의 첫 선택·로비·준비·상점·설정·LAN·전투·결과와 20:9 로비·전투, Solo8·Team4대4의 두 화면 비율을 PNG로 남긴다. Android의 손가락 가림·모션·소리·진동 확인은 새 APK의 실기기 검사로 별도 기록한다.
