# 재화와 구매 가격 제안 v01

상태: 2026-10-09 사용자가 재화명·무료 캐릭터·구매 재화를 지정했고, 추가 피해·부활 없는 장신구 방향을 승인했다. 전투 옵션은 ADR-031로 적용하지만 가격·보상 수치는 아직 제안이며 실제 게임·DB에 적용하지 않는다. 캐릭터 외 상품의 무지개돌 전용 구매는 사용자 지정이며 그 경쟁 공정성은 플레이 검증이 필요하다. [ADR-010](decisions.md#adr-010-장신구-획득경제-정책-제안)은 가격·결제 등 전체 경제 정책 검토가 끝나지 않아 proposed로 유지한다. 현재 0원 상점과 ADR-029의 개발용 저장 범위는 그대로다.

## 재화

- **조약돌**: 게임 내에서 얻는 재화. 캐릭터 구매에 사용한다.
- **무지개돌**: 유료 재화. 자현 외 캐릭터와 캐릭터 외 구매 상품에 사용한다.

위 명칭과 용도는 사용자 지정이다. 이전 잎새전·단일 재화 제안은 폐기한다. 기록인장은 이야기의 자료 접근 증명물이므로 구매 재화로 쓰지 않는다. 무지개돌 현금 패키지 가격·무료 지급 여부·두 재화 간 교환·환불 규칙은 미정이며 결제 구현은 승인하지 않았다.

## 구매 가격

| 구매 항목 | 사용 재화 | 가격 상태·규칙 |
| --- | --- | --- |
| 자현 | 무료 | 유일한 무료 캐릭터。첫 캐릭터 자유 선택 제안은 폐기 |
| 묘령·나비·유란 | 조약돌 또는 무지개돌 | 조약돌 각각 3,000은 기존 제안 유지, 무지개돌 가격 미정. 한 재화로 전액 구매하며 합산 사용은 미정 |
| 철갑옷 | 무지개돌만 | 가격 미정, 계속 보유 |
| 복싱 글러브 | 무지개돌만 | 가격 미정, 계속 보유 |
| 균형 장신구 | 무지개돌만 | 가격 미정, 계속 보유 |
| 도약 장갑 | 무지개돌만 | 가격 미정, 계속 보유 |
| 집중 장신구 | 무지개돌만 | 가격 미정, 계속 보유 |
| 활공 장신구 | 무지개돌만 | 가격 미정, 부활 효과 없음 |
| 캐릭터 색상 변형・감정 표현 | 무지개돌만 | 미래 상품, 가격 미정・전투 효과 없음 |
| 프로필 아이콘・테두리 | 무지개돌만 | 미래 상품, 가격 미정 |
| 신규 의상 | 무지개돌만 | 미래 상품, 가격 미정・승인 외형과 판독성 검증 필요 |

캐릭터 외 상품은 사용자의 “나머지는 전부 무지개돌로만 구매”를 장신구·외형 상품에 적용해 해석했다. 첫 장신구 무료 지급과 이전 조약돌 환산 상품 가격 제안은 폐기한다. 조약돌 숫자를 무지개돌 가격으로 그대로 옮기지 않는다. 유료 가격은 무지개돌 패키지 단위·현금 가격이 정해진 뒤 제안한다.

색상·감정 표현·프로필 장식·의상은 현재 등록 상품이 아니며 제작·구현 승인이 아니다. 직업·전직·능력치 강화·경기장·Story 진행·접근성 설정은 구매 대상으로 정하지 않는다. 직업과 Story의 해금 방식은 별도 결정한다.

장신구 등급·희귀도·강화 단계는 추가하지 않는다. 사용자는 추가 피해·부활을 제외하고 공격 방식 변경이나 과도하지 않은 특수 옵션을 게임에 적용하도록 요청했다. [현재 장신구 설정](../gameplay/accessories-v01.md)에서 반사도 제거하고 장단점을 함께 둔다. 기존 제품 비전의 현금 전투 우위 금지는 유지한다. 공격 방식·이동·게이지 옵션도 실제 우위를 만들 수 있으므로 유료 전용 구매의 공정성이 입증됐다고 기록하지 않는다. 가격·결제·경제 구현은 별도 승인과 검증을 기다린다. 경쟁 경기 무료 대여는 자동 채택하지 않는다.

## 획득량과 구매 속도

보상량은 가격의 의미를 비교하기 위한 초기 가정이다. Story 보상·성장·일일 과제 기능을 구현하거나 승인한 것으로 보지 않는다.

| 획득 조건 | 조약돌 | 반복 조건 |
| --- | ---: | --- |
| 최초 시작 선물 | 600 | 프로필당 1회 |
| 보상 대상 경기 정상 완료 | 100 | 경기 결과별 1회 |
| 승리 추가 보상 | 20 | 같은 경기 기본 보상에 더함 |
| 그날 보상 대상 경기 3판 완료 | 200 | 하루 1회, 연속 출석 요구 없음 |
| Practice·중도 이탈·무효 경기 | 0 | 재화 반복 획득 경로로 사용하지 않음 |

보상 대상 모드·AI 난이도·짧은 경기와 입력 없는 반복 경기 처리·하루 경계는 구현 전에 정한다. 현재 신뢰된 경기 결과가 없는 기기 저장·LAN 결과를 그대로 DB 재화 지급 근거로 사용하지 않는다. 승패보다 경기 참여를 중심으로 보상하되, 반복 획득 방지와 정상 패배 보상을 함께 검증해야 한다.

승률 50%일 때 평균은 1판 110 조약돌이다. 시작 선물·일일 보상을 제외하면 캐릭터는 약 28판이다. 하루 3판이면 평균 530 조약돌로 캐릭터 1종은 약 6일이며, 최초 선물 600을 보태면 첫 추가 캐릭터는 약 5일이다. 이는 관측 결과가 아니라 계산상 목표다. 장신구에는 조약돌 구매까지의 판 수를 적용하지 않는다. 한 판 4~5분을 가정할 때 캐릭터는 약 2시간 전후의 순수 경기 시간이지만 메뉴·대기 시간은 별도다.

## 기존 저장과 향후 구현 조건

- 이미 무료로 얻은 캐릭터·장신구는 회수하지 않고 추가 비용도 청구하지 않는다. 신규 가격은 미보유 상품에만 적용한다.
- 기존 프로필의 시작 선물 지급 여부는 버전이 있는 이전 규칙으로 정하고 중복 지급을 방지한다. 새 규칙은 자현 무료 시작을 기준으로 하되 기존 무료 보유를 회수하지 않는다. 저장 초기화를 요구하지 않는다.
- 구현 전에 사용자 가격안 승인과 경제 구현 범위 승인을 받는다. 승인 뒤 재화 잔액·지급 이력·구매 가격 버전·중복 처리·환불 규칙과 기기/DB 모드 범위를 별도 설계한다.
- 가격표는 구매 요청을 처리하는 서버에서도 검사한다. 잔액 감소와 상품 보유 추가는 함께 성공하거나 함께 취소되도록 한다.

## 이름 있는 설계 재검사

`ECONOMY-PRICE-V01`: 현재 4캐릭터·6장신구 누락 없음, 조약돌/무지개돌 구분, 자현만 무료, 다른 캐릭터는 재화 택일, 다른 상품은 무지개돌 전용, 기존 보유 보존, 미래 상품 미구현 표시를 확인한다. 금지 효과 제거와 별개로 유료 옵션의 경쟁 공정성 검증은 남아 있다.

`ECONOMY-PACE-V01`: 승률 50% 기준 110/판·530/일 계산을 확인한다. 구현 이후 신규 사용자 플레이테스트로 추가 캐릭터 구매 시간, 패배 시 진행감, 보상 없는 반복 플레이를 검증하고 숫자를 조정한다. 현재 플레이테스트 근거는 없다.
