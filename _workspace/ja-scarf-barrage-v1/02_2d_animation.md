## 부착점 전달

`source/barrage-a-r02.anchors.json`, `source/barrage-b-r01.anchors.json`은 각 시트의 셀 좌상단을 기준으로 한 수동 목 접점/잡은 손/휘두르는 천끝 좌표다. 셀 원점도 별도로 적었다. `mark-anchors.py`는 좌표 기록과 진단 표식을 재생성하며 원화 PNG를 바꾸지 않는다. 표식 프리뷰의 R/H/T는 목/손/천끝이다. 숨은 목 접점은 추정이며, 두번째 천끝은 독립된 천끝인지 확실하게 읽히지 않아 모두 null로 남겼다.31–32의 손은 천을 놓았으므로 null이다. 수동 천끝이 낮은 alpha 픽셀에 놓였으면20px 범위에서 가장 가까운 불투명 파란 천 픽셀로 보정했다. 이는 진단 좌표만 바꾸며 그림을 수정하지 않는다. 수동 좌표는 독립 부착 QA 전의 후보이지 정확성이 입증된 데이터가 아니다.

## 권리와 적용 한계

승인 콘셉트의 파생 생성 원화이며 외부 영상의 화면·소리·다른 캐릭터 디자인을 복사하지 않았다. 사용자 설명과 root의 해당 구간 직접 관찰에서 안무의 리듬만 참고했다. 추가 외부 권리 검증은 주장하지 않는다. 게임용 runtime/manifest·현재26개 후보는 변경하지 않았다. 정상·느린 게임 재생, 좌우 반전·작은 크기, 독립 QA와 모션별 사용자 승인이 남았다. 원화 완료는 품질 통과나 런타임 완료를 뜻하지 않는다.

## 실제 재생 뒤 단계 조정

원화 생성 때의 위32장 표는 최초 구상이다. 실제 재생 QA에서 F28은 이미 손을 몸 쪽으로 회수하는 그림임을 확인해 현재 표시는 준비F1–4, 공격F5–27, 회복F28–32로 조정했다. 그림 PNG와 전체 전투12/60/24틱은 바꾸지 않았다. 회복 연장 천은 마지막 공격F27의 방향을 유지한 채 현재 손에서 짧은 원화 길이로 회수한다. F19의 손 연결 수정과 실제 회복 문제의 발견·수정은 별도 QA 기록을 따른다.
