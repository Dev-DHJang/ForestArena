# 로비 하단 메뉴 개편 요청

사용자 요청에 따라 와일드 리프트의 로비 메뉴 배치를 참고해 Forest Arena 로비를 정리한다. 주요 메뉴만 하단에 배치하며 프로필·설정은 상단에 유지한다. 기존 숲빛 자산을 재사용하고 게임 고유 리소스를 복제하지 않는다.

Penpot 원본 SCR_03_Lobby, 20:9 비교, 통합 프로토타입과 개발 전달을 함께 갱신한다. Godot 구현은 이번 범위에 포함하지 않는다. 하단에는 캐릭터·장신구·프리셋·미션·친구·상점과 가장 큰 플레이 버튼을 배치한다.

1920×1080 기준 메뉴 x=128+184×순서, y=896, 168×112. 플레이는 x=1328,y=888,464×120. 중앙 승인 캐릭터와 편성 요약, 축소된 오른쪽 안내 카드, 상단 프로필·설정을 유지한다.
