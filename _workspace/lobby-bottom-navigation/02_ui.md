# 하단 메뉴 구성과 전달

Penpot SCR_03_Lobby 원본 ID를 유지했다. 중앙 캐릭터는 480×640으로 정리하고 오른쪽 안내 카드는 높이 152로 줄였다. 상단은 기존 96px 유리 영역을 유지해 프로필·설정의 큰 터치 영역을 확보했다. 메뉴는 아이콘 위·한글 아래이며 x=128,312,496,680,864,1048 / y=896 / 168×112다. 플레이는 1328/888/464/120이다. 시각 영역 전체를 터치 영역으로 사용한다. 메뉴 간격 16px, 하단 여백 72px다.

숲빛 재사용 자산으로 기본·눌림·선택·사용 불가 LobbyNav 컴포넌트 4개를 만들고 로비에 기본 인스턴스 6개를 배치했다. 아이콘은 기존 벡터 컴포넌트로 재사용했다. 상점도 다른 보조 메뉴와 같은 위계다. 와일드 리프트 자료는 배치 참고만 사용했고 원화·아이콘·문양을 복제하지 않았다.

원본·CMP20 비교·10_Prototype 로비 이미지와 실제 클릭 영역 12개를 갱신했다. 개발 전달 페이지에 LOBBY / 하단 메뉴 v01 보드를 추가했다. 20:9는 중앙 1920 영역과 x+240 정책을 유지한다. Godot 1280×720은 2/3 환산한다. 기존 원본은 ARCHIVE before lobby-bottom-navigation으로 보관했다.

## 이름 있는 검토

- LOBBY-VIS-01: final.png와 compare20.png를 시각 확인했다. 한글 잘림·캐릭터와 하단 메뉴 겹침이 없고 플레이가 가장 크다. 초기 검토에서 유리 배경이 플레이 위를 덮던 순서를 수정했다.
- LOBBY-NAV-01: 실제 보기 모드에서 캐릭터·장신구·프리셋·미션·친구·상점·플레이·프로필·설정 9개를 각각 클릭했다. 기대 대상 화면 이동과 각 화면의 뒤로 가기로 로비 복귀를 확인했다.
