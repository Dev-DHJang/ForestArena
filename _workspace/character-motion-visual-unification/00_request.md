# 캐릭터 모션 외형 통일 요청

## 요청

- 자현의 모든 모션이 승인 콘셉트와 닮았는지 확인하고 모션별 캐릭터 디자인을 통일한다.
- 자현의 현재 모션 중 `attack_heavy_charge_16f.png`를 가장 콘셉트에 가까운 기준 시트로 사용한다.
- 점프처럼 동작 또는 이미지가 비정상인 모션을 찾는다.
- 자현뿐 아니라 묘령, 나비, 유란의 등록된 전체 모션도 전수 점검한다.

## 작업 경계

- 2026-10-09 Goal 지시: Android 검증은 이후로 미룬다. 이 재개에서는 Android export·설치·에뮬레이터·실기기 검증을 새로 실행하지 않는다. 기존 결과는 당시 기록으로만 보존한다.

- 2026-10-08: 사용자가 직전 `03_review.md`의 교체 후보 119종을 “승인한다.”로 승인했다. 정확한 목록의 SHA-256은 `approval.json`에 고정했다.

- 외형과 프레임 표현만 다루며 공격 시간, 판정, 피해, 밀어내기와 승패 계산은 바꾸지 않는다.
- 등록된 120개 런타임 시트의 16프레임을 모두 검사한다.
- 새로 만든 시안은 사용자 명시 승인 전까지 검토 경로에만 둔다.
- 승인 전에는 런타임 PNG, manifest와 `SpriteFrames`를 교체하지 않는다.
- 현재 작업트리의 다른 미커밋 변경은 보존한다.

## 수용 기준

- 자현은 승인 콘셉트와 기준 시트의 은백색 머리, 큰 둥근 귀 2개, 가는 꼬리 1개, 흰색·검정·코발트 복장과 인간형 손발을 모든 모션에서 유지한다.
- 모든 캐릭터의 등록 시트가 2048×128 RGBA, 128×128 셀 16개, 실제 alpha와 비어 있지 않은 프레임을 유지한다.
- 각 모션의 준비·발동·회복 흐름, 기준 방향, 잘림, 귀·꼬리 수와 외형 계약을 확인한다.
- 비정상 모션은 이름과 근거를 남기고, 교체 시안과 기존 시트를 비교할 수 있게 한다.
- 승인된 교체본만 런타임에 반영하고 전체 계약·Godot 리소스·Android 내보내기를 다시 검사한다.
