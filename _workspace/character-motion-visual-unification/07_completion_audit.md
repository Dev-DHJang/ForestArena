## 감사 도구 보완

이전 도구는 오류 여부를 보고서에만 기록하고 정상 종료했으며, 모션 목록이 누락돼도 성공할 수 있었다. 현재는 고정 로스터와 각 모션 수까지 확인하고 실패 종료한다. `test_motion_visual_tools.py`에 정상 목록·누락/로스터 오류·해시/alpha/빈 프레임 오류·이름 중복 검사를 추가했다. 승인 PNG와 게임 수치는 바꾸지 않았다.

## 미진행

- 사용자 지시로 미룬 Android 검사.
- 원격 통합은 기존 계획과 팀 명세의 완료 조건으로 포함한다. 다른 작업 변경을 섞지 않고 관련 변경만 게시한다. 병합 전까지 전체 Goal은 완료로 처리하지 않는다.

## 물리 파일 누락 보완

등록된 고유 모션 120종과 별도로 나비의 오래된 약공격 경로 2개가 남아 있었다. 소비자 검색 결과 실제 SpriteFrames는 `local_ai_v01`의 승인 경로를 사용한다. 두 예전 파일도 이미 승인된 같은 모션의 PNG로 맞췄으며 새로운 포즈나 모션 ID를 추가하지 않았다. 원본은 백업했고 전후 해시는 `08_legacy_aliases.json`에 기록했다. 물리 파일은 122개, 고유 모션은 120종이다. 감사는 이제 알려지지 않은 미등록 시트와 오래된 별도 경로도 실패로 판정한다. 관련 단위 검사는 10개다.
