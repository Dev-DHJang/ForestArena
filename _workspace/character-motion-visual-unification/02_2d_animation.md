# 캐릭터 모션 외형 통일 제작 기록

상태: 119종 사용자 승인·런타임 등록 완료. 최종 검증은 `04_closeout.md` 참조.

## 2026-10-08 구현

- 원본 모드와 alpha 채널을 RGBA 변환 전에 검사하도록 감사 도구를 수정했다.
- 반복 프레임 비교는 투명 픽셀의 숨은 RGB를 제외한 검정 배경 합성 결과로 계산한다.
- 현재 등록된 120개 시트 모두 규격, 실제 alpha, 16개 비어 있지 않은 셀, manifest 해시가 맞는다. 이 자동 결과는 디자인 일치나 정상 동작 판정을 대신하지 않는다.
- 자현의 `idle`, `run`, `jump`, `attack_light_combo_01~03`은 기준 시트와 크기·색상·얼굴 비율 차이가 커 교체 후보로 분류했다.
- 묘령의 `idle/run`에는 위아래 셀의 잘린 신체 조각이 있으며 연계 공격에서도 경계 접촉이 있다. `jump`는 체공 실루엣을 보강한다.
- 나비·유란은 등록 시트의 경계 접촉이 없고 전수 개요판에서 큰 디자인 이탈이 보이지 않는다. 확대·재생 검토를 완료하기 전 최종 통과로 간주하지 않는다.
- 기존 자현 r01 시안은 정규화 중 칸 경계 접촉이 검출되어 승인 후보 등록을 중단했다. 좁은 칸 분할로 신체를 잘라 통과시키지 않고 재생성 또는 안전한 원본 분리로 해결한다.
- 묘령 생성 결과에 보이는 빨강·흰색 잔상 중 순수 빨강 픽셀은 alpha 1–4였다. 불투명한 배경으로 단정하지 않고 alpha 제거 뒤 다시 검사한다.

## 점프 재생 구현

- 상승은 프레임 3–5, 정점은 6–9, 하강은 10–12를 선택하며 정점 기준은 수직 속도 절댓값 60 이하다.
- 단계 변경과 수직 속도의 상승 방향 재설정에서 해당 프레임 구간을 다시 시작한다.
- 공중에서 IDLE 지상 상태로 전환했을 때만 13–15 착지 구간을 0.25초 동안 재생한다. RUN·공격·방어·피격 상태에서는 즉시 해당 모션으로 전환한다.
- 프레젠테이션 코드는 전투 상태와 물리 이동 값을 읽으며 수정하지 않는다.
- 네 캐릭터를 대상으로 이륙, 정점, 하강, 공중 점프 재시작, 착지, 이동 중단, 플랫폼 낙하와 물리 상태 보존 자동 검사가 통과했다.
