# 프리미엄 메뉴 기능 v01 마무리

## 결과

미션·친구·랭크·프로필을 실제 기기 기록과 인증된 개발 서버 데이터에 연결했다. 기기·DB·LAN 프로필의 소유 증명, 보유 합집합, 현재 편성·설정·프리셋 보존과 통합 실패 재시도를 구현했다. 무료 구매와 기존 전투 규칙, LAN v2 필수 필드는 유지한다. 보상·재화·채팅·정식 인터넷 서비스는 추가하지 않았다.

- 기기 AI·Solo·Team 정상 종료와 LAN 결과는 출처를 구분한다. 연습·Story·기권·잘못된 경기는 정상 집계에서 제외한다.
- LAN 서버는 실제 참가자와 결과를 파일에 먼저 남기고 API에 전송한다. 재대전마다 새 UUID를 사용하고 연결 실패·서버 재시작에도 같은 결과를 중복 집계하지 않는다.
- 친구는 실제 검색·요청·수락·거절·취소·삭제·접속·최근 상대·대기방 초대다. 순위는 실제 LAN 정상 경기의 전체·이번 달·친구 승패다.
- 프로필·미션은 즉시 기기 기록을 표시하고 서버 조회와 전송 확인을 함께 저장한다. 50개 전송 제한과 전체 미전송 표시를 분리했다.
- 기존 사용자 ID·원본 기록·승인 자산은 보존한다. 병합 뒤 같은 사용자끼리였던 경기는 집계에서 제외한다.

## 미확인과 환경 보존

- Galaxy S23 Ultra와 물리 Android 두 대 LAN, 실제 Wi-Fi 단절·복귀·동시 터치는 실행하지 않았다. 실기기 통과가 아니다.
- 서버 기능은 개발 서버에 연결해야 한다. 공용 인터넷 운영·출시용 서명·스토어 배포는 이번 범위가 아니다.
- 검사는 별도 DB와 QA 저장 폴더에서 진행했다. 일반 개발 DB에 migration을 강제로 적용하거나 사용자 데이터를 초기화하지 않았다.
- 에뮬레이터와 검사용 프로세스를 종료했고 작업 전 꺼져 있던 Colima도 종료해 원래 상태로 돌렸다.
- 재사용 작업 트리의 기존 두 QA JSON 변경과 주 작업 폴더의 다른 미커밋 변경은 포함하지 않는다.

## 원격 통합과 되돌리기

최신 develop `5fe62756ea7d6a1c570e5eff77f4e16ffc7486fe`에서 `codex/premium-menu-features-v01`로 작업했다. 독립 QA와 실제 산출물 확인 뒤 PR을 거쳐 develop에 병합한다. PR·병합 SHA는 실제 병합 완료 뒤 이 절에 기록한다.

되돌릴 때 관련 앱·서버 커밋을 되돌리고 추가 저장 파일과 DB 테이블·원본 사용자·기록은 보존한다. 통합 원본이나 소유 데이터를 자동 삭제하지 않는다.
