# 통합 작업 기록

- 기준 origin/develop 5fe62756에서 codex/premium-menu-features-v01 생성. 붙어 있던 작업 트리를 재사용했고 이전 작업의 두 QA JSON 수정은 제외한다.
- 역할: 공용 연결 규칙·ADR 선행 후 서버/API/DB 담당, 앱 서비스·저장·UI 담당, 독립 QA 담당으로 나눴다. 루트는 앱 연결·LAN 기록 전송·문서·최종 빌드와 원격 통합을 맡는다.
- 기존 LAN 서버는 결과를 방송만 했으므로 실제 참가자 등록→결과 전송을 추가했다. 매 재대전 UUID를 새로 만들고 전송 전에 파일에 저장한다. API 실패는 전투 진행에 영향을 주지 않는다.
- LAN v2에 match_id/result_sync와 result_sync 메시지를 선택 정보로 추가했다. 기존 필수 필드는 보존한다. UI 결과는 저장 대기/실패를 표시한다.
- 기기 경기는 기존 확정 결과 화면에서 읽는다. MatchController의 기권 표시는 기록 제외에만 사용하며 전투 계산은 바꾸지 않는다. reset에서 기록용 ID와 기권 표시를 지운다.
- 통합 callback은 서비스의 재시도 기록을 유지한 채 DB/LAN 세션과 로컬 프로필을 저장하고 성공 후 메모리를 반영한다. 통합 중 프로필 변경은 차단한다. 통합 후 LAN은 하나의 인증 갱신 경로를 사용한다.
- 독립 QA가 지적한 사회 행동 재전송 ID, 공동 순위 1·1·3, 합병 후 동일 사용자 경기 제외, 출처별 전송 대기와 원래 계정 확인을 계약에 반영했다.
- LAN 기본 자동 검사는 별도 임시 전송 대기 파일을 사용하며 실제 등록/결과/재대전 UUID 전송을 test fixture에서 확인한다. 실제 PostgreSQL 집계 검사는 별도로 구분한다.
- 검증 결과·해시·미확인과 PR은 04_closeout에 최종 기록한다.
