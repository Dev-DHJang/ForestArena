# UI 제작 기준

기존 넓은 밝은 패널과 배경 위 흰색 처리를 줄인다. 캐릭터와 배경을 드러내고 작은 어두운 유리 구획에 밝은 글자를 사용한다. 주요 버튼은 연두색 면, 하늘색 경계, 두꺼운 실루엣과 세 단계 명암으로 표현한다. 장식은 글자 뒤에 두지 않는다.

색상: 연두 #B8DE78, 하늘색 #91D5EF, 숲 초록 #27634D, 밝은 바탕 #F4F9EE, 진한 글자 #183D35. 작은 금색 강조는 주요 행동, 산호색은 위험 행동에 한정한다. 한국어는 네이티브 텍스트다.

기본·눌림·선택·사용 불가는 높이·명암·경계·체크로 구분한다. 버튼 눌림 80ms, 복귀 120ms, 패널 전환 180ms, 캐릭터 호흡 4초를 전달 의도로 유지한다. 정지 PNG와 움직임 예시는 구분한다.

## 영상에서 확인한 내용

- 숲 게임 영상 약 0:02: 밝은 청백색 카드, 짙은 상단 표시, 작은 입체 아이콘, 선택된 하단 버튼의 높이와 명암. 약 0:08: 숲을 드러낸 캐릭터 미리보기와 짙은 상세 구획. 약 0:15–18: 입체 아이콘 카드, 작은 구획과 큰 여백. 영상의 재화·소환·성장·등급은 새 기능으로 가져오지 않는다.
- 니케 영상 약 0:10: 큰 중앙 캐릭터, 작은 상단 메뉴, 주변 행동 구획과 배경 노출. 약 0:54·1:12·3:13: Story 목록의 명확한 선택 표시와 정보 간격. 약 2:00: 어두운 배경 위 상세 창의 제목·초상·내용 위계.
- 두 영상은 게임의 모든 실행·전투·오류 화면을 보여주지 않는다. 확인되지 않은 화면은 같은 시각 규칙과 기존 Forest Arena 화면 계약으로 설계한다.

## 검토 순서

Splash·로비·캐릭터 선택·8인 전투를 먼저 제작하고 배경 대비·주요 행동·아이콘 식별을 확인한다. 이후 55개 전체 화면, 52개 프로토타입과 호흡 2개를 갱신한다. 전투 터치 영역과 조이스틱 동작은 v05에서 변경하지 않는다.

## 최종 적용과 수정

55개 원본·상태·비교 보드, 52개 프로토타입과 호흡 2개를 v06으로 적용했다. 검토에서 상세 카드·목록·전투 상태 구획의 흰색 글자 대비를 높이고, Splash/Login 로고를 네이티브 한 줄 흰색 텍스트로 정리했다. 나가기 확인은 산호색 위험 버튼으로 구분했다. 전투 경기장·플랫폼·조작 위치는 보존했다.

전체 PNG는 `exports/`, 55개 화면별 검토는 `screen-review.csv`, 14개 검토 모음은 `review/`, 실제 클릭 확인은 `manual-flow-review.md`에 있다. Penpot 전달표 38개와 로컬 CSV는 화면 목록, 컴포넌트, 실제 좌표·터치 영역, 이미지 매핑, 287개 연결, 제작 자산, 미제작 47개 자리를 다룬다. 전달표의 줄바꿈·잘림 검사와 좌표·터치 표 PNG 검토도 수행했다.

호흡은 승인 투명 PNG의 rest/inhale 4초 전환 예시다. 캐릭터 영역과 메뉴의 최소 간격은 6px이며 Android 조작성 통과로 기록하지 않는다. 최초 방향패드 계획과 달라진 고정·플로팅 조이스틱은 사용자의 추가 요청을 반영한 v05 설계를 유지한다.
