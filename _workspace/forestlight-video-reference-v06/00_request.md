# 영상 참고 UI v06 요청

두 YouTube 영상과 사용자 첨부 모바일 게임 화면을 참고해 실행부터 결과까지 Forest_Arena_UI의 전체 화면 품질을 개선한다. 사용자가 선택한 방향은 **숲 배경 + 니케 구도**다. 선명한 숲 배경·입체 아이콘과 캐릭터 중심 여백·작은 정보 구획을 결합한다.

- 기준 목록: 화면·비교·추가 예시 55개, 프로토타입 52개, 호흡 보드 2개, 연결 287개. 적용 전 실제 Penpot 저장 상태와 대조한다.
- 기존 ID·이동 목적지·1920×1080/1280×720 기준과 20:9 비교를 유지한다.
- 승인 투명 PNG와 4초 호흡, 하단 메뉴 6개, 오른쪽 아래 큰 플레이 버튼을 유지한다.
- v05 고정·플로팅 조이스틱 동작과 전투 터치 좌표를 유지한다.
- Splash 무캐릭터, 장신구 무등급, 미구현 온라인·경제·Story는 미래 설계다. 미정 능력치·보상을 만들지 않는다.
- Penpot·설계 자산·개발 전달만 변경한다. Godot API·입력·저장·등록은 변경하지 않는다. 이전 버전과 다른 작업의 수정은 보존한다.

참고: https://www.youtube.com/shorts/Bpc9UZw8-mo , https://www.youtube.com/watch?v=MA6_fLqTphw . 영상 이미지나 고유 문양을 추출·트레이싱·재색칠하지 않는다. 상용 게임 내부 제작 사양과 동일하다고 주장하지 않는다.

## 시작 상태

2026-10-11: Penpot MCP 읽기 호출에서 연결된 인스턴스가 없음을 확인했다. 사용자에게 Forest_Arena_UI의 연결을 요청했고, 로컬 제작을 먼저 진행한다. 전체 완료 여부는 실제 Penpot 적용과 내보낸 화면 검토 이후 판단한다.
