# v06 제작 출처

참고는 사용자 제공 영상 두 편의 정보 위계, 캐릭터가 차지하는 면적, 메뉴 간격, 입체 명암이다. 다른 게임의 그림, 캐릭터, 문양, 프레임, 아이콘을 추출하거나 트레이싱하지 않았다.

- 숲 메뉴 영상: https://www.youtube.com/shorts/Bpc9UZw8-mo
- 니케 안내 영상: https://www.youtube.com/watch?v=MA6_fLqTphw
- 영상에서 확인하지 못한 실행 직후 화면과 오류 상태는 Forest Arena 기존 화면 목록을 기준으로 설계했다. 다른 게임의 전체 실행 흐름이나 내부 제작 사양을 확인했다는 뜻은 아니다.

## 배경

내장 이미지 생성 도구로 새로운 숲 공터·마을 배경을 만들었다. 생성 지시의 핵심은 밝은 하늘, 여러 층의 숲과 먼 산, 가장자리의 작은 집, 오른쪽 폭포, 중앙 캐릭터 뒤의 여백, 하단 메뉴를 받치는 어두운 식생이다. 글자·캐릭터·메뉴·로고를 배경에 합치지 않았다.

- 원본: `/Users/jdh/.codex/generated_images/01a0a530-8f01-7f61-a947-9719bb0397f4/exec-2bec64ab-fe3b-462d-8c39-045fd86613cc.png`
- 전달본: `assets/ui/forestlight-video-reference-v06/background-forest-v06.png`
- 실제 크기: 1672×941. Penpot에서 이미지 채우기로 1920×1080에 대응한다.
- 전투 경기장 그림은 기존 자료를 유지한다.

## 벡터

`build.mjs`에서 Forest Arena 의미에 맞는 실루엣을 직접 작성했다. 92개 SVG와 동일 이름의 투명 PNG를 생성했다. 외곽선, 면의 세 단계 명암, 작은 아래 그림자, 하늘색 테두리를 사용한다. 기본·눌림·선택·사용 불가는 명암과 테두리·표시 기호로 구분한다. 버튼 글자는 SVG/PNG에 넣지 않고 Penpot의 Noto Sans KR 텍스트로 유지한다.

조이스틱은 사용자 참고의 원형 받침·움직이는 손잡이 구조를 재해석한 기존 v05 자체 벡터를 사용한다. 숲 색상과 씨앗·잎 문양을 유지하고 테두리 대비를 높였다. 고정·플로팅, 입력 소유권과 터치 영역은 v05 전달 계약을 유지한다.

총 93개 고유 자산: 벡터 92개와 배경 1개. 제공 파일은 SVG 92개, PNG 93개다. 설계 전용 `.gdignore`를 두었고 Godot 리소스 등록이나 기존 런타임 ID는 변경하지 않았다. 파일 해시는 자산 `manifest.json`에 기록한다.

## 보존

Penpot 변경 전에 `Before Forestlight video reference v06 — v04/v05 preserved` 버전을 저장했다. v04/v05 컴포넌트는 그대로 보존하고 v06 103개 컴포넌트를 별도 경로 `Forestlight Video v06`에 추가했다. 승인 캐릭터 PNG와 미구현 정책 표시는 유지한다.
