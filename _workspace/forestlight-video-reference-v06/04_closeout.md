## 남은 콘텐츠와 제품 결정

기존 미제작 `IMG/*` 콘텐츠 자리 47개는 정확한 이름으로 `missing-assets.csv`와 Penpot에 남겼다. 실제 만든 UI 93개로 이 자리를 충족했다고 표시하지 않는다. 온라인·경제·Story는 미래 설계이며 신규 재화·뽑기·출석·길드·성장 기능을 추가하지 않았다.

직업 상세 능력·경기장 해금, Story 대화/보상, 성장·보상·가격 수치, 온라인 재접속·시간 제한, 조이스틱 무입력 범위·방향 임계값·크기/투명도 상하한은 미정이다. 기본값은 고정·100%·85% 설계 기준이며 자유 이동 편집은 없다. 구현 후 Android에서 동시 입력, 버튼 밖 이탈, 플로팅 경계, 앱 중단·복귀, 시작 모드 복귀, 실제 손가락 가림을 확인해야 한다.

공용 Pause/Leave 프로토타입은 1대1 대표 복귀 목적지를 유지했다. 실제 모드 복귀는 경기 문맥을 보존해야 한다. 승인 캐릭터, Splash 무캐릭터, 장신구 무등급 원칙을 유지했다. 다른 게임 내부 제작 사양과 동일하다고 주장하지 않는다.
