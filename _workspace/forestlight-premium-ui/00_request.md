# 숲빛 프리미엄 UI 업그레이드 요청

사용자는 실제 서비스 중인 유명 모바일 게임을 참고해 버튼과 전체 UI 품질을 높이도록 요청했고, 전체 Penpot·자산 적용 및 숲빛 프리미엄 방향을 선택했다. 승인 계획의 범위는 편집 원본 50개, 20:9 비교 3개, 프로토타입과 로비 움직임 보드, SVG·투명 PNG와 개발 전달이다.

기존 자산·승인 캐릭터·로비 투명 PNG·하단 메뉴·화면 ID와 이동 목적지를 유지한다. 신규 전투 기능, 보상·경제 정책, Godot 화면·입력·저장 코드 변경은 제외한다. 참고 자료의 이미지 추출·트레이싱·재색칠은 하지 않는다. 새 버전을 별도로 제작하고 전후 비교·출처·검사 증거를 남긴다.

참고: Wild Rift(엄지 배치와 버튼 위계), Brawl Stars(작은 화면에서 실루엣 식별), Pokémon UNITE(전투 정보와 행동 구분). 공개 웹 자료는 확인 날짜 2026-10-08 기준이며 내부 제작 사양을 동일하다고 주장하지 않는다.
