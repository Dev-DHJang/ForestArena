# 숲빛 프리미엄 UI 설계

## 제작 기준

공통 색상은 연두 #B8DE78, 하늘색 #91D5EF, 숲 초록 #27634D, 밝은 바탕 #F4F9EE, 글자 #183D35다. 금색 #C4A564는 주요 버튼 테두리의 작은 강조로 쓰고 산호색은 위험 버튼에 제한한다. 버튼은 유리 표면의 밝은 윗면·어두운 아랫면, 얇은 테두리와 비대칭 모서리로 제작한다. 패널은 밝은 불투명 바탕과 외부 그림자를 사용한다. 아이콘은 기존 프로젝트 의미 도형을 정리해 3.2px 선 기준의 이중 톤 벡터로 제작했다.

기본·눌림·선택·사용 불가 상태를 별도 SVG와 PNG로 제공한다. 선택은 표시선과 체크를 추가하고 사용 불가는 명암과 비활성 표시를 함께 사용한다. 글자는 자산에 포함하지 않는다. 주요 글자색 조합 대비는 asset-audit.json에 기록하며 전체 화면의 실제 픽셀 대비 검사와 구분한다.

## Penpot 적용 상태

2026-10-09 최종 확인: 기존 편집 원본 50개와 20:9 비교 3개에 새 컴포넌트를 적용했다. 신규 컴포넌트는 벡터 91개, 조합 6개와 로비 메뉴 조합 4개로 총 102개(축소 방향패드 1개 포함)다. 기존 컴포넌트와 원본 자산은 보존했다. 변경 전 화면은 ARCHIVE premium-before 이름으로 보관했다. 화면 ID와 버튼 위치·목적지는 유지한다. 프로토타입 50개와 로비 호흡 보드 2개를 갱신했고 전체 53개 화면을 내보내 시각 검토했다. 기존 119개와 신규 102개를 합쳐 로컬 라이브러리는 221개다.

Penpot board.resize는 내부 벡터 크기를 함께 바꾸지 않아 잘림이 발생했다. 원형 행동 버튼과 단순 아이콘은 내부 SVG 그룹 크기를 명시적으로 맞췄다. 회전된 잎이 중첩된 방향패드는 원래 320×320 크기를 유지한다. 동일 크기 그룹을 다시 resize하면 회전 도형이 변형되는 문제를 발견해 방향패드에서는 해당 처리를 제외했다.

Penpot의 내부 그림자 적용 시 패널 채우기가 사라지는 렌더링 문제가 있어 내부 그림자를 제거하고 외부 그림자로 고쳤다. 대표 화면 3개의 내보내기에서 버튼 잘림과 씨앗 아이콘 표시 문제를 발견·수정했다. 수정 후 53개 PNG와 개별 설정·확인 대화상자에서 재검토했다.

## 크기와 반응

1920×1080 설계, Godot 1280×720 논리 크기를 유지한다. 원본 좌표는 기존 touch-layout.csv와 로비 penpot-audit.json을 따른다. 이미지 크기와 터치 영역을 분리하며 입력 코드·저장 형식은 바꾸지 않는다. 늘어나는 큰 패널은 Penpot 네이티브 사각형으로 표현해 장식과 모서리가 늘어나지 않게 한다. SVG 원본은 자유 확대 가능하지만 긴 버튼은 모서리·가운데·아이콘을 분리해 구현하는 전달 규칙을 기록한다.

반응 명세는 눌림 80ms, 복귀 120ms, 패널 180ms이며 로컬 연속 미리보기와 정지 버튼을 검증했고 움직임 줄이기 CSS를 제공한다. 시스템 설정을 바꾼 실제 검사는 하지 않았다. 기존 자현 투명 PNG와 로비 4초 호흡 의도를 유지한다.

## 범위와 남은 일

Godot 화면·입력·전투 모션·기존 논리 자산 연결을 변경하지 않는다. 온라인·상점·성장은 미래 설계이며 신규 경제·보상 규칙은 추가하지 않는다. Splash 무캐릭터, 승인 캐릭터와 장신구 무등급을 유지한다. Android 실제 터치와 앱 복귀는 구현 후 확인한다.
