VIS-02: 밝은 패널 채우기, 씨앗 표시, 주요 버튼 위계 확인. Solo8·Team4v4의 P1–P8, 피해율·기회, TEAM A/B 문자와 색상, 중앙 참가자가 하단 조작과 분리된다. 정적 최대 줌아웃 예시이며 실제 카메라 검사는 아니다.

VIS-03: 조작 설정 방향패드 축소 잘림을 발견해 240px 전용 벡터 컴포넌트로 교체했다. SVG 루트 표시를 수정하고 최종 PNG에서 네 방향 잎·다섯 행동 버튼과 겹침 없음을 재확인했다. 재개·나가기 확인의 이전 위험 버튼 2개도 교체 후 다시 내보냈다.

GEOMETRY: 기본·85%·100%·110% 크기에서 지정 터치 영역 겹침 0, 안전 영역 이탈 0. 좌표는 touch-layout.csv, 화면별 버튼은 screen-button-layout.csv. 수치 검사는 실제 손가락 조작성 통과가 아니다.

## 프로젝트 검사와 제한

verify-docs.sh, verify.sh 및 Godot 리소스 검사 통과. 기본 검사는 제한 환경의 Godot 실행 중단 뒤 시스템 접근이 가능한 환경에서 종료 코드 0과 Forest Arena verification passed를 확인했다. 리소스 검사 346개 논리 자산 통과. 로그는 verify-docs.log, verify.log, verify-resources.log. 현재 게임 검사와 새 UI 시각 검토는 별개다. 신규 디자인은 런타임 등록하지 않았다.

Penpot 사용량 한도와 브라우저 연결 문제는 재연결 뒤 해결했다. 로컬 수신기의 임의 출처+인증 허용 확대는 자동 승인 검토가 거절했고 적용하지 않았다. Penpot 기본 다운로드로 증거를 확보했다.

사용자 요청대로 Android 기기 검증은 이후 별도로 수행한다. TOUCH-01 이동+공격 동시 입력, TOUCH-02 버튼 밖 이탈·손가락 교체·pointer cancel, LIFECYCLE-01 앱 중단·복귀와 오프라인 재개, HUD-08 8인전 실제 카메라, SAFE-20 기기 안전 영역을 확인한다. 온라인은 메뉴를 열어도 경기를 멈추지 않는 기대 동작을 따로 검사한다. Penpot·HTML 검토를 실제 Android 입력·성능 통과로 기록하지 않는다.
