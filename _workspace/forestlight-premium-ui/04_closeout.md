## 남은 제품 결정과 범위

신규 UI 누락 자산 0개. 직업·경기장·Story 챕터 확정 콘텐츠 원화, 보상·성장·경제·AI 난이도 정책은 미정이다. 해당 화면은 준비 중 또는 미래 설계로 유지하며 확정 수치를 만들지 않았다. 다른 승인 캐릭터 콘셉트 원본을 임의로 교체하지 않았다.

Godot 화면·전투 입력·저장 형식·런타임 리소스 등록은 변경하지 않았다. Splash 무캐릭터, 장신구 무등급, 미승인 전투 기능 제외 원칙을 유지한다. 전투 배치는 기존 입력 구현과 다른 설계안이며 구현 시 전달 표에 따라 별도 검증한다.

공개 모바일 게임은 조작 접근성과 정보 위계 참고에 사용했다. 원본 리소스 추출·트레이싱·재색칠 없이 프로젝트 소유 도형으로 제작했으며 상용 게임 내부 사양과 동일함을 검증했다고 주장하지 않는다.
