# 자현 후속 13종 원화 제작

2026-10-23. 사용자가 대표 10종을 승인한 뒤 진행한다. 담당은 원화 제작이며 새 13종의 사용자 승인은 아직 없다. 런타임·manifest·후보 목록은 수정하지 않는다.

공통 외형은 승인 idle 및 대표 펀치 모델의 머리 단위·사람 손발·은백색 머리·큰 둥근 귀 두 개·가는 분홍 꼬리 하나·백/흑/코발트 의상이다. 목의 실제 파란 목도리 두 갈래만 사용하며 추가 리본이나 별도 무기를 만들지 않는다. 오른쪽을 바라보는 3/4 시점, 투명 배경, 셀 사이 여백을 둔 전체 포즈 시트. 각 그림은 다시 그린 자세이고 늘이기·복제로 수를 채우지 않는다.

## 1차 원화 제작 결과

13종 모두 새 원화를 만들었다. 선택 목록은 `remaining/ja-hyun/sources-index.json`이며, 각 원화 JSON에 SHA256·크기·내장 생성 원본 경로·참조·권리 근거·프롬프트 경로를 기록했다. 파일 전체는 해당 폴더에 보존한다. 프롬프트는 `.prompt.txt`다. 새 원화는 아직 전부 독립 QA 및 사용자 승인 대기다.

- `idle-r02.png`: 16장. r01의 마지막 줄 신발이 바닥에 닿아 r02 전체를 새로 생성했다. r01은 폐기 근거로 보존한다.
- `guard`, `hitstun`, `launch`, `knock_down`, `wake_up`, `death`, `ring_out`, `spawn`, `attack_air_light`, `attack_air_heavy`: 각 `<ID>-r01.png`, 16장.
- `special_neutral-r02-combined.png`: 16장 조합 원화. r01의 F6·F7 목도리가 서로 붙어 전체 인물 분리에 실패했다. image_gen으로 해당 F4~7 네 자세를 `special_neutral-impact-quarter-r02.png`에 새로 그리고, 원본의 나머지 12장과 조합했다. 새 quarter 4장 전체에 같은 0.58배를 적용하여 원본 머리 단위에 맞췄다. 원본의 귀 위~턱 약119px, quarter 약205px를 비교한 값이다. 원본 12장에는 1.0배다. 목도리 연결을 잘라 수선하거나 팔다리를 변형하지 않았다. `combine-heavy-r02.py`와 조합 JSON에 입력 해시·원본 영역·프레임별 위치·배율을 남겼다.
- `special_scarf_sweep-part-a-r01.png`와 `part-b-r01.png`: 각 16장, 앞·뒤 합계 32장. 앞쪽은 준비 4장과 판정 12장, 뒤쪽은 판정 8장과 회복 8장이다. 원본 전체 두 파일 모두 남긴다. 각 파트는 4×4지만 전체 모션은 반드시 32장으로 처리한다.

원본 잘림 여부는 alpha(투명도)32 이상을 기준으로 검사했다. 선택 원화는 네 외곽의 유효 픽셀 접촉이 0이며, `split_figures`로 16명씩 완전한 인물을 분리했다. 강공격 새 quarter는 4명, 최종 강공격 조합은 16명 분리에 성공했다. 이 검사는 안전한 포장 여부를 확인하며 행동·전환의 독립 QA를 대신하지 않는다. 배경색처럼 보이는 투명 영역의 RGB 값은 alpha0이므로 그 자체를 결함으로 판단하지 않았다.

## 공통 표시 배율 제안

현재 1254×1254 원화들의 머리·귀 단위에 대해 소스→128셀 **0.285배**를 공통 시작값으로 제안한다. `remaining/ja-hyun/common-scale-0285-diagnostic-r01.png`는 승인 idle의 실제 128셀과 새 13종의 전체 인물을 같은 0.285배로 놓은 비교판이다. 새 지상 강 조합은 이미 quarter를 0.58로 맞췄으므로 조합 후 전체에 0.285를 적용한다. 눕기에는 총 키를 올리지 않아 낮고, 공중 자세에는 다리 접힘만큼 총 키가 줄어든다. 머리·귀 단위를 보고 결정하며 총 키를 idle77px에 강제로 맞추지 않는다.

이 비교판은 배율만 보는 자료다. 모든 포즈를 진단용 바닥선에 놓았으므로 공중 위치·실제 피격 이동·공격 타이밍을 재현했다고 보지 않는다. 최종 포장에서는 각 모션 전체에 하나의 균일 배율을 쓰고, 프레임별로 머리나 몸을 따로 늘이지 않는다. 실제 상태 전환과 승인 run/jump/punch 연결에서 배율을 재확인한다.

## 전달과 남은 확인

공중 약·강은 새 그림마다 실제 목도리를 잡은 손 `scarf_hand`, 지상 강은 `scarf_root`, 좌우위 특수는 `scarf_root`와 두 `scarf_tips`를 다시 짚어야 한다. 새 그림에 과거16개 좌표를 그대로 쓰지 않는다. 공중 강 F9~13의 위로 천을 회수하는 동작이 두 번째 공격 준비로 오독되는지 실제12/5/22틱 정상·느린 재생에서 확인해야 한다. 제작자가 이를 확인한 pass로 기록하지 않았다.

공통 부착점·실제 게임 재생·반전·소형 표시·공중과 착지 전환·피격에서 쓰러짐과 일어남 전환은 root 포장 및 독립 QA에 넘긴다. 런타임·manifest·후보 목록·전투 데이터는 이 담당 작업에서 수정하지 않았다. Android 기기 검증도 실행하지 않았다.
