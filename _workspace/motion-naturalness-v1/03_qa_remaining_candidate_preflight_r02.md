# 남은 26종 후보 통합 사전 점검 r02 — 시각 판정 대기

2026-10-23. 이 기록은 통합 담당자의 기술 점검이며 **독립 모션 QA의 `pass`가 아니다**. 남은 26종의 사용자 승인과 런타임 등록도 아직 없다. 이전 원화 사전 검토는 `03_qa_remaining_source_preflight_r01.md`에 있다.

## 후보와 표시 경계

- 자현 13종·나비 13종을 원화 전체 인물의 모션별 균일 배율로 128×128 셀에 배치했다. 24종은 16장, 자현 좌우위 목도리·나비 뒤돌아 할퀴기 2종은 32장이다. 원본을 늘이거나 개별 자세를 다시 그리지 않았다. 나비 특수기 앞·뒤 원화의 폭 1px 차이는 각 시트의 원래 4×4 격자에서 따로 분리하여 처리했다.
- `remaining-candidate-catalog.json`은 정확히 26종이고 `remaining-candidate-scope.json`은 그 목록의 SHA-256을 고정한다. 26개 PNG·SpriteFrames와 원본·변환 기록은 `_workspace/motion-naturalness-v1/` 안에만 있다. `assets/character/` 런타임·manifest는 바꾸지 않았다.
- 최신 목록의 `qa/remaining-candidate-preflight-r03.json` 읽기 전용 후보 검사와 `qa/remaining-candidate-timeline-r03.log` 실제 표시 코드 시간표 생성이 통과했다. 검토 페이지는 `qa/remaining-candidate-review-r03/index.html`이다. 26종 기본 판정은 모두 `blocked`이며 담당자의 프레임별 품질 검토를 기다린다. 26개 포장 명세를 다시 실행했을 때 모든 PNG·SpriteFrames 바이트가 재현됐다.
- 손/천 끝 좌표는 현재 원화에서 새로 뽑는다. 자현 공중 강의 회복 마지막 2장에는 보이는 손잡이가 없고, 좌우위 특수의 판정 3장에는 목도리 한쪽 끝이 가려진다. 가려진 끝을 지어내지 않고 한쪽만 표시하도록 처리했다. 이 위치와 효과의 연결 품질은 독립 QA 확인이 남았다. 나비 새 공격의 손·발톱 좌표는 아직 제작 중이다.

## 실제 게임 입력 표본

- 최신 코드와 목록의 헤드리스 게임 상태 검사 `qa/remaining-live-state-r05.log`: 자현·나비의 달리기, 점프, 전체 약연계, 지상 강공격, 특수기, 공중 강·약공격 **14개 장면·7,173개 상태 검사 통과**. 수정 후 `qa/remaining-nabi-special-state-r03.log`에서 나비 특수 하나를 따로 확인했고 500개 검사가 통과했다. 44틱 전체에서 `special_side`가 표시되고 이동 중 `run` 대체가 사라졌다. 기존 승인 16장 특수의 달리기 표시를 유지하는 `tests/local_fighter_presentation.gd`도 통과했다.
- 최신 코드로 얻은 실제 화면 표본: 나비 전체 약연계, 나비 특수, 자현 좌우위 특수, 자현 공중 강. 각각 723·540·540·541개 상태 검사가 통과했다. 60Hz 전투는 매 틱 실행하고 화면은 3틱마다 저장했다. 총 174장(54+40+40+40)의 PNG를 `archive-remaining-samples.py`로 H.264 RGB 무손실 MKV에 보관하고, 원본과 디코딩한 RGBA 프레임 해시를 전부 대조했다. 각 폴더의 `state-report.json`과 `sample-archive.json`에 입력·그림 번호·해시가 있다. 이 촬영은 20fps 화면 표본이므로 **60fps 전 프레임 시각 검토를 대신하지 않는다**.
- 화면 표본에서 나비 특수는 전용 낮은 이동→상대 뒤로 이동→한 번의 발톱 타격→회복 순서와 대상 HP 100→93을 보였다. 자현 공중 강은 공중 준비→실제 착용 목도리의 내려치기와 대상 쓰러짐을 보였다. 자현 특수는 실제 착용 목도리의 좌우 휘두름과 여러 번의 대상 HP 감소를 보였다. 이 관찰은 선택한 정상 방향 장면에 한정한다.
- 네 화면 표본을 찍은 뒤 후보 목록의 자현 좌우위 특수 `unresolved_source_anchor_frames` 설명 필드 하나를 정리해 목록 SHA가 갱신됐다. `qa/remaining-catalog-metadata-diff-r03.json`은 당시 목록과 현재 목록의 26개 PNG·SpriteFrames·프레임 부착점·단계·크기 표시 값이 모두 같고 그 비표시 설명 필드 하나만 다름을 확인한다. 따라서 화면 표본은 같은 그림·표시 값의 증거이지만 현재 목록 해시로 재촬영한 것으로 표기하지 않는다.
- 전체 화면 촬영을 한 번에 수행한 두 시도는 macOS 창이 뒤로 간 뒤 중단됐다. 완성된 검사나 영상으로 기록하지 않는다. 부분 PNG는 작업 폴더 밖 `/tmp/forest-arena-aborted-captures-20261023/`으로 옮겼다. 최근 네 성공 촬영의 원본 PNG는 `sample-archive.json` 확인 뒤 `/tmp/forest-arena-sampled-pngs-20261023/`에 보존했다. Git에는 검증한 무손실 영상과 해시 기록을 남긴다.
- 현재 변경을 포함한 `qa/verify-remaining-candidate-r01.log`의 `./scripts/verify.sh` 전체 검사가 통과했다. 같은 실행에서 LAN, 문서, AI 경기, Godot 리소스 519개 논리 항목과 품질 변형 25개를 검사했다. adb 연결 실패 메시지는 실제 Android 기기가 없음을 뜻하며 기기 시험 통과로 기록하지 않는다.

## 남은 품질 확인

- 독립 담당자가 26종 전 프레임·정상 속도·느린 속도·실제 전환·좌우 반전·작은 표시를 직접 판정해야 한다. 특히 자현 공중 강 F9–13의 목도리 회수가 두 번째 공격처럼 보이는지, 나비 강·공중 강의 같은 팔 연결, 나비 특수의 이동→돌기→단타 전환, 맞음→쓰러짐→일어남과 장외 포즈를 확인한다.
- 나비 발톱 효과의 실제 손 위치 연결은 새 원화 좌표 작업 뒤 확인한다. 신규 26종은 사용자 모션별 명시 승인 전 등록할 수 없다. Android 실제 기기는 연결되지 않아 엄지 접근성·가독성·중단/복귀를 통과로 기록하지 않는다.
