남은 모션 실제 입력 표본

자현·나비의 승인 전 후보 26종 중 실제 경기 입력으로 찍은 네 장면이다. 60Hz 전투의 3틱마다 화면을 저장해 20fps로 재생한다. 영상의 각 화면은 원본 PNG와 무손실 보관본의 RGBA 해시로 대조했다.

검토 상태: 대기. 이 네 영상은 26종 전체 품질 확인이 아니다. 정상·느린 속도, 좌우 반전, 작은 표시, 전환과 타격 효과를 독립 QA가 모두 판정한 뒤 모션별 사용자 승인을 받는다. 영상 촬영 후 후보 목록의 비표시 설명 필드 한 개만 정리했으며 그림·표시 값은 동일하다.

26종 전체 프레임·표시 시간 검토 페이지 · 검사 범위와 미확인 항목

나비 · 뒤로 이동해 한 번 할퀴기

전용 이동 자세 → 상대 뒤 고정 위치 → 한 번 타격 → 회복. 40장 화면 표본.

자현 · 좌우위 목도리 특수기

실제 착용 목도리의 연속 휘두름. 40장 화면 표본.

자현 · 공중 강공격

공중 준비 → 목도리 내려치기 → 공중 회수. 40장 화면 표본.

나비 · 약공격 연계

전체 약연계와 새 대기 자세 연결. 54장 화면 표본.
