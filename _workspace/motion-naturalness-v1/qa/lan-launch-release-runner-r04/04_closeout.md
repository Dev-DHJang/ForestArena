# 검토 중

제품·네트워크·모션은 변경하지 않았다. r03와의 차이는 기본 출력 분기를 포함한 resolve 한 줄이며 이전 실제 LAN r04는 명시적 절대 경로여서 영향이 없다. 기본 출력 symlink 거부의 독립 재검사가 남아 있다.

독립 QA의 21개 출력·실패 경계 검사를 모두 통과했다. 기본 경로의 바깥 심볼릭 링크도 시작 전에 거부했고 기존 자료는 변경하지 않았다. r03와의 차이는 출력 전체의 실제 경로 확인 한 줄이며 클라이언트 fixture는 바이트가 같다. 앞선 명시적 절대 경로의 실제 제품 LAN r04 결과(자연1581·공격1591·점프1587, 합계4759)를 독립 재검산해 보존했다. 이 한 줄 수정으로 제품 전투·표시·LAN 메시지나 실제 실행 경로의 의미가 달라지지 않아 소켓 검사를 반복하지 않았다. `03_qa_runner_r03.md`와 `independent-delta-r03.json`을 근거로 삼는다.
