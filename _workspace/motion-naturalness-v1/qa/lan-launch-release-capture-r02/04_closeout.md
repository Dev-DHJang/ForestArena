# 실제 실행과 독립 검토 완료

네 경우 모두 PASS, 총10,136검사다. 2,828개 실행 입력 파일은 시작 전·종료 후·독립 확인 시점에 동일했다. 실제 draw callback과 픽셀 표식이306장의 자세·방향·수신 상태와 일치했고 연결하지 못한 frame은0이었다. 원격/소유 클라이언트 양쪽에서 네 후반 자세를 실제로 그렸다. 자세한 범위는 ../../03_qa_lan_visual_r01.md를 따른다.

압축본8개와 원본 RGBA·PNG306장의 바이트가 독립 대조됐다. 원시 .rgba 파일은 로컬에 보존하고 Git에는 검증한 .rgba.gz와 PNG·보고서를 기록한다. 다른 체크아웃에서 원시 파일이 필요하면 개별 압축본에 `gzip -dk 파일.rgba.gz`를 실행해 복원할 수 있다. 같은 이름의 기존 파일은 덮어쓰지 않는다. 복원 SHA는 run-report.json의 raw_sha256와 대조한다.

표시 소스·등록 계획·그림·runtime·manifest는 변경하지 않았다. 실제 앱 HUD·Android·낮은 FPS 환경의 통과를 뜻하지 않으며, 사용자 승인과 등록은 남아 있다. 앞선 capture-r01 실패는 별도 폴더에 보존했다.


최종 기록 범위 정정: 불필요한 중복 대용량 전송을 줄이려고 원시RGBA뿐 아니라 PNG306장·GZIP8개도 로컬에 보존한다. Git에는 요약·소스목록·검토 기록과 파생 검토 영상4개를 남긴다. 위의 GZIP/PNG를 모두 Git에 기록한다는 문장은 초기 계획이며 최종 전달 범위가 아니다. 원본 삭제는 하지 않았다.
