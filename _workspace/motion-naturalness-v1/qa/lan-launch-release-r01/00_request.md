기존 `scripts/verify-lan-runtime.sh`, `tests/lan_auth_fixture.py`, `tests/lan_reconnect_auth.gd`의 인증/방 절차와 공개 QA 입력 API를 재사용한다. 실제 Android·화면 품질·DB 결과는 별도 범위다.
