# LAN 날림 종료 표시 연결 시안

LAN3에 남은 경직이 없어 launch가 F5에서 끝날 수 있다. 실제 상태·입력·경직·프로토콜을 바꾸지 않고, 선택 값이 있는 모션에서만 남은 후반 연결 그림을 최대4표시틱 보여 주는 복제 코드를 만든다.

제품 `scripts/local_fighter_presentation.gd`의 실제 LAUNCH 길이 매핑2조건 통합본을 읽기 원본으로 복제한다. 원본·고정 r09 자산·목록·manifest·기존 테스트를 수정하지 않는다. 새 값은 시험 프로세스 메모리 안에서만 r09 entry의 복사본에 넣는다. 이 폴더 자료는 제작자 시안이며 실제 게임 픽셀 검토나 독립 QA 완료를 뜻하지 않는다.
