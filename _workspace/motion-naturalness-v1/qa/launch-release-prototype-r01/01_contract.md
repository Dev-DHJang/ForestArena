# 시안 표시 값과 호환 경계

선행 약속: `_workspace/motion-naturalness-v1/01_contract.md`의 “LAN 날림 종료의 짧은 표시 연결 시안”. 해당 원본은 이 작업에서 수정하지 않았다.

- `launch_release_frame_range`: 정수 두 개의 배열 `[begin,end)`, `0<=begin<end<=실제그림수`.
- `launch_release_ticks`: 정수1..12, 구간 그림 수 이상. 두 값이 함께 있고 원화 `sha256`이 있어야 한다. 기본 시안은[12,16)·4틱.
- LAN3의 없는 경직 길이는 추정하지 않는다. 전투·저장·LAN 메시지와 기존 승인 모션은 변경하지 않는다. JSON의 별도 영구 등록도 하지 않는다.
- 새 공격·가드·회피·점프 입력을 소비하지 않는다. 이미 적용된 상태, active_attack, activation_serial, air_jumps_remaining, launcher_jump_available, velocity.y만 읽어 새 행동 결과를 발견한다.
- 실제 LAUNCH→JUMP/FALL이고 마지막 launch 그림에 미도달한 경우에만 시작한다. 마지막으로 본 그림이 구간 안이면 그 다음 그림에서 시작한다. F16 도달 또는 선택 필드 누락/잘못된 값은 기존 표시로 넘어간다.
- 매 표시 호출을 한 틱으로 세지 않고 delta의 초 단위를 누적한다. 전환을 처음 관찰한 시점을t=0으로 하고4/60초 뒤 해제한다. 30FPS에서4장 모두가 샘플될 수는 없지만 표시 시간을 늘리지 않는다.
- 새 타격 신호/유효한 LAN HIT 재진입, 실제 새 공격, 점프 허용 횟수 소비·발사 점프 허용 소진·위쪽 속도 충격·FALL→JUMP, 착지/방어/회피/다운/KO/경기종료·reset·캐릭터/프로필 변경은 즉시 해제한다. 같은 LAN HIT 중복은 기존 순서 검사로 무시한다.
- 연결 중 원화 해시가 달라지거나 선택 값이 잘못되면 즉시 해제한다. 같은 해시에 실행 중 다른 유효 구간으로 교체하는 동적 편집은 제품 사용 흐름으로 지원하지 않는다. 등록/교체는 reset을 동반해야 한다.

그림 구간은 순서대로 균등한 표시 구간으로 나눈다. 현재 r09의 원래 frame_durations는 모두1이다. 향후 서로 다른 가중치의 모션에 이 필드를 등록하려면 가중치 재사용 여부를 별도로 합의하고 검사해야 한다.
