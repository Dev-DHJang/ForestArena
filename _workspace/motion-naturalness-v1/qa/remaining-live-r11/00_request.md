# 현재 표시 코드와 25종 후보의 실제 재생

r10 후보 목록은 r09의 모든 PNG·SpriteFrames를 보존하고 두 캐릭터의 launch에 선택 표시 연결만 추가한다. 현재 제품 표시 코드에서 정상 방향과 반전·축소 방향을 모두 확인한다. 후보는 실행 중 메모리에만 연결하며 승인 런타임 자산은 수정하지 않는다.

공중 날림·착지·재피격·쓰러짐·기상·사망·재등장과 남은 공격을 실제 전투 입력으로 재생한다. 원본 RGBA는 무손실 영상의 모든 프레임 일치 확인 후에만 제거한다. 이 자료는 독립 시각 검토와 사용자 승인 전 단계다. Android 실제 기기 통과를 뜻하지 않는다.
