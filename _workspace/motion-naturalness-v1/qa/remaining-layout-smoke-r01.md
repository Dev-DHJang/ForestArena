# 남은 모션 포장 도구 부분 검사 r01

2026-10-23. `pack-remaining.py`는 원화 전체 인물을 한 모션에 같은 배율로 128px 셀에 배치하는 검토용 도구다. 이 단계에서 게임 런타임·manifest를 변경하지 않았다.

- 자현·나비의 수정 대기 `idle-r02`와 기존 `guard-r01` 4개 원화를 16장 후보로 포장했다. 각각 원화 외곽 알파 접촉 없음, 16개 전체 인물 분리, 셀 안쪽 여백, 원본·후보 SHA-256 기록을 확인했다. 입력이 같은 포장을 다시 실행했을 때 4개 PNG 해시가 모두 같았다.
- 첫 프레임 표시 높이: 자현 idle 74.0px, guard 76.5px, 나비 idle 87.6px, guard 86.0px. 자현은 원화 전체에 같은 화면 배율 0.285를 적용한 제작자 비교판을 기준으로 삼았다. 배율은 원화 시트마다 동일한 얼굴·귀 크기를 맞추도록 정했으며 누운 자세를 대기 전체 키로 확대하지 않는다.
- 후보 위치: `candidates/remaining/{ja-hyun,nabi}/`. 이들은 원화 분리·배율·프레임 수의 부분 확인 자료다. 실제 경기에서의 자연스러움, 26종 전체 품질, 사용자 승인, 게임 등록은 아직 확인하지 않았다.
