# 남은 모션의 머리 단위 교정 시안

기존 단일 배율은 원화마다 모델이 같은 크기로 그려졌다고 가정했다. 독립 검토에서 나비의 대기·가드·피격·띄워짐 사이에 크기 차이가 보였고, 원화의 귀 끝–턱 단위 차이와도 맞았다. 승인된 idle의 약42.2px와 현재 승인 run의 약40.7px 사이인41.5world px를 초기 기준으로 삼았다.

`calibrate-nabi-r07.py`는 나비13종의 비교 시안을 만든다. 단일 원화12종은 PNG를 그대로 두고 표시 배율만 조정한다.32장 특수기의 두 원화는 각 원화 전체에 하나의 균일 배율을 적용해 서로 다른 그림 크기를 맞춘 뒤 공통 표시 배율을 쓴다. 개별 자세나 머리·몸 부분을 따로 늘이지 않는다. 원화별 선택 지점은 한 프레임의 수동 판독이므로 전체16/32장의 자연스러움을 보장하지 않는다.

`pack-calibrated.py`의 작업용 설정 `source_scale_multipliers`는 원화 수와 같은 길이의 유한한 양수 배열이며, 기본값은 모두1이다. 원화마다 같은 값으로 그림 전체와 부착점을 함께 옮기고 전체 모션에 공통 fit와 표시 배율을 사용한다. 전투 Resource·LAN·저장 형식은 바꾸지 않는다. 기존 포장 도구와 승인된 자산은 보존한다.

단일 원화12개 PNG 보존과25종 시간표 검사가 통과했다. 새 좌표93개는 포장된 가시 그림에서 최대1.46px 거리다. 이는 좌표·배율 계산 검사이며 시각 QA 통과가 아니다. 새 목록은 등록된 자현 특수를 제외한25종이고 출처 필드도 준비했지만, 독립 전환 검토와 사용자 승인 전에는 등록하지 않는다. 자현과 승인 점프 사이의 크기 연결도 별도로 해결해야 한다.
