# 대표 세트의 머리 기준 표시 크기 진단 r05

담당: scale_qa. 2026-10-22. 킥 원인 재분류 이후 나머지9종에서 같은 전체 높이 정규화 문제가 명확하게 보이는지 정적으로 비교했다. 이 기록은 전체 행위·재생 pass가 아니다. 원화·후보·코드·catalog는 수정하지 않았다.

## 관찰

- **자현 run/jump는 고정 표시 배율 재검토가 필요하다.** 승인 idle 첫셀의 귀 상단~턱은 눈으로 짚으면 약33px, 현재1.0 후보의 run/jump 대표포즈는 약39~41px다. 윤곽 경계가 흐린 작은 그림을 눈으로 짚은 근삿값이므로 정밀 측정값으로 쓰지 않는다. 얼굴 폭도 같은 방향으로 커진다. 원본 source 전체를 함께 확인했으며 같은 모션 내부의 각 프레임마다 크기를 바꿔야 할 명확한 결함을 먼저 확정하지 않았다.
- run의 앞으로 기울인 몸과 교차한 다리, jump의 접은 무릎은 전체 높이를 낮춘다. 전체 높이를 idle77px와 같게 포장하면 머리까지 커질 수 있다. 따라서 `qa/ja-run-jump-uniform085-diagnostic-r05.jpg`에서 각 모션 **전부에 동일한0.85배**를 가정했다. run F0/4/8/12/15, jump F0/6/12/18/23의 머리·얼굴 크기가 idle에 가까워졌다. 전체 자세 높이를 억지로 같게 만들지 않았다.
- 0.85는 후속 실제 비교용 시험값이다. 달리기의 보폭·발 디딤, idle 진입·이탈, 점프 공중과 착지·idle 연결을 실제 프레임 순서에서 다시 보기 전에는 확정하거나 pass로 기록하지 않는다. 표시 크기를 바꾸기 위해 실제 이동속도·보폭 데이터·점프 계산을 바꾸는 제안이 아니다.
- 자현 두 펀치와 나비5종에는 같은 정도로 명확한 전모션 공통 크기 결함을 이번 대표포즈 비교에서 확인하지 않았다. 기존 긍정 결과를 모션별 최종 통과로 바꾸지 않는다. 나비X의1.072276은 셀 여백 안에 원화를 넣으면서 축소한 비율을 역보정한 값이므로 숫자만 보고1.0으로 바꾸는 근거가 없다.
