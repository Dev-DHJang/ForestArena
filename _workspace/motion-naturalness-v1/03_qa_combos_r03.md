# 실제 연계 비율·접지 기준 재검토 r03

담당: pilot_qa. 2026-10-22. `review/live-combos-r03`의 두 캐릭터 162tick씩 총324tick PNG를 새로 시간순으로 직접 대조하고 경계 확대판을 만들었다. 새 자현 약1·약2 전체16셀과 source 원화도 대조했다. root가 원본 PNG를 보존한 동안 검사했으며 코드나 후보 픽셀을 수정하지 않았다. 완료 report는1645검사·오류0이고, 실제 제품 계산·공격 판정·전투 위치를 그림에 맞추어 바꾸지 않았다.

## 자현: 두 펀치 개선, 킥 비율 fix 남음

r03 두 펀치는 r02보다 머리·귀 폭이 줄고 몸통과 다리가 길어져 승인 idle에 가까워졌다. 가까운 왼손 단타와 먼 오른손 크로스, 반대 손 가드의 안무는 유지된다. 접지 root 보정 뒤 펀치 셀 사이에 인물 전체가 좌우로 흐르는 현상도 줄었다. 두 펀치를 다시 먼저 그릴 필요가 있는 상태는 아니다.

다만 tick100 약3 회복→101 킥 준비에서 킥 머리·귀가 승인 idle 및 새 펀치보다 뚜렷이 작아 몸통이 길어 보인다. tick136 킥 회복도 같은 비율이며 tick137 idle로 돌아올 때 변화가 읽힌다. 처음 두 펀치가 커 보인 문제를 고쳤다고 해서 연계 전체가 같은 모델로 이어진다고 통과시키지 않았다.

다음 수정은 킥의 단일 준비 핵심 자세를 승인 idle과 같은 표시 높이에서 먼저 확인한 뒤 전체16장으로 확장한다. 같은 원인의 두 회차 이후, 두 펀치 전체에 계속 같은 수정 요청을 반복하는 접근은 중단한다. 새 펀치의 안무·비율 개선은 보존하고 킥을 기존 idle 모델에 맞춘다. 전체 연계 판정은 **fix**다.

증거: `qa/ja-full-combo-actual-r03-part1.jpg`~`part5.jpg`, `qa/ja-combo-transition-independent-r03.jpg`. 핵심 경계는11/12,40/41,70/71,100/101,136/137이다. 새 약1 SHA256은 `7fc8bcb8e3de49ab25cde2e0184fee53d99525803fc408849120db8caf887982`, 약2는 `c9a885dabc3cbc2daa732f0043d46bd3fcf32f93a7c0dc7ee9b7d656bf1651fd`다. 신체 기준 메타데이터는 각각r04 JSON에 들어 있다.

## 나비: 접지 기준 수정 해소 확인

같은 기존 PNG에 표시 전용 body_root를 추가한 새 메타데이터(왼손r03/Xr05)를 실제 연계에서 확인했다.

- tick70 up 회복→71/72 X F0→73 X F1에서 이전처럼 인물 전체가 오른쪽으로 튄 뒤 돌아오지 않는다. 발 기준이 이어지고 준비 중 몸의 회전만 남는다.
- X 원화 행마다 첫 칸 오른쪽/끝 칸 왼쪽으로 흐르던 전체 위치 변화가 실제 프레임 순서에서 해소됐다. claw 끝은 원화 그대로 유지되며 셀 밖을 잘라 해결한 그림이 아니다.
- 왼손→up의 접지 중심 차이도 줄었다. 왼손 단일 전방 할퀴기, 먼 오른손 올려 할퀴기, 두 손 X의 순서와 각 한 번 공격이 구별된다.
- 교체한 up F5는 먼 X 소매 팔로 이어지고 가까운 팔은 가드한다. 왼손 회복의 작은 손 벌림은 다시 긴 공격을 시작하는 것으로 읽히지 않는다.
- 107tick 이후 idle로 복귀한다. 얼굴·몸통의 전체 크기가 전환마다 다른 모델처럼 바뀌는 결함은 이번 나비 연계에서 확인하지 않았다.

따라서 이 회차의 **나비 접지 기준 fix는 해소**됐다. 전체 모션 pass는 최종 고정 코드/메타데이터의 전체 프레임·정상/느린 재생·반전/소형 자료를 모두 확인한 뒤에만 기록한다. 현재의 긍정 결과를 사용자 승인으로 쓰지 않는다.

증거: `qa/nabi-full-combo-actual-r03-part1.jpg`~`part5.jpg`, `qa/nabi-combo-transition-independent-r03.jpg`. 이 비교판은 이전 고정 크롭이 일부 팔을 가린 한계를 줄이기 위해 가로180px로 넓혔다. 경계는 원본 전체 화면도 대조한다.
