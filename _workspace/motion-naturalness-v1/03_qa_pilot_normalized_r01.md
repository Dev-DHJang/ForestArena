# 대표 모션 포장 독립 검토 r01

담당: pilot_qa. 2026-10-22. 이전 담당 기록을 읽고 현재 후보 PNG를 새로 직접 확인했다. 원화 제작·전투·표현 코드는 수정하지 않았다. 범위는 아래 9개 후보의 전체 프레임 비교판과 승인 idle 대비 같은 128셀 크기 비교다. 자현 run 최종 후보, 실제 정상/느린 재생, 반전·소형 표시, 실제 경기 상태 전환은 아직 전달 전이므로 전체 자연스러움은 **blocked**다. 원화 행위에 대한 긍정 관찰을 모션 pass나 사용자 승인으로 쓰지 않는다.

## 수정 필요

- 나비 `run_16f_r04.png`는 F2 머리 우상, F3 머리 바로 위, F7 오른쪽 위에 보라 수평 파편이 떠 있다. F8 발밑 작은 보라 점과 F10 머리 위 작은 성분도 함께 분리 확인해야 한다. 배경색으로 합성한 비교판에 보이므로 alpha 0의 숨은 RGB 문제가 아니다. 원화의 이웃 몸 조각 또는 분리된 잘림 성분만 포장 단계에서 제외하고 머리·꼬리의 유효 실루엣을 보존해야 한다. 확인 자료: `qa/nabi-run_r04-independent-board.png`.
- 자현 약1 준비 F0은 승인 idle 대비 머리·귀가 넓고 킥 준비 F0은 상대적으로 좁다. 전체 높이를 맞췄어도 머리-몸 비율 변화가 연계 때 외형이 바뀌는 인상을 만들 수 있다. 회전·자세 차이의 정당한 변화인지, 실제 연계에서 크기 튐으로 보이는지 확인해야 한다. 단순 전체 확대/축소는 머리와 몸의 상대 비율을 동시에 고치지 못한다. 확인 자료: `qa/ja-proportions-independent.png`. 숫자로 고정한 얼굴 폭 제한을 새로 정한 것은 아니다.

## 원화 행위와 포장 관찰

- 자현 jump r03: 24개 전체에서 이전 파란 목도리·분홍 이웃 조각이 사라졌다. F5는 벌린 팔, F15는 접은 공중 발로 읽힌다. F16부터 접지·압축·기립이 나타난다. 실제 첫 접지와 착지 재생 시점은 경기 자료로 확인한다.
- 나비 jump r03: 24개 전체에서 이전 위쪽 신발·머리 조각이 보이지 않는다. F16~23의 접지·압축·기립 순서는 합당하다. F7~11 공중 발의 펴짐/접힘이 실제 정점 시간에서 페달 밟기처럼 튀는지는 미확인이다.
- 자현 약1 r02: 가까운 왼손이 한 번 펴졌다가 회수한다. 이전 두 번 공격/20포즈 문제는 없다. 프레임 수는 16이다.
- 자현 약2 r02: 먼 오른 어깨의 팔이 F4~6에서 신전하며 가까운 흰 소매 손은 가드에 남는다. 왼손 펀치와 구분된다. 16프레임 전체에서 한 번의 크로스로 읽힌다.
- 자현 킥 r02: F2~3 무릎 올림, F4~6 전방 신전, F7~9 회수, F10~15 접지/가드다. 한 번의 킥으로 읽힌다.
- 나비 run r04: 반창고가 있는 가까운 다리와 X 스트랩의 먼 다리가 전방으로 교대한다. F0 근처 가까운 다리 전방/가까운 팔 뒤, F8 근처 먼 다리 전방/가까운 팔 앞으로 반대 스윙이 읽힌다. 한쪽 다리만 반복하던 첫 원화와 다르다. 이 관찰은 접촉 발 미끄러짐이나 전체 반복 경계 통과가 아니다.
- 나비 왼손 r02: 선택한 16개는 단일 전방 할퀴기로 읽힌다. F9 가드 다음 F10 열린 손이 다시 넓어지는 변화가 실제 짧은 회복에서 재신전으로 튀는지는 연속 재생에서 확인한다.
- 나비 up r03: F4→새 F5→F6에서 먼 X 소매 팔이 올라가고 가까운 왼팔은 가드다. 확대 비교 `qa/nabi-up-f4-f6-independent.png`에서 F5의 머리 폭·발 기준은 주변과 대체로 맞으며 명백한 별도 얼굴 크기 결함은 확인하지 않았다. 이웃 15개를 그대로 두고 새 F5를 넣은 연결의 최종 판단은 실제 4tick 판정 재생을 본 뒤에 한다.
- 나비 X r03: F2~4 교차, F5~7 양손 동시 전개, F8~11 회수, F12~15 가드로 단일 X 공격이 읽힌다. 준비5/판정3/회복8 그림 구분과 합당하다.

각 후보의 alpha 32 이상 실루엣이 셀의 x/y 0 또는 128 경계에 닿는지 함께 확인했고, 아래 해시의 9개 모두 가장자리 접촉은 없었다. 이는 원화의 손실이 없다는 완전 증명이나 그림 의미·자연스러움 자동 통과가 아니다.
