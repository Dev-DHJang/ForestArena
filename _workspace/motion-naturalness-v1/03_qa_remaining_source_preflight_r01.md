# 후속 26종 원화 사전 점검 r01

담당 `installed_pilot_qa` / 독립 QA. 2026-10-23. 현재 생성된 r01 원본28 PNG(일반24개와 32장 특수의 16장 부분4개)를 확인했다. **이 기록은 원화 사전 문제 전달이며, 전체 모션 pass·사용자 승인 기록이 아니다.** 제작자 PNG·메타데이터·전투 코드·manifest를 수정하지 않았다.

원 요청, 두 제작자의 제작 계획, `remaining-motion-brief.json`, 승인된 자현·나비 외형, `docs/content/motion-action-review.md`, 실제 표시·대시 종료 방향 코드를 읽었다. 현재 소스 해시·크기·알파 외곽과 연결된 전체 인물 분리 결과는 `qa/remaining-source-preflight-r01/source-inventory-r02.json`에 고정했다. 이전 `figure-separation-r01.json`의 부분 특수에 대한32장 기대값은 잘못된 추정이었다. 실제로 두 부분은 각각16장이며, 이를 고친 r02 기록과 최종 inventory를 사용한다.

## 확인한 범위

- 28개 원본의 전체 자세를 직접 보았다. 배경의 RGB가 남아 있는 투명 PNG는 회색 체커/배경에 실제 알파로 합성해 판단했다. 알파0의 보라색·분홍색 RGB만으로 불투명 배경이나 외곽 번짐이라고 판정하지 않았다.
- 자현의 큰 둥근 귀2·분홍 꼬리1·사람 얼굴과 손발·은백색/코발트 머리·백/흑/코발트 의상, 나비의 고양이귀2·보라 꼬리1·사람 얼굴·검정보라 머리/의상·방울·클로는 대체로 승인 외형으로 읽힌다. 실제128px 포장과 고정 머리 단위·부착점·작은 화면 비교는 아직이다.
- 대기와 가드, 맞음과 공중으로 밀림, 넘어짐과 일어남, 사망과 장외 탈락·등장의 행위가 대체로 구별된다. 자현 공중 약은 공중 단타와 회수, 공중 강은 목도리의 위 준비→하향타격→회수를 포함한다. 이를 실제 게임의 전환·길이·정상/느린 재생 품질 통과로 확대하지 않는다.
- 연결된 전체 인물을 분리하는 `split_figures(alpha≥32)`를 실행했다. 같은 머리 크기의 실제 자세를 통째로 포장할 수 있는지 확인하는 보조 검사이며, 그림의 의미나 자연스러움을 자동 증명하지 않는다.

## 실제 재생 때 남길 확인

- 자현 공중 강 F9~13의 큰 머리 위 회수는 두 번째 공격 준비로 오독될 여지가 있다. 원화에는 두 번째 내리치기가 없어 소스만으로 필수 재제작을 단정하지 않았다. 실제12/5/22틱의 단타·회수로 읽히는지 본다.
- 자현 특수의 두16장 사이 연결, 좌/우/위 천 움직임, 착용 중인 두 목도리 끝의 부착점과 실제 효과가 한 몸으로 보이는지 확인한다. 새 리본으로 대체하지 않는다.
- 나비 특수는 준비0~3, 이동4~19, 도달 단타20~23, 회복24~31의 기본 우향 원화와 표시 선택을 맞추는 root 계획을 읽었다. 실제 `_finish_attack_travel`의 성공 시 공격 단계20 진입과 도달 후 facing 반전을 유지한다. 가까운/먼 적·적 없음·이동 실패와 좌우 반전에서 프레임 건너뜀, 방향, 단 한 번 타격, 회복을 검사해야 한다.
- 모든 원화의 실제128px 셀 포장, SpriteFrames/표시 데이터, 반전·소형 표시, 전체 프레임·정상/느린 실제 전환 검토와 각 모션 사용자 승인은 아직이다. 이 사전 기록으로 등록하거나 승인 요청을 통과시키지 않는다. Android 실기기도 미실행이다.
