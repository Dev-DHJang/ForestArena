# 검토 자료 준비

`build.py`로25종 비교판과 실제 영상30개를 연결했다. 영상은 보통/0.5배속을 선택할 수 있다. 원본·runtime·manifest는 변경하지 않았다. 현재 정식 판정은 확인 중이며 최종 QA 뒤 페이지를 다시 생성한다. 이 페이지 제작은 모션의 품질 판정이나 사용자 승인을 뜻하지 않는다.

최종 독립25종 파일을 읽도록 연결하고 통과25·수정0·미확인0으로 재생성했다. 이는 QA 결과이며 사용자의 등록 승인은 아직 없다. 읽기 전용 등록 계획과 exact motion 범위가 준비됐고 LAN 연결 화면의 마지막 검사를 진행 중이다.
