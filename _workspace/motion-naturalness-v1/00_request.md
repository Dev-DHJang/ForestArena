# 자현·나비 모션 자연스러움 개선

2026-10-21 사용자 승인 계획 구현. 자연스러운 연결과 선명한 타격감을 우선한다. 먼저 두 캐릭터 달리기·점프·약공격 전체 연계(실사용 그림10종)를 새 품질 기준으로 만들고 독립 QA·사용자 검토 뒤 나머지26종에 적용한다. 기존 효과 수정과 새5모션 승인 요청은 이전 시안으로 보존한다. 새 후보는 사용자 모션별 승인 전 runtime·manifest에 등록하지 않는다.

원본 미커밋 폴더를 건드리지 않고 PR109 작업 폴더/브랜치를 계속 쓴다. 공격·이동 계산과60Hz·LAN 형식은 유지한다. 새 원화는 내장 imagegen으로 제작하고 단순 그림 복제/변형으로 프레임 수를 채우지 않는다. 실제 Android 미실행을 통과로 기록하지 않는다.
