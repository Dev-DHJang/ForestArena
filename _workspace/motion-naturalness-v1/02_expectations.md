# 대표 세트 제작 기준

자현·나비의 승인 idle은 외형과 비율의 기준이다. 각 모션 그림은 동일한 모델·시점·크기·조명·의상으로 보여야 한다. 얼굴·손·팔다리의 동일성을 유지하고 의도하지 않은 형태 변화를 허용하지 않는다.

대표 세트 10개는 자현 run/jump/attack_light_combo_01/attack_light_combo_02/attack_light_combo_04와 나비 run/jump/attack_light_combo_01/attack_light_up/attack_light_combo_02다. 자현 약공격 1·3타는 같은 왼손 펀치를 써서 실제 연계는 4타다.

- 달리기: 완성된 16포즈부터 시도한다. 좌우 발 접촉→하중→통과→차오르기→반대 발 접촉의 온전한 주기를 만든다. 단순한 몸 기울임만 16개 그리지 않는다. 지면 기준, 팔의 반대 스윙, 작은 상하 이동을 유지하고 목도리와 꼬리는 한 박자 늦게 따른다. 달리기 한 주기의 기준 이동 거리는96px다. 최종 그림을 모션 전체에 같은 비율로 표시 보정하면 발이 그리는 이동 거리도 함께 보정한다. 현재 자현 후보는0.85배와81.6px, 나비 후보는1.0배와96px다. 전투의 실제 이동속도는 바꾸지 않는다.
- 점프: 24포즈를 상승 0..5, 정점 6..9, 하강 10..15, 착지 16..23으로 나눈다. 앞 16개에는 지면을 디디는 자세가 없다. 착지 8개는 실제 접촉 뒤에만 재생한다. 그림이 캐릭터의 위치와 속도를 결정하지 않는다.
- 약공격: 처음에는 24포즈(준비 6/판정 4/회복 14), 마무리는 32포즈(8/4/20)를 제안했다. 제작 검토에서 팔이 바뀌거나 공격을 반복하는 그림이 발생하여, 승인된 계획의 16·24·32 선택 원칙에 따라 **16개의 정확한 포즈와 단계별 표시 시간부터** 검증한다. 일반 4/4/8, 나비 X는 5/3/8을 후보로 쓴다. 그림 복제·왜곡으로 수를 채우지 않는다. 실제 재생에서 부족한 구간만 새 중간 그림을 추가한다.

자현은 가까운 왼손→먼 오른손→왼손→발차기, 나비는 왼손 앞으로 할퀴기→오른손 위로 할퀴기→두 손 X 안무를 유지한다. 펀치하지 않는 손은 가드한다. 마지막 자세가 다음 준비 자세와 자연스럽게 연결되어야 한다.

전투의 준비·판정·회복 시간과 별도의 입력 대기시간은 바꾸지 않는다. 후보는 작업 폴더에만 둔다. 새 중간 그림은 원화를 새로 제작하며 기존 포즈의 복제·회전·늘리기로 채우지 않는다. 원화의 배경 투명도, 이웃 인물 조각, 잘림과 발 기준은 포장 뒤 다시 확인한다.

포장은 원화의 연결된 인물 영역을 분리한다. 서로 다른 원본 묶음을 합칠 때는 승인 모델의 머리 단위에 맞춰 원본 묶음마다 동일한 비율로 맞춘 뒤, 전체 모션에 같은 배율을 적용한다. 무릎을 접은 자세와 선 자세의 전체 높이가 달라질 수 있다. 접지 기준은 그림별로 기록해 픽셀을 자르거나 전투 위치를 움직이지 않고 몸 전체를 배치한다. 셀 안의 여백을 위해 전체 그림을 위로 이동하면 발 기준 좌표도 같은 만큼 이동하여 게임 안의 크기와 위치를 보존한다. 개별 프레임을 제각각 확대하거나 자세를 다시 그리지 않는다.
