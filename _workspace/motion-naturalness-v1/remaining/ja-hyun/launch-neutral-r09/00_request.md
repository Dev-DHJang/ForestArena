# launch 후반 중립 낙하 연결 후보 r09

피격 재생 시간을 실제 남은 경직에 맞춘 뒤에도 자현 launch의 뒤로 젖힌 끝자세와 승인 jump 낙하 첫 자세가 달라지는 문제를 줄인다. 기존 첫12셀·승인 jump·기존 r07 목록은 보존한다. 새 F13–15는 기존 imagegen r02 원화를 사용하며 F16은 승인 jump F11 전체 그림을 공통 경계 자세로 공유한다. 제품 코드·manifest·runtime·기존 QA 자료는 수정하지 않는다.

현재 단계는 제작자 포장/검토 자료다. 독립 QA와 모션별 명시 승인 전 제품 사용 금지. 나비도 같은 경계 자세 진단만 추가하며 새 나비 원화는 이번 작업에 만들지 않는다.
