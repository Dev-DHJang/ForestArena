# QA 기록 r01

## 통과

- `./scripts/verify-online-server.sh`: TypeScript 단위 검사 4개, Godot token·snapshot 계약 통과.
- `./scripts/server-dev.sh verify-runtime`: 실제 Godot 클라이언트 두 개의 guest 인증, refresh token 회전, 고정 slot 매칭, match ticket 재사용 거부, 입력 뒤 snapshot, 재접속과 잘못된 승자 거부를 통과했다. 이어서 한 클라이언트를 끊고 60초 유예 만료를 기다려 `disconnect` 기권 종료와 게임 서버의 결과 제출까지 확인했다.
- 최신 `develop` 재배치 뒤 런타임 검증 경기 `1a16528c-402a-4327-b3b7-2b83e9be1906`은 PostgreSQL에서 `ended | disconnect | winner 있음 | final_tick 3627`로 확인했다. 같은 결과의 재요청은 `duplicate`를 반환했다.
- 게임 서버 컨테이너는 의존 스크립트 구문 검사가 끝나고 준비 표식을 만든 뒤에만 healthy가 된다. 준비 표식과 WebSocket 포트를 함께 확인해 스크립트 로드 실패를 정상 상태로 오인하지 않는다.
- `./scripts/verify-database.sh`: 로컬 DB 설정·migration 0002·비밀 제외 규칙 통과.
- `python3 tools/forest_arena/verify_godot_resources.py --project-root .`: 논리 자산 345개 통과.
- `./scripts/verify-docs.sh`, `./scripts/verify-harness.sh`: 문서와 역할 경계 통과.
- `./scripts/verify.sh`: 기존 오프라인 전투·AI·UI 전체 회귀와 새 온라인 계약 통과.
- `./scripts/verify-database-runtime.sh`: 실제 PostgreSQL 표식·반복 migration·앱 권한 통과.
- `./scripts/export-debug-android.sh`: Android debug APK 생성과 계약 검사 통과.

## 남은 확인

- 컨테이너 환경의 60초 유예 만료는 확인했지만 물리 Android 기기에서 Wi-Fi 전환·60초 재접속·중단/복귀는 확인하지 않았다.
- 첫 구현은 보간용 20Hz snapshot만 사용하며 클라이언트 예측은 없다.
