# 요청

로컬 개발 환경에 PostgreSQL, TypeScript API와 Godot headless 게임 서버를 함께 구성한다. 게스트 로그인, 2인 매칭, 자현 대 묘령 서버 권위 전투, 재접속과 경기 결과 저장까지 실제 Godot 개발 클라이언트로 연결한다.

## 승인된 범위

- 현재 Phase 3은 유지하고 Phase 7의 로컬 2인 기술 기반만 예외로 선행한다.
- 서버는 60Hz로 판정하고 클라이언트는 의미 입력만 보낸다. 서버 스냅샷은 20Hz다.
- 첫 버전은 클라이언트 예측 없이 보간만 사용한다.
- 연결이 끊기면 입력을 해제한 캐릭터를 그대로 두고 경기를 계속한다. 60초 안에는 재접속할 수 있고 이후에는 이탈 패배다.
- 첫 편성은 기본 자현 대 묘령으로 고정한다.
- 기본 접속은 로컬 전용이며 명시적 환경값에서만 같은 Wi-Fi에 연다.

## 제외

- 클라우드 배포, 운영 보안, Redis, Kubernetes, 8인전과 다중 경기 동시 실행.
- 정식 로그인·선택·로비 UI, Google·Apple·이메일 로그인.
- 랭킹, 보상, 성장, 재화, 상점과 결제.
