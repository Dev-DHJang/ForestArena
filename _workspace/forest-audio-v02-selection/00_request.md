# r03 청취 선택

사용자는 로비·전투 음악과 점프·묘령 특수기는 예전 버전이 더 좋다고 밝혔다. 비교 화면의 A가 ‘이전 버전’이며 최초 v01임을 명시했으므로 이 네 항목은 A 선호로 기록한다. 화면의 묘령 항목은 위 특수기 하나이므로 이 선택을 묘령의 모든 기술로 확대하지 않는다.

네 항목의 조합 선택을 A로 바꾸고 비교 화면에 선택을 표시한다. 다른 다섯 항목은 현재 B를 조합 후보로 유지하되 이번에 승인된 것으로 기록하지 않는다. 기존 A/B 음원 바이트·음악 악보와 게임 연결은 변경하지 않는다. 신규 음악 제작 대신 사용자가 더 좋아한 음원을 선택한다.
