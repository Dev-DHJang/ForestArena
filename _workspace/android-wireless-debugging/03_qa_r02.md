# QA r02 — 명시 실기기 런타임 검사

## 범위

- 2026-09-18 최신 Android debug APK를 Wireless debugging으로 연결된 테스트 실기기에서 검사했다.
- 기기 식별에 쓰는 IP 주소·포트·페어링 정보는 이 기록에 저장하지 않는다.

## 통과

- Galaxy S23 계열(Android 15)에서 APK 재설치와 Godot 콜드 시작을 확인했다.
- `FOREST_ARENA_TOUCH` 로그에서 오른쪽 이동과 점프의 press 입력을 확인했다.
- 가로 활성 뷰포트(3088×1440), Forest Arena 전면 활동 상태를 확인했다.
- 홈 전환 뒤 `FOREST_ARENA_INPUT_RESET reason=pause`와 앱 복귀를 확인했다.

## 검사 경로

- 기본 `./scripts/verify-android-emulator.sh`는 계속 `emulator-*` 대상만 자동 선택한다.
- 실기기는 `ANDROID_DEVICE_SERIAL=<명시 serial>`을 지정했을 때만 같은 설치·입력·복귀 경로를 실행한다. 따라서 다른 연결 기기를 임의로 선택하지 않는다.

## 한계

- 이 결과는 실제 기기의 터치·가로 실행·중단/복귀 자동 회귀 통과를 뜻한다.
- 네 캐릭터 스타일의 플레이 감각과 채택·폐기 판단은 별도의 직접 플레이 기록으로 남겨야 하며, 이 검사로 대신하지 않는다.
