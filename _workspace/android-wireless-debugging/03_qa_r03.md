# QA r03 — USB 실기기 로컬 AI 검사

2026-10-05, USB로 연결된 Galaxy S23 Ultra(`SM_S918N`)에서 최신 debug APK를 재설치했다.

- 로컬 AI 앱의 첫 선택 이후 `오프라인 대전` → `대전 시작`을 실제 터치로 통과했다.
- 이동·점프의 터치 입력, Home 중단, 재개, 일시정지, 대전 종료와 로비 복귀를 확인했다.
- Godot 성능 표본은 약 59.6 FPS, p95 약 18.1 ms였다.
- Android 검사가 현재 실제 UI 이름인 `오프라인 대전`을 사용하도록 갱신됐다. 실기기는
  `ANDROID_DEVICE_SERIAL`을 명시한 경우에만 선택한다.
