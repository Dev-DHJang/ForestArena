## 실제 재현한 문제와 처리

1. 부분 스테이징 누락: 파일을 수정해 `git add`한 뒤 작업 파일만 원래 내용으로 되돌리면 `MM` 상태인데 변경 목록이 비었다. 생산자가 커밋·스테이징·작업 파일·미추적 목록의 합집합으로 수정했고 실제 Git 재현 검사를 추가해 확인했다.
2. 리소스를 읽는 UI 변경 선택에서 리소스 검사가 빠졌다. 앱·패널·터치·표시 경로에 resources를 추가한 수정과4경로 검사가 통과했다.
3. timeout 뒤 고아 프로세스: 임시 Git 폴더의 검사 명령이 손자 프로세스를 만들고0.2초에 timeout되면 runner는 잠금을 해제하지만 손자가1초 뒤 파일을 썼다. 새 실행을 시작할 수 있는 상태에서 이전 쓰기가 계속되는 것을 확인했다. 프로세스 그룹 종료·종료 확인 후 잠금 해제가 필요하다.
4. 결과 파일의 부분 통과: 각 명령 성공 시 최상위 status를 pass로 쓰므로 실행 중 또는 외부 중단 후에도 미완료 검사가 PASS로 보일 수 있다. 실행 중/완료 수를 기록하고 모든 명령 완료 후에만 최종 pass로 확정해야 한다.
5. `_workspace/character-personality-concepts/`의 승인·설치 기준 JSON은 실제 검사 입력인데 변경 시 검사0개로 선택됐다. 일반 로그와 실제 사용하는 승인·기준 입력을 구분해야 한다.

문제3~5의 수정 확인 뒤 이 기록의 최종 판정을 갱신한다. 기존 baseline 전체검사517.579초·종료0은 변경 전 실행이며 새 통합본 통과로 재사용하지 않는다. Android 실제 홈 화면·업데이트 설치·재실행은 미실행이다.
