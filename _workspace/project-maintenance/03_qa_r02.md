## 수정 재확인

- timeout 고아 작업: 실제 자식→손자 프로세스를 만드는 임시 Git 검사로 다시 실행했다. timeout 뒤 결과는 `fail`, 동일 작업 잠금 재획득이 가능했고 손자의 지연 쓰기 파일은 생성되지 않았다. 프로세스 그룹 종료가 잠금 해제 전에 수행된다.
- 외부 중단: 별도 실제 runner 프로세스에 SIGTERM을 보냈다. 종료값1, 결과 `interrupted`, 손자 쓰기 파일 미생성을 독립 확인했다. 정상·중간·실패 경로 모두 실행별 결과 파일에 남는다.
- 부분 통과: 검사1개가 끝난 시점에 다음 검사 명령이 결과 JSON을 직접 읽는 자동 검사를 실행했다. 최상위 상태는 `running`, 완료1/전체2였다. 마지막 검사 종료 후에만 `pass`로 확정된다.
- 승인·기준 자료 선택: personality의 승인·정규화·설치·이전 manifest JSON은 `characters`, 아이콘 승인 원본은 `branding`으로 선택된다. manifest에 연결된 출처·승인 작업 폴더도 연결하고 일반 요청·종료 문서와 로그는 구분한다.
- r01의 부분 스테이징과 UI 리소스 누락 수정도 포함한 runner15개 검사가 통과했다. 같은 내용의 무의미한 반복이 아니라 추가된 수정·실패 경로를 확인한 재검사다.
