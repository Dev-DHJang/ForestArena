# 최신 APK 실기기 확인 완료

2026-10-29. Galaxy S23 Ultra(SM-S918N), Android16의 실제 무선 연결로 확인했다. 두 ADB 주소는 같은 물리 기기이며 한 주소만 선택했다. 주소·기기 고유 식별자·개인 홈 화면 원본은 공유하지 않는다.

## 확인 결과

- 이전 설치 APK는53b687cb…였고, 최신 정비 APK a26385bf…로 `install -r` 업데이트했다. 설치 파일과 배포 파일의 전체 SHA-256이 일치한다.
- 실제 Samsung One UI Home 앱 서랍에서 Forest Arena를 검색해 목·어깨·분홍/흰 옷이 이어지는 아이콘을 직접 확인했다. 아이콘 탭으로 앱을 시작했다. 기본 홈 페이지에는 해당 바로가기가 없어 새로 추가하거나 배치를 바꾸지 않았다.
- 가로 타이틀·TITLE_READY와 ‘게임 시작’ 표시, HOME 이동·동일 PID 복귀, force-stop 후 새 PID의 콜드 시작을 확인했다. 마지막에는 HOME으로 복귀했다.
- 기존 앱 데이터 삭제 없이 파일 경로87개를 유지했다. 업데이트 후 첫 실행 전부터 재실행 뒤까지 JSON59개 내용 지문이 같다. 설치 전후 전체 파일 바이트를 비교한 검사는 아니다.

## 증거와 범위

`device-test-results.json`에6개 항목과 증거 해시를 남겼다. `launcher-icon-actual.png`는 실제 런처 화면에서 앱 아이콘·이름 부분만 자른 자료이며, 원본은 qa-local에 보존한다. `ready-title-actual.png`는 실제 앱 화면이다. 앱 시작 중 준비 화면과 원시 로그·파일 목록은 qa-local에만 보존한다. 독립 검토나 전체 게임 검사를 수행했다고 표현하지 않는다.

게임·설정·이미지 원본과 APK를 변경하지 않았다. 이전 전체87개 검사 결과는 같은 코드의 이전 결과로 유지하며 반복하지 않는다. 전투·모든 모션·성능·소리·두 물리 기기 LAN은 이번 확인에 포함하지 않는다.
