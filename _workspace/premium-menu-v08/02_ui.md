# 메뉴 v08 UI 제작 기록

2026-10-20 중단된 제작을 이어서 로비와 기존 하위 13개 메뉴의 편집 가능한 제작 명세를 완성했다. 이 문서는 로컬 설계 명세의 결과이며 Penpot 실제 저장·PNG·프로토타입 클릭 검사 결과는 담당자의 별도 증적으로 확인한다. Godot 메뉴 배치·전투·저장/API·제품 기능은 변경하지 않는다.

## 구성과 범위

`scene-spec.json`은 14개 기본 화면과 관련 200개 상태, 총 214개다. 기존 v07의 기본 13개와 상태 68개 모두 `legacyMapping` 81개로 연결한다. 공식 화면 이름은 원래 `SCR_*`, `EXT_*`, `CBT_*`를 유지하고 추가 화면만 `MENU08 /` 이름을 쓴다. 기존 v07 원본과 무관한 화면은 삭제 대상이 아니다.

처음 네 장은 로비 `SCR_03_Lobby`, 캐릭터 상세 `SCR_05_CharacterDetail`, 상점 `SCR_19_Shop`, 일반 설정 `EXT_06_GeneralSettings`다. 로비에서 193개 화면에 연결되며, 나머지 검토 상태 18개는 `MENU08 / Review`에서 시작하는 세 페이지에 진입 버튼을 둔다. 검토 페이지 자체 3장을 포함하여 전체 214장이 로비 또는 검토 시작점에서 도달한다. 검토 페이지는 실제 게임 메뉴에 추가할 기능이 아니다.

- 로비: 중앙 묘령, 오른쪽 현재 편성, 아래 여섯 메뉴와 가장 큰 플레이 버튼, 위 프로필·설정. 전체 메뉴는 도감·랭크를 포함한다. 이름 중복을 줄이고 원화의 다리 위 라벨을 제거했다.
- 캐릭터: 목록은 초상 갤러리, 상세는 얇은 초상 목록·큰 원화·정보 영역으로 나눴다. 전체/균형/기동/근접/견제 필터를 제공하며 각각 자현/묘령/나비/유란과 연결한다. 필터 결과 선택과 상세 탭·뒤로에서 필터를 유지한다.
- 장신구: 기능 필터와 4열 진열, 큰 그림과 현재 장착 비교. 철갑옷은 장착 중, 나머지는 미보유 상태의 예시다. 미보유 장신구의 주요 행동은 상점에서 획득이며 곧바로 장착 성공으로 이동하지 않는다.
- 프리셋: 네 슬롯과 선택 편성의 큰 미리보기. 로비·프리셋·프로필의 현재 편성은 모두 묘령+철갑옷, 직업 설명은 현재 구현의 기본 전투 스타일로 통일했다. 빈 슬롯 저장·적용은 선택 누락 안내로 연결한다.
- 상점·도감: 0원 무료 획득 확인과 보유 상태를 분리한다. 도감 상세는 읽기 전용이며 장착 버튼을 표시하지 않는다. 장신구+미보유 상태도 독립적으로 유지한다.
- 미션: 실제 구현의 일일·주간·누적 조건을 쓴다. 주간·누적 각 행은 자신의 분류와 조건의 상세로 연결한다. 보상 버튼과 가짜 보상 수치를 만들지 않는다.
- 친구·랭크·프로필: 미연결/빈 자료/조회 중/오류/이전 자료를 분리한다. 친구가 있는 화면의 계정·접속 자료는 시안 예시라고 명시하고 검토 페이지에서 진입한다. 검색·요청·삭제·초대 조건 안내를 연결한다. 순위는 정상 완료한 LAN 기록만 다룬다.
- 설정: 실제 앱의 소리(음악·효과음·전체 음소거), 화면 효과(피격 번쩍임 줄이기), 접근성(글자·진동), 미니맵(투명도·얼굴/점·이름), 조작(고정/플로팅·크기·투명도)을 표시한다. 분류마다 복원·적용과 미적용 이동 확인을 제공한다.

## 제작 기준

1920×1080, 8px 간격, 좌우 96px·상하 48px 안전 여백, 주요 조작 최소72×72px, 이동200ms다. 바탕 `#10181C`, 패널 `#1C282C`, 글자 `#F2F3ED`, 보조 글자 `#BBC6C6`, 선택 `#D9C58E`, 보조 강조 `#8CBFB2`를 사용한다. 제목48–56px, 본문30–34px, 보조 안내24–28px다. 선택에는 선·체크·상태 문구를 함께 쓴다.

요소는 기존 제작기가 지원하는 `rect`, `text`, `image`, `svg`, `button`, `hotspot`, `circle`로만 구성한다. 글자는 이미지를 합성하지 않고 Penpot 네이티브 텍스트로 만든다. 새 네트워크 기능·가격·보상·성장·장신구 희귀도는 없다.

## 로컬 검사 결과

`python3 _workspace/premium-menu-v08/build_spec.py`와 `python3 _workspace/premium-menu-v08/check_spec.py`를 실행했다. 214개 전체에서 프레임 경계·텍스트 안전 여백·72px 조작 영역·이동 목적지, 보이는 텍스트 박스끼리 또는 버튼과의 겹침 0건이다. 설치된 Noto Sans CJK KR 글리프 폭으로 모든 명시된 텍스트 줄이 박스 폭 안에 들어오는지도 확인했다. 결과는 `geometry-audit.json`에 있다.

이 검사는 실제 Penpot의 줄바꿈·마스크·글꼴 대체·사진 비율·PNG 출력 품질과 클릭 결과를 대신하지 않는다. 1280×720 전체 출력, 20:9 비교 5종, 저장·클릭·컴포넌트 사용·공식24개 원본 보존은 별도 실측이 필요하다. 실제 Android 검사는 아이콘 작업의 별도 결과에 따른다.

## 수동 재검사 이름

1. `V08-Lobby-Roundtrip`: 아래 여섯 메뉴 및 프로필·설정·전체 메뉴를 열고 상세/취소/뒤로로 로비 복귀.
2. `V08-Character-Filter-Persistence`: 기동→묘령, 근접→나비, 견제→유란, 상세 탭과 뒤로 후 동일 필터 유지.
3. `V08-Accessory-Ownership`: 장착/미보유/무료 획득 확인/취소 및 장신구의 희귀도 표시 없음.
4. `V08-Codex-ReadOnly`: 캐릭터/장신구와 보유/미보유 필터 유지, 상세에 장착 행동 없음.
5. `V08-Preset-Required`: 빈 슬롯1–3의 저장·적용에서 성공 확인이 아닌 선택 안내.
6. `V08-Settings-Draft`: 분류별 변경·복원·적용, 미적용 분류 이동·취소/버리기, 로비/일시정지 원래 진입점으로 복귀.
7. `V08-Review-States`: 검토 세 페이지 왕복, 친구 예시와 조회/오류/이전 자료 상태 진입.

## 선택 연결 후속 수정

기존 173개 제작 중 재검토에서 캐릭터 상세의 편성 행동이 항상 묘령 편성으로 이동하고 장신구 필터 선택이 전체로 돌아가는 두 문제를 확인해 고쳤다. 기존 순서 173개는 그대로 유지하고 캐릭터별 선택 흐름32개·장신구 필터 흐름9개를 뒤에 추가했다. 기존 씬 변경은 캐릭터 상세24개와 장신구 필터3개, 총27개이며 나머지146개는 명세가 같다. 변경 전·후 canonical JSON SHA-256과 신규41개 목록은 `changed-scenes.json`, 비교 기준173개 해시는 `selection-fix-baseline.json`에 있다.

캐릭터 선택은 네 종 각각의 편집 중 프리셋으로 이어지고, 저장 확인/취소·저장됨·적용 확인/취소·적용됨·적용 결과 로비/프로필에서 같은 캐릭터를 유지한다. 선택된 첫 슬롯을 다시 눌러도 선택이 초기화되지 않는다. 장신구 이동·방어·기술의 카드 선택·상세·뒤로는 같은 분류와 선택 항목을 유지한다. 빈 슬롯 저장·적용의 선택 누락 검사도 유지했다. 이 흐름은 Penpot의 명시된 시안 상태이며 Godot 실행 상태나 실제 저장 처리를 바꾸지 않는다.

`check_spec.py`에 선택 캐릭터 전달, 장신구 분류 밖 항목 차단과 카드/상세/뒤로 분류 보존, 저장/적용/취소의 캐릭터 일치, 빈 슬롯 성공 안내 금지를 추가했다. 전체214개 명세 검사 오류0건이다. `build_handoff.py`를 다시 실행하여 이미지 매핑838개·조작 좌표2346개(활성1325개)를 갱신했다. Penpot 실제 네이티브 보드 재제작 대상은 `changed-scenes.json`의27개+신규41개다.
