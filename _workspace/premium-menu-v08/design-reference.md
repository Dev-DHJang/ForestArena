# 메뉴 v08 디자인 참고와 적용

## 참고 범위

- [브롤스타즈 로비](https://interfaceingame.com/screenshots/brawl-stars-main-menu/): 대표 캐릭터와 시작 행동의 우선순위를 참고한다. Forest Arena에서는 중앙 묘령, 아래 여섯 메뉴, 오른쪽 가장 큰 플레이 버튼으로 번역한다.
- [붕괴: 스타레일 캐릭터 상세](https://interfaceingame.com/screenshots/honkai-star-rail-character-details/): 캐릭터 원화와 목록 탐색·상세 정보가 서로 읽히는 구성을 참고한다. Forest Arena의 승인 원화, 역할 필터와 네이티브 정보 탭으로 재구성한다.
- [기존 명조 영상](https://www.youtube.com/watch?v=ZDnToIvA570): 분류 탐색과 선택 강조, 정돈된 항목 진열의 기존 사용자 승인 방향을 이어간다.
- [기존 코드아크 영상](https://www.youtube.com/watch?v=zzXrdmW39Ak): 큰 이미지와 목록의 분리 원칙을 유지하되 모든 메뉴를 같은 큰 사각 패널로 반복하지 않는다.

위 링크는 구성 원칙을 설명하는 참고다. 이 기록에서 해당 게임의 최신 화면이나 인기 순위를 새로 검증했다고 주장하지 않는다. 타 게임의 이미지·로고·전용 글꼴·상품 가격·성장 체계는 가져오지 않는다.

## Forest Arena에 적용한 차이

숲의 캐릭터실·공방·상점·기록실·교류 공간·전망대 여섯 배경과 승인된 네 캐릭터 원화를 재사용한다. 로비는 열린 중심과 비대칭 정보 배치, 캐릭터 목록은 갤러리, 상세는 원화와 정보, 장신구는 4열 진열, 상점은 추천 이미지와 상품, 설정은 넓은 행과 고정 행동 위치로 서로 다른 목적을 드러낸다.

v07의 큰 패널 반복을 줄이고 어두운 배경 위 얇은 선과 금빛 선택을 사용한다. 기존 밝은 숲의 전투·준비·결과 화면의 스타일 규칙을 바꾸는 전면 테마 변경은 아니다. 로비+하위 메뉴에 한정한 v08 어두운 변형이다. Godot의 메뉴 배치는 이번 작업 범위에 포함하지 않는다.

## 자산 출처와 편집 경계

- 배경·원화·벡터: 기존 `assets/ui/premium-menu-v07/` 및 `_workspace/premium-menu-v07/approved-source/`의 승인 자산과 제작자가 직접 작성한 v07 SVG 경로를 사용한다. 생성 배경의 원 출처·해시는 v07 `02_image.md`와 해당 manifest를 따른다.
- 글꼴: 기존 Noto Sans KR와 SIL OFL 라이선스를 유지한다. 정적 줄 폭 검사는 설치된 Noto Sans CJK KR로 수행하며 실제 Penpot 출력 확인이 최종 판단이다.
- `IMG/*`는 기존 공식 슬롯을 유지한다. 추가 공간·원화 별칭은 `DESIGN/*`로 구분하며 Godot의 새 리소스 논리 ID로 등록하지 않는다.
- 아이콘 v02는 메뉴 배경과 별도 작업이며 `_workspace/myoryung-app-branding-v02/`의 출처·해시·PNG 마스크·APK 검사 기록을 따른다.

`scene-spec.json`은 편집 가능한 요소의 원본 명세이며 통짜 화면 이미지로 글자를 대체하지 않는다. 실제 Penpot 저장·이미지 매핑·컴포넌트 인스턴스·핫스폿·출력 해시는 실행 담당자의 최종 전달 자료에 기록한다.

## 선택 상태 연결 보완

큰 원화가 바뀌는 시각 효과뿐 아니라 편성으로 넘긴 캐릭터와 필터 선택도 실제 프로토타입 경로에 반영한다. 캐릭터마다 편집·저장·적용 결과를 구분한 상태를 만들며, 장신구는 분류 안에서 선택·상세·뒤로가 이어진다. 타 게임의 기능을 추가하는 작업이 아니라 기존 네 캐릭터·기존 장신구·네 프리셋 계약의 행동을 명시하는 보완이다. 기존173개 순서를 유지하고 변경27개와 신규41개의 해시를 기록했다.

2026-10-20에 위 두 Interface In Game 기록 이미지를 다시 열어 중앙 캐릭터·오른쪽 주요 시작 행동과 탐색·원화·상세 분리를 확인했다. 기록된 스크린샷을 검토한 것이며 현재 게임 버전이나 인기 순위의 확인은 아니다. 참고 이미지는 저장소 자산에 포함하지 않는다.
