# 설정·입력 상태 정합성 보완

2026-10-20. 저장된 214개 원본을 기준으로 설정의 적용값·복원값·취소 복귀와 닉네임 입력 시안을 보완했다. 이 기록은 정적 시안과 생성 데이터 검사 결과다. 실제 Penpot 저장·출력·클릭 검사는 담당 작업의 별도 기록으로 확인한다.

## 바뀐 범위

- 기존 214개 이름과 순서를 유지했다. 23개를 수정하고 191개는 장면 단위 SHA-256까지 같다. 새 관련 상태 49개를 더해 263개다.
- 기존 24개 공식 화면 ID, 14개 기본 메뉴 이름, v07 추적 81개를 유지한다. Godot 코드·게임 규칙·저장 형식·런타임 메뉴 배치는 바꾸지 않았다.
- 분류별 대표 변경을 적용하면 확인 창과 닫은 뒤의 설정에서 같은 값이 유지된다. 복원 확인을 취소하면 그 저장값으로 돌아간다.
- 복원한 값은 적용 전 임시 변경으로 표시한다. 임시 변경의 취소 확인에서 계속 조절을 선택하면 임시 값을, 변경 버리기를 선택하면 해당 상태의 이전 저장값을 표시한다.
- 화면 효과·접근성의 초기값은 이미 기본값과 같다. 이때 기본값 복원은 불필요한 변경 상태를 만들지 않고 기존 설정 화면으로 연결한다.
- 플로팅 조이스틱의 정보 창 확인·취소와 복원 창 취소는 원래 플로팅 상태로 돌아간다. 로비에서 연 경우와 전투 일시정지에서 연 경우를 구분한다.
- 닉네임 창에 편집 가능한 `INPUT / value` 텍스트를 넣었다. `숲빛 여행자` 입력 예시를 확인하면 같은 이름의 결과 창과 프로필 예시로 이어진다. 실제 입력·기기 저장 자료라고 표현하지 않는다.
- 유란 특징 설명의 `위치 유지을`을 `위치 유지를`로 고쳤다.

## 유한 프로토타입의 범위

이 시안은 각 분류의 대표 값 묶음 한 번 변경·적용·닫기·복원·취소 흐름을 보여준다. 슬라이더의 모든 중간 값, 토글·글자 크기의 모든 조합, 여러 분류를 오간 뒤의 전체 설정 조합을 실행 앱처럼 저장하는 기능은 포함하지 않는다. 다른 분류 이동은 기존 시안의 대표 진입 상태를 유지한다. 새 값 조합이나 앱 기능을 제안하지 않는다.

닉네임과 친구 검색은 편집 가능한 Penpot 텍스트와 이름 붙인 입력·결과 예시다. 프로토타입에서 실제 키보드 입력이나 서버 저장을 했다는 의미가 아니다.
