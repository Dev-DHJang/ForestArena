## 독립 재현 검사

- 캐릭터 상세의 모든 캐릭터·탭·역할 필터 변형에서 `편성에 넣기`가 화면의 큰 캐릭터와 같은 캐릭터의 draft 편성으로 이동한다.
- 자현·묘령·나비·유란 각각 draft → 저장 확인 → saved와 draft → 적용 확인 → applied가 분리된다. 저장만으로 적용 상태를 표시하지 않는다.
- 저장/적용 확인의 취소는 해당 캐릭터의 직전 draft로 돌아간다. saved에서 적용 확인 후 취소는 같은 saved로 돌아간다.
- saved의 저장됨 버튼은 사용 불가이며 이동이 없다. draft·saved 편성의 취소는 같은 캐릭터의 상세로 돌아간다.
- applied에서 로비·프로필로 이동하면 캐릭터 선택값이 동일한 applied 상태를 유지한다. 적용 뒤 로비·프로필의 편성 진입도 해당 편성으로 연결된다.
- 이동·방어·기술 장신구 필터별 허용 항목, 카드 선택, 상세·비교, 상세 뒤로의 필터 유지가 일치한다.
