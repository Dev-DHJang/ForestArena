# 메뉴 시안 v08 및 상반신 앱 아이콘 적용 요청

2026-10-19 사용자가 승인 계획의 구현을 요청했다. 로비와 하위 13개 메뉴는 Penpot 편집 원본과 클릭 프로토타입을 개선한다. Godot 메뉴 배치는 변경하지 않는다. 브롤스타즈의 시작 행동 위계, 스타레일의 원화·정보 분리, 기존 명조 참고 방향을 독창적인 숲 공간 디자인에 적용한다.

기존 v07·승인 원화·공식 24개 화면 ID·범위 밖 화면·저장/API 계약을 보존한다. 1920×1080 설계와 1280×720 전 화면, 로비·캐릭터·상점·친구·설정 20:9를 검사한다. 편집 텍스트·상태 컴포넌트·200ms 이동·필터/탭/선택/확인/취소/뒤로 연결을 전달한다.

아이콘은 첨부 묘령 이미지의 목·어깨·상반신이 이어지는 구도로 v02를 별도 제작하고 실제 Android 내보내기에 적용한다. Godot 시작 로고 숨김을 유지한다. 아이콘 제작·모바일 증적은 ../myoryung-app-branding-v02/에 둔다.

최종 전달: Penpot 저장 버전과 프로토타입, PNG, 비교표, 컴포넌트·상태표, 클릭 좌표, IMG 매핑, 출처·해시, 검사 결과·미확인과 마무리 기록. 실제 기기 확인 없이 기기 통과를 기록하지 않는다.
