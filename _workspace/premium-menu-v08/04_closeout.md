## 이번에 바로잡은 부분

보존 검사의 대량 오류는 생략된 fill image와 null, JSON 키 순서, 검색 도구가 부모 보드까지 포함한 결과를 서로 다르게 비교한 문제였다. 실제 기존 색·투명도·이미지·자식순서·추가 요소 변경은 계속 검출하도록 보정했다. `check-audit-preservation.cjs`의12개 검사를 통과했다.

실제 자료 오류는 캐릭터 상세의 버튼 목적지 메타데이터1개와20:9 친구 화면의 자동 높이 글자 영역17개였다. 해당 부분만 수정했으며 친구 비교 PNG를 다시 출력한 실제 SHA는 이전 출력과 동일했다. 전체 원화나531개 PNG는 재생성하지 않았다. 실제 사용하지 않는 화살표·닫기·메일3개 manifest 항목은 제거했지만 원본 SVG·기존 컴포넌트는 보존했다. 재생성 도구도 같은 목록을 만들도록 고쳤다.
