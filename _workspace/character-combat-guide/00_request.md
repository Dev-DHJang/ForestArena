# 요청: 현재 캐릭터별 전투 방법 정리

## 목표

자현, 묘령, 나비가 현재 어떤 방식으로 움직이고 공격하도록 구현되어 있는지 자세히 설명한다. 게임 개발 용어보다 실제 조작, 쓰는 상황과 주의점을 먼저 쓴다.

## 현재 단계

Phase 2 완료 상태다. Phase 1 전투 코드와 Phase 2 캐릭터·직업·장신구 조합 데이터가 동작한다.

## 범위

- 현재 기본 실행 화면에서 실제로 조작하거나 확인할 수 있는 범위
- 세 캐릭터의 이동 수치와 실제 `MoveSetData` 공격
- 공통 입력, 연속 공격, 공중 행동, 링아웃과 복귀 규칙
- 캐릭터별 추천 운영, 기본 공격 흐름과 위험 요소
- 데이터는 있지만 화면에서 선택할 수 없는 캐릭터와 아직 구현되지 않은 기술의 구분

## 제외

- 새로운 전투 기술·수치·캐릭터 선택 UI 구현
- 밸런스 조정과 새 ADR
- 애니메이션 생성 또는 전투 화면 연결
- Phase 3 이후 막기·회피·잡기·궁극기 구현

## 반드시 지킬 조건

- 설계 문서의 미래 기술을 현재 구현된 기능처럼 쓰지 않는다.
- 실제 `.tres`, 전투 코드와 테스트를 최종 확인 근거로 사용한다.
- 60 tick과 공격 수치는 쉬운 시간·용도 설명을 함께 제공한다.
- `survivability`처럼 현재 승패 계산에 쓰이지 않는 값은 효과가 있는 것처럼 설명하지 않는다.

## 완료 판단 조건

- 독자가 현재 누구를 직접 조작할 수 있는지 알 수 있다.
- 각 캐릭터의 강점, 약점, 기본 공격 순서와 복귀 방법을 찾을 수 있다.
- 현재 구현, 데이터만 준비됨, 미래 제안을 명확히 구분한다.
- 문서 색인과 전투 규칙 문서에서 새 가이드로 이동할 수 있다.
