# 캐릭터 전투 가이드 구성

## 독자가 먼저 답을 얻어야 하는 질문

1. 지금 게임을 실행하면 누구를 조작하는가?
2. 각 버튼은 어떤 공격을 만드는가?
3. 세 캐릭터의 실제 차이는 무엇인가?
4. 피해를 쌓은 뒤 어떻게 링아웃시키는가?
5. 경기장 밖에서 어떻게 돌아오는가?
6. 문서에 이름은 있지만 아직 사용할 수 없는 기술은 무엇인가?

## 설명 순서

`현재 사용 가능 여부 → 공통 조작 → 승리 규칙 → 공통 공격 → 캐릭터 비교 → 캐릭터별 운영 → 복귀 → 미구현 기술` 순서로 구성했다.

## 쉬운 표현

- `startup/active/recovery`는 `준비/적중/회복`으로 먼저 설명했다.
- `hit confirm`은 `공격이 맞았는지 확인한 뒤 다음 기술 선택`으로 풀었다.
- `DI`는 `맞는 순간 방향을 입력해 밀리는 각도를 조금 변경`으로 풀었다.
- `neutral special`은 `방향을 놓고 누르는 중립 특수기`로 풀었다.
- `recovery`의 두 뜻이 섞이지 않도록 공격 뒤에는 `회복 시간`, 경기장 복귀에는 `경기장으로 돌아오기`를 사용했다.

## 제품 상태 표시

현재 기본 화면, 데이터만 준비된 상태와 Phase 3 이후 제안을 표와 별도 절로 구분했다. 미래 기술 이름은 참고용으로만 싣고 현재 추천 입력에는 포함하지 않았다.
