# QA

2026-10-05 Galaxy S23 Ultra(`SM-S918N`) USB 연결에서 수행했다.

- 최신 debug APK를 재설치하고 로비 → 오프라인 대전 → AI 1대1 → 대전 시작을 실제 터치로 통과했다.
- 나비 대 자현 경기에서 HP가 실제로 줄고, AI가 3 stock을 모두 소진시켜 `패배` 결과 화면까지 도달했다.
- 결과 화면의 `같은 조건으로 재대전`을 눌러 새 경기를 시작했다.
- 실제 전투 화면에서 두 승인 캐릭터, 중앙 통과형 발판, 양끝 낭떠러지, 터치 D-pad와 6개 행동 버튼을 확인했다.
- 기기 로그 표본: 60 FPS, frame p95 약 16.7 ms, draw calls 12, texture bytes 184,103,107.

## 미확인

- 자동 화면 검사는 절차 생성 SFX가 사람이 듣기에 적절한지를 증명하지 못한다.
- 네 캐릭터 전체 조합과 모든 장신구의 실기기 재생, 접근성 글자 크기·진동의 실제 체감은 아직 미확인이다.
