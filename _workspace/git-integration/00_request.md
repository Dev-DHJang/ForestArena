# 추가 개발 전체 Git 통합 요청

2026-10-18 사용자 승인 계획을 구현한다. 최신 origin/develop 기준 별도 작업 폴더에서 미커밋 작업 전체를 비교하고 필요한 코드·최종 자산·문서·개발 도구·승인 근거를 통합한다. 기존 타이틀·로딩·메뉴를 보존하고 새 묘령 앱 아이콘, Godot 부트 로고 제거와 승인된 묘령31·나비29·유란30 모션을 반영한다.

중간 제작 이미지·백업은 기존 로컬 폴더에 보존한다. Git에는 최종본과 핵심 기록, 승인 확인·재현에 필요한 원본을 저장하고 제외 파일의 목록·해시·위치를 남긴다. 제안과 미승인 시안은 승인 기능으로 활성화하지 않는다. 기존 앱 ID·서명·저장 형식과 기존 작업을 보존한다.

사용자 요청으로 실기기 설치·실행·조작·터치·화면·중단/복귀·성능 검증은 제외한다. 자동 검사·문서·하네스·리소스 검사와 APK 생성·패키지 검사를 완료하고 독립 QA 후 commit·push·PR·develop 병합까지 진행한다. main 변경·강제 push·이력 재작성은 범위 밖이다.

완료 기록은 04_closeout.md에 검사 결과·미확인·APK 해시·PR·병합 SHA·되돌리는 방법을 포함한다. source-inventory.json은 원본 위치·목록·해시이며 원본 대화나 비밀정보를 복사하지 않는다.
