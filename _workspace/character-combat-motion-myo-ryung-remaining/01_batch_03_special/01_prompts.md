# batch-03 생성 프롬프트 기록

- 도구: 내장 이미지 생성 도구로 모션별 4×4 시트를 따로 만들었다.
- 참조: 승인된 `myo-ryung-concept-v01`, 기본 약공격 04, 승인된 `attack_heavy_up`, `attack_air_heavy` 시트.
- 공통 기준: 우향 전신 16포즈, 은백색 머리, 긴 흰 토끼 귀 2개, 인간형 손발, 분홍·흰 운동복, 큰 운동화와 장미색 리본 유지. 상대·무기·문자·워터마크·판정 표시와 시각 효과 금지.
- 배경 처리: 내장 도구의 `background-extraction` 편집을 원본별로 시도했으나 실제 alpha가 없는 RGB가 반환됐다. 포즈와 색을 다시 그리지 않기 위해 각 RGB 원본의 서로 이어진 무채색 체크무늬 영역만 alpha 0으로 바꾸고, 작은 배경 점을 제거했다. 캐릭터와 배치는 바꾸지 않았다.
