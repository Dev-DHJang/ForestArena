# 묘령 잔여 전투 모션 2D 애니메이션 계획

## 공통 시각 계약

- 각 시안은 투명 배경의 우향 전신 4×4·16포즈다. 프레임 순서는 좌→우, 위→아래이며 좌향은 향후 시각 래퍼에서 수평 반전한다.
- 준비·공격·후행·회복에 걸쳐 팔다리·몸통·긴 귀·장미색 리본이 실제로 변한다. 검토 프레임은 AttackData의 시작·활성·회복·다단 간격·피해·넉백·충돌을 정의하지 않는다.
- 승인 전에는 검토 경로만 사용한다. 승인된 시안의 런타임 정규화와 등록은 별도 요청이다.

## batch-01: 일반 지상 공격

| visual state | 연기 의도 |
| --- | --- |
| `attack_light_up` | 낮은 가드에서 빠르게 뻗는 상승 킥과 짧은 착지 회복 |
| `attack_light_down` | 중심을 낮추고 앞발 끝으로 하단을 확인하는 짧은 토 킥 |
| `attack_heavy_side` | 지지발 회전과 귀·리본 후행이 큰 수평 사이드 킥 |
| `attack_heavy_up` | 깊은 웅크림에서 높이 도약해 올려 차는 런처 킥 |
| `attack_heavy_down` | 낮은 축을 유지하며 넓게 도는 회전 로 킥 |

## batch-02: 대시·공중 공격

| visual state | 연기 의도 |
| --- | --- |
| `attack_dash_light` | 전진 관성을 유지한 짧은 슬라이딩 프런트 킥과 제동 |
| `attack_dash_heavy` | 크게 체중을 싣는 도약 사이드 킥과 긴 착지 회복 |
| `attack_air_light` | 몸을 작게 접은 빠른 공중 스냅 킥으로 추격을 이어가는 동작 |
| `attack_air_heavy` | 큰 회전과 전하방 발차기로 착지 압박을 표현하는 공중 피니시 |

## batch-03: 특수기

| visual state | 연기 의도 |
| --- | --- |
| `special_neutral` | 짧은 거리에서 전진하며 세 차례 빠른 연속 킥을 가하는 다단 동작 |
| `special_up` | 강한 수직 도약 킥으로 높이 상승한 뒤 긴 체공·회복을 보이는 복귀기 |
