# 프리미엄 메뉴 v07 실제 앱 구현 요청

2026-10-14. 사용자가 승인한 앱 구현 계획을 실행한다. Penpot 기본13개와 관련81개 상태 명세를 네이티브 Godot UI로 구현한다. 화면 PNG를 UI로 붙이지 않는다. 로비 배치를 유지하며 하위 메뉴의 전체 메뉴에서 도감·랭크·프로필을 연다.

프리셋4개 및 고정/플로팅·버튼크기·투명도 설정을 기기에 저장한다. 미션·친구·랭크는 준비 중·빈 상태이며 가짜 서비스 데이터를 만들지 않는다. 기존0원 구매·보유·선택·접근성·오디오·미니맵·닉네임을 유지한다. 프로필v3·DB/LAN API와 전투 판정은 변경하지 않는다.

1920×1080 설계/1280×720 런타임, 안전여백96/48·주요영역72×72·전환200ms·글자확대1.0/1.15/1.3 및20:9를 검사한다. 기존 시작/지급/준비/전투/결과/LAN 흐름을 검사하고 APK를 생성한다. 실기기 미실행은 통과로 쓰지 않는다.

작업 위치는 최신develop 기반 기존 격리 작업 폴더이며 브랜치는codex/premium-menu-v07-runtime이다. 이전설계 검사에서 생긴 두JSON 재조회 변경과 사용자 주폴더의 다른변경은 이번 커밋에서 제외한다. 관련 변경만 commit·push·PR·독립QA·develop 병합한다.
