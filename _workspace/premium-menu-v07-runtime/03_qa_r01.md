[81개 설계 상태 대응표](state-runtime-coverage.csv)는 실제 메뉴·매개변수·조작·대응 이유를 한 행씩 기록한다. 설계의 친구·미션·순위 예시는 사용자 요청에 따라 준비 중 빈 화면으로 대응한다. `Review`는 제작 검토용 모음 보드이며 별도 제품 화면으로 만들지 않는다. 대응표를 작성했다는 사실은 런타임 검사 통과를 뜻하지 않는다.

독립 검사 코드는 [premium_menu_runtime.gd](../../tests/premium_menu_runtime.gd)이며 프로필·메뉴 설정·소리 설정을 검사 전용 폴더로 고립한다. `--ui-capture`는 실제 `RenderingServer.frame_post_draw` 뒤 화면을 저장한다. 빈 이미지나 headless 출력을 화면 증거로 인정하지 않는다. 테스트의 문법 확인은 통과했고 실제 앱 연결이 준비되면 실행한다.

현재 정적 읽기에서 발견한 대전 설정 뒤로 경로는 생산자에게 전달했다. 기존 `resume_match()`는 `screen == pause`를 요구하므로 조작 설정에서 직접 호출하면 복귀가 되지 않을 수 있다. 실제 수정 및 실행 결과는 후속 회차에 기록한다.
