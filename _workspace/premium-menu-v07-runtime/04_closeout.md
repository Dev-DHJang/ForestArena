# 프리미엄 메뉴 v07 앱 구현 마무리

2026-10-15. 실제 Godot 네이티브 메뉴 13개와 동작 연결을 완료했다. 최종 APK 생성·패키지 검사, 실제 Godot 출력과 Android 에뮬레이터 검사를 통과했다. 구현 PR #96을 develop에 병합했다. 물리 Android 기기 검사는 미실행이다.

## 실제 구현

- 밝은 로비 배치를 유지하고 캐릭터·장신구·프리셋·상점·도감·미션·친구·랭크·프로필·일반/조작 설정으로 연결했다. 배경·원화·아이콘만 이미지이고 글자·버튼·탭·목록·슬라이더·팝업은 네이티브 UI다.
- 실제 보유·선택과 가격0원 무료 구매, 기술 데이터·닉네임·소리·접근성·미니맵 설정을 연결했다. 프리셋4개와 조작 설정은 별도 버전 1 기기 파일이며 기존 프로필 v3/DB/LAN API를 유지한다.
- 설정은 초안·적용·취소·복원·변경버리기 확인을 제공한다. 저장 실패 때 이전 값을 유지하고 재시도한다. 사용자 전환에서 불러오기 실패하면 이전 사용자의 프리셋 표시·변경을 차단한다.
- 고정/플로팅, 크기100–120%, 투명도0–50%가 전투 그림과 입력영역에 함께 적용된다. 기본값은 기존 조작을 유지한다. 일시정지에서 조작설정 뒤로는 일시정지로 돌아간다.
- 미션·친구·랭크의 설계 예시는 준비 중·빈 상태로 대응한다. 가짜 서비스 자료·보상·순위·희귀도는 추가하지 않았다.

## 미확인과 정리

Galaxy S23 Ultra를 포함한 물리 기기가 연결되지 않아 실기기 터치 동시 입력·HOME/BACK·가독성·진동·성능은 미확인이다. 에뮬레이터 결과로 물리 기기 통과를 대신하지 않는다. 전체 검사에서 빠르게 사라진 버튼의 개발용 지연 로그 오류도 발견했다. WeakRef로 버튼의 유효 여부를 확인하도록 수정했고 해당 앱 흐름을 재실행해 PASS 및 지연 로그 오류 0개를 확인했다([재검사](legacy-flow-deferred-fix.log)). 전체 검사 로그의 수정 전 오류는 보존했다. 일부 headless Godot 검사는 종료 때 리소스 정리 경고를 출력하지만 검사 조건과 종료 코드는 통과했다. 실제 출력과 Android 에뮬레이터에는 스크립트/파싱 오류가 없다.

검사에 시작한 에뮬레이터는 저장 상태 덮어쓰기 없이 종료했다. DB 검사에 시작한 Colima는 시작 전 정지 상태로 복구했다. 원래 작업 폴더의 다른 미커밋 변경과 이전 설계 QA의 두 갱신 파일은 이번 커밋에서 제외한다.
