# 메뉴 조작 설정과 터치 확인

2026-10-15. `TouchCommandSource.apply_menu_controls()`를 추가했다. 설정을 적용할 때 기존 손가락 입력을 풀고 그림과 실제 누르는 영역을 함께 바꾼다. 기본값은 숲빛 v06의 기존 위치·크기를 유지한다.

플로팅은 왼쪽 아래 예약영역의 첫 손가락만 이동을 맡는다. 시작점이 안전영역 끝에 붙어도 처음에는 중립이며, 그림은 예약영역 안에 머문다. 방향이 바뀌어도 처음 손가락의 위치를 유지하고 다른 손가락의 공격을 끊지 않는다. 취소·손가락 해제·초점 상실·화면 크기 변경·앱 중단 시 필요한 입력을 해제한다.

투명도는 조이스틱과 동작 버튼 그림 및 버튼 안의 글자에만 적용하며 최저 alpha는 0.5다. 가드·특수기·궁극기 준비 상태 글자는 기존 선명도를 유지한다. 기존 비숲빛 조작에는 새 배치·투명도를 적용하지 않는다. 전투 명령과 승패 규칙은 변경하지 않았다.
