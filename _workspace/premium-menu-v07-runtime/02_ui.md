# v07 실제 메뉴 UI 제작 기록

2026-10-15. 소유 파일은 `premium_menu_theme.gd`, `premium_menu_view.gd`, `premium_menu_router.gd` 세 개다. 기존 앱·저장 파일·터치 입력·자산 등록은 다른 역할이 연결한다.

## 실제 화면과 조작

- 1280×720 중심 콘텐츠와 화면 전체 배경. 운영체제 안전 영역을 `CombatUiGeometry.safe_rect()`로 읽고 중심 배치하며, 좁아질 때 주요 버튼의 실제 터치 크기를 72px 이상으로 보정한다. 20:9는 배경을 넓히고 콘텐츠를 중심에 둔다.
- Noto Sans KR 가변 폰트에 본문 굵기 500·제목 700을 명시했다. 모든 글자·버튼·입력은 Godot 네이티브 노드다. 배경 6·원화 4·SVG 아이콘만 논리 ID로 읽는다.
- 캐릭터는 목록·큰 원화·설명 3열, 장신구는 4열 카드, 편성은 원화와 4슬롯, 상점은 왼쪽 분류·추천 원화·상품 카드, 설정은 왼쪽 분류와 오른쪽 스크롤 패널로 만든다.
- 선택은 금빛 선과 ✓ 또는 장착 문구로 함께 표시한다. 주요 버튼은 72px 이상이며 전환 200ms 동안 라우터 입력을 막는다.
- 캐릭터 기술은 기존 MoveSetData의 입력·방향·피해·준비/공격/회복 시간을 읽는다. 연계는 실제 ComboLinkData를 읽는다. 내부 자산 ID와 미구현 클래스 이름은 제품 화면에 표시하지 않는다. 이야기는 기존 캐릭터 설명이다.
- 장신구 효과는 기존 상품 설명이다. 실제 `fixture-*` ID를 그대로 저장·선택하며 아이콘과 기능 분류를 찾을 때만 문자열을 정리한다. 필터가 현재 선택을 제외하면 첫 표시 항목을 선택한다.
- 상세 뒤로는 이전 목록의 필터·선택·스크롤을 복원한다. 모든 메뉴의 전체 메뉴는 13개 화면군으로 이동한다.
- 도감은 읽기 전용 모달이며 선택·구매를 제공하지 않는다. 미션·친구·랭크는 승인한 분류와 준비 중·빈 상태를 표시한다. 예시 친구·접속·보상·점수는 만들지 않는다.

## 실제 데이터 연결

- 구매·선택·닉네임·접근성·미니맵은 `await app._change_profile()`을 사용한다. 상점 카드의 기존 `purchase/<id>` ID는 무료 구매 확인 모달을 연다. 확인은 한 번만 처리한다.
- 프리셋 캐릭터·장신구 선택은 초안만 바꾼다. 저장은 로컬 4슬롯만 바꾸며, 적용은 보유·카탈로그 검사를 통과한 뒤 실제 편성을 저장하고 준비 화면을 연다. 프로필 적용 후 메뉴 파일 저장에 실패한 경우 부분 저장 사실을 안내한다.
- 소리·화면 효과·접근성·미니맵·조작은 현재 분류의 초안과 실제 값을 분리한다. 적용·취소·기본값 복원, 분류 이동 전 변경 버리기 확인을 제공한다. 소리 저장 실패는 실행 중 음량도 이전 값으로 돌린다.
- 조작 저장 성공은 앱의 `_apply_menu_control_settings()`를 호출한다. 고정/플로팅·크기·투명도 미리보기는 현재 초안을 보여 준다. 미니맵은 장면에 들어간 다음 초기화하여 리소스 노드를 안전하게 찾는다.
- 일시정지에서 들어온 설정은 전투 상태·음악을 유지하고 뒤로 이동 시 실제 일시정지 화면으로 돌아간다. 로비·준비 화면에서 들어온 경우 각각 그 화면으로 돌아간다.
- DB 저장 요청이 남으면 실제 DB 저장 재시도 버튼을 제공한다. 메뉴 파일 읽기 실패는 프리셋·조작 오류를 각각 보존하고 재시도 버튼을 제공한다. 다른 사용자 파일 읽기가 실패하면 이전 사용자의 슬롯은 표시하지 않고 편성 변경·저장·적용을 막는다.

## 최종 QA 보완

큰 글자 1.3에서 긴 저장 실패 안내가 하단 HBoxContainer의 최소 높이를 105px로 늘려 하단 버튼이 화면 밖으로 나가는 문제를 확인했다. 안내는 `FooterNoticeScroll` 안에서 읽도록 바꾸고 하단 주요 버튼은 72px 높이를 유지한다. DB 요청과 메뉴 파일 오류가 동시에 있어도 재시도 두 개는 상단의 서로 다른 72px 영역에 표시하여 하단 가로 폭을 늘리지 않는다. 기존 재시도 QA ID는 유지했다. 좁은 안전 영역의 슬라이더·닉네임 입력도 최소 높이를 보정한다.

이름을 붙인 재검사 `긴 오류·동시 재시도·1184·1.3`를 격리 프로필과 실제 Godot 노드로 실행했다. 1184×720 논리 화면·글자 1.3·DB 요청과 메뉴 오류 동시 상태에서 하단 적용/취소/기본값은 각각 높이 72.15px, 상단 재시도 둘은 72px로 화면 안에 배치됐다. 안내 영역은 72.15px 높이를 유지하고 긴 안내 전체를 세로 스크롤할 수 있었다. 결과는 통과이며 Android 실기기 결과가 아니다. 독립 QA의 최종 출력은 별도 QA 기록을 따른다.

독립 QA에서 캐릭터 목록에 원화 제작 명세(`concept_summary`)가 표시되는 문제를 확인했다. 목록은 기존 전투 역할과 `passive_description`의 전투 방향 설명만 보여 주며, 미구현 상시 효과는 준비 중으로 표시한다. 이야기 탭은 기존 `background_setting`만 표시한다. 캐릭터의 외형 제작 명세는 메뉴에 표시하지 않는다. 새로운 이야기·기능·수치는 만들지 않았다.
