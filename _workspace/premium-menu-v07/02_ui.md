# 메뉴 UI v07 제작 기록

## 대상과 배치

사용자가 승인한 어두운 프리미엄 메뉴 방향을 13개 로비 하위 화면에 적용한다. 로비·실행·플레이 준비·전투·결과는 보존한다. 공식 화면 ID, 1920×1080 설계와 1280×720 출력은 유지한다. 조작 설정의 미리보기는 비전투 메뉴의 표현이며 전투 입력 위치·동작을 바꾸지 않는다.

캐릭터는 목록/큰 원화/상세의 세 영역, 장신구는 4열 진열/선택 상세, 상점은 카테고리/추천/진열, 친구·미션은 목록/선택 상세, 설정은 분류/항목/설명으로 구분한다. 큰 녹색 카드 대신 낮은 채도의 숲 배경과 어두운 면, 얇은 금빛 선택선, 읽기 쉬운 글자를 사용한다.

원화는 승인 자현·묘령·나비·유란을 변경 없이 연결한다. 자산 그림과 조작 상태는 독립적이다. 별·등급·희귀도 단서는 없으며 가격·보상·성장 수치를 만들지 않는다. 친구 이름/접속·보유 표시는 기존 설계 예시임을 명시한다.

## 상태와 조작

`scene-spec.json`은 런타임 데이터가 아니라 Penpot의 편집 가능한 원본을 만들기 위한 작업 자료다. 기본 화면13개와 메뉴 상태·상세·선택·탭·검토 예시68개, 총81개다. 기본·주요 행동·보조 행동·선택·눌림·사용 불가·보유·장착·위험 표면 9개와 자체 벡터 아이콘 16개를 별도 컴포넌트 이름 공간 `Premium Menu v07`에 추가한다.

주요 터치 영역은 최소72×72, 안전 여백은 좌우96/상하48이다. 전환은 기본200ms로 만든다. 원본 화면의 v06 자식은 숨기고 보존하며 변경 전 Penpot 버전을 별도로 저장한다. 기존 프로토타입 연결 ID·목적지는 보존하고 대상 메뉴의 원본 이미지·클릭 위치를 갱신한다. 새 탭·선택·팝업은 별도 연결로 추가한다.

## 대표 화면 검토 1회차

상점·캐릭터 상세·일반 설정의 실제 Penpot PNG를 내보내 확인했다. 원화의 비율·배경 분리, 한국어 대비, 주요 버튼과 분류를 확인했다. 상점의 긴 안내를 짧은 세 줄로 줄였고 캐릭터 발과 겹치는 중복 이름을 제거했다. 나머지 메뉴는 이 수정 내용을 적용한다.

이후 전체 81개 화면, 20:9 비교 4개와 기본 화면의 1920×1080 출력 13개를 내보냈다. 최종 저장·실제 클릭 이동·독립 품질 확인의 결과는 `04_closeout.md`와 `03_qa_r02.md`에 기록한다. 실제 Android 기기 검증은 수행하지 않는다.

## 독립 검토에서 반영한 수정

하단 행동은 y952, 높이80px로 올려 상하48px 안전 여백을 지킨다. 캐릭터 목록·상점·도감의 항목별 상세 연결과 장신구의 항목별 상세 연결을 선택 대상에 맞춘다. 장신구 이동·기술 필터를 열면 첫 해당 항목을 선택하며 선택 문구와 장착 문구를 구분한다. 일반 설정의 기본값 복원은 일반 설정 배경과 소리·화면 효과·접근성 복원 안내를 사용한다.

작은 캐릭터 초상은 승인 원화를 변경 없이 clip board에 넣어 얼굴과 상반신을 크게 보인다. 중앙 원화·친구·프로필의 큰 그림은 유지한다. 바이트 보존 원본 사본과 출처·SHA는 `approved-source/`와 자산 manifest에 있다.

`component-state-table.csv`는 공통 표면9종의 상태와 동작, `state-table.csv`는 전체81화면의 분류·배경·선택·팝업 행동을 기록한다. `control-coordinates.csv`와 실제 Penpot 검사 기록은 설계 좌표 및 연결 검증에 사용한다. `missing-assets.md`는 이번 전달 범위와 기존47개 미제작 요구를 구분한다.

## 출력 글자 검증과 이미지 이름

Penpot의 텍스트 내용 조회와 실제 SVG 글자가 다른 캐시 문제가 두 장신구 필터에서 확인됐다. 편집 가능한 새 텍스트를 같은 자리에 만들어 실제 렌더링 내용을 갱신했다. 캐릭터 특징과 장신구 효과는 의미 단위 두 줄로 정리하고 관련25화면 및상점6상세 설명을 다시 구성했다. 이전 숨긴 원본 도형은 건드리지 않았다. 조회값만으로 시각 확인을 통과 처리하지 않는다.

기존 요구표의 `IMG/*` 이름을 그대로 사용하고, 공식 이름이 없는 나비의 큰 원화와 유란의 디자인 미리보기는 `DESIGN/*` 별칭으로 구분한다. `source-slot-reference.csv`에는 기존 납품 경로와 승인 원본·보존 사본·해시를 함께 기록한다. 원본을 잘라 보이는 Penpot 미리보기는 공식 얼굴 PNG를 해당 납품 경로에 새로 만든 결과가 아니다.

상태표의 surface는 배경 면 컴포넌트다. 선택·보유·장착 문구 및 체크 표시를 별도의 편집 가능한 텍스트·벡터와 함께 사용한다.

## 메뉴 전용 경계 상태

빈 목록 예시는 팝업 뒤의 보유 카드4개를 제거한다. 선택 누락 예시는 큰 캐릭터 원화와 선택 값을 비우고 선택 안내를 표시하며, 배경의 플레이 행동을 사용 불가로 만든다. 이 두 작업용 상태는 정식 기본 화면과 기존 전투 공유 상태에 영향을 주지 않는다.

원본 13개 화면의 숨긴 도형은 새 메뉴 도형을 제외하고 원래 숨김 값으로 비교했을 때 변경 전 전체 도형 내용 요약값(FNV)과 도형 수가 모두 일치했다. 기준 파일과 실제 비교값은 `legacy-native-preservation.json`에있다.

## 최종 산출물 검사

실제 Penpot에서 기본 13개와 상태 68개를 확인하고, 해당 81개 프로토타입의 681개 활성 클릭 연결을 기록했다. 전체 846개 조작 영역에는 팝업 뒤에서 비활성인 영역과 사용 불가 상태도 포함된다. `control-coordinates.csv`는 원본 도형 ID·프로토타입 도형 ID·목적지 ID와 1920/1280 좌표를 함께 제공한다. 화면 이미지 매핑은 196행이다.

원본 536개 컴포넌트에 새 25개를 더했고, 새 화면에서 실제 컴포넌트 참조 1,352개를 확인했다. 원래 프로토타입 연결 287개, 범위 밖 원본 42개와 공식 화면 ID 24개가 유지된다. `final-audit.json`, `component-usage.json`, `delivery-audit.json`에 실제 파일 비교 결과를 남긴다. 전체 PNG는 최종 98개이며 파일별 SHA-256은 `export-hashes.json`으로 확인한다.

실제 Chrome 보기 모드에서 101개의 이름 붙인 검사를 수행했다. 로비 진입과 뒤로 복귀, 필터·목록 선택·상세 탭, 상점 팝업 닫기, 친구 선택, 설정 적용·취소·복원, 메뉴 전용 경계 상태를 확인했다. 랭크·도감과 기존 조작 설정은 원래 검토 목록으로 진입하며, 로비에 새 버튼을 추가하지 않는다. 기본 13개 화면 전부가 실제 검토에 포함됐다. 보드 선택창을 닫지 않아 썸네일을 누른 한 번의 검사 조작 실수는 `manualAttempts`에 보존하고 패널을 닫은 재검사 통과를 별도로 남겼다.

최종 영구 버전은 `프리미엄 메뉴 v07 · 81 원본과 프로토타입 · 최종 전달`이다. `penpot-final-save.json`의 저장 시각은2026-10-14T09:02:06.384Z이며 이후 실제 클릭 검토는 원본을 바꾸지 않았다. 기존 자산·개발 전달 페이지에 이번 작업 전용 보드5개를 추가했다. 기존 보드와 겹치지 않는 위치 및 실제 내용 조회는 `handoff-records.json`에 남겼다.
