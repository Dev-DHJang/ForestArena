# 메뉴 UI v07 제작 기록

## 대상과 배치

사용자가 승인한 어두운 프리미엄 메뉴 방향을 13개 로비 하위 화면에 적용한다. 로비·실행·플레이 준비·전투·결과는 보존한다. 공식 화면 ID, 1920×1080 설계와 1280×720 출력은 유지한다. 조작 설정의 미리보기는 비전투 메뉴의 표현이며 전투 입력 위치·동작을 바꾸지 않는다.

캐릭터는 목록/큰 원화/상세의 세 영역, 장신구는 4열 진열/선택 상세, 상점은 카테고리/추천/진열, 친구·미션은 목록/선택 상세, 설정은 분류/항목/설명으로 구분한다. 큰 녹색 카드 대신 낮은 채도의 숲 배경과 어두운 면, 얇은 금빛 선택선, 읽기 쉬운 글자를 사용한다.

원화는 승인 자현·묘령·나비·유란을 변경 없이 연결한다. 자산 그림과 조작 상태는 독립적이다. 별·등급·희귀도 단서는 없으며 가격·보상·성장 수치를 만들지 않는다. 친구 이름/접속·보유 표시는 기존 설계 예시임을 명시한다.

## 상태와 조작

`scene-spec.json`은 런타임 데이터가 아니라 Penpot의 편집 가능한 원본을 만들기 위한 작업 자료다. 기본 화면 13개와 메뉴 상태·상세·선택·탭 예시 57개다. 기본·주요 행동·보조 행동·선택·눌림·사용 불가·보유·장착·위험 표면 9개와 자체 벡터 아이콘 16개를 별도 컴포넌트 이름 공간 `Premium Menu v07`에 추가한다.

주요 터치 영역은 최소72×72, 안전 여백은 좌우96/상하48이다. 전환은 기본200ms로 만든다. 원본 화면의 v06 자식은 숨기고 보존하며 변경 전 Penpot 버전을 별도로 저장한다. 기존 프로토타입 연결 ID·목적지는 보존하고 대상 메뉴의 원본 이미지·클릭 위치를 갱신한다. 새 탭·선택·팝업은 별도 연결로 추가한다.

## 대표 화면 검토 1회차

상점·캐릭터 상세·일반 설정의 실제 Penpot PNG를 내보내 확인했다. 원화의 비율·배경 분리, 한국어 대비, 주요 버튼과 분류를 확인했다. 상점의 긴 안내를 짧은 세 줄로 줄였고 캐릭터 발과 겹치는 중복 이름을 제거했다. 나머지 메뉴는 이 수정 내용을 적용한다.

전체 적용·상태 예시·프로토타입·20:9 비교·별도 품질 확인은 작업 중이다. 실제 Android 기기 검증은 수행하지 않는다.
