## 화면과 수정 결과

한국어 제목·본문·안내, 선택 표시, 주요/보조/사용 불가 버튼의 구분을 확인했다. 최종 PNG에서 잘림·겹침·원화 비율 왜곡을 발견하지 않았다. 어두운 숲 공간과 낮은 채도의 패널, 금빛 선택선이 메뉴별 구조를 구분한다. 장신구 희귀도나 별 표시, 미정 가격·보상·성장 수치를 추가하지 않았다. 친구·보유 표시와 미래 기능 안내는 설계 예시 범위를 유지한다.

캐릭터 특징 설명은 의미 단위 두 줄로 정리됐다. 이전 나비·유란 설명의 잘림 의심은 확대 픽셀 확인에서 오판으로 정정했으며, 이 줄바꿈은 잘림 결함 수정으로 기록하지 않는다. 장신구 설명의 한 글자만 다음 줄에 남던 표현도 의미 단위로 정리됐다.

20:9 상점·캐릭터 목록·친구·일반 설정은 2400×1080 설계를 1600×720으로 출력했다. 가운데 메뉴 배치와 원화 비율을 유지하고 좌우 배경을 확장한다. 가운데 1280×720 영역은 일반 PNG와 완전히 같은 픽셀은 아니다. 다른 픽셀 비율은 약 0.011–0.605%, 최대 평균 채널 차이는 255단계 중 0.164이며, 직접 검토에서 읽기·배치 결함은 없었다. [실제 측정](qa-review/independent-checks.json)에 수치를 남긴다.

## 원본·연결·런타임 보존

- 공식 24개 화면의 ID와 1920×1080 크기가 변경 전 기록과 같다. 수정 대상 기본 13개 ID도 같다. 범위 밖 원본 42개는 실제 검사에서 변경 0개다.
- 대상 13개의 숨겨 보존한 기존 자식 도형은 전체 내용 요약값과 도형 수가 변경 전과 같다. [기존 원본 비교](legacy-native-preservation.json)를 확인했다.
- 기존 컴포넌트 536개를 유지하고 표면 9개·벡터 아이콘 16개를 더해 라이브러리는 561개다. 실제 새 화면의 컴포넌트 참조는 1,352개이며, 라이브러리 개수와 구분한다.
- 기존 연결 287개의 ID·목적지·동작·전환을 포함한 기록 전체가 변경 전과 일치한다. 새 활성 연결 681개와 합쳐 총 968개다. 전체 조작 영역 846개를 이름·좌표·목적지별로 대조했다. 팝업 뒤와 사용 불가 영역은 연결이 없고, 활성 연결은 클릭 및 200ms 전환을 사용한다.
- 자산 22개의 SHA-256, 승인 캐릭터 4개의 사용자 작업 원본·보관 사본·manifest SHA가 같다. 사용자 작업 원화를 설계에 연결한 출처 맥락을 유지했으며 develop의 런타임 원화를 교체하지 않았다.
- 주 작업 폴더와 격리 작업 폴더 각각의 기준 파일 5개는 비교 SHA가 같다. 최신 develop `403b0b61758ca5e619ec923063b0bf9d2faea7cb` 대비 격리 작업 차이는 설계·문서·작업 자료다. 이것은 다른 사용자 작업 전체를 보존했다는 포괄적 주장이 아니다. [최종 해시 검사](qa-review/preservation-hashes.json)를 참조한다.

## 실제 조작 증거의 해석

현재 보기 모드 화면 순서는 원본 루트 배열의 역순이다. 123개 보드에서 `viewer index = 122 - nativeRootIndex`이며, URL의 `frame-id`는 최초 진입 화면으로 남는다. [화면 목록](prototype-frame-index.json)의 실제 ID와 현재 화면 이름·index를 함께 대조했다. 101건 모두 기대·관찰 화면과 일치한다. 자동으로 확인한 전체 681개 연결과 사람이 조작한 101건은 서로 다른 증거다.

빈 목록의 첫 시도는 보기 모드의 보드 선택창을 닫지 않아 썸네일을 눌렀다. 원래 실패와 원인을 `manualAttempts`에 보존했고 `V07-STATE-02R`에서 실제 화면 버튼을 재검사해 통과했다. Penpot 원본 수정 없이 해결된 검사 조작 실수다.

## 코드 검사와 한계

최신 develop을 반영한 격리 작업 폴더의 기본·문서·리소스 검사는 모두 종료 코드 0이다. 기본 검사에는 `SCRIPT ERROR` 0줄, 종료 때 리소스가 남았다는 `ERROR` 8줄과 `WARNING` 12줄이 있다. 이전 초기 검사 수치 9/13과 구분하며 오류·경고가 없었다고 기록하지 않는다. [최종 검사 기록](checks.json)의 `final_worktree_checks`와 `verify-worktree-final.log`, `verify-docs-worktree-final.log`, `verify-resources-worktree-final.log`를 확인했다.

배경 원본은 1672×940–941이며 1920px 원본으로 보고하지 않는다. 1920×1080 설계 출력과 원본 해상도를 구분한다. Android 실기기 터치·가독성·성능 검사는 수행하지 않았다. 자동 검사에 Android라는 이름의 테스트가 있어도 실제 기기 통과를 뜻하지 않는다. 이 pass는 Penpot 설계·전달 범위에 대한 판정이다.
