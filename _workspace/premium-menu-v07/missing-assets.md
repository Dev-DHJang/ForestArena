# 미제작·원본 해상도 기록

이번 메뉴에서 사용하는 배경6개·자체 벡터 아이콘16개는 모두 제작했다. 승인 캐릭터4개는 사용자 작업 폴더의 원본을 변경 없이 Penpot에 올렸다. 원화의 바이트 보존 사본은 `approved-source/`이며 자산 manifest에 원본·사본 경로와 SHA-256을 함께 기록했다. 이 사본은 Godot 자산 교체나 런타임 등록이 아니다.

`missing-assets-baseline.csv`의 47행은 이전 v06 전체 자산 요구표의 미제작 목록이다. 이번 메뉴에서 쓸 새 버전 배경과 벡터를 만들었다고 해서 이 원래 납품 경로의 상태를 완료로 바꾸지 않는다. 공식 전체 이미지 슬롯 요구표와 새 디자인 별칭은 별도로 유지한다.

배경 원본은1672×940–941이다. 생성 도구에1920px이상을 요청했지만 실제 출력은 그보다 작다. 1920설계에서는 비율을 유지해 표시하고1280PNG로 검토한다. 큰 장신구 그림은 이번에 작성한 벡터 기능 그림을 사용하며, 별도의 장신구 채색 원화·등급 장식은 제작하지 않았다.

친구·랭크·미션·보유 상태는 디자인 예시다. 미정 가격·보상·성장 수치와 온라인·저장 기능은 만들지 않는다. Android 실기기 검사는 실행하지 않았다.
