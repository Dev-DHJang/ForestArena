# 조율 기록

- 깨끗한 작업공간: `feature/penpot-full-ui-ux`, 기준 `origin/develop`의 `5118dcb`.
- Penpot 파일: `Personal Projects / Forest_Arena / Forest_Arena_UI`.
- 새 조직은 Enterprise 구독 화면으로만 만들 수 있어 결제를 진행하지 않았다.
- 로컬 MCP: manifest·plugin.js가 터미널에서는 200으로 응답한다. Penpot 플러그인 관리자는 `localhost`와 `127.0.0.1` URL을 유효하지 않은 플러그인으로 거절했다. 자동화 브라우저도 localhost를 차단했다.
- 재개: 사용자의 로컬 Penpot 브라우저에서 `http://localhost:4400/manifest.json`을 직접 설치해 연결하거나, 접근 가능한 HTTPS MCP 플러그인 URL을 제공한다.
