# 요청: 쉬운 문장 규칙과 문서 구조 정리

## 목표

- 앞으로 만드는 문서와 작업 기록에서 가능한 쉬운 용어를 먼저 사용한다.
- 목적을 모르면 파일을 찾기 어려운 현재 `docs/` 구조를 역할별 폴더로 정리한다.
- 한 문서에서 전체 문서 위치, 읽는 순서와 최종 기준 파일을 찾을 수 있게 한다.

## 현재 단계

Phase 2 완료 상태를 유지한다. 이 작업은 문서 위치와 작성 규칙만 바꾸며 게임 기능과 제품 규칙은 바꾸지 않는다.

## 범위

- `docs/`의 제품, 게임플레이, 공용 데이터 형식, 엔지니어링, 콘텐츠, UI, 작업 운영 문서를 목적별 폴더로 이동한다.
- `docs/INDEX.md`를 문서 탐색의 시작점으로 추가한다.
- README, AGENTS, 스킬, 검사 스크립트와 문서 내부의 이전 경로를 모두 새 경로로 바꾼다.
- 쉬운 문장 원칙을 AGENTS와 AI 개발 가이드에 넣고 자동 검사를 추가한다.

## 제외

- 게임 코드, Godot 장면, 이미지·소리와 데이터 내용 변경
- Phase 범위, 전투 규칙과 ADR 상태 변경
- `_workspace` 과거 작업 기록의 역사적 경로 일괄 변경

## 반드시 지킬 조건

- 공용 JSON 파일의 내용과 ID는 바꾸지 않는다.
- 이동 뒤 모든 활성 문서, 스킬, 코드와 검사가 새 경로를 사용해야 한다.
- 과거 `_workspace` 기록은 당시 상태의 감사 자료이므로 수정하지 않는다.
- 새 문서는 쉬운 표현을 먼저 쓰고 필요한 전문 용어만 `docs/GLOSSARY.md`로 연결한다.

## 완료 판단 조건

- `docs/INDEX.md`에서 목적별 문서와 권장 읽기 순서를 찾을 수 있다.
- `docs/` 최상위에는 시작 문서와 용어 가이드만 남는다.
- 활성 파일에서 이동 전 경로 참조가 발견되지 않는다.
- 기본 검사, 하네스 검사와 문서 구조 검사가 통과한다.
