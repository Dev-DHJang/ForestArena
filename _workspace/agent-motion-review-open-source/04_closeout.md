# 모션 검토·오픈소스 역할 작업 결과

## 결과

- 별도 중복 역할 대신 기존 QA에 행위 표현 검토를 통합했다. 전체 프레임·정상/느린/반전/소형 재생·실제 프레임 선택·공격 단계·차지 맥락과 파일 해시를 확인한다. 자동 검사는 근거 누락·변경·허위 통과를 거부하며 그림 의미는 독립 검토자가 판단한다.
- 오픈소스 활용 역할을 추가해 공식 원본·이용 조건·버전·유지보수·호환성을 조사하고 격리 시험 후 담당 개발 역할과 반영하도록 연결했다. ADR-034와 활성15역할 명세를 갱신했다.
- 현재 로컬 승인 모션120종: pass92/fix22/redo6. 문제28종은 재생 제안13종과 새 원화15종(19회차)으로 전달했다. 최종 시안 검토·잔여 문제는 `03_qa_motion_r01.md`와 `qa-drafts-final.json`에 있다.
- 모션별 사용자 승인 전이므로 새 시안은 게임에 등록하지 않았다. 나비/유란 달리기와 유란 연계2타는 두 회차 뒤에도 미해결이며 제작 접근 재분류가 필요하다. 새 그림19개 모두 정규화·셀 경계 재검사가 남아runtime-ready=false다.
- 기존 Pillow 재사용을 비교·시험했고 알려진 문제 수정 버전13.0.0을 개발 전용 requirements에 고정했다. 기존 Python 설치나 Android 의존성은 변경하지 않았다.

## 검증

- 최신 코드의 모션 도구 자동 검사25개 통과(Pillow13.0.0 격리 환경).
- `./scripts/verify.sh` 통과: `verify-final.log`. 로그의 기존 Godot 종료 시 리소스 경고와adb 미연결은 별도 기기 검사 통과를 뜻하지 않는다.
- `verify-docs.sh`, `verify-harness.sh`, Godot 리소스 검사와`git diff --check` 통과. 활성15역할·논리자산519개 확인.
- 독립 도구 QA4회차: `03_qa_harness_r01.md`~`r04.md`. 재수집한 통합r05는120모션·idle240/run160samples와 해시 일치 확인.
- 원본243파일 해시 불변. 원본 검토 자료의 무결성 검사는 통과하지만`--require-pass`는 기존28문제를 이유로 정상 실패한다. 이 결과를 모션 전체 통과로 쓰지 않는다.
- 원본 검토는 요청 시점 로컬 수정 자산을 대상으로 했다. PR 기준 develop의 원화와 다르므로 검토용 PNG 사본을`review/sheets/`에 보존했다. 게임 자산 경로는 바꾸지 않았다.
- Android 실기기 검사는 하지 않았다.

## 버전 관리와 되돌리기

- 기준: origin/develop `42eda52`, 작업 브랜치`codex/motion-review-open-source`.
- 사용자 작업 폴더와 분리한 managed worktree에서 관련 변경만 commit·push한다. 원본의 다른 변경은 보존한다.
- PR·실제 병합 SHA는 원격 병합 확인 뒤 이 파일에 추가한다.
- 되돌리기: 구현 PR의 병합 커밋을`git revert -m 1 <merge-sha>`로 되돌리고 일반 PR 절차를 따른다. 이미지 원본·승인 기록은 이 작업에서 변경하지 않아 별도 복구가 필요 없다.

## 다음 작업

사용자가 실제 교체를 원할 때 모션별 시안을 선택·승인하고, 미해결 그림/설계는 재분류한 제작 방식으로 정리한다. 정규화 후 독립 검토와 게임·기기 확인을 다시 수행한다. 이 후속 제작을 에이전트/검토 도구 구현 완료와 혼동하지 않는다.
