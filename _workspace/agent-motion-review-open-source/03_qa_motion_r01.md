# 기존 모션과 수정 제안 검토

- 기준: 요청 시점 원본 작업 폴더의 승인 모션120종, 전체1920프레임. 통합 브랜치 원화와 다른 현재 로컬 자산임을 `01_source_snapshot.json`에 고정했다.
- 최종 기존 모션 판정: **pass92 / fix22 / redo6**. 원문 기대 행위·공격 단계·실제 선택 프레임·근거와 각 파일 해시는 `review/motion-review.json`에 있다. 비교판과 정상/느린/반전/소형 미리보기를 확인했다. metadata만으로 의미 통과를 정하지 않았다.
- `timeline-r05.json`은 완전한 반복2주기, 실제 차지 해제 최소12/최대90tick의3방향을 포함한다. 시험으로 강제 유지한 상태 시간이며 실제 경기 수명·경로를 재현한 검사는 아니다.
- 수정 대상28종을 기존 승인 프레임 재배치13종과 새 그림15종(19개 회차)으로 모두 연결했다. 원본과 모든 실패 시안을 보존했다.
- 독립 원화 검토: `qa-drafts-*.json`. 부모 재생·소형 확인: `qa-drafts-final.json`. `drafts/index.html`과 `drafts/sequence-proposals.html`로 비교할 수 있다.
- 새 그림 중 나비 달리기·유란 달리기·유란 연계2타는 두 회차 뒤에도 발 교대·전방 꼬리 방향 문제가 남았다. 두 번의 생성으로 해결되지 않아 제작 접근 재분류를 기록했다. 자동 반복으로 통과시키지 않았다.
- 일부 균등 셀 미리보기에는 이웃 셀 조각이 보인다(묘령 중립 필살기13, 나비 아래 필살기r02 회복12, 유란 달리기r01의7). 새 그림19개는 모두 미정규화 제작 시안이며 runtime-ready=false다. 원화 부분 개선과 게임 적용 가능 판정을 분리한다.
- 차지4종·나비 아래 필살기·유란 옆 필살기의 설계 불일치는 사용자 결정 전redo를 유지한다. 모션별 승인·128px 셀 정규화·적용 후 게임 재검사는 후속 작업이며 이번 요청의 에이전트/검토 도구 구현 완료와 구분한다.
- 요청 시점 PNG/SpriteFrames·manifest·전투 계약·표현 코드 총243파일 해시가 그대로임을 재확인했다. Android 실기기 통과를 주장하지 않는다.
