# 요청과 작업 범위

- 요청: 계획 구현. 기존 QA에 모션 행위 표현 검증을 통합하고 오픈소스 조사·비교·시험·반영 역할을 추가한다.
- 현재 단계: Phase 6. 기존 온라인 예외와 자산 승인 규칙 유지.
- 기존 네 캐릭터 120종을 현재 파일 해시 기준으로 전체 검토하고 문제 모션의 수정 시안까지 제작한다. 게임용 이미지 교체는 모션별 사용자 승인 뒤 별도 진행한다.
- 외부 도구는 실제 개발 필요가 있을 때 조사한다. 이번 작업에 특정 라이브러리 도입 의무는 없다.
- 산출물: 스킬·운영 문서·검사 도구·자동 테스트, 전체 모션 검토 자료와 결과, 수정 시안과 재검토, 별도 QA, 마무리 기록.
- 검사: verify-harness, verify-docs, verify, Godot 자산 검사와 도구 테스트. Android 실제 기기 검증과 구분한다.
- 기존 미커밋 변경은 보존한다. 최신 origin/develop 작업 폴더에서 이번 변경만 PR·검토·develop 병합한다.
