# 2회 시안 QA — fix 유지

- 로컬 알파 정리 승인 답변이 없어 실행하지 않았다. 허용된 내장 이미지 편집만으로 자현 r02의 그림 크기와 배치를 보완했다.
- 자현 r02는 실제 그림(alpha 8 이상)이 `(161,173)~(853,1347)`에 들어가므로 전신의 위치·여백이 개선됐다. 얼굴·귀 2개·꼬리 1개·주머니와 후드에 손을 둔 자세를 유지했다.
- 그러나 alpha 1 이상을 전부 세면 `(127,121)~(996,1536)`으로 캔버스 아래 끝까지 미세한 잔여물이 남는다. 따라서 48px 완전 투명 여백 검사는 계속 실패한다. 눈에 잘 안 보인다는 이유로 검사 기준을 낮추지 않는다.
- 같은 내장 편집을 다른 세 캐릭터에 반복하면 이 문제가 해결된다는 증거가 없어 반복 생성을 중단했다. 기존 시안과 새 자현 r02는 모두 보존했다.
- 현재 선택은 자현 r02·묘령 r02·나비 r01·유란 r01이다. 사용자 최종 승인 및 등록은 아직 없다.
- 구조 검사에서 같은 파일/같은 해시를 네 캐릭터에 반복 연결하는 경우와 잘못된 참조 ID/원본 해시를 추가로 거부하도록 보완했다. 시각 유사도나 사용자 승인을 자동 판정하는 검사는 아니다.
- 재개에는 사용자의 로컬 규격 정리 허용 여부와 이후 네 최종 후보별 승인이 필요하다. 기존 게임 자산·manifest·외형 JSON·모션은 이번 작업에서 변경하지 않았다.
