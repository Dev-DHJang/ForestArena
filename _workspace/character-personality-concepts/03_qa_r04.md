## 데이터·코드 검토

- `approval.json`의 채택 승인과 정확한 네 이미지 해시가 고정된 `normalized-candidates.json` 해시 `65e21cdfade2232ac7cba52876a3252066f4ef6a6b72e1d151ca95e197bb0129`에 연결된다. 후보 보고서의 과거 `user_approved:false`를 덮어쓰지 않고 별도 승인 기록을 사용한다.
- manifest는 기존 항목의 순서·값을 유지하고 마지막에 `concept-variant/personality` 네 항목만 추가했다. 기존 `type=concept` 네 항목과 CharacterData 대표 참조는 유지한다. 각 추가 자산의 대표 참조·해시·디자인 기록 연결을 확인했다.
- 외형 JSON은 기존 네 캐릭터 profiles가 HEAD와 동일하다. 포즈 예외는 이름을 명시한 추가 정지 이미지 네 장에만 적용되고 신체·의상·종 특징과 금지 외형은 유지한다. 전투 모션과 기존 대표 이미지를 완화하지 않는다.
- `installation.json`의 기존 파일 보존 목록은 2,115개다. 설치 검사에서 해시를 재확인했다. Git 변경 목록에서 기존 대표 PNG, CharacterData, 모션, 전투·UI 구현 파일 교체는 없었다.
- 기존 보존 도구 두 개는 추가 항목을 무조건 제외하지 않는다. 정확한 네 항목의 내용·승인·실제 PNG 해시를 확인한 뒤에만 역사적 manifest 비교에서 분리한다. 부분 등록·알 수 없는 항목·중복·수정된 해시/참조는 거부한다.

## 발견 사항과 재검사

최초 구현의 설치 검사에서 신규 네 manifest 항목을 모두 제거해도 PASS가 되는 누락을 발견했다. 실제 파일은 바꾸지 않고 읽기 함수에 메모리 가짜 입력을 연결해 재현했다. 담당자가 설치 검사에 정확한 네 항목 존재 검사를 추가하고 전체 삭제 실패 테스트를 만들었다. 수정된 코드와 새 테스트를 다시 읽고 실행해 해결을 확인했다. 역사적 helper의 설치 전 0개 허용과 실제 설치 완료의 4개 필수 조건은 분리되어 있다.

독립적으로 다시 실행한 명령:

- `python3 tools/forest_arena/test_personality_registration.py`: 9개 PASS.
- `python3 tools/forest_arena/install_personality_concepts.py`: PASS.
- `godot --headless --path . --script res://tests/character_personality_concept_contract.gd`: PASS. 네 PNG의 Godot Texture2D 가져오기와 기존 CharacterData 참조를 확인했다.
- `git diff --check`: PASS.

전체 `./scripts/verify.sh`, 문서 검사, Godot 리소스 전체 검사, PR 검토·병합은 담당자의 최신 실행 결과와 마무리 기록으로 별도 확인해야 한다. 이 기록은 실행 중인 전체 검사를 미리 통과로 기록하지 않는다.

## 부록 — 생성 원본 확인 강화 재검토

최종 소규모 강화에서 `approved_report()`가 보고서의 `raw_source_path`를 실제 경로로 확인해 이 작업의 `03_drafts/` 안에만 있도록 제한하고, 실제 원본 파일 SHA-256을 `raw_source_sha256`과 비교하는 코드를 직접 읽었다. 승인된 출력 PNG만이 아니라 생성 원본까지 추적할 수 있도록 한 검사이며 런타임·manifest·외형을 바꾸지 않는다.

변경된 원본 해시를 가짜 입력으로 제공하면 거부되는 새 테스트를 확인했다. `python3 tools/forest_arena/test_personality_registration.py`를 독립 재실행해 **10개 PASS**, `python3 tools/forest_arena/install_personality_concepts.py`도 다시 **PASS**였다. 위의 9개 결과는 이전 재검사 당시의 사실로 남긴다. 전체 검사 실행 결과는 이 부록의 범위가 아니며 여전히 담당자의 완료 로그로 별도 확인한다.
