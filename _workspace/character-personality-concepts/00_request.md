# 차분한 비전투 개성 콘셉트 4종 추가

- 사용자 요청: 각 캐릭터마다 전투 포즈가 아닌 개성에 맞는 콘셉트 한 장씩 추가한다.
- 확정 선택: 더 차분하고 성숙하게. 체형·노출·3등신 비율을 바꾸지 않고 자세와 미세한 표정으로 표현한다.
- 자현: 한 손 주머니·다른 손 후드 가장자리, 조심스러운 미소. 묘령: 양손 몸 앞에 모으고 주변을 살피는 차분한 표정. 나비: 한 손 허리·다른 손 머리카락, 여유로운 미소. 유란: 팔짱·자연스러운 체중 이동, 침착하고 자신 있는 시선.
- 최종 출력: 캐릭터별 1024×1536 실제 투명 RGBA PNG, 전신과 최소 48px 여백. 추가 소품·무기·배경·문구 없음.
- 기존 대표 콘셉트·CharacterData·모션·전투·UI는 보존한다. 신규 이미지는 concept-variant/personality이며 사용자 승인 후에만 assets와 manifest에 등록한다.
- 먼저 검토 시안과 QA 자료를 만든다. 시안 제작 요청은 최종 시안의 사용자 승인으로 간주하지 않는다.
- 최종 단계는 새 검증·전체 검사·문서·Godot 리소스 검사·원격 PR 검토와 develop 병합이다. Android는 기존 사용자 결정대로 이연한다.
