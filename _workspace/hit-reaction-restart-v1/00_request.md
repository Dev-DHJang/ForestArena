# 피격 모션 재진입

사용자 요청: 이전 동작에서 피격 자세로 들어간 뒤 마지막 피격 자세까지 표시하고 idle로 돌아온다. 이미 피격 모션을 표시하는 중에도 새 타격이 들어오면 이전 모션 완료를 기다리지 않고 피격 모션 첫 프레임부터 다시 시작한다.

## 구현 범위

- 피격 표현의 재생 시간만 변경한다. 피해, 경직 시간, 위치, 승패와 LAN 메시지 형식은 변경하지 않는다.
- 같은 상태에서 경직이 늘거나 줄거나 같아도 실제 새 타격을 구분한다.
- 무효·가드·갑옷 판정은 새 피격으로 취급하지 않는다. 가드 파괴는 별도 피격 진입이다.
- 새 모션 이미지나 승인되지 않은 캐릭터 자산을 등록하지 않는다.
- 현재 자현 특수기 녹화의 파일 해시 고정이 끝날 때까지 기존 제품 파일은 수정하지 않는다.

## 검사

실제 FighterController.apply_hit와 HitResolver 경로, 같은 상태의 연속 타격, 경직 종료, 재시작·프로필 교체, 기존 LAN hit_resolved 이벤트 전달과 반복 이벤트 처리를 자동 검사한다. 시각 표시 전후 전체 전투 snapshot이 같은지 검사한다. Android 실기기 결과로 기록하지 않는다.
