# 피격 모션 재진입 마무리

## 변경

연속 피격에서도 매 타격마다 첫 피격 그림으로 다시 시작하도록 수정했다. 로컬 일반 피격은 실제로 정해진 경직 시간 안에 마지막 그림까지 표시하고, 전투 상태가 idle로 돌아오면 즉시 idle을 표시한다. 피해·경직 길이·승패·LAN 메시지 형식은 변경하지 않았다. 새 이미지나 승인되지 않은 모션 자산은 등록하지 않았다.

기존 상태가 같고 공격 activation_serial도 바뀌지 않으면 재생 시간을 다시 시작하지 않던 원인을 실제 `apply_hit`로 재현했다. 변경 전 80검사 중6실패 기록은 `qa/before-r01.log`에 있다. 변경 뒤 확장한 `tests/hit_reaction_presentation.gd` 330검사가 통과했다. 기존 상태 모션 검사 430·53검사와 두 캐릭터 표시 검사도 통과했다.

## 전달과 남은 확인

제품3파일과 새 검사를 조율 역할에 전달했다. `verify.sh` 새 검사 연결, 독립 검토, 최종 통합 검사와 브랜치/PR109 전달은 조율 역할이 수행한다. 자현 특수기 효과 코드는 이 역할에서 변경하지 않았다. 원래 미커밋 변경은 보존했다.

LAN3에는 남은 경직 시간이 없으므로 기존 HIT 이벤트로 첫 프레임 재진입을 알리고 기존 모션 속도로 표시한다. LAN의 정확한 전체 피격 그림 종료 시점은 서버 상태 변경에 따른다. UI가 경직을 계산하지 않는다. 기존 단일 WebSocket 순서를 확인했고 지연/중복 이벤트 처리도 자동 검사했다. 실제 Android 기기 확인 또는 새 LAN 실제 연결 통과로 기록하지 않는다.

자세한 파일과 확인 범위는 `02_2d_animation.md`를 따른다. 목표 전체 완료나 병합 완료를 뜻하지 않는다.


## 통합 검사 및 촬영

현재 제품의 승인된 runtime만 읽는 실제 연속 피격 촬영을 추가했다. `runtime-only-catalog.json`의 assets는 비어 있으며 후보 그림을 덮어 넣지 않는다. `render-live.gd`는 실제 전투와 같은 순서로 물리 계산 뒤 공개 `apply_hit`를12/18틱에 호출한다. 두 캐릭터 모두 진행 중인 피격에서 첫 그림으로 돌아가고33틱 마지막 그림 다음34틱에idle로 돌아온다. headless사전 검사는500개/2장면, 정상/반전소형 실제 촬영은각740개/2장면을 통과했고240RGBA전체를 무손실 보존했다. `qa/independent-r02/`에독립픽셀검토의중간자료가있으며최종기록은직접재생확인뒤남긴다. 이 자료는공격판정상자의실제적중이나실기기검증을뜻하지않는다.

`qa/lan-runtime-r01.log`에서현재버전의실제루프백연결·재접속·결과전달이통과했다. 전체verify-integrated-r01 실행은 프로세스와도구handle81586이사라졌음을재확인했으며완료문구가없는중단자료다. 제품8파일의SHA는시작목록과동일했다. 동일소스의r02전체검사를새로시작했고완료전통과로기록하지않는다.


## 최신 검증 결과

`03_qa_r01.md`는 독립 코드·자동 검사 통과, `03_qa_r02.md`는 승인된 runtime 두 캐릭터의 정상·반전/소형 실제240틱 및 정상/느린 재생 표본 검토 통과다. 실제 픽셀에서도 진행 중인 피격의 첫 그림 재진입과 마지막 자세 다음의 대기 복귀를 확인했다. 새로운 그림을 승인하거나 설치한 작업은 아니다.

`qa/verify-integrated-r02.log`의 전체 `verify.sh`가 exit0과 최종 통과 문구로 완료됐다. 시작 시 고정한 제품/검사8파일 해시가 끝에도 일치하고 SCRIPT ERROR/FAIL/Traceback이 없음을 `qa/verify-integrated-result-r02.json`에 기록했다. 같은 버전의 LAN 실제 루프백 연결·재접속·결과 전달, Godot 리소스519개·품질 변형25개, 문서와 하네스 검사도 포함됐다. 메뉴 자동 검사가 만든 시각/프로필ID 차이만 원래 보고서로 되돌렸다.

이 작업의 피격 재진입 구현·로컬 픽셀 검토는 완료했다. 나비 추가 VFX·남은 모션 승인/등록과 PR109 전체 검토·병합은 상위 목표에서 계속한다. 물리 Android 기기의 읽기 쉬움·터치·중단/복귀와 실제 LAN 기기 영상은 통과로 기록하지 않는다.
