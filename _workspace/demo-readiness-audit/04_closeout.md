# 데모 출시 점검 마무리

- 작성 시작: 2026-10-09. 중단 후 재개: 2026-10-10.
- 산출물: [APK 직접 설치 데모 출시 점검](../../docs/product/demo-readiness-audit.md).
- 결과: 무료 APK 직접 설치·게스트 로그인·닉네임·로컬 서버 한 대·동일 네트워크라는 지정 조건에 맞춰 부족 항목 12개를 정리했다.
- 핵심 부족: 게스트 세션과 LAN 참가 통합, 닉네임 입력·검증·표시, 같은 네트워크 제한, 배포 APK·서버 묶음, 두 물리 Android 기기의 전체 흐름.
- 제외: 결제·스토어·AAB·공용 인터넷·전체 성장·Story를 데모 출시의 필수로 추가하지 않았다.
- 미정: 온라인 참가 인원·동시 경기 수, 게스트 유지 기간, 닉네임 정책, 데모 콘텐츠. 1대1 한 경기는 기존 구현을 바탕으로 한 임시 점검 기준이다.
- 기존 서비스 점검과 중앙 색인에 데모 점검 링크를 연결했다. 최신 장신구 결정도 참고하도록 연결했다.

## 검증

- 중단 전 기본 검사는 `t: command not found`로 종료되어 전체 통과가 아니다. 원본 로그를 보존했다.
- 제한된 환경의 기본 검사 재실행은 사용자 설정·로그 폴더 접근 실패 후 종료 코드 134로 멈췄다. [로그](verify-resume.log). 코드 검사 통과로 처리하지 않았다.
- 현재 버전의 기본 검사를 필요한 접근 권한으로 다시 실행해 통과했다. 종료 코드 0, `Forest Arena verification passed.` 확인. [로그](verify-resume-authorized.log).
- 최종 문서 검사: 통과, 종료 코드 0. [로그](verify-docs.log).
- 구체적 결과와 제한은 [근거 재검토](03_qa_r01.md)에 연결한다.
- 검사 종료 시 객체 잔류와 테스트 원본 이미지 읽기 경고는 남아 있다. 실제 APK·기기·반복 경기 확인 항목으로 유지한다.
- 이번 작업은 문서 점검이며 게스트·닉네임 기능 구현 또는 데모 배포 완료 판정이 아니다. 신규 기기·운영 환경 시험은 수행하지 않았다.

## 버전 관리

기존 작업 폴더의 코드·자산·문서 변경은 보존했다. 코드 수정, commit·PR·원격 병합은 하지 않았다. 점검 문서와 작업 기록만 작성·갱신했다.
