# 데모 범위 점검

- 사용자 지정 조건은 [데모 점검 원본](../../docs/product/demo-readiness-audit.md)에 기록했다.
- 12개 부족 항목과 온라인 규모별 추가 조건을 정리했다.
- 현재 LAN은 익명 방 접속이며 개발 게스트 API와 자동 생성 표시 이름은 닉네임 설정 기능이 아니다.
- 동일 네트워크 제한은 사설 IP 검사와 구분했다. 서버 한 대와 단일 경기 조건도 구분했다.
- 유료 결제·스토어·공용 인터넷·전체 Story를 데모 필수에서 제외했다. 해당 제외는 정식 서비스 로드맵을 삭제하는 결정이 아니다.
- 신규 ADR 승인, 데이터 형식 변경, 코드 구현과 Phase 변경은 수행하지 않았다.
