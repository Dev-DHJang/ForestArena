# 요청

공격 속도와 입력 기회를 조정해 콤보를 안정화하고, 피격 경직과 캐릭터 겹침·발 높이를 고친다. 경기장은 폭 2,160의 비대칭 다층 구조로 확장하며 이번 변경에서는 충돌과 일치하는 임시 도형을 사용한다.

## 확정 기준

- 기본 연계 중간타는 22 tick이며 회복 시작 2 tick 전부터 다음 입력 하나를 예약한다.
- 경직은 다음 공격이 실제로 이어질 수 있는 길이로 공격별 조정한다.
- Pushbox 분리는 고정 tick 결과이며 시각 프레임과 무관하다.
- 플레이어 중심 1.25배 카메라와 화면 밖 상대 화살표는 유지한다.
- 실제 Android 기기에서 확인하지 않은 항목은 미확인으로 기록한다.
