# 표현 구현과 원화 사용

## 실제 착용물

자현의 승인 원화와 프리미엄 메뉴에 복제된 같은 PNG는 SHA-256 `a4dcff0f9fdeb592ee86a209603c5dc97ca059f2a461b7f61576b1acf3ce3311`로 같다. `ForestArenaResources`의 기존 논리 ID `fa.ui.menu.v07.character.ja-hyun`에서 읽는다. 원본 PNG·manifest·후보 PNG는 수정하지 않는다.

원화 왼쪽 착용 목도리의 청색 천·흰 인쇄를 UV(이미지에서 읽을 좌표)로 삼각형 망에 표시한다. 새 광선·별도 장비를 만들지 않는다. 표면은 천처럼 넓고 비틀리며 끝이 가늘어진다. 독립 QA가 UV 단면 사이 모든 픽셀이 alpha255임을 확인했다. 후드·투명 배경이 섞인 초기 좌표는 폐기했다.

## 본체와 연결

- 공중 강은 프레임별 공격 손에 연결한 한 가닥이며 위에서 오른쪽 아래로 내려친다. 나머지 착용 천은 원래 그림을 쓴다.
- 특수는 프레임별 목 뒤 착용부와 두 꼬리 방향을 따르며 좌우·위 동작을 표시한다. 머리에 고정한 대칭 부속 형태는 폐기했다.
- 준비에는 이 두 기술의 원래 천만 보인다. 공격 후 대기 시작 뒤7tick 안에 표면 잔상이 감쇠하고 피격·취소·공격 종료 시 즉시 지워진다. 이 수치는 표시 수명이며 공격 후 대기나 경직을 바꾸지 않는다.
- 나비 공중·지상 강은 아래에서 위로 움직이는 끝이 가는 세 발톱 곡선으로 표시한다. 준비에 정지 광선을 띄우지 않는다. 공용 함수를 쓰는 공중 약·특수도 함께 검토한다. 특수의 실제 마지막4판정tick을0..1 진행률로 표시한다.
- 없는 모션을 idle로 대신 표시할 때는 해당 공격 효과를 붙이지 않는다. 새5모션의 runtime 등록은 기존 승인 절차 뒤에 진행한다.

## 기록

VFX 코드는 전투 데이터를 읽기만 한다. 각 천은66개 정점·64개 삼각형과 두 외곽선으로 그린다. Canvas 그리기 명령이 참조하는 망은 다음 redraw까지 보관한다. 실제 Android 성능은 미확인이다.

`vfx-r01/r02`는 독립 QA fix, `r03`은 중간 확인이다. `r04`에서 공중 강의 아래 끝을 확인하기에 촬영 위치가 낮아 `r05`는 공중 기술만80px 위에서 찍는다. 이는 촬영 장면 위치만 바꾸며 전투 코드를 바꾸지 않는다. 최종 자료는 `review/vfx-r05`와 그 아래 `mirror-small`이다. 합성 상태의 실제 표현 코드 재생이며 실제 경기 영상으로 부르지 않는다.
