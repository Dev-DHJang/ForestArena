# 공격 효과 품질 개선

2026-10-21 사용자 요청: 자현 공중 강·좌우위 특수와 나비 공중 강 올려치기의 효과 품질을 높이고 실제 착용한 목도리를 사용한다.

기존 PR #109의 후속 수정이다. 원본 작업 폴더의 미커밋 변경과 이전 모션 QA·영상은 보존한다. 공격 시간·판정·피해·LAN 형식은 바꾸지 않는다. 승인 원화의 목도리 부분을 읽어 천의 무늬·명암을 재사용하고 몸의 착용 위치에 연결한다. 나비는 아래→위로 휘어지는 세 갈래 발톱 잔상을 준비·판정·회복에 맞춘다.

검사: 실제 표현 코드 영상, 좌우 반전, 작은 화면, 준비/판정/회복·중단, 전투 상태 불변 자동 검사, 독립 QA, 기본 검사·문서·리소스 검사. Android 실기기 미실행. 승인 전 새 모션 PNG는 runtime·manifest에 등록하지 않는다.
