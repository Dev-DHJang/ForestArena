## 배치·상태·해상도

로비: 프로필 왼쪽 위, 설정 오른쪽 위, 승인 투명 PNG 중앙 648,124 / 552×736. 하단 메뉴는 x128+184i, y864, 168×144, 아이콘 96px, 간격 16px. 플레이 1328,888 / 464×120. 미션은 왼쪽 분류·중앙 목록·오른쪽 설명이며 진행 0/1·1/3·2/5는 설계 예시다.

기본·눌림·선택·사용 불가는 표면 높이·명암·테두리·체크로 구분한다. 눌림 80ms, 복귀 120ms, 패널 180ms를 전달 의도로 유지한다. 크기 조절은 모서리·선 두께를 보존하며 조작 설정은 크기·투명도·기본값 복원만 제공한다.

1920×1080에서 논리 1280×720로 2/3배 변환한다. 전투 안전 영역 x125–1795/y54–1026. 20:9는 2400×1080 중앙 1920 영역과 좌우 240 여백이며 버튼을 가로로 늘리지 않는다. 터치 영역은 시각 크기와 별개이고 실제 기기 노치·제스처 여백은 재검사한다. 전투 좌표는 기존 Penpot 설계 그대로이며 현재 구현 배치와 다른 제안이다.

호흡은 4초, 최대 1.006배·작은 이동·약 0.1도 회전. PNG 자체는 정지 이미지다. 휴식 648,124 / 552×736, 들숨 646.344,117.584 / 555.312×740.416. 최대 바닥 y858은 하단 메뉴 y864를 침범하지 않는다. 움직임 일시정지·OS 움직임 줄이기를 구현 시 제공한다.

## 재검사와 미정 정책

VIS-01: 53개 내보내기, 한국어 잘림·겹침·큰 행동 위계·8인 번호/피해율/씨앗, A/B 문자와 색 구분 확인. SAFE-20: 비교 보드와 정적 엄지 가림 확인. 실제 카메라 움직임·최대 줌아웃은 구현 후 재검사.

NAV-01: 276개 목적지 유지, 121개 원본 클릭 영역 대조·25개 수정. 보기 모드에서 로비→모드→AI→선택·뒤로, 연습→일시정지→나가기/취소, 복귀→카운트다운, 미션·설정·조작 설정 왕복 확인. 정적 프로토타입은 경기 모드를 기억하지 않고 취소·재개 예시가 고정 1대1로 이동한다.

온라인·경제·Story 미구현 부분은 미래 설계다. AI 난이도·Story 해금·보상·성장·경제·확정 콘텐츠 원화와 피해율↔현재 Godot HP/stock 연결 정책은 별도 결정이다. 신규 UI 자산 누락은 0개이며 기존 missing 슬롯 47개는 별도 목록을 유지한다. Splash 무캐릭터·장신구 무등급·승인 외형 유지, 신규 재화·뽑기·길드·궁극기·잡기 추가 없음.
