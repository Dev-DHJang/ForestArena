## 발견하고 고친 문제

같은 이름의 버튼을 ID와 이름의 OR 조건으로 찾으면 첫 같은 이름을 잘못 고르는 문제가 있었다. 원래 저장한 연결 순서와 원본 버튼 ID를 복구 기준으로 사용해 121개 클릭 영역을 대조하고 25개를 수정했다. 대화상자는 부모 안 좌표가 아니라 화면 기준 좌표로 바꿨다. 이동 목적지는 보존했다. hotspot-repair-audit.json과 link-comparison.json에 기록했다.

ParticipantWide 마스터의 배경이 피해율·기회를 가린 문제를 마스터에서 고쳐 실제 인스턴스에 반영했고 영향 화면 9개를 다시 내보냈다. 나가기 버튼도 산호색 위험 표면으로 바꿨다. 캐릭터 PNG는 수정하지 않았으며 작은 호흡의 최대 바닥 y858은 메뉴 y864를 침범하지 않는다.

09_Dev_Handoff에 실제 화면별 좌표 186행, 자산 91종, 연결·상태·해상도·제작 출처·누락 슬롯을 기록했다. 로컬 실제 연결은 final-audit.json, screen-component-mapping.json, screen-button-layout.csv를 따른다.

## 제약과 남은 제품 결정

Godot 화면·API·입력·저장 형식·런타임 등록은 변경하지 않았다. 현재 전투 배치는 기존 Penpot 제안을 유지하며 실제 게임 구현 배치와 다를 수 있다. Splash 무캐릭터, 장신구 무등급, 승인 캐릭터 외형을 유지했다. 다른 게임 이미지를 추출·트레이싱·재색칠하지 않았고 상용 게임 내부 제작 사양과 동일하다고 주장하지 않는다.

기존 자산 목록의 missing 47개는 새 UI 자산 91개와 별개이며 missing-assets.json에 정확한 IMG 이름으로 남겼다. 승인 원화·직업·경기장·Story 콘텐츠, AI 난이도, 해금·보상·경제, 피해율과 현재 HP/stock 연결 정책은 별도 확정이 필요하다. 예시 수치는 제품 규칙 확정으로 쓰지 않는다.

정적 프로토타입의 취소·재개는 기존 고정 1대1 목적지를 유지하며 경기 모드를 기억하는 런타임이 아니다. Android 실제 터치, 중단·복귀, 노치·카메라 최대 줌아웃은 구현 후 재검사 대상이다. 정적 화면·보기 모드 검토를 실제 기기 통과로 기록하지 않는다.

작업 폴더 이동 후 도구 호환을 위해 ForestTales→ForestArena 심볼릭 링크를 만들었다. 파일을 복제하거나 이전 폴더를 덮어쓰지 않았다.

검사 결과는 verification-status.json과 최종 검사 로그를 따른다. 기존 게임 검사 통과와 새 UI 시각 검토는 서로 다른 증거다.
