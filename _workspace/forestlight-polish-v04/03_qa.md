# v04 검토 기록 — 진행 중

## 로컬 화면 검토

Penpot 연결 지연 동안 preview-layouts.mjs로 독립된 SVG 화면을 조합했다. 원본 배경과 승인 투명 PNG는 변경하지 않았다. 텍스트는 SVG text이며 최종 Penpot 반영 시 네이티브 텍스트로 만든다. 이 출력은 Penpot export가 아니다.

- LOCAL-LOBBY-1280: lobby-layout-draft-1280.png, 1280×720에서 직접 시각 검토. 중앙 캐릭터와 하단 메뉴 사이 분리, 프로필·설정·플레이 위계, 메뉴 6개 글자, 우측 안내 카드의 한글을 확인했다. 잘림·글자 겹침 없음. 캐릭터 PNG의 사각 배경 없음.
- LOCAL-MISSION-1280: mission-layout-draft-1280.png, 1280×720에서 직접 시각 검토. 왼쪽 분류·가운데 목표 3개·우측 설명의 읽는 순서를 확인했다. 진행 막대 0/1은 채움 없음, 1/3은 33.3%, 2/5는 40%. 보상 확정 수치 없음. 글자 잘림·겹침 없음.
- LOCAL-1920: 동일한 두 화면의 1920×1080 출력도 직접 검토했다.

로컬 로비의 새로운 좌측 편성 패널과 우측 안내 카드도 아직 Penpot 원본에 적용되지 않은 제안이다. Penpot 미션의 마지막 막대 갱신은 별도로 실제 export를 다시 확인해야 한다.
