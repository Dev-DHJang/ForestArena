2026-10-15 사용자 요청과 승인 계획을 구현한다.

- 대상: 묘령 31종, 나비 29종, 유란 30종. manifest에 등록된 90개 상태를 고정한다.
- 자현 `idle`의 몸 비율과 실제 표시 크기를 기본 기준으로, `attack_heavy_charge`를 공격 자세 보조 기준으로 사용한다.

- 새 묶음 표시 배율 1.0, 발 기준 y=124. 실제 신체 배율을 고정하고 긴 귀/꼬리 때문에 몸 전체를 축소하지 않는다.
- 자현 원본/manifest 항목, 기존 콘셉트, ID/FPS/반복/전투 데이터와 관련 없는 미커밋 변경을 보존한다. 등록 직전 대상 PNG와 manifest를 백업한다.
