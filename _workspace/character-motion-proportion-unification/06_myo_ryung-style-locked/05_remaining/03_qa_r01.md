- 31개 상태와 파일명은 시작 시점 묘령 목록과 일치한다. 각 시트는 512×512 RGBA, 4×4·16셀이다. 각 셀은 128×128이고 실제 투명도가 0~255다.
- 각 모션에서 비어 있지 않은 서로 다른 RGBA 프레임 16개와 하나의 고정 배율을 확인했다. 픽셀 값이 다르다는 검사만으로 실제 관절 움직임을 입증했다고 주장하지 않으며 아래 눈으로 하는 검사를 함께 수행했다.

- 최종 시트와 원본 해시, GIF 16프레임 및 재생 간격, 기존 FPS·loop 보존을 확인했다. GIF는 검토 편의를 위한 반복이며 게임의 단발 공격 설정을 변경하지 않는다. 10ms 단위 GIF 시간은 누적 반올림했으며 게임 판정 시간을 정의하지 않는다.
- 자현 머리 높이 26px에 대해 눈으로 표시한 측정 위치 기준의 새 전체 묘령 머리 높이는 약 23.66~27.55px다. 같은 기본 자세를 측정할 수 있는 모션은 몸 높이 72px로 맞췄고, 웅크림·회전·공중 자세는 머리 크기를 기준으로 삼았다. 한 모션 안에서 프레임별 크기를 따로 바꾸지 않았다.
- 이 수치는 눈으로 표시한 2D 위치의 비교다. 모든 어깨·몸통·팔·다리 관절 길이가 10% 이내라는 3D 측정이나 완벽한 그림체 일치의 자동 점수가 아니다. 전체 비율의 최종 판단은 사용자 검토에 남긴다.

## 눈으로 하는 확인 — MYO_RYUNG_REMAINING_STYLE_REVIEW_R01

`../04_review/qa-pages/page-01.png`부터 `page-08.png`까지 전체 31종·496포즈를 좌→우·상→하 순서로 확인했다. 배경을 합성한 검토판을 사용해 투명 픽셀 안의 RGB 표시 잡음과 실제 불투명 그림을 구분했다.

- 같은 선택 원본에서 추출한 두 참조만 사용했다. 기존 시안이나 다른 화풍 이미지를 새 생성에 섞지 않았다. 얼굴·은백색 앞머리·장미색 리본·분홍/흰 의상·운동화 패널·가는 색 선·부드러운 명암을 승인 3종과 비교했다. 전체가 같은 그림체 방향임을 확인했으며 사용자 최종 승인은 별도다.
- 귀 2개와 인간형 손발, 허용되는 측·후면의 작은 둥근 꼬리를 확인했다. 동물 주둥이·털 팔다리·추가 귀/꼬리·무기·상대·글자·판정 표시·효과는 발견하지 못했다.
- 점프의 웅크림/도약/착지, 잽→무릎→지상 회전 킥→점프 회전 피니시의 구분, 상/하 약공격과 수평/상승/낮은 스윕 강공격, 차지 준비와 대시 제동, 공중 약공격을 확인했다.
- 중립 특수기의 세 발차기와 그 사이 회수 자세를 확인했다. 위 특수기는 상승 킥, 옆 특수기는 전진 도약 진입, 아래 특수기는 도약 뒤 전하방 타격으로 구분된다. 각 포즈 배분은 연기용이며 다단 판정 간격이나 AttackData를 정의하지 않는다.
- 궁극기 r01의 11·12번째 발차기가 위로 향하는 문제를 발견했다. 해당 두 포즈의 타격 방향만 전하방으로 수정한 r02를 최종 후보로 선택하고, 8번째 검토 페이지에서 다시 확인했다. r01도 이력으로 보존한다. 요청과 결과는 `../03_alpha/ultimate-r02-request.json`, `ultimate-r02-alpha-result.json`에 있다.
- 피격 뒤 자세 회복, 공중으로 밀려나는 반응, 옆으로 넘어져 머무는 다운, 누운 자세에서 일어나는 기상, 비유혈 패배, 역상 회전이 있는 링아웃, 낮게 등장한 뒤 가드로 정리하는 동작이 구분된다. 회전 중 정면/후면/역상이 되는 포즈는 의도된 회전이지 시트 전체를 좌향으로 뒤집은 결과가 아니다.
- 각 모션 안에서 몸통·팔다리 자세 변화와 귀·리본 후행, 신체 잘림 없음을 확인했다. 작은 회복 포즈 차이를 포함하되 단순히 같은 그림을 옮긴 시트로 제출하지 않았다.
- 지상 포즈는 발 기준 y=124다. 혼합 도약 모션은 지상 구간과 공중 구간을 구분하고, 공중 구간의 그림 중심을 일정 위치에 맞췄다. 급격한 크기 변화나 의도되지 않은 셀 밖 잘림은 발견하지 못했다. 지상/공중 배치 값은 검토 이미지용이며 전투 이동 값을 바꾸지 않는다.
- 128px에서 긴 귀·장미색 리본·큰 운동화와 타격 방향이 읽힌다. 브라우저 검토 페이지의 GIF 31개가 128px 원본 크기로 모두 로드됐고 상단 재생 표본을 확인했다. 전체 GIF의 16프레임/시간 검사는 자동 검사, 전체 자세의 순서 검토는 8개 접촉판으로 수행했다.
