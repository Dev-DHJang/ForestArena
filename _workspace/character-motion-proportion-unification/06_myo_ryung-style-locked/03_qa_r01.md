# MYO_RYUNG_STYLE_LOCK_REVIEW_R01

상태: 첫 3종은 사용자 승인 완료. 구조 검사와 제작자 그림체 비교 뒤 사용자 “승인한다.”로 idle·run·attack_air_heavy를 승인받았다. `approval-proof-3.json`에 파일을 고정했다. 새 나머지 28종의 검사는 `05_remaining/03_qa_r01.md`를 따른다.

## 기준

- 선택 원본과 해시는 `01_style_reference/selection.json`에 기록했다.
- 3종 모두 선택 원본에서만 추출한 같은 두 참조를 쓴다. 옛 idle·공격 시트나 다른 화풍 이미지를 추가하지 않는다.
- 얼굴의 눈/코/입과 앞머리, 색이 있는 가는 선, 부드럽게 섞인 명암, 피부·옷·운동화의 재질 표현을 선택 원본과 비교한다. 몸 크기만 맞는 것은 그림체 통과가 아니다.
- 귀 2개, 인간형 손발, 장미색 리본, 큰 운동화와 의상 패널을 각 포즈에서 확인한다. 움직임 때문에 가려지는 부분과 실제 사라진 부분을 구분한다.
- 16포즈 분리·PNG/RGBA·실제 투명도·중복·잘림·파일명·해시를 검사한다. 움직임의 품질과 그림체 일치는 사람이 보는 별도 검사로 남긴다.
- 자현과 표시 크기 비교는 128px에서 한다. 머리/몸/다리의 정량 비교는 같은 기본 자세에서 눈으로 지정한 위치에 한정한다. 회전·웅크림의 세로 높이를 펴진 신체 길이로 오인하지 않는다.
- 지상 발 기준은 y=124, 공중 동작은 몸 중심이 갑자기 튀지 않는지 확인한다. 모션 안에서는 하나의 배율을 유지하며 프레임마다 크기를 달리하지 않는다.

## 현재 검사

- 이전 생성 반복 중단: 확인.
- 기존 파일 보존: `check_baseline.py` 통과. 런타임 PNG 120개, SpriteFrames, 자현 manifest 항목, 콘셉트와 전투 데이터가 시작 시점과 같다.
- `./scripts/verify-docs.sh`: 통과.
- 새 3종: idle, run, attack_air_heavy. 내장 도구로 각각 생성했고, 공중 강공격은 7~9번째 포즈의 타격 방향만 전하방으로 수정했다. 각 회색 원본을 단독 참조해 배경을 제거했다. 프롬프트와 편집 요청은 `generation-prompts-r01.json`, `edit-requests-r01.json`, `03_alpha/attack_air_heavy-r02-request.json`에 있다.
- PNG 디코딩·실제 RGBA/alpha 0~255·원본 1254×1254·각 16개 인물 분리·원본 신체 가장자리 접촉 없음: 통과. `04_review/inspection/report.json`.
- 검토판 3개는 512×512, 4×4·16셀, 각 셀 128×128이다. 각 모션 안에서 동일 배율 하나를 썼다. 프레임마다 크기를 맞춰 축소하지 않았다. 서로 다른 RGBA 프레임 16개, 셀 가장자리 2px 이상의 여유와 파일명/상태 일치: 통과. `04_review/report.json`에 크기·배율·배치·SHA-256을 기록했다.
- 지상기는 발 기준 y=124로 배치했다. 가로 위치는 원본의 셀 기준 이동을 유지했다. 공중기는 발이 아니라 그림 영역 중심 y=78로 배치했다. 이 기준은 검토용 배치이며 골반 위치를 자동 측정했다는 뜻이 아니다.
- 첫 포즈의 눈으로 표시한 머리 꼭대기/턱/발 위치를 기록했다. 자현 머리 높이 26px에 대해 idle 25.5px, run·attack_air_heavy 26px다. 같은 대기 자세의 몸 높이는 자현과 새 묘령 모두 72px다. `landmarks-r01.json`과 각 모션 `frame01-landmarks.png`.
- 이 정량 확인은 머리와 대기 자세 세로 높이에 한정한다. 모든 어깨/팔/몸통/다리 관절 길이가 10% 이내라는 측정 결과로 확대하지 않는다. 최종 전신 비율 판단은 전체 제작과 사용자 검토에서 계속 확인한다.
- 제작자 수동 비교: 선택 이미지와 새 3종의 원본 포즈 접촉판 및 얼굴 크기를 맞춘 비교판을 눈으로 확인했다. 작은 눈/코/입의 모양, 은백색 앞머리, 가는 색 선, 부드러운 분홍/회색 명암, 흰 재킷·분홍 장식·운동화 표현이 같은 방향임을 확인했다. 귀 2개, 측면 작은 둥근 꼬리, 인간형 팔·다리, 리본과 전신을 확인했다. 공중 강공격의 7~9번째 발끝은 전하방으로 향한다. 스타일의 완벽한 동일성을 자동 수치로 주장하지 않는다.
- 128px 비교판: 귀·장미색 리본·큰 운동화와 우향이 읽힌다. 순서대로 배치된 16포즈에서 갑작스러운 잘림·별도 개체·추가 팔다리는 발견하지 못했다. 실시간 게임 재생이나 기기 검증은 아니다.
- GIF 디코딩: 각 16프레임, idle 평균 8 FPS, run·attack_air_heavy 약 12 FPS. 10ms 단위 누적 반올림으로 12 FPS GIF 총 길이는 1330ms다. 검토 편의를 위해 GIF는 반복 재생하며, 기존 단발 공중 공격의 게임 loop=false는 변경하지 않았다.
- `./scripts/verify.sh`: 통과. `verify-project.log` 끝의 `Forest Arena verification passed.` 확인. 문서·하네스 검사도 포함된다.
- 전체 31종 완료 및 Android 실제 기기: 미수행.
