# Phase 3 직접 플레이 기록 양식

이 양식은 자동 테스트 통과 기록이 아니다. 한 명 이상의 사람이 키보드로 직접 조작한 뒤에만 `결과`와 `판단`을 작성한다.

## 공통 조건

- 실행 명령: `godot --path . scenes/debug/phase3_style_playtest.tscn -- --style=<character-id>`
- 경기장: 개발용 비교 장면의 고정 바닥·중앙 발판
- 규칙: 기본 `CombatRules`, HP·stock 3회, 45 tick 복귀·60 tick 무적
- 상대: 같은 스타일 데이터의 정지한 `playtest-rival`
- 입력: WASD, Space, J/K/L, H, U. 잡기 입력은 없다.
- 각 캐릭터에서 다음을 최소 한 번 확인한다: 이동·점프·공중 공격·약연계·방향 강공격 차지·방어·회피·특수기 쿨다운·궁극기 게이지·HP 소진 또는 링아웃 복귀.

## 완료 판단

- 네 행의 관찰 결과와 채택·폐기 이유가 실제 조작 근거로 채워졌는가?
