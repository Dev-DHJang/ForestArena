# 품질 확인 r02 — Phase 3 직접 플레이 마무리

## 직접 플레이 비교

- 2026-09-19 Android debug 개발 비교 APK에서 자현·묘령·나비·유란을 사람이 직접 비교했다.
- 네 스타일 모두 사용자 판단은 `채택`이다. 사용자는 별도의 체감 사유·불균형 신고를 남기지 않았다.
- 실제로 조작해 확인한 입력 범위는 [직접 플레이 기록](03_manual_playtest_template.md)에 캐릭터별로 적었다. 그 밖의 입력을 사람이 확인했다고 추정하지 않는다.
- 비교 장면은 정지한 동일 상대, 고정 바닥·중앙 발판, 기본 CombatRules, HP·stock 3회, 45 tick 복귀·60 tick 무적을 사용했다.

## 근거와 한계

- 고기동 4단·3회 다단(묘령), 무거운 3단(자현), 빠른 접근 2단(나비), 공간 장악 3단·넓은 중립 특수기(유란)의 차이를 같은 비교 조건에서 제시하고 사용자 채택 판단을 기록했다.
- HP·stock·최종 사망·동시 무승부, 방어·회피·차지·특수·궁극기의 권위 규칙은 `./scripts/verify.sh`의 전투 회귀로 검사한다. 이번 직접 터치 비교에서 해당 고급 행동을 모두 수동 조작했다고 기록하지 않는다.
- 실제 Android 기기의 기본 터치·가로 실행·중단/복귀 자동 검사는 [Android QA r02](../android-wireless-debugging/03_qa_r02.md)를 근거로 한다. 성능 수치 측정과 정식 추가 행동 버튼 UX는 이번 개발 비교 APK의 통과 항목이 아니며, 미확인이다.

## Phase 3 판단

로드맵의 Phase 3 완료 조건인 스타일별 확인 대상, 동일 비교 조건, 결과와 채택·폐기 이유의 기록을 충족했다. 따라서 Phase 3은 완료로 기록한다. 이 판단은 Phase 4 장신구, Phase 5 직업 변화, 정식 선택 UI·성장·경제 또는 온라인 기능의 완료를 뜻하지 않는다.
