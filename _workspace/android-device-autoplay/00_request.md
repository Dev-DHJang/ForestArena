# 무선 실기기 자동 플레이 요청

- 날짜: 2026-10-11
- 승인 계획: Android 실기기 1~4대 명시 선택, 오프라인 병렬·두 쌍 LAN, 실제 터치와 debug 자동 입력, 10분/30분 반복.
- 첫 선택·상점·저장·전투·결과·재대전·생명주기·실패·재접속을 확인한다.
- 테스트 저장을 분리하며 승인 자산과 기존 작업 변경을 보존한다.
- 실제 Wi-Fi 단절·동시 터치·사운드·진동 체감은 이름 있는 수동 재검사다.
- 기기 미연결은 blocked 또는 미실행이며 기기 통과로 기록하지 않는다.
- 최신 origin/develop의 LAN v2 게스트·닉네임·API 인증 흐름을 유지한다. 테스트용 API는 실제 API·DB 인증 검증과 구분한다.
