# 현재 APK 수동 재검사 절차

자동 검사 종료 후 두 기기를 사용자에게 돌려놓고 수행한다. 자동 검사 중에는 기기 화면·Wi-Fi를 조작하지 않는다. 사용자는 수동 검사 가능하다고 답했으며 현재는 자동 검사 종료를 기다리는 상태다. 아래 항목은 사용자의 실제 조작과 관측 결과를 받은 뒤에만 pass/fail을 기록한다.

## 실제 두 손가락 회피

1. 연습 경기에서 플레이어가 지면에 서 있는지 확인한다.
2. 한 손가락으로 오른쪽 또는 왼쪽 방향을 누른 채 다른 손가락으로 회피를 누른다.
3. 두 손가락을 모두 뗀다. 캐릭터가 짧게 회피하고, 이후 방향을 다시 누르지 않으면 이동·회피가 계속되지 않아야 한다.
4. 방향 없이 회피만 눌렀을 때는 회피 이동이 발생하지 않아야 한다. 두 방향에서 한 번씩 확인한다.

기기별 결과: `MANUAL-EVADE / 기기 이름 / 정상 또는 문제 / 관측 내용`. 자동 ADB 두 포인터 결과와 사람이 느끼는 두 손가락 조작 품질을 구분한다.

## 실제 Wi-Fi 끄기/켜기

1. 두 기기의 LAN 경기에서 첫 번째 기기만 Wi-Fi를 끈다. 두 번째 기기는 켜 둔다.
2. 두 번째 기기에서 상대 연결 끊김 안내와 상대 입력 해제를 확인한다. 첫 번째 기기의 캐릭터가 마지막 방향으로 계속 움직이면 문제다.
3. 5~10초 뒤 첫 번째 기기의 Wi-Fi를 다시 켠다. 같은 캐릭터·같은 참가자 슬롯으로 복귀하고 양쪽에서 이동·공격이 정상 동작해야 한다.
4. 이탈 패배의 실제 Wi-Fi 재검사가 필요하면 새 경기에서 65초 동안 끈 뒤 켠다. 남은 기기에 60초 초과 상대 이탈 승리가 표시되어야 한다. 10초 복귀 검사와 별도 경기로 수행한다.

재페어링 안내·ADB 연결 손실은 게임 재접속 결과와 별도로 기록한다. Wi-Fi 복귀 후 게임이 돌아오지 않으면 화면 안내와 기다린 시간을 적는다.

## 모션·화면·소리·진동

- 네 캐릭터를 번갈아 연습 경기에서 이동·점프·공중 재점프·약/강/특수 공격한다. 공중에서 착지 자세가 먼저 나오거나 지면 접촉 뒤 표시가 멈추는지 확인한다.
- 무기·귀·꼬리·리본이 잘리거나 캐릭터가 사라지는지, 두 기기의 작은 화면에서도 HUD·선택 목록·결과 글자를 읽고 터치할 수 있는지 확인한다.
- 기기 미디어 음량을 올려 전투와 결과 소리를 듣는다. 현재 APK의 접근성 설정에는 진동 피드백이 있으며 게임 소리 켜기/끄기 설정은 확인되지 않았으므로 해당 메뉴가 있다고 가정하지 않는다. 진동 지원 기기는 진동 피드백 설정과 실제 진동을 비교한다. 기기가 진동을 지원하지 않으면 미확인 사유로 남긴다.

보고 형식: `항목 / S23 또는 Tab S5e / 정상·문제·미확인 / 관측 내용`. 전체 120모션을 실제 기기에서 전수 확인하지 않았다면 전수 통과로 기록하지 않는다.
