# Android 실기기 자동 플레이 마무리 기록

## 현재 상태

요청한 검사와 통합은 태블릿 연결 차단으로 미완료다. 현재 개발 APK의 실제 Solo·Team 결함을 발견했으며 게임 코드를 바꾸어 통과시키지 않았다. S23의 기능 검사와 10분 반복, Tab의 기능 검사는 관측했지만 Tab 반복·양쪽 LAN·사용자 수동 확인이 남아 있다. 자세한 최신 판정은 [현재 기기 결과](06_current_device_results.md), 독립 감사는 [QA 기록](03_qa_r02.md)에 있다.

## 구현과 도구 검증

명시적 실기기 1~4대 선택, 오프라인 병렬, LAN 두 쌍 분리, smoke/10분 soak/30분 extended, debug 전용 저장과 실행 인자, 실제 ADB 터치·두 포인터와 기존 AI 입력, 입력 해제, 설치 APK 동일성, 성능·단절·한국어 결과 증거를 구현했다.

현재 미커밋 개발 내용은 원본을 보존한 복제본으로 검사한다. LAN v1/v2 선택과 현재 장신구 설정 확인, Android 11 앱 PID 로그, 모드별 독립 실패/복구, 음수 기회 즉시 증거 저장, HOME 복귀의 새 화면·버튼 위치 확인, 실행별 도구 소스 보존과 필요한 사례만 새로 실행하는 기능을 보완했다.

최신 전체 도구 검증은 `qa-verify-tools-r07.log`에서 종료 0과 마지막 완료 문구를 확인했다. 전체 실행 시작 시점 호스트 112개·터치 전달 10개·Android 인자 전달 8개, Godot QA·LAN runtime·두 서버 분리·문서·리소스 검사 통과다. 마지막 두 경계 추가 뒤 최신 호스트 114개는 `qa-fleet-capacity-r02.log`에서 별도 독립 통과했다. 실제 화면 없는 LAN v1/v2 정원 참가자 검사도 통과했으나 실제 APK 오류 화면 통과가 아니다. 개발 기준 리소스 검사는 397개/품질 변형 24개이며 현재 동결 개발 복제본은 346개/24개다. 서로 다른 소스의 결과를 섞지 않는다. 기본 ObjectDB 정리 경고는 남아 있다.

최초 구현의 48개 검사와 이전 APK 실행 이력은 [이전 QA 기록](03_qa_r01.md)에 보존한다. 이는 현재 APK의 실제 기기 통과 결과를 뜻하지 않는다.

## 원본과 실기기 증거

원본 HEAD는 `423b1a898f25fa10609833dd9c5449df33a521fa`다. 원본 파일 2,913개와 승인 자산은 복제 전후 및 재개 후 해시 차이 0을 확인했다. current-qa-r02 APK SHA256은 `6b855d25aa5376f4b24958ce985e1c88cad21b6f0df5bdb1e82c8b613a3d092f`이며 실행별 원본 전후·설치 해시를 비교한다. 페어링 코드·디버그 키·인증/재접속 토큰은 기록하지 않는다.

실제 기기는 S23 Ultra(Android 16)와 Tab S5e(Android 11) 두 대다. ADB 연결 경로 수를 실제 기기 수로 세지 않았다. 연결 단절·호스트 프로세스 종료·미실행 수동 항목은 완료 또는 pass로 바꾸지 않는다. 네 기기 동시 실행·30분/28개 전수 조합은 수행하지 않았다.

## 연결 대기 중 보존한 중간 기록

2026-10-12 06:25 KST에 S23의 지정 TCP 주소는 응답했고 Tab의 기존 주소는 시간 초과였다. 사용자의 태블릿 잠금 해제·같은 Wi-Fi·무선 디버깅 주소 확인 답변을 기다린다. 단절 시도 `967a78215f6d4ae7964590294153121b`는 종료 코드 2와 blocked 요약을 보존했으며 같은 시도를 덮어쓰지 않는다.

동일 APK의 완료 관측 참조를 `build/android-current-device-test/current-evidence-index-incomplete.json`에 모았다. 24개 기기별 사례 중 pass 13개·fail 2개·blocked 7개·미실행 2개이며 서로 다른 새 시도를 참조하는 중간 색인이다. 단일 전체 실행 통과가 아니며 기존 실패 이력을 그대로 남긴다. 성능 표본 집계와 제한은 [현재 기기 결과](06_current_device_results.md)에 기록했다.

LAN-02는 현재 APK가 오류 Label을 진단 목록에 내보내지 않아 자동 오류 이벤트·화면 복귀와 안내 문구의 시각 확인을 분리한다. 실제 정원 초과 화면 캡처를 읽기 전에는 전체 LAN-02를 blocked로 남긴다. LAN-03은 단절 전 정상 정지 상태에서 debug 자동 입력을 켜고 새 RUN·위치 변화 표본을 확인한 뒤 단절한다. 현재 서버는 단절 직전 입력값을 직접 발행하지 않으므로 그 값은 미확인이라고 적는다. 실제 터치와 혼동하지 않는다.

독립 QA는 완료 관측 색인 13/2/7/2개와 원본 사례 JSON의 일치, 성능 집계의 모든 통계 일치를 확인했다. 도구 검증 통과와 제품 Solo/Team 실패, 연결 차단으로 미완료인 실제 검사를 구분한다. 사용자 연결 확인 답변 전에는 새 Tab 반복·LAN을 시작하지 않는다. PR은 draft로 유지하며 남은 실제 검사 뒤 통합 판정을 다시 확인한다.

## 연결 차단과 재개 조건

2026-10-12 06:35 KST까지 같은 Tab 무선 연결 응답 없음이 세 연속 목표 턴에서 확인됐다. 마지막에는 기기 이름 서비스가 기존 주소를 다시 알렸지만 직접 TCP·기존 페어링 ADB 연결·하드웨어 식별 조회는 모두 시간 초과였다. 서비스 이름이나 오래된 ADB device 목록만으로 복구됐다고 판단하지 않는다. 세 번째 관측과 후속 확인은 `build/android-current-device-test/resume-observation/connection-blocked-audit-turn-3.json` 및 `connection-blocked-audit-turn-3-followup.json`에 보존했다.

도구 구현·독립 QA·중간 결과의 원격 보존은 완료했다. 실기기 전체 목표는 `blocked`이며 완료 또는 사용자가 요청한 일시정지가 아니다. Tab의 화면 잠금 해제·Mac과 같은 Wi-Fi·무선 디버깅 허용과 현재 IP:포트를 사용자가 확인해야 한다. 복구된 연결에서 선택한 동일 하드웨어를 확인한 뒤 새 실행 ID로 Tab 600초 반복, 두 실제 APK LAN-01/02/03, 자동 검사 종료 안내 후 사용자 실제 Wi-Fi/두 손가락/모션/소리/진동 확인을 이어간다. 기존 시도·APK·원본 코드를 보존한다. PR은 초안이며 develop 병합은 남은 실제 확인 뒤 판정한다.
