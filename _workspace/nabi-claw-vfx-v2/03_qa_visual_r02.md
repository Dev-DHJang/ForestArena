## 재생 확인 범위

QuickTime Player의 정식 로컬 파일 열기로 `normal-reel.mp4`와 `mirror-small-reel.mp4`를 재생했다. 릴은 검증된 MP4 네 개를 순서대로 이어 붙인 8초 자료이며 순서는 지상 강공격 0~2초, 공중 강공격 2~4초, 공중 약공격 4~6초, 특수기 6~8초다. 입력 영상과 릴의 SHA는 `playback-reels.json`에 있다.

정상·반전 릴을 각각 **1x와 0.5x로 0초부터 8초 끝까지 seek 없이 재생**했고 끝에서 타임라인 8초와 재생/일시 정지 값 off를 확인했다. 중단 전에 완료한 반전 두 회차 기록을 유지하고 재개 후 정상 두 회차를 마쳤다. 이전 정상 릴의 부분 seek 관찰만으로 전체 완주를 대신하지 않았다.

직접 반환받아 본 UI 화면은 각 회차 5개, 합계 20개 표본이다. 대략 0.35/2.65/4.60/6.50초 이후 및 끝 화면을 관찰했다. 정확한 재생 완료 조건과 표본 시점은 `playback-observations.json`에 구분했다. **전체 재생 완료, UI 화면 표본 관찰, 원화 80장/실제 960틱 정적 전수 관찰은 서로 다른 확인 범위다.** QuickTime의 모든 60fps 프레임을 연속해서 직접 보았다고 주장하지 않는다.
