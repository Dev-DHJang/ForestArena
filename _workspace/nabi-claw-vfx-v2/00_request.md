# 나비 발톱 효과 연결

진행 중인 모션 개선에서 나비 공중 강공격의 효과 품질을 높이고, 새 원화의 실제 손과 발톱에 맞춰 강공격·공중 약공격·특수 타격을 연결한다. 현재 원화80장 중 손80개, 확인 가능한 발톱 끝13개를 검토했다. 가려진 끝67개는 효과도 생략한다.

현재 제품과 다른21종의 독립 QA는 고정 상태다. 이 폴더에서는 먼저 좌표와 궤적을 독립적으로 시험하며 제품 파일·승인 이미지·runtime/manifest는 바꾸지 않는다. 이후 실제 게임 연결과 정상/느린 재생·반전·작은 표시를 독립 검토한다. 피해·판정·공격 단계 시간과 LAN 형식은 바꾸지 않는다.

## 2026-10-25 실제 연결 단계

격리 시험을 마친 뒤 공통 표시 코드에 좌표 해석·그리기를 연결한다. 미승인 나비 PNG·SpriteFrames는 계속 작업 폴더에만 두고 runtime/manifest 등록은 모션별 독립 QA와 명시 승인 뒤 수행한다. 기존 승인 자현 특수기와 피격 표시를 함께 재검사한다.
