# 발톱 연결 진행 상태

2026-10-25 새 나비 원화의 실제 손·발톱 좌표를 읽는 효과를 공통 표시 코드에 연결했다. 위로 치는 공격은 팔 바깥의 보라색 세 줄 곡선으로 보이며, 가운데 끝은 실제 발톱에 연결된다. 가려진 끝67장은 생략하고, 보이는 끝13장만 흔적을 만든다. 원화·전투 계산·공격 시간·LAN 형식은 바꾸지 않았다. 새 나비 모션4종은 미승인이므로 runtime/manifest에는 등록하지 않았다.

자동 검사는 `qa/geometry-r04.log` 291개와 `qa/production-consumer-r01.log` 2,150개, 기존 VFX가 통과했다. 실제 제품 코드의 정상·반전소형8장면960프레임은 시안r04와 픽셀이 같고, 승인 자현 특수기240프레임도 이전 설치 결과와 같다. 자세한 범위와 비교에서 제외한 진단 필드는 `02_2d_animation.md`를 따른다.

현재 동결 코드의 전체 `verify.sh`는 `qa/verification-result-r01.json`에서 통과했다. 같은 버전 LAN 연결·재접속, 문서·하네스와 Godot 리소스519개 검사가 포함된다. 독립 코드 QA는 `03_qa_code_r01.md`에서 통과했고 시각 QA는 진행 중이다. 기존 검사 종료 때 남는 리소스 메시지는 기록에 분리했으며 실제 촬영 로그에는 그리기 오류가 없다. 이 기록은 새 나비 모션의 품질 통과·사용자 승인·Android 실기기 통과를 뜻하지 않는다. 나머지 상태 모션의 비율·전환도 교정 중이다.

작업 브랜치는 `codex/two-fighter-combat-v2`, Draft PR은 https://github.com/Dev-DHJang/ForestArena/pull/109 이다. 원본 미커밋 작업을 보존했다. 등록은 승인 뒤 진행하며 병합은 미완료다. 문제가 생기면 이번 공통 효과 변경과 해당 테스트를 되돌리고 기존 승인 PNG·원본·검토 기록은 보존한다.
