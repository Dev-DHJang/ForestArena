# 발톱 연결 진행 상태

2026-10-25 새 나비 원화의 실제 손·발톱 좌표를 읽는 효과를 공통 표시 코드에 연결했다. 위로 치는 공격은 팔 바깥의 보라색 세 줄 곡선으로 보이며, 가운데 끝은 실제 발톱에 연결된다. 가려진 끝67장은 생략하고, 보이는 끝13장만 흔적을 만든다. 원화·전투 계산·공격 시간·LAN 형식은 바꾸지 않았다. 새 나비 모션4종은 미승인이므로 runtime/manifest에는 등록하지 않았다.

자동 검사는 `qa/geometry-r04.log` 291개와 `qa/production-consumer-r01.log` 2,150개, 기존 VFX가 통과했다. 실제 제품 코드의 정상·반전소형8장면960프레임은 시안r04와 픽셀이 같고, 승인 자현 특수기240프레임도 이전 설치 결과와 같다. 자세한 범위와 비교에서 제외한 진단 필드는 `02_2d_animation.md`를 따른다.

현재 동결 코드의 전체 `verify.sh`는 `qa/verification-result-r01.json`에서 통과했다. 같은 버전 LAN 연결·재접속, 문서·하네스와 Godot 리소스519개 검사가 포함된다. 독립 코드 QA는 `03_qa_code_r01.md`에서 통과했고 시각 QA는 진행 중이다. 기존 검사 종료 때 남는 리소스 메시지는 기록에 분리했으며 실제 촬영 로그에는 그리기 오류가 없다. 이 기록은 새 나비 모션의 품질 통과·사용자 승인·Android 실기기 통과를 뜻하지 않는다. 나머지 상태 모션의 비율·전환도 교정 중이다.

작업 브랜치는 `codex/two-fighter-combat-v2`, Draft PR은 https://github.com/Dev-DHJang/ForestArena/pull/109 이다. 원본 미커밋 작업을 보존했다. 등록은 승인 뒤 진행하며 병합은 미완료다. 문제가 생기면 이번 공통 효과 변경과 해당 테스트를 되돌리고 기존 승인 PNG·원본·검토 기록은 보존한다.

## 2026-10-26 최신 시각 판정

위의 시각 검토 진행 중 상태는 이전 회차다. 현재 r10 후보와 r11 실제 입력 자료는 `03_qa_visual_r02.md`에서4종 모두 독립 통과했다. 이전 지상 강공격은 피해 뒤에 펼친 발톱 자세가 늦게 나왔으나, 표시 구간을 `[0,7)/[7,9)/[9,16)`으로 조정해 실제 첫 피해 tick23의 F7부터 타격 자세와 효과가 맞는다. 전투12/5/20틱은 유지했다.

원화80장·실제960틱을 대조하고 정상/반전의 보통·느린 전체 재생 완료와 시점별 직접 관찰을 구분해 남겼다. 공중 약공격은 이 촬영에서 빗나가므로 적중 검사의 근거로 쓰지 않는다. 특수기의 실제 입력 선택24/32장과 나머지 원화·제어 시간표 확인도 구분한다. 원화나 제품 코드를 이 QA에서 변경하지 않았다.

나머지21종과 합친25종 정식 판정 및 읽기 전용 등록 계획은 `../motion-naturalness-v1/qa/remaining-candidate-review-r10-final/`과 `../motion-naturalness-v1/remaining-registration-plan-r10.json`을 따른다. 전체25종 QA는 통과했지만 사용자 승인 기록은 아직 없고 runtime/manifest 설치도 실행하지 않았다. 실제 Android는 미실행이며 PR109는 계속 Draft다. 이후 공중 피격 전환 코드가 추가됐으므로 앞선240프레임 전후 동등 주장은 당시 공통 발톱 코드 연결의 범위로만 유지한다. 현재 제품 전체 검사는 `../motion-naturalness-v1/qa/verify-current-release-r03.log`에서 통과했다.


## 2026-10-27 승인과 등록

직접 사용자 승인으로 나비13종(본 작업 공격4종 포함)과 자현12종을 등록했다. 새25종의 승인 기록·설치 receipt·독립2256검사/416실제import프레임 확인은 `../motion-naturalness-v1/03_qa_registration_r01.md`를 따른다. 공개 효과·전투·LAN 코드는 등록 과정에서 바꾸지 않았다. 위의 미승인·미등록 표기는 당시 기록이며 현재 상태가 아니다. 최종 통합은 같은 PR109에서 진행한다.
