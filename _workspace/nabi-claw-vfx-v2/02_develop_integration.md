# 최신 develop 통합

`767cee1f`의 승인 비전투 콘셉트4종을 작업 브랜치로 가져왔다. 자산 목록 충돌은 현재126항목을 순서·값 모두 보존하고 승인 콘셉트4항목만 더해 해결했다. 결과는130항목이며 전투 모션122종의 그림·메타데이터는 그대로다. 새 자현 특수기와 나비 미승인 후보의 승인 범위를 바꾸지 않는다.

들어온 콘셉트 검사의 기본 명령은 과거 설치 시점의 모든 게임 파일·자산 목록과 현재 파일이 같은지 요구했다. 이후 승인된 모션 추가도 거부해 실제 실패를 보존했다. 현재 검사는 승인된 정적 변형4개와 승인·원화·최종PNG·메타데이터·기존 대표 콘셉트·외형 계약을 확인하도록 한정했다. 다른 모션의 적합성은 기존 모션·전투 검사에서 확인한다.

설치 당시 모든 항목·게임 파일을 보존했다는 검사는 삭제하지 않았다. `install()`이 항상 `preserve_install_snapshot=True`로 이를 실행한다. `--verify-installation-snapshot`은 과거 설치 시점과 현재 트리가 같은지 감사하는 별도 명령이며, 개발이 진행된 현재 트리에서는 거부되는 것이 맞다. 기존 설치 백업·승인·기록은 수정하지 않았다.

등록14개와 독립 경계16개 검사, 기본 확인, 리소스·문서 검사와 Godot 콘셉트 계약이 통과했다. 첫 Godot 검사는 새PNG의 import 캐시가 없어 실패했고 에디터 import 후 다시 통과했다. 첫 실패 로그를 보존하며 통과로 사용하지 않는다. 실제 입력/시간 표시 전체 검사는 다음 동결 버전에서 다시 진행한다. 독립 판정은 `03_qa_develop_integration_r01.md`를 따른다.
