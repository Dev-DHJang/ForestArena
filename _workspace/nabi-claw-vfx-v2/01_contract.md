# 발톱 흔적 표시 데이터

공통 표시 코드가 새 나비 원화에 들어 있는 `frame_anchors`(프레임별 연결 좌표)를 읽는다. 공격·피해·LAN 데이터 형식은 바꾸지 않는다. 미승인 원화는 작업 폴더에서만 시험하며 실제 자산 목록에는 추가하지 않는다.

- `claw_hand`: 128×128 셀 안 실제 손 좌표 두 수. `claw_tip`: 화면에 보이는 발톱 끝 좌표 두 수. 가려진 끝은 필드를 생략한다. 유한한 0~128 값만 허용한다.
- 각 모션의 그림 수와 같은 길이의 좌표 배열을 전달한다. 현재 원화4종80장에는 손80개·보이는 끝13개가 있다. 없는 끝을 몸 중심이나 임의 위치로 보충하지 않는다.
- 현재 손·끝과 세 그림 전 손으로 곡선 세 가닥을 만든다. 가운데 끝은 실제 원화 끝과 일치한다. 나머지 두 가닥은 시각적 보조선이다. 위로 치는 공격은 팔 바깥으로 곡선을 부풀리며 끝점은 유지한다.
- 위치·같은 가로세로 배율·좌우 반전을 한 번만 적용한다. 준비 중에는 그리지 않고, 특수기는 실제 타격 준비 완료 뒤에만 그린다. 회복 중 기존 효과 감쇠를 따르며 피격 등 다른 상태에서는 즉시 지운다.
- 좌표가 있는 새 모션에서 가려진 끝은 기존 고정 효과로 대체하지 않는다. 좌표가 없는 기존 승인 모션은 기존 표시를 유지한다.
- 삼각형을 직접 나열한 메시로 곡선을 그려 자기 교차 외곽선의 삼각형 분할 오류를 피한다. 전투 상태를 읽기만 하며 판정·전투 시간·피해는 계산하지 않는다.

실제 코드는 `scripts/claw_attack_paths.gd`와 `scripts/fighter_attack_effects.gd`다. `tests/fixtures/nabi_claw_anchors_v01.json`은 좌표만 포함하며 미승인 그림은 포함하지 않는다. 테스트가 작업 폴더에 의존하지 않게 한다.
