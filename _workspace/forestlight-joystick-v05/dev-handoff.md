# 방향 조이스틱 v05 개발 전달

이번 결과는 Penpot 설계와 자산이다. Godot 화면·입력·저장 형식·리소스 등록은 변경하지 않았다. 첨부 예시의 원형 링·입체 손잡이 구조를 참고하고 잎 문양과 색상·벡터 경로는 새로 제작했다.

## 좌표와 방식

1920×1080 좌표이며 1280×720에서는 모두 2/3배다. 20:9 비교 보드는 중앙 1920 영역을 유지하고 좌우 여백 240을 더한다.

| 요소 | x,y | 시각 크기 | 입력 영역 / 기준 |
| --- | --- | --- | --- |
| 고정 조이스틱 | 152,690 | 320×320 | 144,682 / 336×336, 중심 312,850 |
| 플로팅 시작 영역 | 144,642 | 설명용 점선 | 496×384, 실제 경기에서는 점선 숨김 |
| 플로팅 중심 제한 | x304–480,y802–866 | 320×320 링 | 링 전체가 시작 영역 안에 있도록 제한 |
| 고정 선택 | 1212,344 | 244×88 | 같은 크기의 클릭 영역 |
| 플로팅 선택 | 1476,344 | 244×88 | 같은 크기의 클릭 영역 |

고정은 같은 위치에서 시작하고 해제 시 손잡이를 중앙으로 돌린다. 플로팅은 이동 영역 안 첫 터치 지점을 기준으로 링을 생성하며 손을 떼면 숨긴다. 링 중심은 끌기 중 움직이지 않는다. 가장자리 터치는 중심 제한을 적용한다. 기본값 복원은 고정·크기100%·투명도85%다.

손잡이 최대 이동 반경44, 반지름72, 내부 홈 반지름125는 디자인 기준이다. 방향 판정 임계값과 중심 무입력 범위는 Android 검증 후 확정한다. 이동 속도에 아날로그 강도를 추가하지 않는다. 오른쪽 약·강·특수·점프·대시 및 HUD 위치는 유지한다. 자유 이동 배치 편집은 없다.

## 상태와 이미지

assets/ui/forestlight-joystick-v05/에 편집 가능한 SVG 7개와 투명 PNG 7개, manifest.json을 제공한다. 기본·입력 중·선택·사용 불가, 분리 링·손잡이·플로팅 영역이다. 글자는 이미지에 포함하지 않는다. Penpot에는 320px 원본 7개와 설정 미리보기240px를 포함한 실제 재사용 컴포넌트 8개를 만든다. 기존 v02–v04 자산은 보존한다.

## 구현 후 재검사

- JOY-01: 고정 해제 후 중앙 복귀, 플로팅 해제 후 숨김과 새 터치 생성.
- JOY-02: 시작 영역 가장자리 터치, 16:9·20:9의 노치·제스처 여백과 오른쪽 버튼 가림.
- JOY-03: 이동과 공격 동시 입력, 두 번째 이동 손가락이 첫 입력을 빼앗지 않음.
- JOY-04: 버튼 밖 이탈은 이동 반경 제한과 손가락 소유 유지. 해제·pointer cancel·앱 중단·메뉴 이동 시 이동 입력 해제.
- JOY-05: 설정 적용·방식 변경 때 남은 이동 입력 초기화. 기본값 복원은 고정·100%·85%.

위 항목은 개발 전달용이며 실제 Android 기기 통과를 주장하지 않는다. 현재 Penpot 프로토타입은 화면 선택과 미리보기 상태를 보여주며 손가락 추적 엔진을 구현하지 않는다.
