# 조이스틱 v05 설계

독창적인 하늘색 원형 링과 연두색 손잡이, 중앙 잎 실루엣, 반투명 이동 홈을 SVG로 제작했다. 첨부 이미지의 원형 링·입체감 구조만 참고했으며 픽셀 추출·트레이싱·재색칠하지 않았다. 기본·입력 중·선택·사용 불가와 분리 링·손잡이·플로팅 영역, 총 SVG 7개·투명 PNG 7개다. 글자는 별도 Penpot 텍스트다.

## 동작 전달

고정: 기존 중심 312,850, 시각 영역 152,690 / 320×320과 터치 영역 144,682 / 336×336 유지. 처음 위치는 기본값을 유지하는 설계다. 손잡이는 입력 방향으로 움직이고 손을 떼면 중앙으로 돌아온다.

플로팅: 왼쪽 이동 영역 144,642 / 496×384 안 첫 손가락 터치에 생성한다. 링 전체가 영역과 안전 여백 안에 있도록 중심 x304–480, y802–866으로 제한한다. 손을 떼면 링·손잡이가 숨고 다음 터치에서 다시 생성한다. 손가락을 끌어도 링 중심은 시작점에 유지하는 플로팅 방식이며 지속 추적 방식은 추가하지 않는다. 전투 예시는 중심 356,818이다. 영역의 점선은 설명용이고 실제 경기에서는 숨긴다.

손잡이 반지름 72, 내부 홈 반지름 125, 최대 이동 반경 44를 디자인 기준으로 한다. 중심 부근 무입력 범위와 방향 판정 임계값은 Android 조작성 확인 후 확정한다. 기존 방향·동시 공격 입력 형식은 변경하지 않고 아날로그 속도 기능을 추가하지 않는다. 다른 손가락의 공격·점프·대시 입력은 독립적으로 유지한다. 두 번째 이동 손가락은 첫 손가락이 끝날 때까지 이동을 빼앗지 않는다.

버튼 밖 이탈은 손잡이 위치를 최대 반경으로 제한하며 터치 소유권은 유지한다. 손가락 해제·pointer cancel·앱 중단·메뉴 전환 시 이동 입력을 해제한다. 설정에서 모드를 바꾸면 미리보기를 갱신하고 적용 시 이동 상태를 초기화한다. 기본값 복원은 고정·크기100%·투명도85% 설계 기준이다. 자유 위치 편집은 추가하지 않는다.

설정에서 선택은 체크·색상으로 구분하며 두 모드의 설명과 미리보기를 바꾼다. 16:9·20:9에서 오른쪽 행동 버튼과 기존 HUD 좌표는 유지한다. 논리 해상도 1280×720 좌표는 2/3배다.
