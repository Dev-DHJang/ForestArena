# 강공격·특수기·공중 공격 회귀

2026-11-18, root 검토. 실제 CombatIntent·고정 틱·지형·적중 계산을 사용하는 기존 render-pilot.gd로 두 캐릭터의 이동/정지·점프/착지·기본 콤보·지상 강공격·특수기·공중 강/약14클립을 기록했다. 원본 코드/리소스 불변 확인을 포함해7,735조건 pass.

자료: regression/index.html, state-summary.json, 각 MP4와 표본 비교판. 원본 전체 상태: build/combat-naturalness/runtime-regression-r03/state-report.json. 영상은3틱마다 촬영한20FPS 자료이고 macOS이며, OS 포커스 일시정지를 제외한 촬영용 루트만 사용했다. 기기 생명주기 증거가 아니다.

지상 강공격·공중 강공격·특수기·공중 약공격 각 양 캐릭터8개 비교판 전체 표본을 직접 확인했다. 목도리/손톱 공격 준비→타격→회수, 발사/밀림→착지/다운 구분이 유지됐다. 공중 약공격은 높은 위치에서 빗나간 사례이며, 그 영상만으로 공중 약공격 적중을 통과시키지 않는다(적중은 자동 전투 검사 별도). 나비 공중 강공격의 마지막은120틱 시점에 기상 진행 중이므로 해당 클립만으로 기상 종료를 확인했다고 하지 않는다.

발견한 기존 결함: 자현 특수기 진입·복귀에서 머리/몸 전체가 작아졌다 커지는 현상. 독립 검토도 재현했고 r05 표시 크기 후보로 수정한다. 나비 기존 다운 원화의 자세 역행은 앞선 수정 후보의 대상이며 승인 전 기존 runtime 촬영에는 그대로 남아 있다.

이동·점프와 기존 콤보의 자동 촬영 조건은 통과했지만 이 회귀 기록의 추가 육안 판정은 위8개 공격 비교판에 한정한다. 새 콤보 후보 전체 프레임·양방향·축소·재생 관찰은 별도 r04/r05 기록을 따른다.
