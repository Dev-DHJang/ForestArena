# 전투 구현과 검사

활성 두 캐릭터 지상 중간 약공격을 준비8·판정4·회복12틱으로 변경했다. 한 번 예약하는 입력 규칙과 작은 수평 넉백은 유지한다. 기존 위쪽 넉백 성분을 제거해 지상 연타 중 불필요한 뜀을 없앴다. 마지막 타격의10·4·22틱은 유지한다.

지상 피니시는36틱 다운으로 시작하고, 공중 피니시는 실제 착지에서36틱 다운을 시작한다. 누운 상대에게 재타격으로 다운·피해를 재시작하지 않는다. 기상 보호12틱과 유효 공격 시작 시 보호 해제는 기존 규칙을 사용한다. 지상 다운 속도는 지상 마찰로 멈춘다.

LAN 수신 뒤 최대3틱(20Hz 수신 간격)만 표시 시간을 진행한다. 받은 단계의 끝을 넘지 않으며 실제 FighterController 상태·판정은 수정하지 않는다. 몸과 공격 효과는 같은 표시 시간을 쓰고, 새 피격 이벤트는 첫 자세로 재시작한다. 이벤트가 타이머보다 먼저 오면 새 타이머가 올 때까지 첫 피격 자세를 유지한다.

## 자동 검사

- tests/combat_motion_naturalness.gd: 4,315조건. 4가지 공격자/피격자 조합·양방향·근접 거리에서 상대의 공격/가드/점프/이동 시도에도 중간 행동 틈이 없음. 사거리 끝 밀림 이탈, 다운 면역, 공중 착지, 보호 해제, 예약 취소 포함.
- tests/combat_network_presentation.gd: 360조건. 30/60/120FPS·20Hz 수신·중복/정지 패킷·재피격·몸/효과 일치·실제 상태 불변 포함.
- 기존 4캐릭터 기반 검사 match_playtest_combat는 legacy 규칙에 맞는 Catalog.new(false)를 명시했다. 현재 활성 두 캐릭터 연계는 새 검사로 검증한다.
- 최종 전체 실행: build/verification/20261118-040016-e9daa527/result.json, pass. 가져오기1단계+95개 검사,541.85초. 관련 모든 전투·표현·실제 LAN·리소스·하네스 검사 포함. 이 결과는 실제 Android 통과를 뜻하지 않는다.

전체 검사 전 기존 테스트의 오래된 콤보 종료 기준·공중 착지 표현 조건과 새 표시 검사의 분야 분류를 수정했다. 제품 코드의 실패를 무시하거나 검사 기대값을 새 결함에 맞춰 낮추지 않았다.
