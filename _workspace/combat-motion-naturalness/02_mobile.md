# 실제 Android 확인 상태

2026-11-18 adb devices 결과 연결 기기 없음. 실제 기기 설치·터치 연타·가드/점프 끼워넣기·백그라운드 복귀·프레임 속도 확인은 blocked(미실행)다. 자동 검사나 macOS 렌더를 기기 통과로 바꾸지 않는다.
