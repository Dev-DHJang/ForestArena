# 실제 Android 확인 상태

## 완료 처리

2026-11-19 사용자가 이 변경의 자체 실기기 검사를 수행했고, 실기기 검사를 완료 처리하도록 지시했다. 이에 따라 공격·콤보·피격·경직 수정본의 실기기 확인 상태를 `완료(사용자 자체 검사)`로 기록한다.

세부 입력 순서, 영상, 프레임 측정값은 전달받지 않았다. 따라서 이 기록은 사용자가 한 완료 선언을 자동 측정 통과나 별도 재현 증적으로 바꾸어 표현하지 않는다.

## 보조 자동 기록

- 2026-11-18 실기기 `SM-S918N` 한 대에서 디버그 APK 설치·실행과 가로 화면·첫 선택 진입은 DEV-01 pass로 확인했다. 당시 APK SHA-256은 `c6de0a12dc89a727c20b9b892b7107878d76604321ad677288c48f91481f5bec`, 소스 커밋은 `39de04d93da81b8e472f0d75f6bdc5cb639c010b`이다.
- 같은 자동 실행은 상점에서 조약돌 요요 카드를 찾는 경로가 현재 화면 구조와 맞지 않아 UI-01에서 멈췄다. 이 실패는 자동 실행 경로의 한계로 남기며, 사용자 자체 검사 완료를 실패로 덮어쓰지 않는다. 원본 결과는 `artifacts/combat-naturalness-device/0cf281ce55c54a2abdc6077c2de8e37b/summary.md`에 보존한다.

## 범위 밖 또는 별도 확인

- 물리 단말이 한 대여서 두 실기기 간 LAN 대전은 실행하지 않았다.
- 새 모션 후보 네 개는 사용자 승인 전이고 실행 리소스에 등록하지 않았다. 따라서 이번 실기기 완료는 현재 승인된 리소스를 사용한 전투 수정본에 대한 것이다.
