# 승인 조합 적용

최종 9개 선택은 01_contract.md와 assets/audio/v02-selected/manifest.json에 같은 내용으로 기록했다. 다섯 v01은 기존 파일을 유지하고 네 v02만 r03 원본 PCM을 복사했다. v01 음악은 승인된 기존 음색의 전체 80/90초 반복곡을 그대로 재사용한다. 새 반복 음악 렌더링은 없다.

apply_approved_audio_v02.py가 최종 선택을 반복 적용할 수 있게 한다. 실제 경로 네 개만 registry에서 바꾸며 기존 ID와 이벤트 설정은 유지한다. 비교 음량 조정본이 아닌 원본 PCM을 게임의 기존 이벤트 음량으로 재생한다. 선택된 v02 효과음은 직접 합성이며 외부 녹음·샘플·음성이 없다.

전체 비교 컬렉션은 승인된 아홉 선택과 구분한다. 새 B 로비/전투는 비교 자료로만 보존하며 게임에 연결하지 않는다. 전체 47개를 v02로 변경하지 않는다. 새 선택 검사와 기존 v01 원본 검사·Godot 로드·앱 흐름을 함께 확인한다. 실제 Android는 후속이다.
