# 미니맵 독립 품질 확인 1차

판정: **fix**. 구현 담당과 별도로 원 요청·데이터 약속·변경 전체 및 생성된 실제 앱 화면 4개를 검토했다. 물리 Android 검사는 미실행이며 통과로 기록하지 않는다.

## 고칠 항목

1. **내 위치 삼각형 가림** — `scripts/battle_minimap.gd`의 `_place_names`는 얼굴 영역만 예약하고 삼각형 영역을 예약하지 않는다. 기본 얼굴+이름 첫 배치는 이름 배경의 아래쪽이 얼굴 중심의 -15에 놓이며 삼각형(-15~-20)을 덮는다. `screens/app-2-face-16x9.png`에서도 삼각형이 사라진다. 내 위치 삼각형 영역을 이름 배치 제외 영역에 포함하고 얼굴+이름 및 점+이름에서 이름과 겹치지 않음을 검사해야 한다.
2. **LAN 줄바꿈 검증 차이** — 초기 `LanMatchClient._valid_nickname`은 U+2028/U+2029를 허용했지만 기기·DB는 거부했다. 담당자가 검토 중 수정했으며 갱신된 `tests/lan_contract.gd` 실행에서 두 문자 거부 통과를 확인했다. 해결됨.

## 확인 결과

- 자동 실행: `tests/battle_minimap.gd`, `battle_minimap_app_flow.gd`, `local_player_store.gd`, `lan_contract.gd` 모두 PASS. app_flow 종료 시 ObjectDB 2개 경고는 남으며 실행 오류는 없었다.
- 지형 좌표, 최대 8인, 팀 파랑/빨강·개인전 흰색, 탈락·재등장, 범위 밖 제한, 얼굴 리소스, 투명도·점·이름 끄기, 설정 저장·복원·실패 시 기존 값 유지에 대한 생산자·표시 코드와 테스트를 확인했다.
- 프로필 v1/v2 기기 이전·DB v2 이전은 보유·선택·접근성 보존 및 v3 기본값 추가를 확인했다. DB 동시 변경 덮어쓰기 방지 조건·중복 요청 응답 이전도 코드 검토했다. 실제 API·DB 검사는 주 담당 결과가 별도로 필요하다.
- LAN 이름 정규화·재접속·재대전 테스트 추가를 확인했다. 실제 WebSocket 실행 결과는 주 담당 검사 중이다. 전투 snapshot에 이름을 추가하지 않고 방 표시 정보에서 읽는다.
- 화면: 2인 얼굴 16:9, 8인 팀 최대 글씨 16:9, 8인 개인전 점+이름끄기 20:9, 설정 미리보기. 미니맵·대전 버튼·터치 조작·경기 정보가 겹치지 않으며 팀 이름·얼굴 테두리와 점 모드는 규칙대로 보인다. 삼각형 가림은 위 수정 필요.
- 별도 /tmp 진단으로 같은 위치의 8명·12자 한글·글씨 1.3에서 이름 상자 겹침 0개, 100번 snapshot 표시 갱신 평균 2.34ms(macOS headless)를 확인했다. 이 측정은 Android 성능 확인을 대신하지 않는다.
- `git diff --check` 통과. 원본 승인 PNG 변경 없이 AtlasTexture와 논리 ID로 얼굴을 재사용한다.
