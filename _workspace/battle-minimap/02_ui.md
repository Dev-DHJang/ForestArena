# 대전 미니맵 UI

- `BattleMinimap`은 공통 대전 장면 CanvasLayer 안의 240×150 Control이다. 우측 상단 화면 안전 영역에 16px 여백을 두고, 일시정지·LAN 나가기 버튼은 미니맵 아래 12px에 같은 너비로 놓는다. 지도는 mouse_filter=IGNORE로 터치를 가로채지 않는다.
- 경기장 전체 ring_bounds를 가로세로 비율을 유지해 축소한다. 충돌면을 간단한 색 면으로 그리고 카메라·승패·판정을 변경하지 않는다.
- configure(stage, participants, local_id, team_mode), apply_settings(settings, text_scale), update_snapshot(snapshot)로 화면 데이터를 받는다. 로컬 Vector2와 LAN {x,y} 좌표를 처리한다.
- 승인 콘셉트를 가리키는 네 AtlasTexture 얼굴 리소스를 추가해 ForestArenaResources 논리 ID로 읽는다. 원본 PNG·CharacterData·승인 모션은 바꾸지 않았다.
- 얼굴·점, 이름 켜기·끄기, 전체 투명도 0~90%(기본 30%)와 1~1.3배 텍스트를 표시한다. 이름은 말줄임 처리하며 얼굴·내 위치 삼각형·다른 이름과 겹치지 않는 가까운 공간으로 옮긴다.
- 팀전은 내 팀 파랑·상대 빨강, 개인전·1대1은 흰색이다. 내 위치 삼각형을 별도로 예약해 이름에 가려지지 않게 한다. 탈락 숨김·재등장 복원·범위 밖 가장자리 표시를 지원한다.
- 설정 화면에는 닉네임 입력·저장, 투명도 슬라이더·저장, 얼굴/점 선택, 이름 토글과 작은 미리보기가 있다. 미리보기는 Container 안에 고정하고 게임 화면 위치 자동 배치를 끈다. 변경은 저장 성공 뒤 다음 경기에 적용한다.
- 재현 가능한 화면 검사: `godot --path . --script res://tools/forest_arena/render_battle_minimap_app.gd`. screens/의 2명·8명 팀전 큰 글씨·20:9 개인전 점·설정 미리보기 네 화면을 생성한다. 실제 Android 기기 확인은 미실행이다.
