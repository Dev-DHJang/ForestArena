# 미니맵 독립 품질 확인 2차

판정: **pass** — 구현·저장·LAN 연결과 macOS 자동·화면 확인 범위. 1차 발견 항목은 모두 해결됐다. 물리 Android 안전 영역·멀티터치·60fps 성능은 미실행이며 이 판정에 포함하지 않는다. PR·develop 병합 결과는 마무리 기록에서 별도로 확인한다.

## 수정 재확인

- 내 위치 삼각형 공간을 이름 배치에서 예약하고, 모든 얼굴·이름을 그린 다음 삼각형을 마지막에 그린다. 겹친 다른 얼굴도 내 위치 표시를 덮지 않는다. 새 자동검사 PASS와 다시 생성한 2인·8인 팀 큰 글씨 화면에서 삼각형 표시를 확인했다.
- LAN U+2028/U+2029 줄바꿈 거부를 기기·DB와 맞췄다. 변경된 LAN 계약 검사 PASS를 확인했다.
- 기기 이전 시 유효한 v1/v2 원본을 .bak에 보존하고 JSON 숫자 형식으로 읽은 버전도 처리한다. 갱신된 LocalPlayerStore 코드와 자동검사 PASS를 확인했다.
- 실제 DB 검사에 추가한 v2 응답 재시도 SQL의 연산 순서 오류는 검사 코드 괄호 수정으로 해결됐다. 서비스 코드 오류는 아니었다.

## 최종 증거

- 직접 재실행: `tests/battle_minimap.gd`, `tests/local_player_store.gd` PASS 및 `git diff --check` 통과. 1차에 직접 실행한 미니맵 앱 흐름·LAN 계약도 PASS였다.
- `/tmp/forest-minimap-verify.log`: `./scripts/verify.sh` 전체 통과. 두 실제 Godot 앱의 LAN 미니맵에서 host/guest 각각의 내 위치와 중립색 검사, 실제 WebSocket 이름·재접속·재대전 검사, API 단위 검사, 문서·리소스·AI 역할 체계 검사를 포함한다.
- `/tmp/forest-minimap-db3.log`: 실제 PostgreSQL에 대해 `verify-db-profile-runtime: PASS`. 닉네임·미니맵 저장·재실행 복원·Godot 값과 SQL 값 일치, 기존 v2 DB 행 이전, v2로 기록된 응답 재시도를 추가한 검사 코드를 함께 확인했다.
- `/tmp/forest-minimap-render3.log`로 다시 생성한 `screens/` 4개 실제 앱 화면을 확인했다. 16:9 2인/8인 팀 큰 글씨 및 20:9 개인전 점·설정 미리보기에서 지도·버튼·터치 영역 배치와 표시 규칙을 확인했다. 승인 얼굴은 원본 변경 없이 논리 ID·AtlasTexture로 읽는다.
- 02_ui.md와 02_contracts.md에 배치·터치·미리보기·저장·LAN 연결 설명을 추가한 것을 확인했다.
- 성능 보조 측정은 1차 기록의 macOS headless 8인 동위치·12자 이름·큰 글씨 100회 평균 2.34ms이며 Android 성능을 증명하지 않는다. 기존 자동검사 종료 시 ObjectDB 경고는 보존해서 기록하며 새 실행 오류는 확인되지 않았다.

현재 확인 범위 안에서 남은 구현 수정 요청은 없다. 물리 Android 미확인 항목과 원격 PR·병합 증거는 최종 마무리 기록에 명시한다.
