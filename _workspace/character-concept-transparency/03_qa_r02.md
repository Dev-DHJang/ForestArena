# 로컬 알파 정리 확인

- 사용자가 편집 방식 전환을 명시 승인했다. 새로운 캐릭터 디자인이나 모션을 만들지 않는다.
- 자현·나비·유란의 기존 RGB 전체 바이트와 후보의 RGB 전체 바이트가 일치한다. 1086×1448 구도와 모든 색상을 보존했고 alpha만 바꿨다.
- 묘령은 기존 투명 PNG를 파일 해시까지 그대로 유지했다.
- 흰색·어두운 배경 검토판 4개를 직접 확인했다. 얼굴·의상·귀·꼬리·리본·신발과 전신이 유지되고 빈 공간이 배경색을 보여 준다. 원본 검은 가장자리 표현을 다시 칠하거나 색 보정하지 않았다.
- 닫힌 검은 영역을 일괄 제거하면 검은 의상도 지울 수 있으므로, 수동 확인한 머리카락·팔·꼬리 사이 빈 영역의 정확한 좌표만 제거한다. 원본 SHA-256 및 영역 형태가 다르면 처리를 거부한다.
- 단위 검사 3개: RGB 보존·큰 검은 내부 영역 보존, 명시한 빈 영역만 제거, 영역 형태 변경 거부. 통과.
- 등록 전 자동 확인은 해상도·실제 alpha·모서리·전경 보존과 원본/출력 해시를 확인한다. 별도 사람의 디자인 승인이나 물리 Android 검사로 주장하지 않는다.
- 전체 검사·원격 검토·병합 결과는 완료 후 `04_closeout.md`에 기록한다. Android는 명시 이연한다.
- 최신 develop 통합 공간 전체 검사 exit 0: `develop-verify.log`. 새 CharacterData의 실제 RGBA 검사도 통과했다. 원격 검토는 아직 진행 중이며, 완료 후 검토 지적을 확인하고 병합한다.
