# 콘셉트 투명 배경 변경 결과

상태: 사용자 승인 후 로컬 알파 정리·등록 완료. 전체 검사와 별도 PR 통합 진행 중.

## 2026-10-09 승인 반영

- 사용자가 로컬 알파 정리 방식을 승인했다(`approval.json`). 원본 RGB 전체 바이트를 보존하며 alpha만 정리했다.
- 자현·나비·유란은 1086×1448 RGBA PNG로 등록했고, 묘령은 기존 파일·해시를 그대로 유지했다. 콘셉트 ID와 사용 경로·외형 계약·전투 수치·승인 모션은 바꾸지 않았다.
- 닫힌 검은 영역은 수동 확인한 빈 공간만 제거한다. 검은 의상을 임의로 지우지 않으며 원본 해시나 확인한 영역의 형태가 바뀌면 실패한다.
- 검토판 4개를 흰색·어두운 배경에서 확인했다. 자동 검사와 단위 검사 3개 통과. 원본 PNG 3개와 이전 manifest는 `03_backup/`에 보존했다.
- 내장 편집 후보는 색상 변화·잔여물로 탈락했으며 등록하지 않았다. 아래 blocked 내용은 승인 전 이력이다.

- 묘령은 기존 1086×1448 RGBA·alpha 0~255로 확인했다. 재생성하지 않았다.
- 자현·나비·유란은 RGB 검은 배경이었다. 내장 이미지 편집으로 같은 해상도의 투명 RGBA 후보를 만들었다.
- 유란 가장자리와 빈 영역에서 색 잔여물을 발견했다. 두 번째 편집에서도 남아 있어 QA 통과나 등록 완료로 기록하지 않는다.
- 원본 색상을 유지하는 로컬 알파 정리로 전환할지 사용자에게 질문했다. 명시 답변 전에는 로컬 스크립트로 이미지를 편집하지 않는다.
- 원본 콘셉트·manifest·외형 계약·승인 모션은 이 추가 작업에서 아직 변경하지 않았다.
- 선행 모션 PR #76은 develop 병합 완료. 배경 제거 품질이 미완료이므로 전체 Goal 완료로 처리하지 않는다.
- 읽기 전용 후보 비교도 완료했다(`check_candidates.py`, `03_qa_r01.md`). 모든 편집 후보에서 불투명 전경 RGB 변화가 확인되어 배경만 제거한 최종본으로 채택하지 않는다. 원본 보존 방식 전환에 대한 사용자 답변이 아직 필요하다.
- 동일한 승인 대기 조건이 최초 질문 턴과 두 번의 자동 재개에서 연속 확인됐다. 후보 제작·재편집·읽기 전용 비교를 수행했지만 요청한 원본 보존을 만족하는 등록본은 없다. 승인 없이 편집 방식을 전환하거나 잘못된 후보를 등록하지 않는다.
- 재개 조건: 사용자가 로컬 알파 정리 방식 또는 다른 허용된 해결 방식을 명시 선택한다. Android 검증 이연과 기존 Goal의 범위·완료 조건은 그대로 유지한다.
