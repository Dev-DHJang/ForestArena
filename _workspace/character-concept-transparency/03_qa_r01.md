# 배경 제거 후보 품질 검사 — fix

## 읽기 전용 검사

`python3 _workspace/character-concept-transparency/check_candidates.py`로 등록 원본과 후보를 같은 좌표에서 비교했다. 이미지·manifest를 수정하지 않았다. 별도 사람의 승인이나 독립 에이전트 검토로 주장하지 않는다.

| 후보 | RGBA·1086×1448·alpha 0~255 | 불투명 전경의 평균 RGB 차이(0~255) | 원본의 거의 검은 위치에 새 밝은 색이 생긴 픽셀 |
| --- | --- | --- | --- |
| 자현 r01 | 확인 | 49.1888 | 1689 |
| 나비 r01 | 확인 | 37.3267 | 3690 |
| 유란 r01 | 확인 | 42.3653 | 3560 |
| 유란 r02 | 확인 | 97.8100 | 40424 |

이 수치는 같은 좌표의 색 변화 진단이지 얼굴 유사도나 해부학 판정이 아니다. 검은 옷도 포함될 수 있으므로 밝은 색 발생 개수를 전부 배경 오류라고 단정하지 않는다. 다만 전경 RGB가 그대로 보존되지 않았으며, 앞선 수동 확인에서도 유란의 배경 색 잔여물이 보였다. 따라서 배경만 바꾸라는 요청의 최종본으로 자동 등록하지 않는다.

## 다음 단계와 제한

- 원본 색상을 유지하는 로컬 알파 정리로 전환할지 사용자 답변이 필요하다. 내장 도구를 계속 반복하는 것은 원본 보존을 보장하지 않는다.
- 답변 전 로컬 이미지 편집·런타임 교체·manifest 갱신은 하지 않는다.
- 묘령은 기존 실제 alpha가 있으므로 유지한다. Android 검증은 사용자 결정으로 이연한다.
