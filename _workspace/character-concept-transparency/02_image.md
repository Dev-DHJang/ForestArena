# 배경 제거 제작 기록

- 방식: 내장 image_gen, `transparent_background=true`, 캐릭터별 현재 등록 PNG를 편집 대상으로 참조.
- 공통 프롬프트: 검은 배경만 실제 RGBA alpha로 제거한다. 얼굴·몸·포즈·비율·색·귀·꼬리·의상·장식·전신 구도를 유지한다. 재디자인·다시 그리기·그림자 배경·체크무늬 픽셀·잘림·테두리 잔여물을 금지한다.
- 자현 고정 요소: 은백색/코발트 머리, 파란 눈, 둥근 쥐 귀 2개, 얇은 분홍 꼬리 1개, 흰색/검정/코발트 의상과 고유 추상 문양.
- 나비 고정 요소: 보라 머리·눈, 고양이 귀 2개·풍성한 보라 꼬리 1개, 검정/흰색/보라 의상, 긴 발톱 장갑, 방울·리본·고양이 문양.
- 유란 고정 요소: 은회색 머리, 갈색 눈, 둥근 귀 2개·갈색/흰색 줄무늬 꼬리 1개, 갈색/흰색/검정 의상, 청록색 보석.
- 유란 추가 정리 프롬프트: 캐릭터는 그대로 두고 다리 사이·머리 위·꼬리 밖·캔버스 가장자리의 분리된 빨강/노랑 색 점과 테두리 잔여물만 제거한다.
- 결과 위치: `01_review/*-transparent-r01.png`, `01_review/yu-ran-transparent-r02-fix-required.png`. 모든 후보는 1086×1448 RGBA·alpha 0~255다. 실제 색 잔여물 때문에 유란은 fix(추가 수정 필요)이며 전체 등록은 보류했다.
- 묘령은 기존 RGBA이므로 재생성하지 않았다. 사용자에게 로컬 알파 정리 방식 전환을 질문했고 답변을 기다린다.
