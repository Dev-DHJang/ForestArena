# 캐릭터 콘셉트 투명 배경 변경

- 요청: 등록된 캐릭터 콘셉트 아트를 배경 없는 PNG로 수정한다(2026-10-09).
- 범위: 자현·묘령·나비·유란의 현재 등록 콘셉트. 기존 실제 alpha가 정상인 파일은 보존한다.
- 디자인·포즈·의상·신체 특징·논리 ID·CharacterData 경로는 유지한다. 배경 제거만 수행하며 전투 수치와 승인 모션은 변경하지 않는다.
- 내장 이미지 편집으로 투명 RGBA PNG를 만들고 원본을 백업한다. 출력의 실제 alpha·전신·모서리·외형 보존을 검사한다. 새 디자인이 되면 자동 등록하지 않는다.
- manifest의 해시·변경 이력·원본 추적을 갱신하고 관련 자동 검사·Godot 리소스·전체 검사를 수행한다. Android 검증은 기존 사용자 결정대로 이연한다.
- 모션 PR #76의 검토·병합 조건은 유지하며, 관련 없는 미커밋 변경은 보존한다.
- 2026-10-09 사용자 `승인한다.`로 원본 색상을 유지하는 로컬 알파 정리 방식 전환을 명시 승인했다. 내장 편집의 색상 변경 후보는 등록하지 않는다.
