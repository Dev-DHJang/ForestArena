# 요청

2026-09-12 사용자 승인에 따라 Phase 3 전투 원형 비교를 구현한다.

- 자현, 묘령, 나비와 각 캐릭터의 전문 프로토타입 직업을 비교한다.
- 방어, 회피, 잡기, 지상 강 차지, 전체 방향 특수기, 궁극기를 결정론적 전투에 추가한다.
- 개발 빌드 전용 매치 런처, 세 결정론 봇 프로필, 읽기 전용 HUD와 로컬 JSONL 플레이테스트 기록을 제공한다.
- ADR-013의 동작 의미와 ADR-007의 Galaxy S23 Ultra 60 FPS 기준을 accepted로 전환한다.
- 정식 선택 UI, 성장·경제, 장신구 시너지, 온라인, 최종 전투 애니메이션은 범위 밖이다.
- 실제 Galaxy S23 Ultra에서 18개 매치와 10분 성능 검증을 실행하지 못하면 Phase 완료로 기록하지 않는다.
