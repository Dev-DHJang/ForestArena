# Phase 3 UI 인수인계

- `TouchCommandSource`는 기존 `dash`와 `grab_support`, `ultimate`을 포함해 press/hold/release를 전송한다.
- grab 버튼은 가드 해제 grace에서만 보인다. 포커스 손실·중단·터치 영역 이탈은 모든 touch/hold를 해제한다.
- HUD는 가드 내구·붕괴, 회피 가능, 특수 쿨다운, 궁극기 게이지·stock 사용 여부를 읽기만 한다.
- `Phase3DebugLauncher`는 개발 빌드의 양측 캐릭터·직업, 봇 프로필, 시나리오 선택용이다. 정식 `SCR_06`–`SCR_08` 선택 UI나 저장은 추가하지 않는다.
- 최종 신규 자산 대신 상태색·텍스트·단순 VFX와 registry fallback으로 판독성을 제공한다.
