# 제품 인수인계

## 원형 가설

- 자현 기본형은 간격 유지와 균형 대응, `ja-hyun-guard-prototype`은 더 오래 버티는 가드와 안정적인 차지 반격을 유도한다.
- 묘령 기본형은 상승·공중 추격, `myo-ryung-aerial-prototype`은 더 긴 회피 이동과 빠른 회피 재사용으로 공중 위치 선점을 유도한다.
- 나비 기본형은 짧고 강한 근접 압박, `nabi-grapple-prototype`은 빠른 잡기와 줄어든 실패 회복으로 가드 대응을 유도한다.

## 공통 비교 조건

- 단일 참여자가 Galaxy S23 Ultra에서 기본형 3개와 전문 직업형 3개를 간격·공중·근접 봇 각각과 3-stock 한 경기씩 플레이한다. 총 18경기다.
- 매치 seed, 원형·봇 ID, 행동·성공 집계, 링아웃과 경기 시간을 같은 JSONL 계약으로 기록한다.
- 기본형과 전문 직업형의 핵심 행동 지표가 구분되지 않으면 해당 직업은 유지가 아니라 재튜닝으로 판정한다.
- 결과 문서에는 각 원형의 유지·조정·폐기 중 하나와 근거를 기록한다. 이 결론은 최종 밸런스 확정이 아니다.

## 종료 경계

- 자동 회귀와 실기기 18경기, 10분 성능 검증, 독립 QA가 모두 통과해야 Phase 3 종료다.
- 정식 선택 UI, 성장·경제, 장신구·태그 시너지, 온라인, 최종 모션·오디오는 후속 Phase 범위다.
