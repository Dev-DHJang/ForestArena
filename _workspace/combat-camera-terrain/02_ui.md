# 카메라·화면 밖 상대 UI

- `CombatCamera`는 플레이어 위치를 따라가며 줌 1.25를 유지한다.
- `LocalFighterPresentation`은 현재 스프라이트의 viewport 사각형을 읽기 전용으로
  제공한다.
- `OffscreenOpponentIndicator`는 상대가 완전히 화면 밖일 때만 방향 화살표를 그린다.
- 화살표는 1280×720 기준 상단 HUD 아래와 하단 터치 영역 위에 배치하며, 비율이 다른
  Android 화면에서도 viewport 크기로 다시 계산한다.
- 모든 갱신 전후 전투 snapshot은 같아야 한다.

## 구현 결과

- `scripts/combat_camera.gd`: 상대와 링 경계에 따른 가변 줌을 제거하고 플레이어 위치와
  고정 줌 1.25만 사용한다. 이동 중에도 플레이어 중심이 밀리지 않도록 위치 지연은 두지
  않는다.
- `scripts/local_fighter_presentation.gd`: 현재 승인 모션 프레임을 화면 사각형으로 변환하는
  `screen_bounds()`를 제공한다.
- `scripts/offscreen_opponent_indicator.gd`: 실제 스프라이트가 viewport와 겹치지 않을 때만
  방향 삼각형을 그리고, HUD와 터치 조작 사이의 비율 기반 안전 영역에 고정한다.
- `scripts/arena_visual.gd`: 승인 배경과 투명 지형을 논리 ID로 읽는다. 지형을 읽지 못한
  경우에만 단순 사각형 발판을 대체 표시한다.
- 위 구성은 표현 계층에만 있으며 `MatchController.snapshot_hash()`를 변경하지 않는다.
