# 나비 콘셉트·전체 모션 이미지 교체 작업 기록

상태: 진행 중 — 29개 고유 시안의 일괄 사용자 승인 대기

## 완료

- 사용자 제공 콘셉트를 기존 `nabi-concept-v01` 경로에 등록했다.
- 나비 외형 계약과 고정 검사를 새 콘셉트에 맞춰 갱신했다.
- 31개 물리 모션 이미지 교체에 필요한 29개 고유 시안을 검토 경로에 만들었다.

## 보류

- 31개 기존 런타임 PNG, manifest 해시, SpriteFrames 소비 연결의 실제 교체는 사용자 승인 뒤에만 한다.
- 기본 편성, 선택 UI, 전투 수치와 판정은 변경하지 않았다.
