# 자현 잔여 전투 모션 2D 애니메이션 계획

## 공통 시각 계약

- 각 시안은 투명 배경의 우향 전신 4×4·16포즈다. 프레임 순서는 좌→우, 위→아래이며 좌향은 향후 시각 래퍼에서 수평 반전한다.
- 준비·공격·후행·회복에 걸쳐 팔·다리·몸통·꼬리·리본이 실제로 변한다. 공격 포즈와 리본 궤적은 AttackData의 시작·활성·회복·피해·넉백·충돌을 정의하지 않는다.
- 승인 전에는 검토 경로만 사용한다. 승인된 검토 시안의 런타임 정규화와 등록은 별도 요청이다.

## batch-01: 일반 지상 공격

| visual state | 연기 의도 |
| --- | --- |
| `attack_light_up` | 낮은 가드에서 짧고 빠른 상승 손 타격 후 가드 복귀 |
| `attack_light_down` | 중심을 낮춰 전방 하단을 확인하는 짧은 손 타격 |
| `attack_heavy_side` | 몸통 회전과 긴 리본 후행이 보이는 큰 수평 발사 타격 |
| `attack_heavy_up` | 깊은 웅크림에서 크게 솟는 런처 타격 |
| `attack_heavy_down` | 낮은 자세의 넓은 다리 스윕과 지면 가까운 리본 원호 |

## batch-02: 대시·공중 공격

| visual state | 연기 의도 |
| --- | --- |
| `attack_dash_light` | 전진 관성을 살린 짧은 돌진 잽과 제동 회복 |
| `attack_dash_heavy` | 큰 전방 체중 이동과 넓은 실루엣의 돌진 피니시 |
| `attack_air_light` | 공중에서 몸을 작게 유지하는 빠른 손·발 견제 |
| `attack_air_heavy` | 몸통 회전과 리본 궤적이 큰 공중 피니시 |

## batch-03: 특수기

| visual state | 연기 의도 |
| --- | --- |
| `special_neutral` | 긴 파란 리본을 전방으로 뻗었다가 안쪽으로 감아 당기는 동작 |
| `special_up` | 지상 또는 공중에서 상승 회전하며 리본이 나선형으로 후행하는 복귀기 |
