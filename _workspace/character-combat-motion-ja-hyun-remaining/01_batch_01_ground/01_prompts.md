# batch-01 생성 프롬프트 기록

- 도구: 내장 이미지 생성 도구. 각 모션은 별도 생성했고, 생성 결과가 RGB 체크무늬를 포함한 경우 같은 결과를 파일 경로로 참조해 배경만 제거하는 별도 편집을 수행했다.
- 공통 참조: `assets/character/ja-hyun/concept/ja-hyun-concept-v01.png`, 기존 승인 약공격 시트. 배경 정리에서는 해당 모션의 원본 생성 PNG만 참조했다.
- 공통 제약: 투명 RGBA, 우향 전신 4×4·16포즈, 은백색 머리·쥐 귀 2개·꼬리 1개·인간형 손발·흰색/검정/코발트 의상·긴 파란 리본 유지. 상대·문자·워터마크·브랜드·무기·판정/VFX 금지.

| visual state | 생성 핵심 문구 |
| --- | --- |
| `attack_light_up` | 낮은 가드 → 짧고 빠른 상승 손 타격 → 가드 복귀 |
| `attack_light_down` | 중심을 낮춘 전방 하단의 짧은 손 확인 타격 |
| `attack_heavy_side` | 몸통 회전과 긴 리본 후행이 있는 큰 수평 발사 타격 |
| `attack_heavy_up` | 깊은 웅크림 → 크게 솟는 장갑 낀 손 런처 타격 → 긴 회복 |
| `attack_heavy_down` | 낮은 자세 → 넓은 다리 스윕·지면 가까운 리본 원호 → 낮은 회복 |
