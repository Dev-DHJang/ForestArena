## 코드·미리듣기 검토

SFX는 고정 난수와 목재 공명·공기·중저음 충격을 사용한다. 클릭의 높은 종소리, 점프의 큰 상승, 가드 파괴의 세 음 종, 기술의 연속 상승 음계 비중을 줄이려는 구현을 확인했다. 요청한 방향을 코드에 반영했다는 증거이며 청감 개선 승인은 아니다.

미리듣기는 음악 2쌍·SFX 6쌍, 한 음원씩 재생, 음악 A/B 위치 이어듣기, 효과음 처음부터 재생과 서버 전송 없는 의견 복사를 제공한다. 게임 미연결·청취 방향 확인 전·실기기 미확인을 표시한다. 코드 검토에서 발견한 **늦게 로드된 이전 음원이 최신 선택을 가로채는 문제**는 전역 재생 요청 번호로 오래된 `loadedmetadata` 요청을 취소하도록 수정했고 해당 코드를 다시 확인했다.

추가 브라우저 검토에서 기본 SimpleHTTPServer의 파일 일부 요청(Range) 미지원 때문에 음악 A/B 위치가 0으로 돌아가는 문제가 발견됐다. 전용 `serve_audio_v02_preview.py`가 127.0.0.1에서 시안 폴더만 제공하고 Range를 지원하도록 수정했다. QA 코드 검토에서 발견한 루트 `preview.html` 외부 심볼릭 링크 우회도 최종 파일을 선택한 뒤 다시 경로 경계를 검사하도록 수정했다.

QA 작성 HTTP 검사는 임시 루프백 포트와 폐기 가능한 파일로 실제 GET·HEAD·앞/뒤/끝 생략/끝 초과 Range·416·폴더 목록 차단·직접/인코딩 상위 경로·외부 심볼릭 링크·루트 index 심볼릭 링크 차단을 확인한다. QA sandbox의 socket.bind 제한은 제품 실패와 구분했고, 조율 담당의 허용된 실행 환경에서 **동일 검사 코드**를 포함한 최종 전체 시안 검사 exit 0/PASS를 수집했다. QA가 `/private/tmp/audio-v02-preview-final-verify.log`의 HTTP와 8쌍 음원 재측정 통과를 직접 확인했다. 명시적인 `--skip-http` 옵션 없이 검사 실패를 조용히 넘기지 않는다.

조율 담당 실제 브라우저 조작에서 새 로비 4.1862초 → 이전 4.450922초로 이어 재생, 두 음악 duration/seekableEnd 모두 30초를 확인했다. 전투 전환 때 로비 일시정지와 대표 6개 SFX 버튼 재생·길이·오류 없음을 확인했다. 이는 재생 기능 확인이며 사람이 음악 품질을 승인한 것이 아니다. 이후 음악 끝에서 다시 누르면 0초 재시작하고 의도된 빠른 전환의 AbortError는 파일 오류로 표시하지 않도록 수정한 코드도 QA가 읽었다. 모바일 폭의 독립 시각 검사는 별도 수행하지 않았다.
