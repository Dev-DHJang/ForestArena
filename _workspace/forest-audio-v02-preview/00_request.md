# 요청과 단계

사용자는 MapleStory Title Theme 영상(https://www.youtube.com/watch?v=paAK7Q_AAlo)을 음악 완성도 기준으로 제시하고 효과음의 발랄함을 조금 낮춰 재제작하도록 요청했다. 음색·편곡 완성도를 우선하고 짧은 시안부터 듣는 방식을 선택한 뒤 계획 구현을 지시했다.

## 이번 산출물

- 샘플 악기로 제작한 독자적인 로비·전투 음악 각각 30초.
- 버튼 클릭·점프·강타·가드 파괴·묘령 위 특수기·자현 필살기 6개.
- 기존 v01과 같은 청감 음량으로 비교하는 미리듣기, 원본·MIDI·악기별 오디오·설정·출처와 자동 검사.
- 자동 검사·독립 QA 뒤 시안 제작 파일을 develop에 보존한다. 게임의 v01 연결은 시안 승인 전 교체하지 않는다.

## 후속 단계

사용자가 시안을 듣고 방향을 확정하면 음악 80/90초와 효과음45개를 전체 재제작하고 기존 논리 ID로 연결한다. 사람의 청취와 실제 Android는 자동 검사로 통과 처리하지 않는다. 실제 Android 검증은 사용자 요청대로 후속 작업이다.
