# 음악·효과음 시안 제작

## 음악

파형 합성 v01을 수정하는 대신 새 악보를 작성해 FluidR3 GM 악기로 렌더링했다. 로비96BPM G major12마디, 전투128BPM A minor16마디로 각30초다. 선율·응답·현악 합주·첼로 대선율·하프·피아노·더블베이스·호른·타악9개 파트를 각각 보존한다. 음표마다 강약과 길이·하프 시작의 작은 시간차를 고정 난수로 설정했다. 렌더링은 FluidSynth2.6.0, 고정 샘플·gain·공간 반사 설정을 사용한다. 전투와 로비의 독자적인 선율은 코드/JSON/MIDI에 있으며 참고 영상에서 음표나 녹음을 추출하지 않았다.

시안 끝은0.65초 사라지며 반복 재생용으로 만들지 않았다. 전체80/90초의 반복 전개·경계는 시안 방향 확정 뒤 제작한다.

## 효과음

ui_click: 짧은 나무 스위치/손끝마찰, jump: 낮은 탄성과 공기, hit_heavy: 중저음 충격과 균열, guard_break: 불규칙한 파편·붕괴, myo-ryung_special_up: 가벼운 공중 숨결과 두 공명, ja-hyun_ultimate: 둔한 목재 힘과 낮은 기류. 외부 샘플 없이 고정 난수로 직접 합성한다. 원본과 같은 길이·모노44100Hz PCM16을 유지한다.

## 비교와 권리

음악은 전체 LUFS-I, 짧은 효과음은250ms 간격 반복 LUFS-I로 A/B 크기를 맞춘다. 두 버전이 모두true peak -2dB 아래가 되도록 공통 목표를 낮출 수 있다. 실제 측정값은 manifest에 기록한다. 수치만으로 자연스러움이나 참고곡 품질을 주장하지 않는다.

FluidR3 GM은 Debian 공식3.1-5.3 배포 패키지에서 추출했다. 라이브러리 확인값과 MIT 허가문·저작자·기여자 표시를 보존하며 패키징 코드는 사용하지 않는다. Homebrew 공식 FluidSynth2.6.0을 설치했다. 라이브러리는 제작에만 쓰고 repo/APK에 넣지 않는다.

## 연결 약속

이번에는 자산·의미 이벤트·Music/UI/Combat 버스·우선순위·동시재생 개수를 바꾸지 않는다. 기존fa.audio.*47개는 v01 상태다. 미리듣기 폴더는 assets/audio/.gdignore 아래이며 게임 자동재생 경로가 없다. 사람청취/실기기는 미확인.
