# 관리자 웹 요청

2026-10-08 사용자 계획 전체를 구현한다. Java 21·Spring·Vue 3 기반 로컬 Mac 관리자 웹이며 기존 TypeScript API와 PostgreSQL을 공유한다. 인터넷 배포·정식 플레이어 계정·차단·성장·재화·결제·경기 결과 변경은 제외한다.
