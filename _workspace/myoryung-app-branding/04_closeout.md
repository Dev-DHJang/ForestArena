# 묘령 앱 아이콘·Godot 로고 제거 마무리

## 현재 결과

아이콘 제작과 연결, Godot 엔진 부트 로고 제거, Android APK 빌드·패키지 확인을 완료했다. **실기기 검사는 기기 미연결로 대기 중**이며 전체 필수 검증을 완료했다고 표시하지 않는다.

프로젝트1024PNG와 Android일반192PNG, 적응형전경/배경432PNG를별도로제작했다. 승인묘령원화는보존했다. 얼굴·머리·두귀·리본을유지하고간단한초록숲을배경으로사용했다. 기존게임시작화면·로비·저장·게임규칙·공개API는유지한다.

## 검증과 전달

`previews/contact-sheet.png`에서48·72·192px의원형/둥근사각형을검토했다. APK안의일반·적응형아이콘과시작아이콘도새묘령을확인했다. 실제패키지의설정에서Godot부트로고false, 최소표시지연0, 기존시작장면유지를확인했다. WebP변환의낮은알파가장자리RGB변화는`branding-checks.json`에실측값으로구분했다.

새자산은`assets/branding/myo-ryung-v01/`,출처와SHA-256은manifest및`input-provenance.json`,제작은`02_image.md`,모바일적용은`02_mobile.md`,독립검토는`03_qa_r01.md`를본다. APK는`build/android/ForestArena-debug.apk`다. 원본생성과규격화기록도보관한다.

문서·리소스·APK빌드검사는통과했다. 전체 기본 검사도 종료 코드0으로 통과했다. SCRIPT ERROR는0개, ERROR는12줄, WARNING은16줄이다. 정확한 문구는checks.json과verify.log에 있다. 리소스 검사는518개 논리 자산과24개 품질 변형을 확인했다.

## 남은 실기기 확인

ADB의연결기기와무선서비스목록이비어있다. 사용자에게USB디버깅기기연결또는무선디버깅연결정보를요청했다. 연결후기기에설치해홈화면아이콘,완전종료후3회실행,재실행,홈이동후복귀와실행영상을확인한다. Android시스템시작화면의새아이콘과Godot엔진로고제거를구분한다. 에뮬레이터·패키지검사를실기기통과로대체하지않는다.

## 버전 관리와 복구

최신develop57c7143에서격리작업폴더와`codex/myoryung-app-branding`브랜치를만들었다. 관련파일만커밋한다. 필수실기기검사blocked를전체pass로표시하거나develop병합완료로보고하지않는다. PR와실제커밋상태는후속기록한다.

복구시project.godot의아이콘을기존`res://assets/app_icon.svg`로,Android일반·전경·배경경로도기존SVG로되돌린다. 추가한boot_splash세설정을제거하면기존기본동작으로돌아간다. 이전SVG와승인캐릭터원본은삭제하지않았다.

현재 산출물의 물리 기기 전 검사까지는 완료했으며, 실기기 확인을 남겨둔 초안 PR로 전달한다. 구현·시각·패키지 검사의 통과와 전체 필수 검증의 blocked를 구분한다.
