# 묘령 앱 아이콘·Godot 로고 화면 제거 요청

2026-10-16. 사용자가 승인한 계획을 구현한다. 간단한 숲 배경에 승인 묘령의 얼굴을 크게 넣은 앱 아이콘을 제작하고, Godot 엔진 부트 로고를 제거한다. Android 일반·적응형 아이콘을 각각 연결하고 기존 게임 시작·로비 흐름은 유지한다. 게임 규칙·API·저장 데이터·승인 캐릭터 원본은 변경하지 않는다.

완료 조건은 48/72/192px 및 원형·둥근 사각형 검토, 문서·기본·리소스 검사와 Android APK 빌드·패키지 아이콘 확인이다. 연결된 물리 Android에서 홈 아이콘·완전 종료 후 실행·재실행·중단/복귀를 확인하고 영상을 남긴다. 현재 ADB와무선검색에기기가없으므로실제기기결과를통과로기록하지않는다. Android시스템시작화면과Godot엔진로고는구분한다.
