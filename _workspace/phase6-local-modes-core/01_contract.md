# 로컬 모드·다인 경기 계약

## 모드 ID

경기 구성은 `story`, `solo`, `team`, `ai`, `practice` 다섯 ID만 사용한다. 모든 구성은
버전 번호를 가지며 알 수 없는 모드, 구버전, 누락 참가자와 중복 참가자 ID를 명시적으로
거부한다.

## 참가자와 팀

- 전체 참가자는 2~8명이다.
- `ai`, `practice`, `story`는 첫 묶음에서 플레이어 1명과 AI 1명을 사용한다.
- `solo`는 팀 ID 없이 2~8명을 사용한다.
- `team`은 팀당 1~4명, 전체 2~8명을 사용하며 양 팀 모두 최소 1명이 있어야 한다.
- 한 경기에는 로컬 플레이어가 정확히 1명이며 나머지는 결정론적 로컬 AI다.

## 결과와 전투 권위

개인전은 마지막 생존자가 승리하고, 팀전은 마지막 생존 팀이 승리한다. 마지막 생존자가
없는 같은 tick의 최종 사망은 무승부다. HUD·카메라·표현은 경기 snapshot을 읽기만 하며
승패를 계산하지 않는다. 기존 1대1의 HP·stock·부활·무승부 규칙은 바꾸지 않는다.

## 호환

기존 `LocalMatchConfig.from_store()`는 `ai` 1대1 구성을 만든다. 기존 `MatchController`의
`player`, `training_dummy`, `bot_source` 입력은 1대1 호환 경계로 유지하고, 다인전은 별도
참가자 목록·팀 목록과 AI 목록을 사용한다.
