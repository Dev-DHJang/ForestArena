# 조약돌 요요 외형·회전 수정 r03

사용자 요청에 따라 기존 회색 조약돌·청록 광맥·동색 축을 유지하면서, 둥근 원반과 얇은 금속 테두리·나선 광맥으로 정리했다. 전투용은 정면 원형으로 별도 생성하여 기울어진 두 타원 덩어리가 통째로 뒤집히는 인상을 없앴다. 원본은 `assets/accessory/pebble-yoyo/source/*-r03.png`에도 보존한다.

- 생성: OpenAI 내장 image_gen 편집. 이전 대표 PNG를 직접 첨부하고, 새 대표 PNG를 전투 본체 편집에 직접 첨부했다.
- 대표 출력: 1024×1024. 본체: 알파 경계로 crop한 뒤 한 번의 균일 배율과 중심 이동으로 128×128/120px 원반. 부분 변형·덧그리기 없음.
- 기존 정적 파일의 교체는 이번 사용자 수정 요청 범위다. 캐릭터 후보의 runtime/manifest 승인 경계와 구분한다.
- 전투 표시: 팔에서 기존 권위 경로로 왕복하며, 본체 중심축을 12틱마다 한 바퀴 회전한다. 반전 방향을 반영하고 준비·잡은 뒤 회복에서는 회전을 멈춘다. 28×28 판정·경로·상태·시간은 그대로다.
- 실제 원형 회전은 새 정면 텍스처와 청록 나선이 함께 표현한다. 실의 손 연결점·회수 시 보간 규칙을 유지한다.
- `conversion.json`은 입력·출력 해시, crop과 공통 배율을 기록한다. 이전 소스·manifest 해시 기록은 보존했다.

수동 재검사: 대표/전투 본체 동일 디자인 비교, 28px 청록 나선 식별, 지상·공중/좌우 원형 회전, 손 회수 연결. 실제 Android 미실행.
