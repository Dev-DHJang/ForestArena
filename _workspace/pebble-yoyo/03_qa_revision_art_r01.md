# 조약돌 요요 수정 r03 정적 이미지·회전 코드 독립 검토

## 결과와 범위

정적 이미지 검토 `pass`, 표시 코드 정적 검토 `pass`. 실제 캐릭터 진입 전후·정상/느린/반전 재생의 새 원형 회전 검토는 새 실제 각도 기록이 준비된 뒤 별도로 진행한다. 이 기록은 새 캐릭터 모션 통과나 사용자 채택 승인이 아니다.

## 직접 본 정적 이미지

대표 생성 원본, 전투 본체 생성 원본,128px 등록용 전투 본체를 직접 열어 대조했다. 대표 이미지는 회색의 매끈한 돌 원반 두 장과 축·짧은 실, 얇은 따뜻한 금속 테두리로 요요 구조가 읽힌다. 이전보다 윤곽이 정돈됐고 앞면에 청록색 나선 광맥이 추가돼 회전 방향을 구분할 수 있다.

전투 본체는 같은 돌·청록 나선·테두리를 **정면에서 본 단일 원형 앞면**이다. 이전 비스듬한 두 타원 덩어리를 평면에서 통째로 뒤집는 형태와 구별된다. 느슨한 실·뒤 원반·문자·별·등급 장식이 없다.128px에서도 나선과 원형 윤곽이 구별되며, 대표와 전투 본체의 디자인 연결이 유지된다.

원본과 출력은 실제 RGBA이며 투명 여백이 있다. 등록 출력은1024×1024와128×128이고,128px 전투 본체의 알파64 기준 경계는[4,4,123,124]로119×120이다. 중심과 원형 윤곽의 차이는 약0.5px 이내여서128px 기준 정면 원형으로 읽힌다. 몸체가 화면을 따라 이동할 때28px에서 나선 회전이 계속 읽히는지는 다음 실제 표시 기록에서 확인한다.

`conversion.json`의 원본·출력 해시를 실제 파일 및 manifest와 대조했고 일치한다. 처리 기록은 전체 균일 배율·중심 이동이며 부분 확대·부위 변형을 선언하지 않는다. 기존 원본 두 장도 보존돼 있다.

## 표시 코드 검토

- 새 `display_rotation()`은 능력 준비시간을 제외한 실제 비행틱을 읽어12틱에TAU,3틱에PI/2가 되도록 중심축 각도를 계산한다. `equipment_facing` 부호로 좌우 회전이 반전된다.
- `_draw()`가 이 함수를 직접 사용한다. 새 실제 기록·재현에서도 이 실제 각도를 저장해 사용해야 한다. 이전 검토용 Python 재현의 `tick*.5`를 새 검토에 그대로 쓰면 안 된다.
- 준비 동안0각도, 마무리 동안 실제 잡은 시점의 각도로 고정한다. 조기 벽 회수에서 전체 비행36틱을 가정하지 않도록 `equipment_tick - startup - (equipment_phase_tick+1)`로 잡은 시점을 복원한 현재 코드를 확인했다. 초기 제안의 clamp36만으로는 조기 회수 때 마무리 회전이 남았지만 현재 코드에서 보완됐다.
- 기존 손 연결과 회수끝의 손 위치 보간은 유지한다. 각도·이미지는 표시 전용이고 권위28×28 판정, 본체 경로, 적중/경직/쿨타임 상태를 수정하지 않는다.
- 테스트는1/4회전·한 바퀴·좌우 방향·보통 잡기·조기 벽 잡기 정지를 다룬다. 기존17개 집중검사 및521개 리소스 통과 결과는 parent가 제공한 증거다. 2026-11-02 재개 시 `build/verification/pebble-yoyo/revision-round-spin-r02.log`를 직접 읽어 조기 벽 잡기 보완을 포함한 `PEBBLE_YOYO_UI: PASS`와 오류 없음도 확인했다. 이 검토자는 같은 검사를 재실행하지 않았다.

## 이전 검토에서 놓친 원인

이전에는 운반·회수 궤적과 수치상 회전 여부를 확인했지만, 그 회전이 **둥근 원반의 축 회전으로 읽히는지**를 따로 보지 않았다. 비스듬한3/4 본체의 전체 윤곽을 회전시켜 기울어진 돌 덩어리가 뒤집히는 인상을 남겼다. 새 검토는 정면 원형 윤곽과 나선의0·1/4·1/2·3/4바퀴 및 실제 정상 속도에서의 회전을 확인한다.

캐릭터는 머리색·귀·의상색 같은 큰 특징과 v01 정적 참조만으로 외형 일관성을 넓게 판단했다. 현재 승인 idle/jump의 정확한 얼굴·머리·몸통·팔다리 구조와 진입 전후를 같은 화면에서 비교하지 않아 자현의 모델 구조 변화와 나비의 진입 위치 차이를 놓쳤다. 새 후보에 같은 문제가 있으면 배율·발 기준점을 맞춘 사실만으로 통과시키지 않는다.

## 2026-11-02 재개 확인과 남은 조건
