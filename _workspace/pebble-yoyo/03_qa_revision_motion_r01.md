# 조약돌 요요 수정 r03 모션 독립 검토 r01

## 현재 상태

최종 독립 QA 결과 `pass`5개, 수정 필요/미확인0개. 공식 기록은 `review-r05/motion-review.json`이다. 이전 r02 pass는 재사용하지 않았다. 새 후보는 자현 지상·공중, 나비 지상·공중, 나비 idle 몸 기준점 보정의 다섯 개다. `approval_status`는 `pending`으로 유지하며 runtime/manifest 등록이나 사용자 채택 승인이 아니다. 메타 정리 전 `review-r04`의 blocked 기록은 보존했다.

## 완료한 직접 비교

- 현재 승인 idle/jump 참조와 새 네 모션의 전체 16프레임 contact·좌표 비교판을 직접 열어 외형을 대조했다. 자현의 둥근 귀, 흰 머리·얼굴 비율, 흰 재킷·검은 바지, 파란 리본, 얇은 분홍 꼬리가 현재 승인 모델과 이어진다. 이전 r02의 커지고 두꺼워진 머리·상체 구조가 현재 시안에서는 재현되지 않았다. 공중에서는 무릎이 접힌 자세를 유지한다.
- 나비의 어두운 머리·분홍 안쪽 귀, 사람 얼굴·손·발, 보라/흰 의상, 굵게 굽은 꼬리, 금색 방울이 승인 idle/jump와 이어진다. 새 원본의 불투명 배경 문제는 등록용 후보에서 나타나지 않고 투명 바탕 위 단일 인물로 읽힌다.
- 표시 배율을 적용한 독립 비교판 다섯 개를 `review-r05/independent-boards/`에 만들고 전체 프레임을 직접 확인했다. 손 기준점 노란 표시도 손바닥 또는 잡은 손에 놓인다. 지상에서 손을 내밀었다 거두는 구간과 공중의 접힌 다리가 구별된다.
- 나비 idle 후보 PNG는 현재 승인 PNG와 바이트가 완전히 같다. 후보 사전 검증도 통과하며 배율·FPS·반복·순서·시간·SpriteFrames 내용은 기존 승인 값이다. `body_root`의 가로 보정만 새로 제안한다.
- 실제 32개 진입 표본(16 idle 프레임 × 좌우)의 BEFORE→ENTRY→AFTER 좌표를 적용한 비교판 두 개를 직접 확인했다. 기존 첫 프레임 위치를 유지하고 매 열 약10px씩 이동하던 오류가 사라진다. 승인 PNG의 하단 y112..127 알파64 신발 밴드를 독립 측정한 보정 후 가로 중점은17.5..18.5px이다. 반투명 경계에 따른1px 범위이고 열에 따른 체계적 드리프트가 없다. 기존 대기의 세로 호흡은 보존된다.
- QuickTime에서 나비 idle 수정 전/후 정상4초와 0.25배속16초 영상을 재생해 종료 상태까지 확인했다. 비교판의 전체 프레임과 함께 기존 그림의 호흡·꼬리를 유지한 위치 보정임을 대조했다. 재생 자료는 실제 기기 캡처가 아닌 오프라인 재구성임을 구분한다.

## 발견한 자료 누락과 조치

최초 `game-timeline-r03.json` 공중 표본은27틱 진입 전 낙하 뒤 시전 중 착지했다. 자현 tick42~46, 나비 tick43~46이 지상 장비 모션으로 바뀌어 공중 마지막 회복 프레임과 jump 복귀를 실제 영상에서 확인할 수 없었다. 메인과 생산자에 공중 시작 위치를 높인 별도99틱 기록·영상 제작을 요청했다. 이 자료를 착지 회귀로 보존하고 새 전체 공중 재생을 확인한 뒤 최종 판정한다.

## 누락 보완 뒤 최종 실제 재생

공중 시작 높이를 보완한 최종 `game-timeline-r03.json`을 독립 계산했다. 좌우8개 표본이 각99틱이며 네 모션 모두16그림 전체와 준비·신장·회수·회복4단계를 실제 코드로 선택한다. 공중은 마지막 회복까지 공중 모션을 유지하고, 시전 뒤24틱 동안 승인 jump로 복귀한다. 지상은 idle로 돌아간다. 중간 착지 자료는 `qa-motion-r03/landing-r03/`에 별도 보존되었다.

최종 네 MP4를 QuickTime에서 정상8초·0.25배속16초, 실제 오른쪽/왼쪽 방향으로 열어 재생했고 종료 상태까지 확인했다. 진입 전 idle/jump, 신장, 회수, 잡기, 종료 후 자세를 전체 프레임 비교판과 대조했다. 추가로 느린 영상의 tick41 회수 끝, 왼쪽 tick21 최대 신장 부근, tick45 회복14번·tick46 마지막15번을 직접 이동해 확인했다. 새 원형 본체는 같은 크기의 정면 원반을 유지하고 청록 나선이 축을 중심으로 회전해 이전 타원 덩어리의 뒤집힘과 구별된다. 실은 펼친 손에서 본체로 이어지고 마지막에는 손으로 돌아온다. 공중에 지상 발 디딤이 끼어들던 자료 누락은 보완되었다.

기록된 실제 각도는 비행틱마다 TAU/12(약0.5235988라디안)씩 변하며 실제 좌우 쌍의 각도 합은0이다. 회복 중 각도 변화는0이고, 마지막 회수 본체와 손의 최대 좌표 오차는0.000001px 미만이다. 이 수치는 눈으로 확인한 손·실·원형 회전의 보조 근거다. `review-r05/independent-actual-trace-checks.json`에 각 표본의 프레임 집합·각도·복귀 모션을 남겼다.

생산자가 정리한 자현 공중 참조 메타데이터의 전후 파일도 직접 비교했다. 실제792개 프레임 표본 및32개 진입 표본이 정확히 같다. 이 증거는 `qa-motion-r03/metadata-reconciliation-r03.json`과 그 전상태 trace를 함께 고정했다. 생성 입력에 실제 첨부한 자료와 폐기안 비교 자료를 구분한 메타 정리이며 영상이나 그림을 바꾼 것으로 처리하지 않았다.

| 후보 | 판정 | 핵심 관찰 |

| 자현 공중 요요 | pass | 승인 jump 구조, 접힌 다리, 공중16그림/4단계, jump 복귀 |

| 나비 공중 요요 | pass | 승인 jump 구조, 공중 마지막15번까지 유지, jump 복귀 |
| 나비 idle 기준점 보정 | pass | PNG/시간 동일, 첫 위치 보존, 열별 가로 드리프트 제거 |

`review-r05/motion-review.json`에 후보별 구체적 관찰, 모든 확인 항목,88개 source SHA-256과49개 추가 자료를 고정했다. 추가 자료에는 최종 실제 trace, 후보 JSON5개, 승인 참조, 영상6개, 재현기·수치 검사 코드, 독립 표시 배율/32개 진입 비교판과 수치 결과가 들어 있다. 표준 검증기의 후보별 `materials`는 필수 board+sheet 두 개로 유지하고 추가 자료는 `sources` 및 `supplemental_materials`에 연결했다. 검토 자료는 **실제 전투·표시 코드를 기록한 오프라인 재구성**이며 게임/Android 화면 캡처가 아니다.

최종 무결성 검사: `review_motion_actions.py validate --require-pass` → `Review decisions: {'pass': 5}` / `MOTION_ACTION_REVIEW: PASS (record integrity only)`. 이 도구 결과는 위 직접 관찰을 대신하지 않는다. 새 사용자 채택이 필요한 모션5개는 승인 대기 상태다. 실제 Android 검사는 수행하지 않았다. 이 독립 검토에서 runtime/manifest·전투 판정·생산 중 원화를 변경하지 않았다.
