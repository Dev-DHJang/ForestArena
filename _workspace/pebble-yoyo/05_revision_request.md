# 2026-10-30 사용자 수정 요청

1. 자현은 직전 모션과 캐릭터 외형 구조가 달라지는 문제를 해결한다.
2. 나비는 스탠딩에서 요요 모션에 진입할 때 표시 위치가 바뀌는 문제를 해결한다.
3. 조약돌 요요를 더 멋있는 둥근 조약돌 형태로 수정하고 사용 중 원형 회전이 읽히게 한다.

기존 r02 시안은 채택되지 않았다. 이전 독립 QA의 외형·전환 일관성 판단은 사용자 피드백에 따라 수정 대상으로 되돌린다. 새 시안에는 정지 프레임뿐 아니라 실제 승인 idle/jump에서 진입·복귀하는 재생 증거를 포함한다. 캐릭터 외형 계약·전투 경로·판정·시간은 유지한다. 본체의 원형 회전은 표시만 바꾸며 적중 판정에 영향을 주지 않는다.

생산 소유: 메인(요요 정적 이미지·표시 코드·통합), motion_revision(캐릭터 후보·연결 재생·검토 자료). 새 독립 QA 뒤 모션별 사용자 채택을 요청한다.

## 2026-11-02 재개 후 원인과 검토 범위

나비의 기존 승인 idle 시트 자체에서 열마다 양발중앙이 약10px씩 달라졌다. 단일 요요 첫 자세를 한 idle 프레임에만 맞추면 다른 프레임에서 진입·복귀할 때 다시 튄다. 따라서 PNG·프레임·순서·FPS·시간을 유지한 채 프레임별 몸 위치 기준점(body_root)만 보정하는 idle 후보를 추가한다. 기존 idle0의 실제 화면 위치를 보존하며 다른 프레임의 의도치 않은 좌우 이동을 제거한다.

새 검토·사용자 채택 범위는 자현/나비 지상·공중 요요4종과 나비 idle 위치 보정1종, 총5종이다. idle PNG가 같아도 표시 위치가 달라지므로 모션 채택 승인을 생략하지 않는다. 승인 전 기존 runtime PNG·SpriteFrames·manifest는 바꾸지 않는다.

재검사: 모든 idle 프레임에서 장비 진입·복귀 위치, 기존 승인 idle/jump와 같은 캔버스에서 외형 구조, 실제 좌우 방향 trace와 실제 회전 각도, 전체 프레임·정상·느린 재생. 정적 요요와 회전 코드 검토는 별도로 통과했으며 캐릭터 후보 통과를 대신하지 않는다.
