# 요요 모션 수정 r03 제작 인계

2026-11-02. 사용자 지적에 따라 이전 r02의 독립 QA 통과를 외형·연결의 보장으로 재사용하지 않는다. 이전 검토는 종 특징과 규격을 확인했지만 현재 승인된 대기·점프의 정확한 몸 구조와 진입·복귀 위치 차이를 놓쳤다.

## 수정 내용

- 자현: 현재 승인 idle·jump와 v01 대전/측면 참조를 직접 비교했다. r02의 큰 머리·귀와 직립한 상체를 버리고 현재 게임 모델을 직접 입력으로 새로 제작했다. 공중 첫 재생 시안도 몸이 직립해 보여 `source-first-attempt.png`으로 폐기 보존했다. 최종 공중 원화는 승인 jump의 고해상도 원본을 직접 편집 입력으로 사용했고, 행 경계가 닿은 중간본은 `source-spacing-input.png`에 남긴 뒤 내장 이미지 도구로 전체 그림 간격만 넓혔다.
- 나비: 지상 동작도 현재 낮은 idle 자세를 직접 첨부하여 다시 제작했다. 가장 낮은 신발의12픽셀만 잡던 기존 기준을 폐기했다. 두 신발을 모두 포함하는 확인된55픽셀 영역에서 두 발의 중점을 잡고, 실제 승인 idle 첫 그림의 몸 표시 위치에 맞췄다. 뻗은 손이128픽셀 셀 밖으로 잘리지 않도록 이미지 셀과 화면 기준점을 분리했다.
- 나비 대기: 승인된 원본 PNG 자체의 그림이 네 열마다 약10픽셀씩 왼쪽으로 이동했다. 이 그림·순서·시간·배율·발 높이는 그대로 두고 `body_root`(몸의 표시 기준점)의 가로 좌표만 그림마다 달리 지정한 다섯 번째 후보를 만들었다. 첫 idle 그림의 기존 위치를 유지했다. 새 그림을 생성하지 않았다.
- 지상 두 모션의 시작·회복 끝 그림은 승인 idle의 전체 그림을 바이트 그대로 재사용한다. 부분 합성·신체 변형이나 반복 채움은 하지 않았다. 중간 원화의 외형 검토는 별도로 필요하다.
- 각 모션 전체에 하나의 공통 원화 배율을 사용한다. 자현 지상0.3353/공중0.375, 나비 지상0.34/공중0.29이며 정확한 셀 이동과 기준점은 각 `candidate.json`의 `packing`에 기록했다. 손 앵커는 전체 그림 비교판에서 측정했다. 그림·앵커·표시만 다루며 전투 시간·판정을 바꾸지 않았다.

## 후보와 소비 경계

`motions/<character>/<ground|air>/r03/`의4개 모션과 `motions/nabi/idle/r03/`의 대기 표시 보정이다. 카탈로그/스코프에5개를 포함한다. 정식 캐릭터 runtime PNG·TRES 및 manifest는 변경하지 않았다. 독립 QA와 각 후보의 사용자 명시 채택 뒤에만 메인 담당자가 표준 등록 도구로 반영한다.

실제 첨부 PNG·생성 프롬프트·입출력 해시는 `motion-prompts-r03.json`에 있다. 내장 `image_gen`을 사용했다. 원화의 보라색처럼 보이는 바깥 RGB는 실제 alpha0이며 Python 배경 제거·신체 재그림을 수행하지 않았다.

## 실제 코드 재생 자료

- `record_preview.gd` → `game-timeline-r03.json`: 기존 표시 코드·전투 코드를 실행하고 시안 리소스를 메모리에만 넣었다. 진입 전27틱, 사용 후24틱을 포함한다. 실제 좌우 facing 각각 자현·나비 지상/공중, 총8개 시퀀스다. 손·실 끝·원반 회전은 `equipment_effects.display_tip()` 및 `display_rotation()`의 실제 값을 기록했다.
- 완결 공중 시퀀스는 y=-4000에서 시작한다. 모든 활성 구간이 공중 모션이고16개 그림 및 준비/발사/회수/회복4구간이 모두 보이며 이후24틱은 jump라는 실행 시 단언을 넣었다. 별도 보존한 착지 회귀는 `qa-motion-r03/landing-r03/`이다. 최초 낮은 높이의 시안은 공중 회복 끝이 착지에 가려져 필수 공중 재생으로 사용하지 않는다.
- `qa-motion-r03/trace-{normal,slow}{,-flip}.mp4`: 실제 코드 기록을 같은 카메라 좌표에 재현한4영상이다. 실제 게임 캡처나 Android 실기기 검증이 아니다. 왼쪽 영상은 전체 패널을 반전하지 않고 실제 facing=-1의 sprite flip·손/요요 좌표·회전 기록을 사용한다.
- `qa-motion-r03/nabi-idle-before-after-{normal,slow}.mp4`: 동일 승인 PNG·8FPS로 정확히 두 주기를 재생하는 기존/보정 비교다. 첫 그림의 두 신발 중점을 노란 선으로 표시한다.
- `qa-motion-r03/idle-entry-probes.json`: 대기16개 그림 각각에서 좌우 장비 진입·복귀, 총32개 실제 표시 기록이다. 두 신발 중점의 최대 차이는0.000001014픽셀로 통과했다. 이 수치 검사는 신체·행동의 시각 QA를 대신하지 않는다.
- `standard-timeline-r03.json`: 표준 표시 시간 도구로 후보5개 통과. 정식 독립 검토 입력은 메인이 준비한 `review-r05/`이며 자동 생성 기본 상태를 통과로 바꾸지 않았다.
- `index.html`: 사용자가 여섯 영상, 전체 그림, 표준 검토와 승인 기준을 열어 볼 수 있는 현행 검토 페이지다.
- 최종 코드 기록·렌더러·여섯 영상의 해시는 `qa-motion-r03/final-evidence-sha256.json`에 고정했다.

## 제작 입력 메타데이터 정리

자현 공중의 `reference_attachments`는 실제 선택 제작 체인에 첨부한 원본 jump와 v01 두 각도만 남겼다. 최초 폐기 시안에서만 사용한 저해상도 jump 비교판은 `comparison_references`로 분리했다. `motion-prompts-r03.json`의 선택된 실제 호출·직접 첨부 해시와 구분한다. 후보 PNG·앵커·구간·그림 표시 시간은 불변이다.

이전 메타데이터 자료는 `qa-motion-r03/metadata-before-r03/`, 동일성 증명은 `metadata-reconciliation-r03.json`에 있다. 실제 좌우8개 시퀀스의792개 표시 표본 전체와 나비32개 진입·복귀 기록을 새 실행과 정확히 비교해 같음을 확인했다. 표준 시간 기록5개도 다시 통과했다. 영상 여섯 개는 같은 그림·좌표·각도를 사용하므로 재렌더하지 않았고, 현재 trace와 증명에 맞춰 `reconstruction.json` 및 최종 해시 목록만 갱신했다.
