# 조약돌 요요 모션 독립 검토 3차

결과: 자현·나비의 지상·공중 모션4개 `pass`. 사용자 채택 승인은 아직 `pending`이며 런타임 등록 승인을 대신하지 않는다.

## 검토한 자료와 방법

- 승인된 각 캐릭터 v01 combat·side 참조, 원본4장, 전체16프레임 비교판4장(총64프레임),128px 셀과 손 연결 표시를 직접 비교했다. 첨부 참조·원본·시트의 해시와 실제 RGBA도 대조했다.
- `game-timeline.json`은 실제 전투·캐릭터 표시·요요 표시 코드를 실행한49틱 기록이다. 각 동작의16개 프레임과 준비6·발사18·회수18·마무리6틱을 확인했다.
- 이 기록의 프레임·배율·위치·손 좌표·실제 표시 요요 좌표를 사용해 네 모션을 한 화면에 담은 정상1×와 느린0.25× 영상을 만들었다. QuickTime Player에서 실제 재생하고, 전개 초반7틱·최대 전개22틱·회수40틱·완료48틱을 이동·정지하며 직접 확인했다. 좌우 반전 느린 영상도 재생·정지해 손·실·요요가 함께 반전되는지 확인했다.
- 영상은 실제 게임 화면 촬영이 아니라 **실제 코드 기록의 검토용 재현**이다. 캐릭터를 따라가는 관찰 기준, 단색 배경과 바닥선으로 표현한다. 영상의 거친 실 가장자리는 Python 재현의 선 그리기 결과이며 Godot 안티앨리어싱 품질 검증이 아니다.
- 표시 배율은 자현0.9·나비0.8, 공통 원화 포장 배율0.32와 발 기준120px를 유지한다. 카메라1.5에서 실제 적용 크기로 보았고,128px 비교판과 좌우 반전에서도 외형을 확인했다. 실제 Android 화면·성능 검사는 하지 않았다.

## 모션별 관찰

| 모션 | 관찰 |
| --- | --- |
| 자현 지상 |0~2번에서 팔을 몸 쪽과 위로 거둔 뒤3~7번에서 전방으로 뻗는다.8~12번은 주먹을 당겨 회수하고13~15번은 경계 자세로 돌아온다. 양발의 접지와 낮은 자세, 흰 머리·푸른 장식·가느다란 꼬리가 유지된다. 손에서 실이 시작하고 요요가 나갔다 손으로 돌아온다. |
| 자현 공중 |무릎을 굽힌 떠 있는 자세에서 팔을 준비하고 전방 투척 후 손목을 돌려 회수한다. 회수 중9~10번의 빠른 손목 전환은 실을 끌어오는 동작으로 읽힌다. 공중 전 구간에 지상 디딤 자세를 넣지 않으며 종료 뒤 기존 jump 표시로 이어진다. |
| 나비 지상 |준비에서 팔을 거두고3~7번에서 장갑 낀 팔을 전방으로 뻗는다. 회수에서 손이 몸 쪽으로 돌아온 뒤 기본 자세를 회복한다. 머리·고양이 귀·보라색 장식·방울 달린 꼬리와 굽힌 무릎의 크기가 유지되고 귀·손끝·신발이 잘리지 않는다. |
| 나비 공중 |두 무릎을 접고 팔을 뒤/위로 준비한 뒤 전방 투척·회수를 한다. 발을 바닥에 디디는 모습과 구별된다. 실의 시작점은 장갑의 손바닥에 붙고 회수 끝에는 요요가 그 손으로 돌아온다. 얼굴·의상·꼬리 외형도 참조와 일관된다. |

## 수정 확인

- r01 원본의 귀·손끝·신발 경계 잘림은 r02에서 여백을 확보해 해소했다. 원화 외곽을 기준으로 프레임마다 크기를 바꾸지 않았다.
- 처음 손 연결 좌표가 얼굴·가슴·빈 공간에 놓인 프레임들을128px 격자에서 확인하고64개 좌표를 교정했다. 교정 뒤 접점은 투척하는 손바닥/손가락 시작에 놓인다.
- 벽의 조기 회수는 전체48틱 진행 비율 대신 현재 단계·단계 경과틱으로 팔 동작을 선택한다. 발사18틱은 그림 요요 좌표가 권위 좌표와 정확히 같고, 회수 마지막 그림 좌표와 손 좌표 차이는 네 동작 모두0.000001 이하이다. 회수→마무리에서 요요가 먼 논리 원점으로 튀는 문제도 해소됐다.
- 공중 기록이 착지한 뒤에도 계속 공중 시트를 보여주던 검토 페이지 문제를 찾았고 실제 row.motion에 따라 지상/공중/기존 모션을 선택하도록 수정한 최종 재현을 사용했다. 전체 공중 시안은 더 높은 시작점의 r06 기록을 사용한다. 기존 착지 기록은 별도 landing-timeline.json에 보존한다.

## 고정 증거와 한계

정식 검토 기록은 `review-r03/motion-review.json`이다. 표준 비교판·재생 자료 외에 실제 game-timeline, candidate.json4개, 기록 코드, 재현 코드와 정상·느린·각 반전 MP44개의 해시를 추가해 연결했다. 재현 영상은 `qa-motion-r02/trace-normal.mp4`, `trace-slow.mp4`, `trace-normal-flip.mp4`, `trace-slow-flip.mp4`다.

이 판단은 모션의 행위·외형·연결 표현에 대한 독립 검토다. 피해·경직·쿨타임 정확성의 전투 검사, 실제 사람의 조작 감각, 물리 Android 통과와 개별 사용자 모션 채택 승인은 각각 별도이다.
