# 숲빛 UI와 개발 전달

## 작업 범위

기존 `SCR_*` 24개, `CBT_*` 8개, 직업·경기장·Story 챕터·AI 조건·연습 조건·일반 설정 6개, 전투·예외 상태 12개를 상세 설계한다. 기존 v00 화면은 각 페이지의 `ARCHIVE v00` 보관본으로 유지한다.

Penpot 파일 ID는 `d8ac01df-6646-81d2-8008-a3696fea940e`이다. 편집 원본과 클릭 검토용 통합 프로토타입을 구분한다. 여러 페이지 사이의 `navigate-to` 연결은 대상이 비어 저장되는 문제가 있어, `10_Prototype`의 동일 페이지 안에서 화면 스냅샷과 클릭 영역으로 흐름을 연결한다. 원본 화면의 텍스트·컴포넌트는 편집 가능하다.

안전 영역은 16:9 설계상 x=125..1795, y=54..1026이다. Godot 1280×720 논리 해상도로 전달할 때 표의 값을 2/3로 환산한다. 실제 물리 기기의 운영체제 안전 영역을 우선 적용한다. 터치 영역끼리 겹치지 않아야 하며 UI는 피해·남은 기회·승패를 계산하지 않는다.

## 설정과 상태

조작 설정은 기본 위치, 버튼 크기와 투명도 조절, 기본값 복원을 제공한다. 크기 85–110%, 투명도 60–100%는 설계 검토용 범위이며 기본값은 100%와 85%다. 자유 이동 편집은 포함하지 않는다. 실제 기기 확인 전 최종 조작 범위로 확정하지 않는다.

크기를 바꿀 때 방향패드는 왼쪽·아래쪽 변을, 행동 버튼은 각 버튼의 오른쪽·아래쪽 변을 유지한다. 중심을 고정한 채 확대하면 방향패드가 하단 안전 영역을 벗어날 수 있으므로 이 방식은 사용하지 않는다. 85%·100%·110%에서 앵커를 유지하는 수치 대조는 `geometry-audit.json`에 기록한다.

오프라인은 중단 시 입력을 해제하고 복귀 확인 후 재개한다. 온라인 메뉴를 열어도 경기 진행이 멈추지 않는다. 온라인·성장·경제·랭크 화면에는 미래 설계를 표시하며 미확정 수치를 확정된 제품 규칙으로 쓰지 않는다.

## 구현 후 이름 있는 수동 재검사

- TOUCH-01: 이동과 공격을 서로 다른 손가락으로 동시에 누르고 각각 떼었을 때 다른 입력을 잃지 않는다.
- TOUCH-02: 손가락이 버튼 경계를 벗어나거나 취소될 때 눌린 상태가 남지 않는다.
- LIFECYCLE-01: 홈 이동·알림·포커스 손실 뒤 입력이 해제되고 오프라인은 확인 후 한 번만 재개한다.
- HUD-08: 최대 줌아웃과 8명 전투에서 참가자·팀·피해율·남은 기회를 구분한다.
- SAFE-20: 20:9·노치·시스템 제스처 영역에서 주요 버튼을 누를 수 있고 화면 내용이 가려지지 않는다.

이 기록은 설계 기대 동작이다. Android 실기기 통과 기록이 아니다.

## 20:9 비교와 원본 보존

로비·캐릭터 선택·4대4 전투를 2400×1080 비교 보드로 만든다. 중앙 1920×1080에 UI를 유지하고 좌우 각각 240px를 확보한다. 전투 카메라를 가로로 확대하는 구현은 포함하지 않는다. 비교 보드의 안전 영역 테두리와 반투명 엄지 가림 표시는 검토용이며 게임 UI에 들어가지 않는다. 화면 중앙 참가자와 상단 HUD가 조작 영역 밖에 있는지 확인한다. 경기 중 카메라 이동으로 전투자가 엄지 아래에 들어가는지는 구현 후 실기기 재검사에 포함한다.

이번 약·강·특수·점프·대시 재배치는 기존 Godot 배치와 다른 신규 설계안이다. 입력 코드와 저장 형식은 변경하지 않는다. 기존 v00 보드와 시험 보드는 `ARCHIVE` 이름으로 보관하고 검토 프로토타입에서 제외한다.

## 재사용과 전달 파일

새 벡터 컴포넌트 87개 외에 Damage, Chances, ParticipantCompact, ParticipantWide, ParticipantSlot, Dialog 조합 컴포넌트 6개를 만든다. 전투 HUD 32개, 참가자 슬롯 8개, 대화상자 9개에 실제 인스턴스를 연결한다. 인스턴스의 문구와 피해율·참가자 표기는 텍스트로 편집할 수 있다.

- `touch-layout.csv`: 시각 영역, 터치 영역, 앵커와 Godot 환산 좌표.
- `penpot-final-audit.json`: 최종 화면·컴포넌트 ID와 실제 프로토타입 연결 검사. `penpot-live-state.json`은 제작 중간 기록이다.
- `geometry-audit.json`: 기본 터치 영역의 겹침·안전 영역 대조 및 PNG 목록.
- `exports/`: Penpot에서 직접 내보낸 화면과 검토용 모아보기.
- `image-mapping.csv`, `missing-assets.json`: 기존 이미지 슬롯과 실제 파일 대조.

문서 검사·기본 검사·Godot 리소스 검사는 각각 별도 로그에 남긴다. 이 검사의 통과를 새 UI 시각 검토나 Android 실기기 통과로 해석하지 않는다.
