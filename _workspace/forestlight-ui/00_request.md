# 숲빛 UI 제작 요청

2026-09-16 사용자가 승인한 전체 계획을 실행한다. 숲빛 유리·잎 장식, 연두·하늘색 팔레트의 독창적인 UI 자산을 제작하고 Forest_Arena_UI의 기존 24개 화면·8개 전투 화면과 추가 선택·설정 흐름에 적용한다.

참고는 Wild Rift의 왼손 이동·오른손 행동과 정보 배치 원리만 사용한다. 제3자 파일·아이콘·문양·실루엣의 복제, 추출, 트레이싱과 재색칠은 하지 않는다. 기존 승인 배경·캐릭터 원화는 재사용한다.

벡터 원본, SVG·투명 PNG, Penpot 컴포넌트와 프로토타입 연결, 화면 내보내기, 시각 검토 기록을 납품한다. Godot UI와 입력 구현은 포함하지 않는다. Android 실기기 검증은 구현 후 항목으로 남긴다.
