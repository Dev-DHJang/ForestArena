# v03 이미지 제작 기록

첨부 5개 게임 화면을 정보 위계·캐릭터 중심 구도·아이콘 실루엣 비교에 사용했다. 이미지를 추출·트레이싱·재색칠하지 않았다. 기존 프로젝트 의미 도형에 굵은 외곽선, 채색 면과 그림자를 직접 작성하여 91 SVG와 투명 PNG를 제작했다. 글자는 포함하지 않는다.

새 배경: imagegen으로 2026-10-09 제작한 독창적 숲 공터. 원본 1672×941 PNG. 중앙 공터·하늘 여백·양쪽 큰 나무·먼 폭포를 지정했으며 캐릭터·글자·UI는 포함하지 않는다. assets/ui/forestlight-reference-v03/background-lobby.png에 보관했다. 생성 원본은 Codex generated_images에도 보존한다.

승인 캐릭터와 기존 v02 자산은 보존한다. 새 슬롯은 IMG/forestlight-reference-v03/이고 런타임 등록하지 않았다. Android 실기기 검증은 추후 별도 수행한다.
