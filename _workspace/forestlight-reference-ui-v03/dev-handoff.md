# 숲빛 참고 UI v03 개발 전달

이번 결과는 Penpot 설계와 자산 전달이다. Godot 화면·입력·저장 코드와 논리 해상도 1280×720은 변경하지 않았다. 원본 50개, 20:9 비교 3개를 기존 ID로 유지한다. 전투 버튼 좌표는 기존 v02 설계를 유지한다. 해당 설계는 기존 구현 배치와 다른 제안이며 이번 작업에서 입력 코드는 바꾸지 않았다.

## 좌표와 터치 영역

1920×1080 기준이며 x/y는 왼쪽 위다. 터치 영역은 시각 크기와 별개다. touch-layout.csv에 논리 좌표 2/3 변환도 기록한다.

| 네 방향 이동 | 152,690,320,320 | 144,682,336,336 | 왼쪽·아래 |
| 약 | 1584,804,176,176 | 1580,800,184,184 | 오른쪽·아래 |

로비 메뉴 6개는 x=128+184i(i=0–5), y864, 168×144이고 순서는 캐릭터·장신구·프리셋·미션·친구·상점이다. 메뉴 간격은 16px, 아이콘은 96px이다. 플레이는 x1328 y888, 464×120으로 가장 크다. 프로필은 x96 y48, 232×88, 설정은 x1592 y48, 232×88이다. 기본 버튼의 전체 보드를 터치 영역으로 사용한다. 화면별 다른 버튼의 최종 좌표·목적지는 Penpot 원본과 연결 감사 파일을 따른다.

기본 전투 안전 영역은 x125–1795, y54–1026이다. 20:9 비교는 2400×1080 안의 중앙 1920 영역과 좌우 여백을 표시한다. 버튼 이미지를 가로로 늘리지 않으며 비교 보드의 중앙 영역·엄지 가림 표시는 설명용이다. 기기 노치·시스템 제스처 여백과 실제 Android 카메라 대응은 구현 뒤 별도로 확인한다.

## 재사용과 반응

SVG 91종과 같은 이름의 투명 PNG 91종을 제공한다. manifest.json의 IMG/forestlight-reference-v03/<name> 슬롯은 디자인 전달용이며 런타임 등록을 추가하지 않았다. 기본·눌림·선택·사용 불가를 형태와 명암으로 구분한다. 글자는 이미지에 넣지 않는다. Penpot 조합 컴포넌트는 피해율·씨앗 기회·참가자·대화상자·하단 메뉴를 포함한다. 조작 설정의 240px 방향패드는 별도 벡터 조합이며 실제 전투의 320px 방향패드는 유지한다.

눌림 80ms, 복귀 120ms, 패널 표시 180ms를 기준으로 한다. 긴 버튼을 구현할 때 모서리·가운데·아이콘을 분리해 모서리와 선 두께를 보존한다. 큰 패널은 네이티브 사각형과 외부 그림자를 쓴다. Penpot 내부 그림자에서 채우기 누락이 발생해 제외했다. 원형 행동 SVG는 내부 도형까지 함께 크기를 맞추고, 회전된 잎 방향패드는 단순 그룹 resize 대신 목표 크기의 벡터로 제작한다.

로비 자현은 승인 투명 PNG를 별도 레이어로 사용한다. 4초 작은 호흡(최대 scale 1.006, 2px 이동, 약 0.1도 회전)을 의도로 전달한다. PNG 자체는 정지 이미지다. 움직임 일시정지와 OS 움직임 줄이기를 제공한다. 실제 캐릭터 전투 모션 제작은 이번 범위가 아니다.

## 상태와 미정 정책

온라인·상점·성장·Story 콘텐츠는 미래 설계로 표시한다. 보상·경제·Story 해금·AI 난이도 정책과 확정 원화는 미정이다. 장신구에 희귀도·등급을 넣지 않으며 Splash에 캐릭터를 넣지 않는다. 현재 전투 버튼은 약·강·특수·점프·대시만 유지한다.

## 구현 후 Android 재검사

- TOUCH-01: 이동을 누른 채 각 행동을 입력하고 두 손가락을 바꾸거나 동시에 떼어도 독립 입력이 유지·해제되는지 확인.
- TOUCH-02: 버튼 밖 이탈, pointer cancel, 손가락 추가·제거와 메뉴 전환에서 누른 상태가 남지 않는지 확인.
- LIFECYCLE-01: 앱 중단 시 입력 해제, 복귀 시 오프라인 재개 확인. 온라인 메뉴는 경기를 정지시키지 않음.
- HUD-08: 8인 피해율·씨앗·번호·팀 기호와 색상, 실제 최대 줌아웃·카메라 이동에서 식별과 가림 확인.
- SAFE-20: 16:9·20:9 기기의 노치·제스처 여백, 손 크기와 실제 엄지 접근성 확인.

사용자 요청에 따라 Android 검증은 추후 별도로 진행한다. 현재 정적 PNG·데스크톱 프로토타입·수치 검사를 Android 기기 통과로 해석하지 않는다.

새 배경은 background-lobby.png이며 원본 1672×941이다. 중앙 투명 캐릭터는 648,124 / 552×736으로 확대한다. 선택 목록은 96,330 / 480×548, 미리보기는 660,196 / 480×640, 상세는 1320,230 / 504×640이다. 전투 경기장 배경은 기존 승인 자료를 유지한다. 새 UI SVG·PNG와 배경은 독립 레이어이고 버튼 글자는 이미지에 포함하지 않는다.

## v03 최종 보정

큰 아이콘의 이전 크기 설정을 제거하고 새 컴포넌트 인스턴스로 교체했다. 확대 시 SVG 선 두께도 함께 맞췄다. 대화상자 버튼 문구는 이전 화면의 순서대로 복원하여 연결 목적지와 일치시켰다. 팀 A는 연두, 팀 B는 하늘색과 A/B 문자로 구분한다.

피해율·씨앗 HUD는 Penpot 설계 예시다. 현재 Godot 전투는 HP·stock을 사용하므로 실제 표시 연결 방식은 별도로 확정해야 한다. 현재 런타임 검사의 통과는 이 새 HUD의 구현 통과를 뜻하지 않는다. 새 전투 기능이나 보상 규칙은 추가하지 않았다.
