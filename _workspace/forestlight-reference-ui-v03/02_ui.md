# v03 UI 설계 기록

밝은 숲 공터와 굵은 채색 아이콘을 중심으로 재구성한다. 첨부의 마름모 군집·재화·뽑기 등은 추가하지 않는다. 편집 벡터 91종과 투명 PNG 91종, 새 배경 PNG 1종을 별도로 제작했다. 기존 v02와 승인 캐릭터를 보존한다.

로비: 큰 공통 상단·하단 패널을 제거한다. 프로필 96,48 / 232×88, 브랜드 400,62 / 640×52, 설정 기존 1592,48 / 232×88. 중앙 투명 캐릭터 648,124 / 552×736. 하단 메뉴 128+184i,864 / 168×144, 아이콘 164+184i,876 / 96×96. 플레이 1328,888 / 464×120. 작은 호흡은 별도 레이어에서 유지한다.

선택: 목록 영역 96,330 / 480×548, 중앙 승인 캐릭터 660,196 / 480×640, 오른쪽 상세 1320,230 / 504×640. 기본 캐릭터 목록은 세 줄, 장신구 목록은 두 열 세 줄이다. 재배치 클릭 영역은 표시 버튼과 함께 옮긴다.

1920×1080, 논리 1280×720을 유지한다. 전투 조작의 기존 좌표·터치 영역을 유지하고 색과 아이콘을 새 버전으로 통일한다. 2400×1080 비교 보드는 중앙 1920 영역과 안전 영역을 표시한다.

큰 아이콘은 이전 크기 설정을 없애고 새 인스턴스로 교체했으며 SVG 선 두께도 확대 비율에 맞췄다. 대화상자 문구를 이전 순서로 복원했고 팀 B 식별 띠에는 하늘색을 적용했다. 전체 검증 결과는 03_qa.md 및 04_closeout.md에 기록한다.
