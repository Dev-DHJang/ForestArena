# 첨부 모바일 게임 참고 UI v03 요청

2026-10-09 승인 계획: 밝은 입체 아이콘과 새 숲 배경을 제작해 Penpot 53개 화면과 프로토타입·호흡 보드를 재구성한다. 중앙 승인 투명 캐릭터, 왼쪽 위 프로필, 오른쪽 위 설정, 하단 6개 메뉴와 오른쪽 아래 플레이를 유지한다. 선택 화면은 왼쪽 목록·중앙 미리보기·오른쪽 상세로 구성한다.

첨부 5개 이미지는 구도·정보 위계·실루엣·입체감 비교용이다. 해당 게임 원화·문양·프레임·경제 기능을 복제하지 않는다. v02와 승인 캐릭터를 보존하고 Godot 입력·저장·런타임 등록은 변경하지 않는다. Android 기기는 추후 별도 검증한다.
