# 유란 콘셉트·전투·전체 모션 등록 작업 마감 기록

상태: 진행 중 — 배치 1 등록 완료, 배치 2 시안 제작 대기

## 완료

- 유란의 사용자 제공 콘셉트를 `yu-ran-concept-v01`로 등록했다.
- 외형 계약, `CharacterData`, 14개 공격 `MoveSetData`, 기본 카탈로그와 개발용 파이터 씬을 추가했다.
- 자현 대 묘령 기본 경기와 정식 선택 UI는 바꾸지 않았다.
- ADR-021과 세계관·전투 가이드를 갱신했다.
- 배치 1 `idle`, `run`, `jump` 검토 시안을 만들고 실제 알파를 확인했다.
- 사용자의 2026-09-15 명시 승인 뒤 세 모션을 128×128 셀·2048×128 런타임 시트, `SpriteFrames`, manifest로 등록했고 모션 계약 검사를 통과했다.

## 보류 항목과 재개 조건

- 런타임 모션 17종 중 배치 1의 3종만 등록됐다. 나머지 14종은 아직 런타임 등록하지 않았다.
- 이유: 모션별 사용자 승인 전 런타임 등록을 금지하는 프로젝트 모션 규칙이다.
- 재개 조건: 배치 2의 `attack_light_combo_01~03` 시안 제작·QA 뒤 사용자 명시 승인.
- 다음 순서: 배치 2 약공격 3종 시안 → 승인·정규화·등록·검사 → 배치 3 일반 공격 9종 시안 → 배치 4 특수기 2종 시안.

## 미실행 최종 검사

- 전체 `./scripts/verify.sh`, 하네스 검사, Android debug export, 에뮬레이터 가로 실행·메모리 확인은 모든 모션 승인과 런타임 등록 뒤에 실행한다.
- 실제 물리 Android 기기 검사는 수행하지 않았으며 통과로 기록하지 않는다.
- 현재 작업트리의 다른 미커밋 변경은 건드리지 않았고, 원격 통합·PR·병합은 하지 않았다.
