# 요청: 저장 공간 확보와 프로젝트 폴더 정리

- 요청일: 2026-10-10 (한국 시간).
- 사용자 요청: 더 이상 필요 없는 문서·파일과 PC 캐시를 정리하고 프로젝트 폴더를 정돈한다.
- 현재 문서에는 정확히 같은 Markdown 중복이 없다. 사용 중인 기준 문서와 작업 기록은 보존한다.
- 기존 미커밋 코드·캐릭터·UI 자산, 승인 원본·시안·백업, 개발 DB, APK 배포 묶음, 등록된 다른 작업 폴더는 보존한다.
- 삭제 범위: 재생성 가능한 Android 중간 파일, 실행 중이지 않은 개발 도구의 다운로드·빌드 캐시, Python 캐시, 대응 APK가 없는 서명 파일, 게임에서 사용하지 않는 작업 이미지의 미추적 가져오기 파일.
- Godot 편집기가 실행 중인 기본 폴더의 실행 자산 캐시는 보존한다. 다른 작업 폴더도 소스와 편집기 설정은 남기고 가져오기·셰이더 캐시만 정리한다.
- 폴더 개선: 작업 기록·빌드·배포 폴더를 Godot 스캔에서 제외하고 Python 및 작업 이미지 생성 파일을 Git 추적 대상에서 제외한다. 기존 참조 경로는 유지한다.
- 확인: 삭제 목록과 용량 기록, 기존 변경 파일 해시 비교, 문서 검사, 기본 전체 검사, Godot 리소스 검사와 별도 QA.
- Git 통합: 최신 origin/develop에서 별도 작업 브랜치로 이 요청 변경만 제출한다. 사용자 작업 폴더의 기존 브랜치는 전환하지 않는다.
