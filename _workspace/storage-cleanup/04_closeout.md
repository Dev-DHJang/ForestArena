# 완료 기록: 저장 공간과 프로젝트 폴더 정리

## 결과

- PC 개발 도구 캐시와 별도 프로젝트 복사본의 생성 파일을 정리했다.
- 현행 문서·승인 자산·제작 시안·작업 증적·DB·APK 배포 묶음을 보존했다.
- Godot 자동 검색에서 작업·빌드·배포 폴더를 제외하고 폴더별 관리 안내를 추가했다.
- npm의 관리자 소유 캐시 약 106 MiB는 권한 제한으로 남겼다. 다른 파일의 권한이나 소유권은 바꾸지 않았다.

## 확인

- 문서 검사: 기본 폴더와 최신 develop 통합 폴더에서 통과.
- Godot 리소스 검사: 기본 폴더 346개, 최신 develop 통합 폴더 397개 논리 자산 통과.
- 기존 변경 보존 확인: 148개 파일의 원래 내용 유지. INDEX는 이번에 추가한 안내 문장만 제외해 비교했다.
- 생성 파일 분리 확인: 삭제한 작업 이미지 캐시가 다시 생기지 않음.
- 기본 전체 검사: 기본 폴더와 최신 develop 통합 폴더 모두 `./scripts/verify.sh` 종료 코드 0으로 통과. 하네스·LAN·온라인 계약 검사 포함.
- 별도 QA: `03_qa_r01.md`에서 pass. 추적 파일 누락 0개, 승인 자료·배포 묶음·DB·다른 작업 폴더 보존 확인.
