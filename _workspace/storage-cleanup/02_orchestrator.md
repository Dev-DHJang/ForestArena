# 정리 실행 기록

## 판단

- 문서는 약 364 KiB이며 정확히 같은 Markdown 중복이 없다. 현행 개발 기준·안내 문서와 과거 작업 기록을 보존했다.
- 기본 작업 폴더에 미커밋 변경 148개가 있다. 원래 내용의 SHA-256을 기록하고 의도한 색인 문장 추가를 제외한 모든 내용이 유지됨을 확인했다.
- 기본 Godot 편집기가 실행 중이다. 실행 자산과 편집기 설정은 유지하고 작업 시안의 가져오기 캐시만 정리했다.
- 별도 검토자는 모든 등록 작업 폴더의 추적 파일 목록과 후보를 대조했다. 삭제 후보에 Git 추적 파일과 심볼릭 링크는 없다.

처음 계획한 1,246개 경로 중 1,245개를 삭제했다. npm 캐시는 root 소유 하위 폴더에서 권한 오류가 발생해, 이후 사용자 권한으로 지울 수 있는 파일 1,072개를 추가 정리했다. 권한 제한 파일 4개, 약 106.1 MiB는 남겼다. 권한·소유권은 변경하지 않았다.

이 표는 파일에 할당된 공간을 합산한 값이며 실제 디스크 여유 공간 변화와 차이가 날 수 있다. 전체 검사와 임시 통합 작업 폴더 정리가 끝난 뒤 여유 공간을 별도로 측정한다.

## 폴더 관리 변경

- `_workspace/`, `build/`, `artifacts/`를 Godot 자동 검색 대상에서 제외했다.
- Python 캐시와 새 작업 이미지 `.import` 파일을 Git 관리 대상에서 제외했다. 이미 추적하는 가져오기 설정은 유지했다.
- `docs/operations/project-maintenance.md`에 폴더별 용도와 정리 기준을 모으고 `docs/INDEX.md`에서 연결했다.
- 코드·승인 자산·원본·시안·백업·DB·APK 배포 묶음·다른 작업 폴더의 소스 경로는 유지했다.
- 실행 중인 앱 업데이트, 브라우저 프로필, Codex 대화와 런타임, SDK·에뮬레이터, Gradle wrapper는 보존했다.

## 로컬 상세 기록

기본 작업 폴더의 `cleanup-plan.json`, `cleanup-results.json`, `npm-cleanup-results.json`, `existing-changes.json`, `preservation-results.json`에 삭제 경로와 확인 결과를 남겼다. 이 상세 목록은 해당 PC에서만 사용하는 기록이다.

전체 검사가 끝난 뒤 npm에 다시 생긴 사용자 캐시 36개와 기본 폴더의 Python 캐시도 정리했다. 관리자 소유 잔존 4개는 그대로 남겼다.
