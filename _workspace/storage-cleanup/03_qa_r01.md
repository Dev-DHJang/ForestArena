- 날짜: 2026-10-10 (한국 시간).

- 검토 범위: 요청·정리 계획·실행 결과·기존 변경 보존·폴더 관리 규칙·자동 검사 로그. 실제 Android 기기 검사는 포함하지 않았다.

## 삭제 범위와 보존

- 사전 계획의 1,246개 경로, 약 15.492 GiB를 모든 등록 작업 폴더의 Git 추적 목록과 대조했다. 추적 파일 삭제 후보와 심볼릭 링크 후보는 0개였다. 실행 중인 기본 Godot 편집기의 실행 자산·편집기 설정은 삭제 대상에서 제외했다.
- `cleanup-results.json`은 1,245개 경로 삭제와 npm 캐시 1개 경로의 권한 오류를 기록한다. 이후 `npm-cleanup-results.json`의 사용자 권한 파일 1,072개 추가 삭제와 관리자 소유 잔존 4개 파일, 111,218,688 bytes(약 106.1 MiB)를 확인했다. 권한이나 소유권을 바꾸지 않은 처리다.
- 현재 npm 폴더에서도 관리자 소유 잔존 4개 파일의 할당 용량이 기록과 같다. 전체 검사 중 사용자 소유 파일 36개, 약 4.86 MiB가 다시 생겼다. 관리자 소유 잔존 수와 전체 폴더의 파일 수는 구분한다.
- `existing-changes.json`의 기존 미커밋 파일 148개를 직접 SHA-256으로 다시 비교했다. `docs/INDEX.md`에 이번 작업으로 추가한 안내 문장과 빈 줄만 제외하면 모두 일치한다. `preservation-results.json`의 예상하지 않은 변경 0개와 일치한다.
- 기본 폴더의 Git 추적 파일 누락은 0개다. 추적 작업 기록·가져오기 설정도 모두 남아 있다. 두 APK, 데모 APK·ZIP, 전달용 starter ZIP, 개발 DB 환경 파일과 장신구 작업 폴더의 Git 연결 파일 존재를 확인했다. 승인 원본·시안·DB·다른 작업 폴더 소스를 삭제 후보에 넣지 않았다.

## 폴더 관리와 생성 파일 분리

- `_workspace/`, `build/`, `artifacts/`의 `.gdignore`가 기본 폴더와 통합 폴더에 있으며 내용이 같다. 실행 코드의 `res://_workspace` 참조는 발견되지 않았다.
- Python 캐시와 작업 이미지 `.import` 예시 경로는 `git check-ignore`에서 제외 대상으로 확인됐다. 기존 추적 파일은 유지한다. 통합 폴더의 추가 admin·demo 제외 규칙은 최신 develop의 기존 내용이며 이번 정리 규칙과 충돌하지 않는다.
- `docs/operations/project-maintenance.md`의 내용은 두 폴더에서 같고 기본 색인에 링크가 1개 있다. 폴더별 역할, 보존 대상, 재생성 경로와 이름 있는 수동 재검사를 설명한다.
- 삭제한 기본 작업 이미지 캐시 857개를 현장에서 재확인했으며 재생성 0개다. 삭제 대상 미추적 작업 이미지 가져오기 설정도 잔존 0개다. 기존 경로를 유지해 작업 증적과 검사 스크립트의 직접 참조가 보존된다.

## 검사 증거와 제한

- `/tmp/forest-storage-cleanup-main-verify.log`: 마지막 문장이 `Forest Arena verification passed.`다. 문서·하네스 검사 통과와 논리 자산 346개 확인을 직접 읽었다. `ERROR:`는 0개다.
- `/tmp/forest-storage-cleanup-integration-verify.log`: 마지막 문장이 `Forest Arena verification passed.`다. 문서·하네스 검사 통과와 최신 develop의 논리 자산 397개 확인을 직접 읽었다.
- 통합 로그에 테스트 통과 뒤 Godot 종료 시 `resources still in use at exit` 메시지 6개와 객체 종료 경고가 있다. 스크립트는 성공으로 종료했으며 이번 변경은 코드·테스트를 바꾸지 않는다. 이번 정리의 실패로 판단하지 않았지만 로그에 경고가 없다고 기록하지 않는다.
- 장시간 전체 검사를 반복하지 않고 생산자가 실행한 두 로그와 결과 파일을 독립 대조했다. 실제 Android 기기 실행·터치·생명주기와 Android export 재생성은 이번 검토에서 수행하지 않았으므로 기기 통과로 기록하지 않는다.
- 관리자 소유 npm 캐시 약 106.1 MiB는 권한 제한으로 남아 있다. 최종 디스크 여유 공간과 PR·병합 결과는 오케스트레이터가 완료 기록에 추가한다.
