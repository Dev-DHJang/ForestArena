# 최종 승인본 Android 간단 검사

2026-10-28. 담당 `android_final_smoke`. 실제 Galaxy S23 Ultra(SM-S918N)의 가로 화면3088×1440에서 새 APK를 설치했다. 같은 기기의 두 ADB 연결 이름 중 한 연결만 사용했다. APK 실제 설치 SHA는 `53b687cb1cb5fc138e9b15ef1269b830ca1cc940f189b25eaecb6294c6cd70d7`이며 원본 APK와 같다. 검토한 manifest SHA는 `8cc96f05ba1531a99eb91235273add7d43b5ae18244cee2a971be2bfba3b7fba`다. 이전 APK의 결과를 재사용하지 않았다.

## 통과한 범위

실제 오프라인 연습에서 터치로 자현 지상 강·공중 약·공중 강을 실행했고 각각 `ja-hyun-heavy`, `ja-hyun-air-light`, `ja-hyun-air-heavy`의 실제 전투 이벤트를 확인했다. 공중 입력은 버튼 좌표를 먼저 읽은 다음 한 ADB 명령으로 점프와 공격을 짧은 간격으로 눌렀다. 전투 상태·피해를 강제로 지정하지 않았다. 나비를 최초 선택한 별도 검사 프로필에서는 실제 이동과 `RUN→IDLE`, `JUMP→FALL→IDLE`을 확인했다. **동작 표본5개 통과**다.

실제 Android screenrecord의 자현20초·나비12초 영상을 QuickTime의 정상 속도로 처음부터 끝까지 재생해 마지막 시간19.9515초/11.9606초와 재생off를 확인했다. 원영상에서 고정 영역만 잘라 모은 두 비교판도 직접 봤다. 자현의 천은 공격 중 몸/손에 붙어 뻗고 회수 뒤 남지 않았으며 나비의 착지 후 대기에서 전신 몸집이 즉시 교체되는 모습은 관찰하지 않았다. 이는 짧은 표본 확인이다. 상대가 화면 밖인 배치이므로 동일 화면의 두 캐릭터 해부학 등신 측정이나 모든18종의 실기기 재생을 통과했다고 주장하지 않는다. 이번 간단 검사에서 느린 재생은 반복하지 않았으며 기존 PC 독립 시각 QA와 구분한다.

## 미확인과 재시도 이력

HOME 중단/복귀와 입력 해제는 **미확인**이다. 검사 중 ADB 연결이 끊겼다는 관찰 스레드 오류와 HOME 뒤 boot_id 비교 실패가 발생했다. 새 게임 오류나 충돌의 원인으로 단정하지 않고 통과시키지 않았다. 앱 로그 수집도 중간에 끊겨 완전한 무충돌 검사를 주장하지 않는다. 사용자 요청대로 짧게 확인하고 추가 재시도는 중단했다.

r03은 노드 재조회·기본 대기 때문에 점프 후 공격이 늦게 눌려 지상 약이 됐고, 기대 공격 ID의 밑줄/하이픈 오타도 있었다. r04는 IP 연결이 끊겼다. r05에서 자현3종은 정상 실행했지만 자현만 보유한 임시 프로필에서 나비로 바꾸려던 검사 명령은 선택을 거부했다. r06은 처음부터 나비를 선택해 이동/점프를 확인했다. 제품 코드를 수정해 통과시킨 것이 아니며 각 실패 원본은 로컬에 보존한다.

## 정리와 증거

고유 검사 ID로 분리한 임시 프로필을 사용했다. 원래 저장 파일 목록은 검사 전후 모두 비어 있었고 동일성 검사가 통과했다. 개인 저장 값을 바꾸거나 정상 프로필의 보유 상태를 강제로 바꾸지 않았다. 검사가 끝난 뒤 autoplay를 정리하고 앱을 종료·일반 실행했으며 실제 APK에서 읽은 런처로 시작 명령의 `Status: ok`를 확인했다.

공유 가능한 결과는 `qa/android-final-summary-r03.json`, `qa/android-final-r05/ja-attacks.mp4`, `qa/android-final-r06/nabi-run-jump.mp4`, 두 폴더의 `*-observation-board.jpg`다. 원시 device/ADB/저장 진단에는 연결 이름 등이 포함될 수 있으므로 로컬에만 보존한다. 게임 원화·runtime·전투 코드는 이 검사 역할이 수정하지 않았다.
