# 자현 목도리 연결 구현

대상은 지상 강 special_neutral, 공중 약 attack_air_light, 공중 강 attack_air_heavy 세 모션이다. 기존 승인 PNG·SpriteFrames·몸 자세는 그대로다. 새 그림을 먼저 늘리기보다 실제 착용 목도리의 목/손 부착점과 궤적을 보정한다.

기존 효과는 단계별 진행률을 서로 다르게 계산하고, 준비 중 일부만 뻗었다가 공격/회복에서 고정 길이·방향으로 즉시 교체했다. 주름의 시간도 단계 시작마다0으로 돌아갔다. 새 `ScarfPaths`는 각 단계 경계에서 끝점·굽힘·폭·투명도·주름 시계가 이어지는 표시 전용 곡선을 만든다. 손/목 시작점은 지금 표시된 원화의 좌표에 정확히 붙고, 그 기준에서 상대 끝점과 곡선만 부드럽게 움직인다. 굽은 천의 파동은 시작·끝에서0이고 회복7틱 안에 접혀 사라진다. 새 곡선에는 실제 착용 목도리 원본의 질감과 평평한 천 끝을 쓴다.

특수기32장/교차잔상과 나비 발톱은 기존 분기를 유지한다. 전투 필드·타격 판정·원화·경직/피해는 수정하지 않는다. 피격/공격종료에는 즉시 효과를 비운다.

새 `tests/scarf_path_continuity.gd`는 실제 승인3모션과 양방향의 단계 경계·클록·폭/투명도 연속, 매틱 상대끝점 이동 상한, 실제 그림 부착점, 전투snapshot불변과 피격시제거를1178검사로 통과했다. 기존VFX도 통과했고 새오류0이다. 첫 실행은 다른 역할의 presentation 중간 편집과 이 새검사의 catalog접근 오타로 실패해 종료했고 r01로그를보존했다. 수정후r02만 현재검사근거다. 전체검사는 아직실행하지않았다.

실제입력 3장면 × 정상/반전은 render-scarf.gd에서 공개전투와표현을사용한다. PNG는 native frame_post_draw 뒤 고정영역[200,40,880,640]을 저장한다. 원본 SpriteFrames와후보그림을끼워넣지않는다. 캡처crop은원본게임/자산크기를변경하지않으며 영상재생/품질검토는독립QA가담당한다. 새중간그림필요여부는 이실제재생을보고판정한다.
