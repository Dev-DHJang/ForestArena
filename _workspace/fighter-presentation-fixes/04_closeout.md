# 목도리·나비 체형 수정 현재 상태

2026-10-28. 자현 목도리 3종과 나비 체형 18종의 수정본을 준비했다. 목도리 3종, 나비 18종의 독립 시각 QA와 표시·후보 검사 코드 검토는 통과했다. **수정본의 사용자 승인·나비 게임 등록·최종 전체 검사·이번 수정본의 Android 확인·develop 병합은 아직 완료하지 않았다.**

## 수정 범위

- 자현 지상 강·공중 약·공중 강: 현재 그림의 목/손 부착점에 실제 착용 목도리 질감을 연결한다. 준비·타격·회수 사이의 길이·굽힘·주름 시간을 이어 주었다. 기존 원화 16장씩과 전투 시간·피해·판정은 유지한다.
- 나비: 기존 16종의 PNG 바이트·SpriteFrames 구성·내부 비율을 보존하고 표시 배율을 0.92배로 조정한 후보를 만들었다. 달리기 16장과 점프 24장은 새 전신 그림을 썼다. 점프의 마지막 착지 자세를 기존 대기 모델로 연결해 몸집이 갑자기 바뀌는 부분을 보정했다.
- 나비 후보의 정식 검토 카탈로그는 `nabi/registration-catalog-r03.json`이다. `registration-wrapper-proof-r03.json`은 기존 r02의 모든 필드를 보존하고 검토에 필요한 설명만 추가했음을 확인한다.
- 같은 승인 PNG를 사용하는 새 배율도 검토할 수 있도록 검토 도구에 `layout_only_from_asset_id`를 추가했다. 정확한 기존 자산·그림·구성을 확인하며 독립 QA와 사용자 승인을 생략하지 않는다. 게임 데이터와 LAN 형식은 바꾸지 않는다.

## 피격 문제 종료

사용자는 관측 환경을 Android 오프라인으로 답했다. 기존 S23 Ultra APK에서 실제 특수기 피격 상태·그림 진입과 14피해를 촬영했다. 그 영상을 제시한 질문에 사용자가 **“해결되었다.”**라고 확인해 첫 문제를 종료했다.

촬영 APK에는 새 LAN형 표시 실험 코드가 없었다. 해결을 그 코드의 효과로 설명하지 않으며, 필요 없어진 lead 설정·API·테스트는 최종 제품 변경에서 제외했다. 당시 코드 `2313481a`와 실험 근거는 이력에 보존했다. 최종 승인 대상에 피격 모션 조정을 포함하지 않는다.

## 확인 결과와 남은 순서

목도리 관련 1178개 검사와 기존 VFX 검사, Python 기존 87개+새 3개 검사를 통과했다. 목도리 실제 입력은 3장면×양방향, 나비 달리기는 양방향, 최종 점프는 양방향으로 촬영했다. 독립 검토는 전체 그림과 실제 재생의 정상/느린 속도를 구분해 기록했다. 자세한 범위는 `03_qa_r01.md`, `03_qa_nabi_r02.md`, `03_qa_code_r01.md`를 따른다.

수정본 승인 뒤 나비 18종을 기존 논리 ID와 SpriteFrames 경로로 등록한다. 그 최종 상태에서 `verify.sh`, 문서·리소스 검사와 필요한 Android 확인을 진행한다. 현재 ADB 기기 목록과 검색 목록에는 연결된 기기가 없으며, 기존 APK 촬영을 이번 새 수정본의 기기 통과로 재사용하지 않는다.
