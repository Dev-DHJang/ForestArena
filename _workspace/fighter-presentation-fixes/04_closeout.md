# 목도리·나비 체형 수정 마무리

2026-10-28. 자현 목도리3종과 나비 체형18종을 사용자 명시 승인 뒤 반영했다. 독립 시각 QA·등록 대조와 전체 검사 목록을 통과했고 S23 Ultra에서 핵심5동작도 확인했다. PR112의 develop 병합을 진행한다. 실기기 HOME 복귀·입력 해제는 미확인으로 남긴다.

## 반영한 내용

- 자현 지상 강·공중 약·공중 강의 착용 목도리를 현재 그림의 목/손에 연결하고 준비·타격·회수 사이의 길이·굽힘·주름 시간을 이어 주었다. 기존 원화와 전투 시간·피해·판정을 유지했다.
- 나비 기존16종은 PNG와 SpriteFrames 구성을 보존하고 표시 크기를0.92배로 맞췄다. 달리기16장·점프24장은 새 전신 그림을 썼고 착지 마지막 자세를 대기 모델과 연결했다. 새 점프의 승인된 재생 설정은8 FPS이며 이전 클립은12 FPS였다. 점프 물리·60Hz 전투 계산·착지 연결 시간은 바꾸지 않았다.
- 같은 승인 그림을 쓰는 배율 수정도 별도로 검토할 수 있게 검토 도구에 `layout_only_from_asset_id`를 추가했다. 정확한 기존 자산·그림·구성을 확인하고 새 배율에도 독립 QA와 사용자 승인을 요구한다. 게임 데이터·LAN 형식은 유지했다.

## 승인과 등록

사용자는 앞선 “수정 필요” 응답 뒤 최종 비교 페이지에 대해 직접 “승인한다.”고 확인했다. 검토본을 바꾸지 않고 이 최신 응답을21종 승인으로 기록했다. `user-presentation-approval-r03.json`은21종, `user-motion-approval-r03.json`은 나비 실제 등록18종의 승인이다.

카탈로그는 `nabi/registration-catalog-r03.json`, 등록 계획 SHA는 `3f8c56e6b2c75250e601eb45e211e4e6d539681bec048dab9a3cef6073ee56f6`이다. 기존18개 자산 ID·SpriteFrames 경로·이전 PNG와 등록 이력을 보존했다. 후보와 실제 파일·표시 설정의 독립 대조228항목을 통과했다. 승인 PNG·TRES·manifest 출력은 최종 검사 뒤에도 등록 receipt의 해시와 같다.

## 피격 문제 종료

기존 Android APK의 실제 특수기 피격 영상에 사용자가 “해결되었다.”고 확인해 첫 문제를 종료했다. 그 APK에는 새 LAN형 표시 실험 코드가 없었다. 해결을 해당 코드의 효과로 설명하지 않으며 미등록 lead 설정·API·검사는 최종 제품 변경에서 제외했다. 당시 코드와 검사 자료는 이력에 보존했고 이번 승인 대상에 피격 모션 조정을 포함하지 않았다.

## 확인 결과

- 자현 목도리3종·나비18종의 전체 그림과 정상/느린 재생 독립 QA를 통과했다. 목도리는 실제 입력3장면×양방향, 나비 달리기와 최종 점프는 각각 양방향으로 촬영했다.
- 목도리1178개 검사·Python90개 검사·등록 대조228항목을 통과했다. `verify.sh`의 전체82개 명령은 r06에서 앞62개를 통과하고 검사 기대값 보정 후 r07에서 나머지20개를 재개해 통과했다. 단일 연속 실행의 종료값0으로 기록하지 않는다. AI16조합과 같은 초기값 재현, 30초 무진행 금지·5분 내 종료 기준, 실제 소켓 LAN 연결, UI·입력·전투·저장·하네스 검사를 포함한다.
- `verify-docs.sh`와 Godot 리소스519개 검사를 통과했다. APK 생성·패키지 검사도 통과했다. 새 APK SHA는 `53b687cb1cb5fc138e9b15ef1269b830ca1cc940f189b25eaecb6294c6cd70d7`이다.
- 같은 APK를 S23 Ultra에 설치해 실제 터치의 자현 지상 강·공중 약·공중 강, 나비 달리기·점프/착지 총5개 표본과 영상을 확인했다. 원래 저장 파일 목록을 보존하고 일반 앱 실행으로 정리했다. HOME 복귀·입력 해제는 ADB 연결 중단과 프로세스 식별값 비교 실패로 미확인이다. 앱 전체 무충돌이나 모든18종의 실기기 재생을 통과했다고 기록하지 않는다.

초기 검사 실패와 보정은 `02_integration_notes.md`, 독립 검토 r05~r07, `qa/final-verification-coverage-r07.json`에 보존했다. 새 이미지 가져오기 순서, 승인된 점프 재생 설정의 기대값, 반복 등록 이력 조회를 바로잡았으며 승인 그림과 게임 코드는 추가로 바꾸지 않았다. 일부 기존 검사에는 종료 시 리소스 정리 경고가 남아 있으므로 전체 로그를 오류0이라고 표현하지 않는다.
