# 같은 원화를 쓰는 배율 수정 후보의 검토 형식

2026-10-28. 요청: 나비 기존16종은 승인 원화의 PNG 바이트와 SpriteFrames 구성을 보존하고 표시 배율만0.92배로 줄인다. 원화가 같다는 이유로 새 배율의 검토를 차단하거나, 기존 승인 재사용으로 오인해 등록 계획에서 빠뜨리지 않아야 한다.

## 공용 도구 값

검토용 `motion-candidates` schema1의 후보 행에 선택 값 `layout_only_from_asset_id`를 둔다. 게임 데이터·LAN 메시지의 필드는 아니다. 값은 현재 manifest의 단 하나인 `animation-runtime` 자산 ID이며 캐릭터·모션도 정확히 같아야 한다.

- 후보 PNG는 `_workspace` 안의 별도 파일이다. 실제 SHA와 후보·승인 manifest의 선언 SHA가 모두 같아야 한다.
- SpriteFrames는 승인본의 PNG 참조 한 곳만 후보 PNG로 바꾼 원문과 같아야 한다. 셀·순서·시간·루프를 바꿀 수 없다.
- 프레임 수·셀·열·표시 가중치·FPS·루프·공격/점프/하강/착지 구간·발 기준·앵커·달리기 거리·상태 유지/연결 시간은 모두 같아야 한다. `presentation_scale`만 이전과 다른 유한 양수다.
- 원본 PNG·SpriteFrames도 검토 자료의 파일 해시 목록에 추가한다. 후보 경로를 런타임 코드/자산에서 참조하는 행위는 계속 거부한다.
- PNG가 다른 경우 이 값을 쓸 수 없다. 새 run/jump 원화는 일반 후보로 검토한다.

## 승인과 등록 경계

이 값은 새 배율에 대한 독립 QA나 사용자 승인을 대신하지 않는다. `reuse_approved_runtime`을 쓰지 않으므로 등록 계획에 후보가 남는다. 기존 등록기의 새 버전 PNG·안정된 논리 ID/소비 경로·승인 해시 일치 검사를 그대로 사용한다. 검토용 값은 manifest로 복사하지 않는다. 원본 경로는 당시 검토의 기준이며 등록 뒤 바뀐 SpriteFrames를 과거 해시와 같다고 보고하지 않는다.

## 검증

`test_motion_action_review.py`에 정상 복사/원본 파일 해시 연결, 식별자·픽셀·표시 구성 변조 거부, 읽기 전용 등록 계획과 승인 없을 때 무변경을 검증하는 세 검사를 추가한다. 합성 테스트 승인과 실제 사용자 승인을 구분한다. 기존 미승인 후보 노출 거부 검사도 유지한다. 기존87+새3, 합계90검사가 통과했다. 잘못된 기존 캐릭터 연결도 별도 확인한 최종 결과는 `qa/layout-only-tests-r02.log`에 남겼다. 실제 나비18종 r03 카탈로그의 읽기 전용 사전 검사는 `qa/layout-only-preflight-r01.json`이다.
