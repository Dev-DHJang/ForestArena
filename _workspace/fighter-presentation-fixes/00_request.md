# 자현 피격·목도리와 나비 체형 수정

2026-10-27 사용자 승인 계획 구현. 자현 특수기의 실제 연속 적중에서 상대 피격 모션을 확인하고 수정한다. 지상 강·공중 약·공중 강의 착용 목도리는 부착·궤적·준비/타격/회복 연결부터 보정하며 원화 자세가 튀는 구간만 새 중간 그림을 추가한다. 나비는 자현을 유지한 채 실제 몸 크기와 등신을 맞추며, 전체 균일 배율로 해결되지 않는 모션만 새로 그린다.

전투 시간·피해·경직·판정·쿨타임·LAN 형식을 유지한다. 새 그림/수정 표시 모션은 기존 원본과 별도로 검토하며 독립 QA 후 해당 수정본의 사용자 명시 승인을 받아 등록한다. 기존에 받은 다른 버전의 승인을 새 수정본 승인으로 재사용하지 않는다.

기존 미커밋 작업과 이전 QA 원본은 보존한다. 현재 재사용 worktree에서 최신 origin/develop 기반 새 브랜치를 쓴다. 변경별 관련 검사만 수행하고 최종 버전에서 전체 검사를 한 번 수행한다. 새 실패/변경이 없으면 전체 재촬영/검사를 반복하지 않는다. 실제 Android는 연결 기기를 확인한 뒤 이번 세 문제만 짧게 확인하고 통과 범위를 구분한다. 요청/전달/QA/마무리 기록은 이 폴더에 둔다.
