# 나비 몸집·등신 후보 전달 r01

최신 검토 대상은 아래 r01 이력을 보존한 `nabi/candidate-catalog-r02.json`18종이다. jump의 공통 크기와 끝 경계를 r02로 수정했고, 사용자 Android 해결 확인에 따라 hitstun의 시험 lead pair는 뺐다. 새 원화 추가 없이 실제 jump 정상/반전2클립만 재촬영했다. 아직 독립 시각 판정/사용자 승인 전이다.

2026-10-27. 담당 nabi_body_alignment. 자현은 보존하고, 나비의 실사용18종(312프레임)을 검토용 후보로 만들었다. 기존16종은 원본PNG의 바이트를 그대로 복사해 전체 인물의 표시 배율만0.92배로 제안했다. 각 그림의 머리·몸 부분을 따로 늘이거나 줄이지 않았다. run16과jump24는 기존 모션을 단순 축소해도 보이는 머리/상체 부피와 자세 차이가 남아 전체 인물을 내장imagegen으로 새로 그렸다. 새 모델·몸집·전환의 최종 판정은 독립 QA 전이다.

## 기준과 실제 관찰

`nabi/uniform-factor-choice-board.jpg`는 같은 바닥·그림 배율에서 자현/나비의 현재·0.92·0.84 비교다. idle은0.92에서 보이는 몸집이 가까워지지만, 기존 나비run/jump는 상체가 더 세워지고 머리/헤어 부피가 커서0.84 축소만으로 등신을 해결했다고 할 수 없었다. 따라서 자현run/jump의 낮은 앞 기울기·몸 구성과 나비idle의 의상/얼굴 정체성을 분리 참조했다.

귀끝~턱의 이전41.5/31~32world px를 서로 나누어 축소율로 사용하지 않았다. 동물 귀·머리카락·꼬리·클로가 포함된 alpha 바깥 상자의 높이로 해부학 등신±5%를 입증하지 않는다. 자세의 웅크림·전방 기울기가 다르므로 전체 높이도 그대로 비교하지 않는다. `representative-body-fit-r01.jpg`와 `run-all-frames-r01.jpg`·`jump-all-frames-r01.jpg`가 현재 후보를 직접 보는 자료다. 정량 기록은 각 후보의 원본/PNG/TRES 해시, 한 모션 전체에 적용한 균일source-to-world배율, 발 기준과 프레임별 가시 상자다. 가시 상자는 잘림 확인용이며 신체 크기의 자동 통과 기준이 아니다.

## 새 원화와 포장

내장도구 생성물·프롬프트·참조는 `nabi/run-r01-source.*`, `jump-r01-source.*`, `jump-repair-r02-source.*`에 보존했다. 초기jump의 도구 미리보기가 보라 배경처럼 보여 불투명으로 오판했으나 실제 빈 영역A=0~1임을 확인해 설명을 정정했다. 원본r01의 실제 인물 수는23, repair는25다. “6×4요청”이라는 문구로24개라고 가정하지 않았다.

`compose-jump-sources.py`는 최초원화의공중16+착지회복6을선택해22개전신crop의RGBArectangle을동일하게보존하고, repair에서첫접지F17·흡수F18 두전신만선택했다. 남은중복성회복자세1개는선택하지않았다. `jump-r02-composition.json`에원본crop·출처·좌표·SHA·순서를남겼다. 부분warp나새그림흉내를위한프레임복제는없다. 공중그림의몸기준점은수동골반지점+가상다리지지높이로전체그림위치만정리했고, 착지8개는실제신발바닥을맞췄다. 기준점은약±3source px의눈판독이며실제전환검토가필요하다.

기존 `pack-calibrated.py`를 새workspace출력폴더로 사용했다. run source-to-world0.276, jump0.34이며 한 모션 전체에 같은 배율이다. 최종presentation_scale은run0.7885714285714286, jump0.7906976744186047이다. 새128px셀·최대16열, run16/loop12FPS, jump24/nonloop8FPS를 유지한다. jump 구간은상승[0,6)/정점[6,10)/하강[10,16)/착지[16,24)로 기존과 같다. run_stride_px도기존선언을유지해이동판정에새규칙을넣지않는다.

## 정확한 검토 대상과 미완료

최종후보는 `nabi/candidate-catalog-r01.json`과 `candidate-scope-r01.json`이며18종이다. `candidate-technical-proof-r01.json`은 빈/전체동일프레임·셀잘림이없고각원본PNG와기존runtime18PNG/TRES·manifest가변경되지않았음을확인한다. 새 run/jump 외16종은그림픽셀과고유내부비율을보존한다. hitstun에는조율역할의공통수정과맞춘표시용pair `[0,6]`/6을포함했다.

기술검사는모션행위·등신·연속전환의독립시각PASS를대신하지않는다. 실제게임run→jump→landing→idle과공격/피격전환자료, 독립QA, 수정본에대한개별사용자승인·등록은남아있다. 이번역할은runtime·manifest·전투·LAN·저장파일을쓰지않았다.


## 실제 전환 확인과 r02 수정

r01 실제 run-stop/jump-land 정상·반전4클립은3472검사·480nativePNG와4MP4를 남겼다. 정적 관찰에서제기된착지F18/F19순서우려는실제fixedfloorPNG의머리높이연속하강과재판정으로철회됐다. 가시상자높이는F17~24가98/86/78/68/69/78/83/83셀px여서F18/F19를바꾸면오히려두번오르는흐름이된다. 순서를바꾸지않았다. 이수치는피격체/해부학측정이아닌해당착지그림의동일바닥선검토보조다.

실제남은문제는jump F24→idle0에서보이는몸집과그림모델이바뀌는경계다. r02는공중의자현대응자세와끝가드의크기를함께고려해모션전체source-to-world를0.34→0.365로맞췄다. 0.38까지크게하지않고, 마지막기존가드의가시높이는약70.45world로현재idle의약73.66world와약4.4%차이다. pose전체높이를등신의자동통과로주장하지않는다.
