# 실험 계약 — 최종 제품에는 미반영

사용자가 Android 오프라인 피격 문제 해결을 확인해 이 LAN 표시 실험을 최종 제품 변경에서 제외했다. 아래는 당시 구현·검증 기록이며 새 데이터 형식이 실제 등록됐다는 뜻이 아니다. 공개 presentation·도구·문서는 기존 버전으로 복귀하며 기록과 소스는 qa/experimental-hit-lead-archive/ 및 커밋2313481에 보존한다.

# 짧은 연속 피격의 표시 약속

2026-10-27. 피격 초반을 빨리 보여 주기 위한 선택 표시 값이며 전투·저장·LAN 메시지 형식은 바꾸지 않는다.

- `hit_reaction_lead_frame_range: [0,end)`와 `hit_reaction_lead_ticks`를 함께 선언한다. `hitstun` 모션에서만 허용한다.
- 구간은 선언된 프레임 안의 비어 있지 않은 앞부분이다. 시간은 정수 1~12틱이고 구간의 그림 수 이상이어야 한다. JSON의 정수값 실수는 허용하지만 bool·소수·NaN·무한대는 거절한다.
- LAN처럼 실제 남은 경직 값이 없는 표시만 새 HIT 직후 첫 구간을 지정한 표시 시간에 재생하고 이후 원화 FPS로 이어 간다. 예: 현재 24FPS 자산의 `[0,6]`/6은 매 6틱 연속 적중 사이에 F0~F5를 보이게 한다. 경직이나 전투 시간을 추측·추가하지 않는다.
- 실제 경직 값이 있는 로컬 표시와 값이 없는 기존 자산은 기존 동작을 유지한다. 새 HIT는 여전히 첫 그림에서 다시 시작하고, 실제 다음 전투 상태가 오면 바로 교체한다.
- 생산자는 작업 후보의 metadata, 검토·등록 도구는 검증과 필드 보존, 공개 presentation은 읽기 전용 표시를 맡는다. 새 수정본의 독립 QA·사용자 명시 승인 전 manifest/runtime에 등록하지 않는다.

도구 변경 검사는 누락 쌍·다른 모션·잘못된 구간/시간 거절, 원 입력 불변, 계획의 읽기 전용 동작, 승인 없는 설치 거절과 승인된 임시 fixture 설치의 필드 보존을 확인한다. 실제 그림·runtime·전투 Resource는 이 계약 담당에서 수정하지 않는다.

## 도구 검사 결과

`python3 tools/forest_arena/test_motion_action_review.py`는 기존 87개와 새 3개를 합친 90개 검사 PASS다. 새 검사는 16/24/32장 및 JSON 정수값 실수, 잘못된 33개 쌍/모션/범위/숫자 사례, 원 입력과 원화 frame duration 불변, 읽기 전용 계획과 승인 누락 시 무쓰기, 승인된 임시 fixture 등록 후 값 보존을 확인한다. 실제 사용자 승인이나 실제 자산 등록을 만든 결과가 아니다.

로그는 `qa/reaction-display-contract-r01.log`다. 문서 검사 `qa/reaction-display-docs-r01.log`와 변경 파일의 `git diff --check`도 통과했다. 공개 presentation의 실제 연속 적중 검사는 전투/표현 역할이 따로 수행한다. 전체 검사나 GPU 촬영은 이 역할에서 반복하지 않았다.
