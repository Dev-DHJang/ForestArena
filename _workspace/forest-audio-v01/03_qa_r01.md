## 수정해야 할 사항

1. **LAN 나가기 확인 후 취소 시 전투 음악이 복구되지 않는다.** `_show_lan_leave_confirm()` → `_new_page()`는 `screen=lan_leave_confirm`을 전달해 로비 음악으로 전환한다. 계속 플레이 버튼의 `_show_lan_match_controls()`는 문맥을 바꾸지 않아 이후에도 로비 음악이 남는다. 확인 화면은 서버 경기가 계속된다고 안내하므로 확인 중에도 전투 음악 유지가 적절하다. `lan_leave_confirm`을 전투 문맥으로 매핑하고 LAN 경기 조작 화면 진입 때 `set_context("lan_match")`를 명시할 것. 재검사: 실제 LAN 경기 화면 → 나가기 확인 → 계속 플레이, 음악이 battle이고 재시작되지 않는지 확인.
2. **결과 음악 전환 순서가 승인 계획과 다르다.** `finish_match()`는 1.35초 결과음을 시작한 직후 로비로 전환한다. 승인 계획은 결과음 뒤 로비 음악이다. 결과음 길이가 끝난 뒤 문맥을 전환하고, 그 전에 재대전/화면 이동이 있으면 이전 완료 작업이 새 문맥을 덮지 않도록 취소 또는 세대 번호를 둘 것. 재검사: 승리/패배/무승부 각각 재생 중 battle 유지 → 결과음 뒤 lobby; 결과음 도중 재대전 시 battle 유지.

## 남은 실제 확인

- **blocked — Android 실기기**: 연결된 adb 실기기가 없다고 조율 담당이 확인했다. 현재 음원이 포함된 APK의 스피커·이어폰 출력 전환, 중단·복귀, 다인 타격음 구분, 소리 겹침은 기기 통과로 기록할 수 없다.
- **미실행 — 사람의 청취**: 이름 있는 수동 재검사로 로비 클릭/선택/오류, 네 캐릭터 모든 특수기·필살기, 최대 8인전, 결과·재대전·로비 복귀, 음악 각 3회 반복의 음색/균형을 듣는 확인이 필요하다. 자동 신호 검사는 이를 대체하지 않는다.
- 전체 `verify.sh`, 문서 검사, Godot 자산 검사, LAN 실제 연결 자동 검사의 최종 종료 결과를 조율 담당이 수집 중이다. 완료 후 수정 2건 재검사와 함께 2회차 기록에 반영한다.
