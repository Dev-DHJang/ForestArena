## 추가 확인과 제한

- 1회차에서 직접 실행한 `verify_audio_v01.py`의 47개 음원/확인값/반복 접점/형식 검사는 통과 상태다. 생성 방법·권리 기록, 생산자와 재생 측 연결, 스냅샷이 과거 신호를 만들지 않는 코드 경로도 다시 확인했으며 추가 높은 영향의 연결 결함은 발견하지 않았다.
- `/private/tmp/audio-verify.log`의 당시 실행은 `scripts/verify.sh: line 38: ath: command not found`로 종료했다. 검사 중 파일 수정과 겹친 가능성이 있으나 추정만으로 통과 처리하지 않는다. 전체 검사 재실행의 최종 성공 줄을 별도 확인할 것.
- `/private/tmp/audio-export.log`의 당시 실행은 Godot export 후 `APK contains development-only documentation, tests, or workspace evidence`로 종료했다. 패키지 제외 목록을 바로잡아 다시 생성·검사해야 하며, 이 기록만으로 배포 APK 통과라고 할 수 없다.
- QA가 `--verbose --log-file /private/tmp/audio-qa-contract-engine.log`로 확인한 종료 잔존 자원은 이번 음악의 `AudioStreamOggVorbis`, `OggPacketSequence`, 두 Playback 유형이다. 이 검사는 테스트 수정 전 실행이므로 결과 assertion 실패는 재검사에서 해소됐으나, OGG 종료 경고 원인을 기존 문제로 단정할 근거는 없다. 정지/stream 해제 등 종료 정리를 검토하고 최종 실행에서 경고 변화를 확인할 것. 이 증거는 실행 중 계속 증가하는 누수까지 증명하지 않는다.

## 사람이 해야 하는 named 수동 재검사

- AUDIO-LISTEN-LOBBY: 버튼 클릭·뒤로·선택·확인 성공·거절을 각각 듣고 구분한다.
- AUDIO-LISTEN-MOVES: 네 캐릭터의 중립/옆/위/아래 특수기와 필살기 발동·적중을 모두 듣는다.
- AUDIO-LISTEN-8P: 최대 8명 경기에서 타격과 주요 기술·링아웃을 구분하고 소리 겹침이 과한지 확인한다.
- AUDIO-LISTEN-FLOW: 결과음 → 로비, 빠른 재대전, 일시정지·복귀와 LAN 나가기 취소를 듣는다.
- AUDIO-LISTEN-LOOP: 두 음악을 각 3회 반복해 반복 접점·음색·균형을 듣는다.
- AUDIO-ANDROID-OUTPUT: 최신 APK에서 스피커·이어폰 출력 전환과 중단·복귀를 확인한다. 실제 기기/버전/결과를 기록하기 전까지 미확인이다.

사람 청취와 Android 검사가 남은 상태로 전체 계획 완료나 Phase 6 완료를 선언하지 않는다. 전체 자동 검사/패키지/종료 자원 정리 완료 결과는 다음 회차에서 보완한다.
