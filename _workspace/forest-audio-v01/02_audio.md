# 오디오 제작·연결 기록

- audio 역할이 NumPy·ffmpeg로 독창적 작곡과 신호 합성을 수행했다. 외부 녹음·음악·샘플·음성은 사용하지 않았다.
- 80초 로비·90초 전투 음악과 45 효과음. 44,100 Hz, 음악 스테레오 OGG와 WAV 원본, 효과음 모노 16-bit WAV. 네 캐릭터 특수기 4방향·필살기는 각각 다른 합성 음색이다.
- 고정 난수와 bitexact 인코딩으로 두 번 생성한 47 실행 파일과 47 원본의 SHA-256이 일치했다. 권리·도구 버전·확인값은 assets/audio/v01/manifest.json에 있다.
- 자동 검사는 파일·확인값·무음·최대 크기·DC 편향·효과음 끝·음악 반복 이음새를 확인했다. OGG 해독 경계 차이는 로비 0.01410, 전투 0.01886이다. 사람의 청취 결과를 의미하지 않는다.
- 효과음 전체 16개/UI 4개 동시 재생 제한, 중요 소리 우선, 음악 낮춤·화면 전환, 기기별 설정을 구현했다.
- 전투 판정과 무관한 성공 동작 신호와 기존 적중 결과를 사용한다. LAN은 같은 서버 표현 이벤트와 경기별 순서를 사용한다.
- QA에서 발견한 LAN 확인 화면 음악과 결과음 뒤 전환 순서를 고쳤다. Android APK 검사에서 개발용 서버 테스트 fixture가 포함되는 기존 설정 문제를 발견해 해당 테스트 폴더를 내보내기 제외 목록에 추가했다.
- 합성 악기 음색이다. 사람이 듣는 품질과 Android 스피커·이어폰 검증은 미실행이다.
