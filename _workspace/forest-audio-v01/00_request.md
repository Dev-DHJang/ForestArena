# 요청

밝은 숲 판타지 분위기의 BGM·효과음을 직접 작곡·합성하고 메뉴·로컬·LAN 대전에 연결한다. 사용자는 계획에서 캐릭터별 주요 기술 구분, 음성 제외, 파일 제작과 게임 연결을 선택했다.

## 완료 조건

- 로비 80초·전투 90초 반복 음악과 UI·이동·타격·가드·차지·네 캐릭터 기술·경기 결과 효과음.
- 논리 ID를 통한 재생, 기기별 음량 저장, 중단·복귀와 중복 방지.
- 생성 코드·출처·원본·미리듣기와 자동 검사, 독립 QA 기록.
- 실제 Android 청취와 출력 전환은 실행 증거가 있을 때만 통과로 기록한다.

## 작업 환경

원 작업 폴더의 미완료 변경을 보존하고 최신 origin/develop b1a0db1에서 /private/tmp/forest-audio-v01 체크아웃과 feature/forest-audio-v01 브랜치를 만들었다. audio 역할은 생성기·음원, 조율 역할은 코드 연결, qa 역할은 독립 확인을 담당한다.
