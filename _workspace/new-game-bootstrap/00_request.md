# 새 게임 사전 구성 지침서 작성 요청

- 날짜: 2026-10-08
- 목표: 다른 프로젝트의 Codex에 문서 하나만 전달해 문서·프로젝트 전용 스킬·작업 절차·구조 검사를 구성하게 한다.
- 산출물: `docs/operations/new-game-bootstrap.md`, `docs/INDEX.md` 연결, 이 폴더의 요청·마무리 기록.
- 포함: 엔진 공통 입력 양식과 핵심 템플릿, 역할 선택, 순서가 있는 실행 절차, Godot·Android 선택 구성, 선택 도구 준비 확인, 검사 규칙과 완료 보고.
- 제외: 게임 코드, 기존 스킬·게임 동작 변경, 다른 프로젝트의 도구 설치·계정 연결·Git 원격 변경 자동 실행.
- 진행 방식: 단일 에이전트가 순서대로 작성하고 시나리오를 검토한다. 별도 역할 전달이나 공용 데이터 변경은 없으므로 추가 전달 기록은 만들지 않는다.
- 근거: 문서 색인, 팀 명세·운영 색인, 콘텐츠 원칙과 하네스 정리·통합·UI 자산 연결·Android 무선 연결 종료 기록.
- 완료 조건: 외부 참고 자료 없이 입력·파일 내용·역할·스킬·검사·마무리를 이해할 수 있고 빈 프로젝트·기존 프로젝트·엔진 미정·도구 없음·재실행·필수 파일 누락 절차가 명확하다.
- 검사: `./scripts/verify-docs.sh`, `./scripts/verify-harness.sh`, `./scripts/verify.sh`, 이름 있는 수동 검사 `bootstrap-six-scenarios`, `bootstrap-standalone-review`.
- 기존 상태: 여러 자산·코드·AGENTS·색인·검사 스크립트의 미커밋 변경이 있다. 기존 변경은 보존하고 색인에는 새 행만 추가한다.
