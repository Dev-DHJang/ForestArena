# 무료 APK 데모 구현 마무리

## 구현

1. ADR-032와 공용 계약에 무료 APK 데모 및 인증된 LAN 선행 범위를 반영했다.
2. DB 고유 제약, 게스트 닉네임 조회·변경과 별도 기기 세션 복원을 구현했다.
3. LAN 계약2에 인증된 참가·재접속, 중복 게스트 차단 및 경기 표시 이름을 연결했다.
4. 사설 네트워크 검사·8초 취소·실패 안내·재접속 재시도·서버 종료와 재시작 도구를 추가했다.
5. 개발 DB 메뉴를 숨긴 데모 APK와 서버 배포 ZIP, 업데이트·설치·방화벽 문서를 만들었다.
6. 자동 검사를 완료했고 실제 두 Android 기기 검사는 미확인이다.

## 확인

전체 기본 검사, API11개, 실제 PostgreSQL/HTTP 동시 닉네임·인증·재시작 복원, 실제 두 LAN 클라이언트와 앱, 재접속 인증 재시도, APK 패키지·서명, ZIP 추출 서버 시작·종료 통과. 독립 품질 확인에서 발견한 오류를 고친 뒤 재검사했다. 자세한 내용은 02 기록과 03_qa_r03.md를 따른다.

원래 작업 폴더의 수정 자산·파일은 보존하고 최신 origin/develop 기반 별도 작업 브랜치에서 구현했다. 시험 서버는 종료했으며 데모 DB 볼륨은 보존했다. 배포 ZIP에는 토큰·비밀 파일·백업을 포함하지 않았다.

## 남은 출시 조건

- 실제 Mac LAN 인터페이스와 PF 적용 후 허용 밖 접속 차단 확인.
- Android 두 대에서 최초 설치·동일 서명 업데이트와 저장 보존, 전체 대전·재대전·단절 복귀, 반복 플레이·터치·오디오·성능 확인.

자동 검사와 배포 준비 완료이며 데모 출시 완료 판정은 보류한다.
