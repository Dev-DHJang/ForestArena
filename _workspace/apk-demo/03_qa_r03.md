# 무료 APK 데모 독립 품질 확인 r03

- 확인일: 2026-10-10.
- 판정: **pass — 검토한 코드/자동 검사/최종 배포 묶음 범위**. 실제 두 Android 출시 확인과 OS 방화벽 적용은 미확인으로 남으며 데모 출시 완료를 뜻하지 않는다.

## 수정 재검

- PF 출력에 lo0의 최소 서버 내부 요청 허용을 첫 규칙으로 추가했다. `python3 tools/forest_arena/demo_firewall.py en0 192.168.1.10 192.168.1.0/24` 실제 출력에서 lo0 허용 → 지정 LAN 허용 → 그 외 차단 순서를 확인했다. 실제 sudo PF 적용과 외부 망 차단은 실행하지 않았다.
- API 500 로그가 URL query를 제외한 pathname만 기록한다. 최종 ZIP 속 코드에도 수정이 포함됐다.
- r01/r02에서 발견한 코드 수정 사항 외 추가 구현 차단 문제는 이번 확인에서 찾지 못했다.

## 최종 ZIP 독립 확인

- 파일: `build/demo/ForestArena-0.1.0-demo.zip`.
- SHA-256: `c88b7a96b9a1f948f989883540374845751116092e0fd99b59ad1d0a94d0818f`.
- ZIP 28개 항목과 manifest 모든 파일의 SHA-256을 실제 읽어 비교했다. 불일치 0.
- .env・keystore・DB 백업・기기 인증/session.json・node_modules 경로는 ZIP에 없다. APK/PCK・명시한 API 소스 및 서버 도구로 구성된다. token 값이 있는 운영 환경 파일은 배포 경로 밖이다.
- ZIP의 서버 실행 셸 스크립트 파일 모드는 100755다. 서버 실행 명령・소스・tsconfig 경로 일치, native API 방식에 불필요한 Dockerfile 제외 확인.
- 최종 ZIP의 server.pck와 project.godot를 임시 폴더에 추출해 원래 저장소 리소스를 쓰지 않고 Godot 4.7.1로 실행했다. 시험 포트 18778, API 주소 127.0.0.1:18301, loopback CIDR에서 `FOREST_ARENA_LAN_READY FAH2|http://127.0.0.1:18301|ws://127.0.0.1:18778|2` 출력과 exit 0 확인. 시험 3프레임 뒤 종료 및 임시 폴더 삭제 완료.
- 전체 서버 독립 확인도 수행했다. ZIP의 server 내용만 임시 폴더에 추출하고 원본 .env.demo를 비밀값 출력 없이 0600으로 로컬 복사했다. 기존 데모 DB 볼륨과 게스트 기록을 유지한 상태로 ./scripts/demo-server.sh start가 npm ci・TypeScript build・DB 준비・API 준비・LAN FAH2 표시까지 exit 0, stop이 exit 0이었다. 종료 뒤 한 번 더 정지 확인 후 임시 폴더와 비밀 파일을 삭제했다. 3001/7778 포트를 해제했다.
- 이 전체 시작/종료 확인은 마지막 서버 업데이트 보호 코드 추가 전 ZIP으로 실행했다. 최종 ZIP의 모든 파일 확인값은 다시 실제 비교했고, 기존 볼륨인데 .env가 없으면 새 비밀을 생성하지 않는 보호 코드와 서버 업데이트 설치 안내가 포함됐음을 확인했다. 그 보호 분기의 실제 실행은 root가 PASS 증거를 제공했으며 reviewer는 정적으로 확인했다.
- 실제 API/DB 두 앱 흐름은 생산자 기록, LAN 3종 실제 통신 시험은 r02 독립 실행 증거를 따른다.

## 남은 현장 확인

물리 Android 두 대 최초 APK 설치・현재 서명 업데이트・기기 저장 보존・한글 키보드/터치/화면/성능/오디오・실제 Wi-Fi 단절 및 복귀, macOS PF 적용과 허용 밖 망 차단, 다른 Mac에서의 신규 서버 설치 및 시작은 미확인이다. 현재 Mac에서 ZIP 추출 서버의 전체 시작/종료는 위와 같이 통과했다. 이 항목의 pass 기록 없이 출시 완료로 변경하지 않는다.
