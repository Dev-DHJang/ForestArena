# 무료 APK 데모 구현

- 승인일: 2026-10-10. 사용자 승인 계획을 구현한다.
- 범위: 같은 네트워크의 1대1 한 경기, 기존 API/PostgreSQL 게스트와 닉네임 유지, 중복 이름 금지・경기 밖 변경, 기존 오프라인 전체 모드, debug APK 직접 설치.
- 현재 작업: 최신 origin/develop의 별도 작업 공간. 원래 작업 폴더의 변경은 보존한다.
- 순서: 기준・계약 → 게스트/닉네임 → LAN 인증 → 제한・운영 → 배포 → 실기기.
- 서버는 macOS 한 대에 demo 전용 API・DB・LAN을 실행한다. 기존 개발 DB를 변경하지 않는다.
- 실제 두 Android가 없으면 기기 검사를 미확인으로 기록한다.
