# UI 구현 기록

- `ArenaVisual/Background`는 품질 의존 `fa.background.combat.training.arena`를 소비하며 품질 변경 신호에 다시 로드한다.
- 기존 터치 좌표 판정과 멀티터치 카운트는 유지하고, 자식 `TextureRect`가 D-pad 방향과 행동 버튼 눌림 상태를 표시한다.
- 방향, DASH, JUMP, LIGHT, HEAVY, SPECIAL, 재시작과 HUD 문구는 네이티브 Godot 텍스트다.
- 재시작 버튼은 기존 secondary medium 상태 리소스, HUD는 기존 dark large 패널 리소스를 사용한다.
- 누락 리소스는 경고와 자홍색 대체 텍스처 및 `MISSING RESOURCE` 문구로 표시한다.
