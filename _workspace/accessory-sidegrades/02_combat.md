# 실제 전투 설정 변경

현재 6종 옵션은 [장신구 설정](../../docs/gameplay/accessories-v01.md)을 따른다. 반사・폭발 추가 피해・부활을 이동/체공 옵션으로 대체하고 무조건 슈퍼아머・복싱 속도 보너스를 제거했다. 궁극기 추가 게이지는 12에서 4로 줄이고 지상 속도 불이익을 둔다.

AccessoryData는 추가 HP 피해・부활 효과를 거부한다. 일반 전투용 효과 기능은 유지한다. 실제 로컬 앱 24조합 검사와 금지 설정 거부 검사를 추가/갱신했다. 기존 ID로 저장된 선택에 새 설정이 연결되며 캐릭터 원본은 바뀌지 않는다.
