# QA r01

## 통과

- `migrate_remove_grab_moves.gd`: 네 MoveSet에서 잡기 기술 슬롯을 제거하고 유효한 Resource로 저장했다.
- `./scripts/verify.sh`: 입력 맵·전투 계약·전투 행동·결정론을 포함한 전체 회귀 통과.
- `./scripts/verify-docs.sh`: 문서·하네스 검사 통과.
- `python3 tools/forest_arena/verify_godot_resources.py --project-root .`: 논리 리소스 345개, 품질 의존 리소스 23개 통과.

## 확인한 경계

- `GRAB` 액션은 입력 맵과 FighterController에서 제거됐다.
- `GRAB` 태그와 잡기 면역 규칙, GrabBox·가드 통과 예외는 제거됐다.
- 제거 마이그레이션 도구만 과거 슬롯 식별자를 보존하며 실행 뒤에는 MoveSet 데이터에 잡기 기술이 없다.
