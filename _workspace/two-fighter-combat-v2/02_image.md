# 새 모션 시안 제작

- 사용 도구: built-in imagegen. 기존 승인 콘셉트와 idle16f를 참조하여 캐릭터 정체성과 비율을 유지했다. 승인 자산을 덮어쓰지 않았다.
- 자현 킥 r01: 앞 킥16포즈4×4. 왼손/오른손 펀치와 구별되는 지상 마지막타다.
- 자현 공중 강 r01: 위에서 아래로 목도리를 휘두르는16포즈. 기존 공중 발차기와 구별한다.
- 나비 오른손 위 할퀴기 r01: 발을 딛고 오른손을 아래에서 위로 올리는16포즈.
- 나비 공중 강 r01은 팔보다 먼저 움직이는 잔상 때문에 부모가 보완 대상으로 남겼다. 첫 표시에서는 배경도 의심했으나 실제 alpha 검사와 단색 배경 합성에서는 투명함을 확인했다. r02는 imagegen으로 팔 움직임을 보완한 후보이며 실제 alpha가 있음을 확인했다. 이전 원본은 이력용으로만 보존한다.
- 생성 원본은 `$CODEX_HOME/generated_images`에서 후보 폴더로 복사했다. 원본은 보존한다.
- SpriteFrames용 변환은 ImageMagick으로 `-crop 4x4@ +repage -resize 122x122 -gravity center -background none -extent 128x128` 뒤16셀을 `+append`한다. 셀 분리·정렬·축소만 수행하며 팔/외형/색을 다시 그리지 않는다. 결과는2048×128이며 검토용 .tres만 `_workspace`에 둔다.
- 후보 제작·기계 검사 통과는 사용자 승인이나 행위 표현 QA 통과를 뜻하지 않는다. runtime/manifest 등록은 모션별 승인 뒤에만 한다.

## 최종 후보와 표시 보완

- 단순4×4자르기에서 이웃 그림/천 끝이 잘려 기존 검증 도구 `motion_sheet_regions.split_regions`로16전경을 분리한 뒤 동일 배율·발 기준점으로 정렬했다. `normalize-layout.py`, `candidate-layout.json`에 입력 해시와 이동/축소만 수행한 값을 남겼다. 후보PNG는새안무그림이며 기존이미지는변경하지않았다.
- 나비 공중 강의 팔 교체는 r02/r03 전체시트 생성으로 해결되지 않아 단일 키 포즈 제작으로 접근을 바꿨다. r03의 동일 전방 팔을 올리는F7을 imagegen으로 확장한 r04 키를F8~10 짧은 유지로 배치했다. 다른 손은 허리에 두었다. r04n02를 독립 QA 대상에 넣었다.
- 자현 킥/공중 강은 승인idle과 나란히 볼 때 머리 폭이 조금 커 보이는 관찰이 있다. 캐릭터 정체성과 안무는 유지하지만 최종 모션 승인은 사용자가 직접 결정한다.
- 실제 표현은 가늘고 끝이 좁아지는 푸른 천을 몸 뒤에서 움직이게 하여 얼굴을 가리지 않는다. 판정은 전투 데이터가 정하며 효과가 피해나 승패를 바꾸지 않는다.
- 원화36모션 검토와 별도로 새5개+리치효과3개의 실제 표현 코드8영상을 기록했다. 실제 나비 특수 성공/빈이동/벽 차단3경기는60Hz입력과피격·뒤돌기까지 함께 기록했다. 합성 공격단계 렌더와 실제 경기 영상은 구분한다.
- 독립 QA가 해시로 고정한 무손실 MKV는 MP4/JPEG·해시·재생성 스크립트와 함께 Git에 보존한다. 원본 HUD PNG는 같은 작업 폴더에 보존하고 Git에는 JPEG 대조본을 넣는다. 승인 전 후보·검토는 `_workspace` 안에만 두며 runtime/manifest 등록은 하지 않는다.
