# 실기기에서 발견한 현재 게임 문제 수정

사용자가 S23 Ultra와 Tab S5e에서 자현 연습을 직접 확인하고 두 기기 모두 같은 문제라고 답했다. 방향을 누른 채 공격하면 의도하지 않은 이동이 생기고, 모션마다 캐릭터 크기가 달라지며, 새 UI가 표시되지 않고, 피격 경직과 연속 공격이 정상 동작하지 않는다. 배경음악·타격음·진동도 정상 적용되지 않았다. 일관된 수정을 요청했다.

기존 무선 기기 검사 목표를 유지하고 위 문제의 수정과 새 APK 재검사를 추가한다. 기존 실패 APK와 실기기 증거는 보존한다. 원본 작업 폴더의 미커밋 코드·승인 자산을 덮어쓰지 않는다. origin/develop 기반 별도 작업 사본에서 수정하고 현재 승인 캐릭터·숲빛 v06 자산을 연결한다. 이미지나 모션 원본을 새로 제작·대체하지 않는다.

- 전투: 일반 공격과 의도된 대시 공격 구분, 공격 중 이동·피격 경직·콤보의 정상 입력 처리 재현과 수정.
- 표현: 모션 간 표시 크기·발 기준 위치 일관성, 기존 승인 모션과 전투 판정 분리.
- UI: 숲빛 v06의 현재 구현된 로비·준비·선택·상점·설정·전투·결과에 실제 실행 연결. 미래 Story 보상·경제·정식 온라인 기능은 추가하지 않는다.
- 오디오·진동: 승인된 기존 음악·효과음과 의미 이벤트 연결, 설정·Android 중단 복귀 확인.
- 기존 발견된 Solo/Team 종료·실제 Wi-Fi 재접속 문제는 실패 증거를 유지하고 수정 필요성을 함께 점검한다.
