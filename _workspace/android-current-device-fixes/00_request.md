# 실기기에서 발견한 현재 게임 문제 수정

사용자가 S23 Ultra와 Tab S5e에서 자현 연습을 직접 확인하고 두 기기 모두 같은 문제라고 답했다. 방향을 누른 채 공격하면 의도하지 않은 이동이 생기고, 모션마다 캐릭터 크기가 달라지며, 새 UI가 표시되지 않고, 피격 경직과 연속 공격이 정상 동작하지 않는다. 배경음악·타격음·진동도 정상 적용되지 않았다. 일관된 수정을 요청했다.

기존 무선 기기 검사 목표를 유지하고 위 문제의 수정과 새 APK 재검사를 추가한다. 기존 실패 APK와 실기기 증거는 보존한다. 원본 작업 폴더의 미커밋 코드·승인 자산을 덮어쓰지 않는다. origin/develop 기반 별도 작업 사본에서 수정하고 현재 승인 캐릭터·숲빛 v06 자산을 연결한다. 이미지나 모션 원본을 새로 제작·대체하지 않는다.

- 전투: 일반 공격과 의도된 대시 공격 구분, 공격 중 이동·피격 경직·콤보의 정상 입력 처리 재현과 수정.
- 표현: 모션 간 표시 크기·발 기준 위치 일관성, 기존 승인 모션과 전투 판정 분리.
- UI: 숲빛 v06의 현재 구현된 로비·준비·선택·상점·설정·전투·결과에 실제 실행 연결. 미래 Story 보상·경제·정식 온라인 기능은 추가하지 않는다.
- 오디오·진동: 승인된 기존 음악·효과음과 의미 이벤트 연결, 설정·Android 중단 복귀 확인.
- 기존 발견된 Solo/Team 종료·실제 Wi-Fi 재접속 문제는 실패 증거를 유지하고 수정 필요성을 함께 점검한다.

기기 사용자 응답·앱/서버 증거: 도구 작업 사본의 build/android-current-device-test/manual/77e501cdb8af46cfbccc93d4af314fc6 및 8325e1e2b5be4adcb4d46c3f93f415f9. 기기별 원래 저장 전후 unchanged true다. 자동 ADB 두 포인터 통과와 실제 사람이 느끼는 조작·소리·진동 실패를 혼동하지 않는다.

## 중단 후 재개와 기기 역할 변경

사용자가 목표를 갱신했다. 토큰 부족으로 중단되면 마지막 확인된 실행과 증거를 확인하고 중단된 부분부터 재개한다. S23을 주 검사 기기로 사용하며 Tab S5e는 네트워크 대전 때만 사용한다. 앞으로 오프라인 기능·10분 반복·사람의 조작/모션/소리/진동 재검사는 S23에서 수행하고, LAN 흐름·두 APK 결과·앱 연결 장애·실제 Wi-Fi 단절은 S23과 Tab을 한 쌍으로 확인한다. 이미 저장된 Tab 오프라인 결과는 삭제하거나 통과로 바꾸지 않는다.

새 APK 첫 실행 b49ce3fd6dfc40528deeeae426611207 종료 뒤 사용자가 “검사 도중 직접 조작함”이라고 확인했다. 일시정지와 foreground 손실이 관측된 실패 기록은 보존하며 조작이 섞인 시도로 표시한다. 사람이 조작한 정확한 시점과 각 오류의 직접 원인은 확정하지 않는다. S23 반복 대전은 새 실행 d6002041832f4ba6a2f37babd9907609에서 재검사한다.
