# 표현 연결의 공용 약속

기존 CombatIntent, AttackData, 고정 tick, 전투 결과와 저장 의미를 보존한다. UI·모션·오디오·진동은 전투 데이터를 읽고 표현하며 승패·피해를 계산하지 않는다. 부당한 상태 전이와 입력 처리 오류를 고치는 경우 재현 입력·기대 상태를 먼저 기록한다.

새 숲빛 UI 자산의 논리 ID는 `fa.ui.forestlight.*` 아래에 등록한다. 실제 승인 v06 파일을 복사하고 원본 해시·출처를 보존한다. UI 텍스트는 네이티브 글자로 만들며 큰 정지 화면 이미지에 클릭 영역만 덧붙이는 방식은 사용하지 않는다. 런타임은 ForestArenaResources로 읽는다. high/medium/low 기존 품질 형식을 유지한다.

캐릭터 크기 수정은 승인된 PNG/SpriteFrames/manifest의 예술적 내용을 변경하지 않는 표현 코드 조정을 우선한다. 표시 기준과 발 위치를 판정 충돌체·공격 데이터와 분리한다. 개별 자세의 자연스러운 압축·펼침과 움직이는 무기를 전투 크기 변경으로 해석하지 않는다.

오디오는 기존 ForestArenaAudio·CombatAudio와 의미 이벤트를 재사용한다. 실제 Android 장치 설정·지원 여부가 다르면 근거를 기록하고 소리·진동 체감을 자동 단위 검사로 대체하지 않는다.

캐릭터 표시 보정은 별도 schema_version 1 데이터에서 캐릭터·모션별 고정 배율과 발 기준을 정의한다. 적용 대상 승인 파일 해시 또는 manifest의 해당 해시와 연결한다. 무기·꼬리·귀를 포함한 전체 불투명 영역만으로 자동 축소하거나 매 프레임 크기를 바꾸지 않는다. 기존 자산 버전에는 잘못된 보정을 적용하지 않는다.

숲빛 전투 조작은 기본 고정 조이스틱을 네 방향 CombatIntent로 전달한다. 이동 손가락은 해제까지 유지하고 두 번째 이동 손가락이 소유권을 빼앗지 않는다. 행동 버튼도 손가락이 영역을 벗어날 때 다른 행동으로 바뀌지 않으며 해제·취소·포커스 손실 때 비운다. 아날로그 속도·자유 위치 편집·미확정 플로팅 설정은 추가하지 않는다. 기존 Phase 1 검사용 입력 배치는 별도로 보존한다.

ADR-028의 기존 LAN protocol_version 2에서 `error/resume_pending`은 API 인증된 같은 참가자·유효한 재접속 토큰이 이미 연결 중인 자기 슬롯에 다른 소켓으로 복귀를 요청했을 때만 보낸다. 서버는 슬롯과 기존 연결을 유지한다. 재접속 중인 클라이언트는 입력을 해제하고 1초 뒤 같은 참가자로 다시 시도하며 기존 60초 제한을 늘리지 않는다. 잘못된 토큰·다른 참가자·기한 만료는 기존 `resume_rejected` 또는 재접속 시간 초과로 끝난다. 일반 참가 오류를 재시도로 감추지 않고 새 게스트·새 슬롯을 만들지 않는다. 이는 기존 승인 LAN 범위의 복구이며 정식 인터넷 온라인 기능은 추가하지 않는다.
