# 피드백 반영 제작

## 음악

로비는 96 BPM, G major, 30초다. 피아노 주선율과 왼손 분산 반주를 독립 악기별 오디오로 구성했다. 첫 마디부터 피아노 선율을 들려주고 6·8마디에 낮은 옥타브를 덧댔다. 피아노 주선율 gain 1.05, 왼손 0.64, 현악 0.28, 하프 0.19, 플루트 응답 0.20으로 배치해 기존 목관 중심 편곡을 바꿨다. 이는 음량 보정 전 파트별 배율이며 최종 비교는 비슷한 청감 음량으로 맞춘다.

전투는 128 BPM, A minor, 30초다. 장조로 밝아지던 중간 구간 대신 단조·Bdim·E7의 긴장을 사용한다. 호른의 짧은 동기, 트레몰로 현악, 첼로 8분 반복과 저음 피아노, 무거운 북·스네어·마지막 박 세분화를 추가했다. 템포와 길이는 유지하면서 화성과 연주 방식으로 긴장감을 높였다.

FluidR3 GM/FluidSynth, 9파트, MIDI, 악보 JSON, 공간 반사 설정과 MIT 출처는 유지한다. 게임용 전체 반복곡이 아닌 30초 시안이다.

## 효과음·비교

클릭 ‘딸각’과 강타 ‘퍽’의 구성은 02_audio_sfx.md에 기록한다. 나머지 대표 효과음 4개는 비트 단위로 유지한다. 시안 비교 A는 최초 v01, B는 r02이며 HTML에 명시했다. r01은 Git 7df5310으로 보존한다. 청감 음량과 최대 순간 음량을 수치로 비교하며, 사람의 청취 승인을 대신하지 않는다.

## 연결

게임 실행 코드·논리 ID·오디오 버스·중단 복귀·LAN 정책은 변경하지 않았다. 시안 방향 확정 후 전체 47개 제작과 게임 연결을 이어간다. Android 검증은 후속이다.
