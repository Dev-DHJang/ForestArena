# 효과음 시안 r02 — 버튼 딸각·타격 퍽

## 요청과 변경

- 사용자의 청취 피드백에 따라 버튼은 기계 스위치의 **딸각**, 강한 타격은 짧고 묵직한 **퍽**을 목표로 다시 합성했다. 이 표현에 맞게 들리는지는 사용자 청취로 확인해야 한다.
- `tools/forest_arena/audio_v02_sfx.py`의 `ui_click`, `hit_heavy`와 두 설명만 변경했다. 외부 녹음·샘플·목소리는 쓰지 않았다. 난수 시작값과 이름별 생성 방식은 유지했다.
- 버튼은 첫 밝은 접촉과 24ms 뒤 낮은 접촉을 서로 다른 잡음 대역으로 표현했다. 각 접촉을 빠르게 줄이고, 이전 목재 음정·종소리 성분은 제거했다.
- 타격은 90Hz·135Hz의 짧은 몸통과 짧은 광대역 접촉(여러 주파수가 섞인 짧은 마찰·충격)을 겹쳤다. 이전 목재 균열 공명과 주파수 상승·하강은 제거했다.
- 둘 다 0.22초, 모노 PCM16 WAV, 44,100Hz를 유지한다. 출력의 크기만 낮추거나 음높이만 바꾼 수정이 아니다.

## 자동 확인

- 임시 디렉터리에서 6개를 두 번 만들고 파일 확인값과 반환 정보가 같은지 확인: 통과.
- 나머지 4개 `jump`, `guard_break`, `myo-ryung_special_up`, `ja-hyun_ultimate`를 변경 전 Git 버전과 비교: 부동소수점 파형 바이트가 모두 같음.
- 6개 형식·길이·첫/끝 샘플 0·무클리핑·무음 아님·직류 편향 절댓값 0.001 미만: 통과.
- 버튼 최대 진폭 0.62, 평균 실효 진폭(RMS) 0.053679, 첫 100ms 내 신호 에너지 99.900%. 타격 최대 진폭 0.76, RMS 0.075417, 첫 100ms 내 신호 에너지 99.748%. 이 수치는 감쇠와 출력 상태의 근거이며 청감 만족도 판정은 아니다.
- 시험 생성은 임시 폴더에만 했다. 자산 파일과 실제 게임의 v01 연결은 이 역할에서 변경하지 않았다.
