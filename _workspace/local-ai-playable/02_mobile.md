# Android 실기기 진행 기록

- 2026-10-01 사용자가 무선 디버깅 연결을 승인하고 세션용 연결 주소를 제공했다. 보안을 위해 IP 주소와 포트는 저장소에 기록하지 않는다.
- ADB 연결 및 `verify`에서 `SM-S918N`(Galaxy S23 Ultra), Android 16을 확인했다. 이 시점은 연결 확인이며 플레이 통과가 아니다.
- 모션 등록 APK 설치 직전에 연결이 사라졌다. 같은 주소 재연결은 `Connection refused`, mDNS 검색은 새 서비스를 찾지 못했다. 무선 디버깅 포트는 세션마다 바뀔 수 있으므로 새 연결 주소를 받아야 한다.
- 실행하지 못한 항목: APK 설치, 실제 터치·빠른 탭, 중단/복귀, 한 판 종료·재대전, 성능 로그. 이 항목은 미확인이다.
- APK 자체는 `build/android/ForestArena-debug.apk`로 다시 생성했고 패키지 계약 검사를 통과했다.
