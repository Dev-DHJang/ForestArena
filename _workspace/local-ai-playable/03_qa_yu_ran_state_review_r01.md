# 유란 추가 상태 r01 시안 QA

## 판정

`attack_heavy_charge`, `death`, `ring_out`, `spawn` 네 시안은 사용자에게 동작·외형
검토용으로 제시할 수 있다. 사용자 채택, 런타임 정규화와 실기기 통과를 뜻하지 않는다.

## 확인 결과

- PNG 네 장은 각각 1254×1254 RGB, 4×4 배열의 16포즈다.
- GIF 네 장은 각각 256×256, 16프레임, 83ms 검토 재생이다.
- PNG·GIF 해시는 `motion-review/yu-ran/state-r01-review.md`와 일치한다.
- 네 시트 모두 승인 외형의 핵심 특징을 유지하며 명백한 추가 꼬리·귀, 동물형 손발,
  신체 잘림이나 이웃 셀 침범은 보이지 않는다.
- 차지 마지막 자세 유지, 사망 후 정지, 링아웃 공중 회전, 복귀 등장 착지·준비 자세가
  서로 구별된다. 표현 프레임은 전투 시간·위치·무적을 소유하지 않는다.
- 불투명 배경, 최종 크기와 발 기준선은 승인 후 정규화 검사 대상으로 남겼다.

## 승인 경계 확인

manifest와 유란 runtime에는 네 상태를 추가하지 않았다. 유란 승인 상태 커버리지는
5/13 그대로이며, 검토 시안만으로 완료 수를 올리지 않았다.
