# 로컬 AI 화면·뒤로가기

## 화면 흐름

- 첫 캐릭터 선택 뒤 로비에서 상점 또는 대전 준비로 이동한다.
- 상점과 대전 준비 화면의 Android 시스템 뒤로가기는 로비로 돌아간다.
- 전투 중 뒤로가기는 입력을 모두 해제하고 일시정지한다. 일시정지 화면에서 다시 뒤로가면 같은 경기를 재개한다.
- 결과 화면의 뒤로가기는 종료된 경기 객체를 정리하고 대전 준비로 돌아간다.
- 로비, 첫 캐릭터 선택, 복구할 수 없는 저장 오류 화면에서만 뒤로가기가 앱 종료 요청으로 이어진다.
- 보유 정보 초기화 확인 화면의 뒤로가기는 저장 오류 안내로 돌아가며 초기화를 실행하지 않는다.

## 경계

- 화면 코드는 전투 HP·stock·승패를 계산하지 않고 `MatchController` 상태를 표시하고 화면 전환만 조율한다.
- 백그라운드 진입은 기존처럼 전투를 일시정지하며, 복귀 후 사용자가 `계속하기`를 선택하기 전에는 진행하지 않는다.
- export 전에 `application/config/quit_on_go_back`을 끄고, 앱 시작 시에도 `SceneTree.quit_on_go_back`을 다시 끈다. `LocalAiApp`이 현재 화면에 따라 Android 뒤로가기를 명시적으로 처리한다.
- Godot 4.7과 target SDK 36 조합에서 한 번의 Android 뒤로가기가 짧은 간격으로 두 번 전달될 수 있으므로 200ms 안의 중복 요청은 한 입력으로 처리한다. 이 시간창은 화면 전환 직후 두 번째 요청이 앱 종료나 즉시 재개를 일으키는 것을 막는다.

## 검사

- `tests/local_ai_app_flow.gd`가 상점→로비, 준비→로비, 전투→일시정지, 일시정지→전투, 결과→준비 전환과 한 입력의 중복 전달 차단을 검사한다.
- Android 실기기에서는 시스템 뒤로가기, 홈 중단·복귀, 터치 입력 해제를 다시 확인한다.
