# 품질 확인 — Android 시스템 뒤로가기 r01

## 재현

- 대상: Galaxy S23 Ultra(`SM-S918N`), Android 16, Godot 4.7.1 debug APK.
- 상점에서 시스템 뒤로가기 키를 한 번 보냈을 때 앱이 로비로 돌아가지 않고 종료됐다.
- 실기기 로그에서 한 키 입력이 `shop`과 전환 직후 `home`에 각각 한 번씩, 6~23ms 간격으로 전달됨을 확인했다.

## 수정

- `application/config/quit_on_go_back=false`를 export 설정에 포함했다.
- 앱 시작 시 `SceneTree.quit_on_go_back=false`를 다시 적용했다.
- 마지막 요청 이후 200ms 안의 뒤로가기 요청은 같은 물리 입력의 중복으로 처리한다.
- 자동 검사에 상점→로비 직후 1ms 뒤 들어온 중복 요청이 로비에서 앱 종료를 실행하지 않는 재현 사례를 추가했다.

## 결과

- 전용 `tests/local_ai_app_flow.gd`: PASS.
- Android debug export 및 APK 계약 검사: PASS.
- 실기기 상점→로비: PASS. 두 요청은 8ms 간격이었고 두 번째 요청은 화면을 바꾸지 않았다.
- 실기기 대전 준비→로비: PASS. 두 요청은 23ms 간격이었다.
- 실기기 전투→일시정지: PASS. 두 요청은 6ms 간격이었다.
- 실기기 일시정지→같은 전투 재개: PASS. 두 요청은 4ms 간격이었다.
- 검사 종료 시 앱 포커스 유지, 치명 오류·ANR·Godot 스크립트 오류 없음.

결과 화면→대전 준비는 동일 화면 전환 함수의 자동 검사로 확인했다. 실제 한 판 종료 후 시스템 뒤로가기를 누르는 실기기 검사는 이번 기록에서 주장하지 않는다.
