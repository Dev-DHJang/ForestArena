# 품질 확인 r04 — 장신구 실제 적중·부활·재대전

## 추가 검사

`tests/local_accessory_play.gd`는 실제 앱의 LocalPlayerStore API로 첫 캐릭터를 지급하고 무료 상품을 구매·선택한 뒤 `start_match()`로 전투를 구성한다. 4캐릭터×6장신구를 각각 확인한다.

- AI 연결과 상대 미장착을 확인한 뒤 효과 수치를 분리 측정하기 위해 봇 명령 생성만 정지한다. 근거리 시작 위치에서 일반 공격 명령과 실제 물리·공격 영역·HitResolver를 사용한다. 효과를 직접 호출하거나 런타임 프로필에 효과를 끼워 넣지 않는다.
- 철갑옷: 무게 증가, 실제 피격 피해, ARMOR 결과, 경직·넉백 방지.
- 복싱 글러브: 이동 속도 증가, 교체된 첫 공격 실행과 연계 링크 개수.
- 가시 갑옷·폭발 장갑·필살 장신구: 실제 적중에 따른 반사 3, 추가 피해 4, 추가 게이지 12.
- 부활: 최종 치명타 이후 1 stock·HP 35, 45 tick 대기, 복귀 HP 35·60 tick 무적, 다음 최종 치명타의 경기 종료.
- 각 조합에서 재대전할 때 HP·3 stock·게이지·부활 사용 상태 초기화.

## 발견한 실제 결함과 수정

1. 부활 직후 HP 35가 설정되어도 45 tick 뒤 `_respawn()`이 최대 HP로 덮어썼다. 다음 복귀의 효과 HP를 별도 런타임 상태에 두고 한 번 적용한 뒤 지우도록 수정했다. 일반 복귀는 최대 HP 규칙을 유지한다.
2. 이전 경기 종료의 지연된 결과 호출이 새 경기까지 일시정지시킬 수 있었다. 종료한 경기 객체와 현재 경기 객체가 일치할 때만 결과를 표시하도록 수정했다. `local_ai_app_flow.gd`에 결과 전달 전에 재대전하는 재현 검사를 추가했다.

장신구 전용 r03 실행 및 앱 흐름 r06 실행은 PASS. 독립 QA 재실행과 일반/효과 복귀 경계 검사는 `03_qa_accessories_independent_r02.md`에 기록했다.

Android debug export r06과 에뮬레이터 앱 흐름 r09는 PASS. 로그는 `/tmp/forest-local-ai-export-r06.log`, `/tmp/forest-local-ai-android-r09.log`. 이동·점프, 백그라운드 복귀 후 수동 재개, 준비 화면·로비 복귀를 확인했다. 버튼은 기존 600ms 누름/해제 검사이며 실기기 빠른 탭 검사가 아니다.

수정 후 전체 `./scripts/verify.sh` r04는 종료 코드 0으로 PASS. 16조합 대전·동일 seed 재현·새 장신구 실제 적용·기존 전투·터치·문서·Godot 리소스 검사를 포함한다. 로그는 `/tmp/forest-local-ai-verify-r04.log`.

## 주장하지 않는 범위

이는 UI 구매 버튼을 터치한 검사나 24조합 AI 완주 검사가 아니다. 복싱 교체 연계를 끝까지 실행한 검사도 아니다. 신규 모션과 실제 Android 기기 플레이·성능은 여전히 미완료다.
