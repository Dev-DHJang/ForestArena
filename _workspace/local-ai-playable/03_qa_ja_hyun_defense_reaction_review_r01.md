# 자현 방어·피격 반응 r01 시안 QA

## 판정

`guard`, `evade`, `hitstun`, `launch` r01은 사용자에게 동작·외형 검토용으로 제시할
수 있다. 사용자 채택, 런타임 정규화와 실기기 통과를 뜻하지 않는다.

## 확인 결과

- PNG 네 장은 각각 1254×1254 RGB, 정확한 4×4 배열의 16포즈다.
- GIF 네 장은 각각 256×256, 16프레임, 83ms 검토 재생이다.
- PNG·GIF 해시는 `motion-review/ja-hyun/defense-reaction-r01-review.md`와 일치한다.
- 네 시트 모두 승인 외형의 작은 화면 핵심 특징인 둥근 귀, 얇은 꼬리, 긴 파란
  리본과 낮은 자세를 유지한다. 명백한 추가 꼬리·귀, 동물형 손발, 신체 잘림이나
  이웃 셀 침범은 보이지 않는다.
- 방어·낮은 회피·서 있는 피격·공중 띄워짐이 서로 다른 실루엣으로 구별된다.
- 표현 프레임은 입력 우선순위, 방어 내구도, 회피 무적, 경직 tick, 속도와 착지를
  소유하지 않는다.
- 불투명 배경, 최종 크기와 발 기준선은 승인 후 정규화 검사 대상으로 남겼다.

## 승인 경계 확인

manifest와 자현 runtime에는 네 상태를 추가하지 않았다. 자현 승인 상태 커버리지는
3/13 그대로이며, 검토 시안만으로 완료 수를 올리지 않았다. 승인되면 원본을 보존한
채 투명화·공통 크기·발 기준선을 적용하고 SpriteFrames를 등록한 뒤 전투 snapshot
비변경과 Android 재생을 별도로 검증한다.
