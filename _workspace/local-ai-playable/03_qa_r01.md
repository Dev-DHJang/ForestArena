# 품질 확인 r01

## 통과한 코드 검사

- 전체 `./scripts/verify.sh`: 통과. 기존 전투·계약 검사와 신규 6개 검사를 포함한다.
- LocalPlayerStore: 첫 지급, 0원 구매, 중복·잘못된 ID·미보유 선택 거부, 재시작 복원, 백업 복구, 쓰기 실패 시 메모리 원상 유지, 4×6 조합 구성.
- LocalAiApp: 네 캐릭터의 16가지 대전 조합, 참가자 ID 분리, 일시정지, 결과 화면, 재대전 초기화, 로비 복귀.
- LocalAIBehavior: 같은 seed의 입력 재현, 회피·궁극기 방향, 중앙 발판 추격, 낭떠러지 복귀. 실제 고정 tick 물리로 2층 도달.
- LocalAISoak: 네 대표 조합을 실제 물리·공격만으로 종료한다. 30초 동안 피해·stock 변화가 없는 정체 및 18,000 tick 시간 초과를 실패로 검사한다.
- LocalFighterPresentation: 승인 자산 로드, 참가자 ID와 캐릭터 ID 분리, 자현·묘령 정확한 약연계, 시각 갱신의 전투 snapshot 비변경.
- LocalTouchControls: 확장 버튼 중심과 빈 영역, 멀티터치·손가락 이탈·중단 입력 해제, 동일 tick 좌향 회피 및 중립 행동의 비방어.
- Android debug export 및 패키지 검사 통과. APK에 캐릭터 manifest와 리소스 registry JSON 포함을 확인했다.

## 발견·수정

- 플랫폼 레이어 8을 캐릭터 충돌 마스크가 처음부터 포함하지 않던 문제를 경기 초기화에서 수정.
- 궁극기 입력이 중립이어야 하는데 AI가 좌우 방향으로 보내 게이지가 찬 뒤 공격을 중단하던 문제 수정.
- 회피가 현재 방향 입력 대신 직전 facing을 사용하던 문제 수정.
- 확장 터치의 빈 영역이 기존 대시 입력으로 처리되던 문제 수정.
- 개발용 훈련 안내와 HUD 겹침 제거, 상점·준비 화면 버튼 크기 조정, 실제 발판 양끝과 낭떠러지 표현 개선.

## 에뮬레이터 확인

Android 15 arm64 에뮬레이터에서 첫 캐릭터 나비 지급, 자현·철갑옷 무료 구매, 보유 표시, 대전 준비와 캐릭터 이미지가 표시되는 실제 대전 진입을 확인했다. 이는 실기기 성능 통과가 아니다. 최종 화면 조정 후 재검사는 후속 기록에 남긴다.

## 미완료

- 전체 신규 전투 모션 제작·사용자 검토·투명 런타임 등록. 현재 나비 약공격 1단 r04 시안까지 제작했고 승인을 기다린다. 나머지 모션은 제작 대기이며 idle 대체 표시를 최종 표현 통과로 보지 않는다.
- 이번 버전의 실제 Android 기기 검사 및 성능 측정. 현재 ADB 실기기 연결 없음.
- 원격 PR·병합은 아직 미완료.

전체 요청 판정은 진행 중이다. 코드 검사의 통과가 위 미완료 항목을 대신하지 않는다.
