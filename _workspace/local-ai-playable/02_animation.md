# 로컬 AI 캐릭터 표현과 모션 제작 목록

## 승인 자산 연결

`local_fighter_presentation.gd`는 `RuntimeCombatProfile.character_id`로 자산 목록의
승인 런타임 SpriteFrames를 찾는다. 경기 참가자 슬롯 ID로 캐릭터 외형을 선택하지 않는다.
기존 인간형 외형 계약을 유지하고, 같은 캐릭터를 양쪽에서 선택해도 각각 표시한다.
우향 원본을 좌우 반전하고 128×128 셀의 발 위치를 전투 몸체 아래쪽에 맞춘다.
공격은 `visual_state_id`의 정확한 연계 단계에 연결한다. 준비·활성·회복 tick을 읽어
재생 위치를 정하며 그림 갱신이 전투 상태·적중·승패를 바꾸지 않는다.

확인 원본은 캐릭터 manifest와 네 기본 MoveSet이다. 철갑옷 등 장신구 규칙은
외형을 자동 변경하지 않는다. 복싱 글러브 교체 MoveSet의 기술도 별도 모션 검토가
필요하다. 승인된 기본 모션 연결만으로 새 전투 모션 제작 완료를 주장하지 않는다.

미제작 공격은 승인 idle을 임시 표시하고 `missing_motion`에 요청 ID를 남긴다.
해당 대체 표시는 전투 모션 승인이 아니며 최종 완료 전 교체해야 한다.
방어·회피 등 상태별 포즈도 현재 승인 idle을 유지한다. run은 이동·대시,
jump는 상승·하강에 한해 재사용한다.

## 다음 모션 검토와 확인 항목

캐릭터별 기존 승인 콘셉트와 외형 계약을 기준으로 누락된 모션을 검토용 경로에
제작한다. 모션별 시트와 재생 미리보기를 사용자에게 제시하고, 명시 승인 후에만
runtime 경로와 manifest에 등록한다. 나비의 흰 꼬리·귀, 묘령의 긴 토끼 귀,
자현의 얇은 꼬리·파란 리본, 유란의 굵은 고리무늬 꼬리를 유지한다.

자동 검사는 네 캐릭터의 승인 자산 16프레임 로드, 슬롯 ID와 외형 ID 분리,
정확한 공격 표현 ID, 좌우 반전과 전투 snapshot 비변경을 확인한다.
잘림·발 위치·작은 화면 가독성·실기기 메모리 및 draw call은 실제 화면 검토와
측정이 필요하며 이 문서 작성만으로 통과 처리하지 않는다.
