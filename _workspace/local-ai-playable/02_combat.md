# 로컬 AI와 경기장 구현

- `LocalAICommandSource`는 한 tick 시작 시점의 공개 snapshot을 읽고 `CombatIntent`만 반환한다. 파이터의 HP·속도·쿨다운·위치를 직접 바꾸지 않는다.
- 기본 반응 간격은 12 tick이며 생성 시 설정할 수 있다. 같은 seed·snapshot·tick은 같은 명령열을 만든다. 경기 초기화 때 난수와 입력 상태도 초기화한다.
- 거리가 멀면 접근하며 가까이서는 약·강 차지·특수·궁극기를 선택한다. 상대 공격에는 아래 방어 또는 방향 회피를 선택하며 성공 여부는 기존 전투 코드가 판단한다.
- 발판 위의 상대는 지상 점프 후 정점 부근의 공중 점프로 추격한다. 위에서 아래로 추격할 때는 아래+점프로 발판 통과를 요청한다. 낭떠러지 근처에서는 안쪽 이동, 남은 공중 점프, 사용 가능한 위 특수 순서로 복귀를 시도한다.
- 아래 방어에서 벗어날 때 해제 명령을 먼저 보낸다. 강 차지 해제 tick에는 다른 공격 명령을 넣지 않아 입력 선택 과정에서 해제가 사라지지 않게 한다.
- `MatchController.bot_source`가 없으면 기존 입력 처리 흐름을 유지한다. 연결된 경우 같은 입력 처리·전투 계산 경로를 쓴다.
- 1층은 폭 1,080, 2층은 폭 540이며 중심 x=640을 공유한다. 충돌체 중심의 높이 차이는 180이고 표면 차이는 두께 차이를 반영해 168이다. 배경 위 지형 표시도 실제 충돌체 크기와 일치한다.

## 자동 확인

`tests/local_ai_behavior.gd`: 반응 간격, snapshot 비변경, 대상 ID, 동일 seed 명령 재현, 접근·복귀·쿨다운·발판 추격/통과 명령, 강공격 해제, 발판 크기/중앙/통과 속성, 실제 파이터 이동과 2층 도달을 확인한다.

`tests/local_ai_soak.gd`: 실제 경기장·충돌·3 stock 규칙으로 두 AI가 네 캐릭터 조합을 끝까지 플레이한다. 기본 위치·2층·양끝 출발을 포함하며, 30초 동안 HP/stock 변화가 없거나 5분 안에 끝나지 않으면 실패한다. 검사 가속 때 물리 실행 빈도와 시간 배율을 함께 올려 이동 계산의 1/60초 간격을 유지한다. 최초 검사에서 궁극기 방향을 좌우로 보내 게이지 100 이후 공격이 멈추는 결함을 찾았고, 데이터에 맞는 중립 방향 명령으로 수정했다.
