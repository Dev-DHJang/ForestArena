# 품질 확인 r02 — Android 앱 흐름

## 환경과 결과

- 확인일: 2026-09-26. Android 15 / API 35 arm64 에뮬레이터.
- `./scripts/export-debug-android.sh`: debug APK 생성 통과.
- `./scripts/verify-android-emulator.sh`: 로컬 AI 시작 장면을 감지해 전용 검사 실행, 통과.
- 재현 경로: APK 설치 → 보유 상태 유지한 앱 시작 → 대전 준비 → 대전 시작 → 이동·점프 터치 → 홈으로 전환 → 앱 복귀 → 계속하기 → 일시정지 → 준비 화면 → 로비.
- 자동 검사는 실제 화면의 버튼 위치 로그를 읽어 Android 터치를 보낸다. 보유 파일을 지우거나 경기 상태를 강제로 변경하지 않는다.
- 최초 실행 로그: `/tmp/forest-local-ai-android-r05.log`. 궁극기 수정 후 APK 재생성 및 최종 실행 로그: `/tmp/forest-local-ai-android-r08.log`. 마지막 결과: `Android local AI: launch, owned selection, match, touch, pause/resume and return PASS.`

## 수정 후 재확인

- 독립 QA에서 발견한 방향 유지 중 궁극기 무시 문제를 수정했다. 네 방향+궁극기 발동, 부족한 게이지 유지, 아래+점프 우선순위를 재검증했다. 세부 증거는 `03_qa_independent_r02.md`.
- 일시정지·결과 화면에서 전투 HUD와 터치를 숨겨 화면 겹침을 없앴다.
- 앱 복귀 때 일시정지 메뉴의 레이아웃을 다시 만들고, 사용자가 계속하기를 누르기 전에는 경기를 재개하지 않는다.
- 디버그 빌드에만 버튼 위치 및 300프레임 성능 표본 로그를 추가했다. 표본 수집은 전투 상태를 바꾸지 않는다.
- 중간 r06/r07에서는 복귀 후 계속하기 자동 탭이 반영되지 않아 실패했다. 실제 화면은 일시정지를 유지했고 후속 수동 입력은 정상 작동했다. 최종 r08에서는 버튼을 600ms 누르고 떼도록 검사 코드를 바꾸어 통과했다. 병렬 장시간 검사도 종료된 상태였다. 이 결과만으로 짧은 탭 누락의 단일 원인을 확정하지 않으며 실기기 빠른 탭 검사를 남긴다.

## 통과로 볼 수 없는 항목

- 이 자동 경로는 신규 설치의 첫 지급·구매나 한 판 전체 승패를 Android 터치로 끝내는 검사를 대신하지 않는다. 첫 지급·구매는 r01 수동 확인과 별도 저장 테스트에서 확인했다.
- 신규 모션 제작·모션별 승인·런타임 등록은 진행 중이다. 임시 idle 표시는 최종 모션 통과가 아니다.
- 실기기는 연결되지 않았으므로 실제 터치·중단/복귀·성능은 미확인이다. 에뮬레이터 성능을 실기기 성능으로 보고하지 않는다.
- 전체 요청은 미완료이며 공식 Phase 6 완료로 처리하지 않는다.
