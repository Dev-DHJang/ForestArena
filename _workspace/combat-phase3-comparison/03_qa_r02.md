# 품질 확인 r02

최신 `develop` 병합본에서 Android 배포 가능 여부를 다시 확인했다.

- `./scripts/export-debug-android.sh`: 통과. `build/android/ForestArena-debug.apk` 생성.
- `./scripts/verify-android-package.sh`: 통과.
- `./scripts/verify-android-emulator.sh`: 연결된 Android 에뮬레이터가 없어 런타임 회귀를 실행하지 못함.

패키지 생성 통과는 에뮬레이터 또는 실제 기기의 터치·성능·중단/복귀 통과가 아니다.
