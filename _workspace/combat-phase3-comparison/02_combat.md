# 전투 비교 설계

`tests/phase3_style_comparison.gd`는 기본 LoadoutCatalog에서 직업·장신구를 넣지 않은 런타임 전투 프로필을 만든다. 따라서 원본 Resource를 경기 중 값으로 바꾸지 않는 기존 계약과 같은 경계를 사용한다.

| 비교 대상 | 같은 조건 | 자동 확인 결과 |
| --- | --- | --- |
| 버티기와 이동 | 기본 캐릭터, 보정 없는 프로필 | 자현 1.05 > 유란 1.00 > 나비 0.92 > 묘령 0.85 무게; 이동·공중 속도는 묘령 > 나비 > 유란 > 자현 |
| HP | 기본 캐릭터, 보정 없는 프로필 | 자현 105, 묘령 95, 나비·유란 100 |
| 약연계 | 기본 MoveSet | 자현 3단, 묘령 4단, 나비 2단, 유란 3단 |
| 중립 특수기 | 기본 MoveSet | 자현 끌어오기, 묘령 3회 다단, 나비 단일 근접 적중, 유란 96×64 공간 장악 영역 |
| 공통 확장 | 기본 MoveSet | 네 캐릭터 모두 궁극기 슬롯 보유, 잡기 슬롯 없음 |

이 비교는 고정 데이터와 빌드 결과의 차이가 사라지는 회귀를 막는다. 플레이 감각, 애니메이션 가독성, 실제 터치와 성능은 별도 수동·기기 검사 항목이다.
