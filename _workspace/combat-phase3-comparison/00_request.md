# 요청

## 목표

전투 개선 뒤에도 네 캐릭터의 서로 다른 전투 스타일을 같은 데이터 조건에서 비교하고, 결과를 재현 가능한 검사와 기록으로 남긴다.

## 범위와 결정

- 승인된 HP·stock·고정 넉백 규칙을 기준으로 한다.
- 잡기 기술과 `GRAB` 공격 태그는 제공하지 않는다.
- 자동 검사는 데이터·런타임 프로필 차이를 확인한다. 실제 사람의 조작 감각과 Android 기기 실행은 이 기록만으로 통과 처리하지 않는다.

## 완료 판단

- 네 기본 캐릭터가 같은 카탈로그에서 빌드된다.
- 이동·무게·HP·약연계 길이·중립 특수기의 차이를 자동으로 확인한다.
- 비교 결과와 아직 확인하지 못한 직접 플레이 항목을 기록한다.
