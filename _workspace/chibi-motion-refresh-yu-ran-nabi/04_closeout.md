# 유란·나비 치비 모션 이미지 재생성 작업 기록

상태: 완료 — 나비 29종·유란 30종 치비 모션 승인, 정규화, 런타임 등록과 검증 완료

## 완료 내용

- 사용자 승인 문구: 2026-10-07 “나비·유란 59종 전체 승인”.
- 나비 29종과 유란 30종을 128×128 셀 16개, 2048×128 RGBA 한 줄 시트로 정규화했다.
- 승인된 59종을 기존 런타임 경로에 교체하고 manifest의 해시·생성 기록·발 기준점을 갱신했다.
- 기존 논리 ID와 `SpriteFrames` 파일은 유지했다. 설치 전후 `.tres` SHA-256이 모두 같다.
- 공격 데이터와 피해·넉백·판정 수치는 변경하지 않았다.
- 검토 시안·GIF·정규화 접촉판·보고서·설치 전후 해시는 이 작업 폴더에 남겼다.
