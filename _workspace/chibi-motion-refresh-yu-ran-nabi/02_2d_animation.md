# 유란·나비 치비 모션 시안 제작 기록

## 생성 방식

- 내장 이미지 생성 도구를 사용해 모션마다 별도 호출했다.
- 각 호출에서 대상 캐릭터 콘셉트는 정체성 참조로, 같은 상태의 자현·묘령 런타임 시트는 스타일·동작 참조로만 사용했다.
- 모든 결과는 우향 전신 4×4·16포즈와 실제 RGBA alpha를 요청했다.
- 일반 성인 비율 대신 머리 1·몸 2에 가까운 3등신, 짧은 팔다리와 큰 운동화를 고정했다.
- 이미지 생성 결과는 반환된 출력 경로와 모션 이름을 직접 매핑해 `01_drafts/<character>/<group>/`에 복사했다. 파일 시간순 추정은 사용하지 않았다.

## 생성 범위

- 나비 29종: 기본 3, 지상 공격 10, 공중·특수 7, 상태 9.
- 유란 30종: 기본 3, 지상 공격 11, 공중·특수 7, 상태 9.
- 나비는 약공격 2단, 유란은 약공격 3단을 유지한다.
- 공격 연기만 새로 만들었으며 `AttackData`, 공격 시간, 피해·넉백·판정은 변경하지 않았다.

## 검토 자료

- 캐릭터별 `base`, `ground`, `air_special`, `state` 개요판을 `01_drafts/`에 만들었다.
- `01_drafts/<character>/review_gif/`에 59개 비런타임 재생 GIF를 만들었다. 각 GIF는 16프레임이며 idle 8 FPS, guard·hitstun 24 FPS, evade 80 FPS, 나머지 12 FPS의 검토 속도를 사용한다.
- 59개 원본 시안의 SHA-256은 `01_drafts/sha256-r01.txt`에 기록했다.
- 낮은 alpha의 숨은 배경 RGB는 런타임 자산이 아니다. 승인 후 정규화 때 `alpha < 8` 픽셀만 제거하고 캐릭터 가장자리는 보존한다.
- 사용자는 2026-10-07에 나비·유란 59종 전체를 명시 승인했다.

## 정규화·등록

- `tools/forest_arena/normalize_chibi_motion_refresh.py`로 각 4×4 시안을 16프레임으로 분리하고, 낮은 alpha와 칸 경계의 잔여 조각을 제거했다.
- 캐릭터별 공통 크기를 적용한 뒤 각 프레임을 128×128 셀의 발 기준점 `(64,124)`에 정렬해 2048×128 RGBA 한 줄 시트로 만들었다.
- 승인된 나비 29종과 유란 30종만 기존 논리 ID의 런타임 PNG에 설치했다.
- 기존 `SpriteFrames` 경로와 파일은 그대로 유지했다. 설치 전후 SHA-256 비교로 `.tres`가 바뀌지 않았음을 확인했다.
- manifest의 59개 항목에 새 파일 SHA-256, `chibi-r01` 생성 기록, 승인 날짜와 발 기준점을 기록했다.
- 정규화 보고서는 `02_normalized/report.json`, 런타임 설치 전후 해시는 `preinstall-*.txt`와 `postinstall-*.txt`에 남겼다.
