# 유란·나비 치비 모션 이미지 재생성 요청

- 요청일: 2026-10-07
- 대상: 사용자가 확정한 `yu-ran` 30종, `nabi` 29종의 등록된 고유 모션 이미지 전체
- 두 캐릭터의 등록된 콘셉트 이미지를 정체성 기준으로 사용하고, 완료된 자현·묘령 런타임 시트를 3등신 비율·채색·실루엣·동작 간격의 스타일 기준으로 사용한다.
- 모든 모션은 2.5~3등신 치비 비율, 우향, 전신, 투명 RGBA, 4×4의 16포즈 검토 시안으로 새로 만든다.
- 얼굴·의상·귀·꼬리·핵심 장식은 외형 계약과 일치해야 한다.
- 기존 런타임 이미지와 manifest는 새 시안의 모션별 사용자 승인 전까지 변경하지 않는다.
- 승인된 시안만 128×128 셀의 2048×128 한 줄 시트와 `SpriteFrames`로 정규화한다.
- 전투 수치, 판정, 기본 편성, 선택 UI는 변경하지 않는다.

## 검토 묶음

1. 기본: `idle`, `run`, `jump`
2. 지상 공격: 약공격 연계, 방향 약·강, 대시 약·강
3. 공중·특수 공격: 공중 약·강, 특수기 4종, 궁극기
4. 상태: `guard`, `evade`, `hitstun`, `launch`, `knock_down`, `wake_up`, `death`, `spawn`, `ring_out`
