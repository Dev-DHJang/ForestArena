# Android 산출물 점검 기록

## 대상 확인

아래 파일은 모두 Git 미추적 파일이며 Android 빌드가 만든 산출물이다.

| 경로 | 종류 | 크기 |
| --- | --- | ---: |
| `android/build/libs/release/godot-lib.template_release.aar` | release AAR | 103,241,219 bytes |
| `android/build/libs/debug/godot-lib.template_debug.aar` | debug AAR | 112,725,277 bytes |
| `build/android/ForestArena-debug.apk` | debug APK | 279,715,747 bytes |

`.so` 파일은 작업 트리에서 발견되지 않았다.

## 기기 검증

이번 작업은 로컬 생성 파일 정리만 수행한다. Android 기기 설치·실행 검증은 수행하지 않는다.
