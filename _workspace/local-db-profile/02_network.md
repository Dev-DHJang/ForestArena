# API·DB 저장 처리

요청은 8초 제한으로 실행하며 접근 토큰 만료 시 한 번 갱신 후 재요청한다. 인증 실패 때 새 계정을 자동 생성하지 않는다. 세션 파일은 기존 온라인 개발 세션과 분리하고 API 주소와 연결한다.

변경 전 요청 ID와 본문을 기기에 기록하고 DB는 행 잠금·트랜잭션과 요청 기록으로 같은 변경을 한 번만 처리한다. 응답 유실 시 동일 요청을 재전송하고 최신 프로필을 다시 읽는다. 다른 실행이 먼저 저장하면 변경 번호 충돌을 알리고 최신 값을 읽는다.

refresh 갱신은 클라이언트가 새 토큰을 먼저 만들어 이전·새 토큰을 기기에 기록한다. 서버는 기존 토큰에 정확한 다음 토큰의 hash만 연결하고 같은 두 토큰을 제시한 재시도만 허용한다. 응답 유실 또는 최종 파일 저장 실패 후에도 기록된 갱신을 재시도해 같은 게스트를 복구한다. 기존 온라인 클라이언트의 토큰 갱신 방식도 유지한다.

프로필 이전은 기록이 없을 때만 수행한다. 읽기 전용 이전은 v1을 메모리에서 v2로 바꾸며 기기 원본을 쓰지 않는다. 서버 카탈로그는 실제 Godot 목록에서 생성·검사한다.

실제 기동에서 기존 게임 서버 이미지가 누락한 pushbox_resolver.gd·stage_controller.gd를 Docker 전송 목록에 추가했다. DB 볼륨과 비밀번호는 기존 값을 유지한다.
