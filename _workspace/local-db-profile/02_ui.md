# 게임 저장 화면 연결

첫 선택과 로비에서 저장 모드를 열 수 있다. 기기 저장은 기존 LocalPlayerStore를 유지하고 DB 모드는 별도 DbProfileClient로 연결한다. 기존 논리 자산 ID와 네이티브 텍스트를 재사용하며 이미지·전투 판정은 변경하지 않는다.

요청 중에는 전체 화면 상태 표시와 터치 차단, 키보드 초점 해제, 뒤로 가기 차단으로 중복 조작을 막는다. 첫 지급·상점·선택·접근성 변경은 API 저장 성공 뒤 반영한다. 실패하면 기존 데이터와 요청 ID를 유지하며 재시도를 제공한다.

DB 모드는 다음 실행에 복원한다. 기기 모드를 선택하면 기존 파일로 돌아가며 DB 실패로 자동 전환하지 않는다. 인증 실패 때 새 게스트는 별도 안내 후 사용자가 선택한다. 동시 최초 지급 충돌 후에는 최신 지급 상태에 맞춰 로비로 이동한다.

tests/db_profile_runtime.gd는 실제 앱 버튼으로 이전·구매·선택·대전 진입을 실행하고 별도 프로세스에서 DB 모드·보유·선택·접근성 복원을 확인한다. Android 실기기 검증은 이번 범위에서 수행하지 않는다.
