# r03 시안 마무리

사용자가 적절하다고 확인한 전투 긴장감과 강한 타격 ‘퍽’을 유지했다. 약한 타격 ‘파악’을 추가하고 가드 파괴를 금속성 ‘채앵’으로 다시 합성했다. 로비 피아노의 선율·화성·왼손 반주 형태를 바꾸고 두 음악을 도입·주제·대조·변형 재현이 있는 60초로 새로 구성했다. 기존 30초를 복제하지 않았다.

## 산출물

- 음악 2개·대표 효과음 7개, 비교 A 최초 v01 / B 최신 r03.
- 각각 9개 악기별 62초 원본, 60초 믹스, 실제 MIDI·악보 JSON·구간 경계·제작기·출처·확인값.
- 비교 화면에 15초 단위 구간 안내, 새 약한 타격과 가드 파괴 설명, r03 의견 항목을 제공했다. 음원 요청에 revision=3을 붙여 이전 시안 캐시와 구분한다.
- 강한 타격·버튼·점프·묘령 위 특수기·자현 필살기 5개는 기존 원본과 비교 A/B 바이트를 유지했다.

## 검증

- `./scripts/verify.sh`: 시스템 접근을 허용한 재실행 종료 코드 0, 전체 PASS. 첫 샌드박스 실행은 Godot editor 설정·user 로그 저장 접근 오류 뒤 중단됐으며 PASS로 기록하지 않는다. 같은 검사 재실행에서 해결됐다. 일부 기존 Godot 테스트의 종료 자원 경고는 남아 있어 전체 무경고로 표현하지 않는다.
- 독립 음원 검사: 9쌍의 파일·실제 음량·최대 순간 크기, 60/62초 형식, 악보와 실제 MIDI의 음표·채널·프로그램·pan, 구간별 밀도·반주 변화, 동일 절반 복제 방지, 5개 효과음 보존과 기존 실행 코드/v01 보존 PASS. 독립 QA 기록은 03_qa_r01.md다.
- 별도 경로 전체 재생성: 51개 파일과 manifest의 실제 바이트가 모두 동일하며 독립 QA도 다시 비교했다.
- `r03-browser-playback`: 로비 B→A 위치 유지, 전투 B 재생, 약한 타격 B(0.22초)·가드 파괴 B(0.65초) 재생을 확인했다. 두 음악 모두 60초, 탐색 가능 상태와 단독 재생을 확인했다. 청취 품질을 판정하지 않았다.
- `verify_audio_v02_preview.py --baseline-ref 60777dd --feedback-baseline-ref 60777dd`: HTTP GET/HEAD/Range/416·외부 경로 차단 포함 종료 코드 0, PASS. `./scripts/verify-docs.sh`와 `git diff --check`도 PASS.

가드 파괴의 A 비교 파일은 같은 최초 v01 원본에 새 B와 공통으로 맞춘 음량 배율을 적용하므로 이전 비교 파일과 바이트가 다르다. 자동 검사에서 원본과 배율만 다른 신호인지 확인했다. QA가 추가한 A 바이트 동일 조건은 이 보정 규칙과 맞지 않아 제거했다. 음원 제작 결함으로 기록하지 않는다.

사람이 느끼는 반복감·파악/채앵 질감·참고곡 수준의 완성도, 게임용 전체 길이 반복 경계, 8인전 믹스와 실제 Android 청취는 미확인이다. 사용자 의견의 전투 긴장감 부분 확인을 전체 승인으로 바꾸지 않았다. 게임 연결은 기존 v01을 유지하며 방향 확정 후 전체 제작·교체를 이어간다.
