# 효과음 시안 r03 — 약한 타격 파악·가드 파괴 채앵

## 요청과 구현

- 사용자의 r03 피드백에 따라 약한 타격 `hit_light`를 추가하고 가드 파괴 `guard_break`를 다시 합성했다. 기존 강한 타격의 **퍽** 합성은 그대로 유지했다.
- 약한 타격은 강타보다 밝고 넓은 잡음 공기층에 빠르게 줄어드는 표면 접촉과 작은 150Hz 몸통을 더해 **파악**을 목표로 했다. 목재·금속 공명과 음정 진행은 넣지 않았다.
- 기존 v01 원본을 실제 WAV 헤더로 확인한 결과 약한 타격 길이는 **0.22초 / 9,702샘플**이었다. 새 시안도 이 길이를 유지해 기존 비교 화면과 맞춘다.
- 가드 파괴는 목재 붕괴를 제거하고 날카로운 첫 접촉, 965Hz의 1·1.414·1.932·2.631·3.791배에 해당하는 불규칙한 금속 공명, 각 공명의 0.23% 차이가 만드는 작은 떨림으로 **채앵**을 목표로 했다. 공명은 동시에 시작하며 높은 성분이 더 빨리 줄어든다. 순차 상승 멜로디나 발랄한 세 음 종소리는 넣지 않았다. 길이는 0.65초를 유지했다.
- 둘 다 직접 작성한 합성 코드만 사용했다. 외부 샘플·녹음·목소리는 없다. 난수 시작값은 바꾸지 않았다.

## 자동 확인

- 수정 직전 소스를 임시 파일로 보존해 비교했다. `ui_click`, `jump`, `hit_heavy`, `myo-ryung_special_up`, `ja-hyun_ultimate`의 파형 바이트가 모두 동일했다.
- 7개 시안을 임시 폴더에서 두 번 생성해 반환 정보와 파일 확인값이 동일한지 확인: 통과.
- 7개 모노·PCM16·44,100Hz·정해진 길이·첫/끝 샘플 0·무클리핑·무음 아님·직류 편향 절댓값 0.001 미만 확인: 통과.
- 약한 타격: 최대 진폭 0.76, 평균 실효 진폭(RMS) 0.060684, 직류 편향 -0.0000126. SHA-256 `dd44dcb9992a255dca170efc347024190acf52fcfb423a90255bc16a6113c842`.
- 가드 파괴: 최대 진폭 0.76, RMS 0.064760, 직류 편향 -0.0000319. SHA-256 `69db1a619ecce0c23c46d60fb358b39316a242598f8108de8767cc32a254e7c8`.

## 인수인계

- `tools/forest_arena/audio_v02_sfx.py`의 `generate(output_dir)`가 7개를 반환한다. 각 항목은 기존과 같은 `name`, `duration`, `notes` 등을 사용한다. 전체 생성 역할이 새 `hit_light` 항목을 비교 목록에도 반영한다.
- 이 역할은 코드와 본 기록만 변경했다. 자산 생성 시험은 임시 폴더에서만 했고, 실제 시안 자산과 게임의 v01 연결은 변경하지 않았다.
- 수치 확인은 출력 형식과 재현성에 대한 근거다. **파악/채앵**의 실제 청감 승인과 Android 실기기 결과는 사용자 확인 전까지 미확인이다.
