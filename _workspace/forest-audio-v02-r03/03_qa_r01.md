## 자동 확인 증거

- **QA 직접 실행:** `python3 tools/forest_arena/verify_audio_v02_preview.py --skip-http --baseline-ref 60777dd --feedback-baseline-ref 60777dd` 종료 0, `/private/tmp/audio-v02-r03-independent-qa.log` PASS. QA 환경의 소켓 권한 제한 때문에 이 실행은 HTTP를 명시적으로 제외했다.
- **HTTP 포함 최종 검사:** 조율 담당 실행 `/private/tmp/audio-v02-r03-final-verify.log`의 실제 GET/HEAD/Range/416·디렉터리/외부 경로 차단 PASS와 마지막 음원 PASS, 종료 0 보고를 확인했다.
- **브라우저 동작:** 조율 담당은 실제 r03 화면에서 음악 두 곡 60초·탐색 가능, 로비 B→A 위치 유지·단독 재생, 약타 0.22초·가드 0.65초 재생 오류 없음으로 확인했다. 이 결과는 재생 동작 검사이며 청취 품질 승인으로 쓰지 않는다.
- **전체 기본 검사:** `/private/tmp/audio-v02-r03-full-verify-retry.log`의 `Forest Arena verification passed.`와 종료 0 보고 확인. 첫 기본 권한 실행은 Godot 로그/사용자 경로 접근 제한과 signal 11로 실패했으며, 허용된 환경의 같은 검사 재실행 결과와 구분한다. 재실행에도 다른 기존 테스트의 종료 자원 진단이 있으므로 전체 무경고로 표현하지 않는다.
- **문서 검사:** QA 직접 `./scripts/verify-docs.sh` 종료 0 및 검사기 `git diff --check` 통과.
- **파일·신호:** manifest 51개 파일의 실제 SHA256·크기·메타데이터, 생성기 확인값, 44100Hz PCM16, 음악 스테레오·효과음 모노, 60초 mix/비교음원·62초 악기별 9개 파일, 무음·샘플 클립·DC·끝 fade, 실제 ffmpeg 음량과 true peak를 확인했다. 모든 비교 true peak는 -1.9dB 이하이며 A/B 차이는 0.3 LUFS 이내다.
- **재현:** `/private/tmp/forest-audio-v02-r03-rebuild`와 현재 시안의 51개 파일 및 manifest 전체를 QA가 실제 바이트로 대조해 모두 동일함을 확인했다.
- **경계·권리:** Git `60777dd` 대비 게임 코드·scripts·project.godot·v01 파일 변경/추가 없음, 기존 `.gdignore` 유지. 악기 라이브러리·공식 패키지의 고정 SHA와 출처·MIT 허가문·저작자 표시를 확인했다. SoundFont는 제작 전용이며 시안에 포함되지 않는다. 참고 영상의 녹음·음표를 복사하지 않았다는 제작 기록을 유지한다.
- **검사 조건 수정:** 첫 검사에서 가드 비교 A의 바이트 불변 조건이 실패했다. 바뀐 B와 공동 음량 목표를 맞추면 A의 비교 gain도 달라질 수 있으므로 그 추가 조건은 제거했다. v01 원본과 비교 A가 gain만 다른지 실제 신호 대조는 그대로 유지한다. 제작물 결함을 수정한 것으로 기록하지 않는다.
