# UI 설계 기록

## Penpot 구조

- 파일: `Forest_Arena_UI`
- 24개 계약 화면: `SCR_01_Splash`부터 `SCR_24_Profile`
- 전투 보드: 1대1, Solo 최대 8명, Team 4대4, Practice, 일시정지, 복귀, 나가기 확인, 조작 설정
- 라이브러리: 버튼, 탭, 카드, 파티 슬롯, HUD, 결과, 대화상자, 전투 조작을 포함한 22개 컴포넌트

## 조작 배치 제안

- 왼쪽 방향패드: 화면 너비 6.5% 안전 여백 안쪽, 하단 58%부터 실제 터치 330×330 기준.
- 오른쪽: 대시는 안쪽, 점프는 아래, 약·강·특수는 오른 엄지 부채꼴로 둔다.
- 이 배치는 현재 런타임의 가로 나열 배치와 다른 설계안이다. Godot 반영 전 실제 Android 기기에서 멀티터치와 손가락 가림을 확인한다.
- 조작 설정은 버튼 크기·투명도·기본값 복원만 제공하며 자유 배치 편집은 포함하지 않는다.

## 제품 상태 표기

- Story, Team, 온라인 파티·매칭, 상점·미션·소셜·랭크·성장 화면은 `FUTURE DESIGN`으로 보인다.
- 장신구에는 희귀도·등급 표현을 사용하지 않는다.
- Splash에는 캐릭터를 사용하지 않는다.
