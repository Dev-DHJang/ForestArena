## 실제 수행한 검사

- `godot --headless --path . --editor --quit`: 종료 0, 구문 오류 없음. 증거 `qa-import.log`.
- `godot --path . --script res://_workspace/title-loading-proportions/qa_independent.gd -- --qa-render`: 실제 macOS 렌더러, 34항목 통과. 증거 `qa-native.log`, `qa-captures/independent-report.json`.
- 시작 진행 중 입력 차단, 진행률 역행 없음, 준비 완료 전 게임 분리, 누르던 터치로 진입 안 됨, 손을 뗀 뒤 새 터치로 1회 진입, 새 저장의 첫 선택 연결을 확인했다.
- 1280×720(16:9)·1600×720(20:9)의 타이틀·시작 문구·버전·저작권 위치와 텍스트 영역을 확인했다. 이미지 합성이 아닌 실제 게임 뷰포트 PNG를 저장했다.
- 전환 직후 바 숨김, 150ms 이후 표시, 중복 요청 거절, 완료 후 제거, 실패 안내·재시도/이전 화면 버튼과 취소 후 해제를 확인했다.

## 발견·전달한 사항

1. 시작 로더의 각 파일 진행률이 전체 진행률을 덮어쓰는 문제를 코드 검토로 발견하고 UI 담당에게 전달했다. 전체 진행률 환산 적용 뒤 독립 실행에서 역행 0회를 확인했다.
2. 전환 덮개만으로 키보드 포커스 입력을 막지 못하는 문제를 전달했다. UI 담당이 포커스 해제와 전환 중 입력 처리를 추가했다. 전용 입력 검사를 추가로 확인할 예정이다.
3. 기존 Android 검사 도구가 새 타이틀 진입을 기다리지 않거나 이전 시작 장면 분기로 가는 문제를 전달했다. 도구 변경 결과와 자동 검사는 별도로 확인할 예정이다.
4. 실제 20:9 화면에서 얇은 시작 글자가 밝은 바닥 위에 놓여 대비가 낮다. `qa-captures/title-ready-1600x720.png`를 근거로 어두운 바탕·명확한 글꼴을 요청했다. 수정 뒤 재촬영 필요.
5. 독립 검사 종료 시 ObjectDB 4개·리소스 2개가 남았다는 Godot 경고가 있다. 검사 종료 정리 영향인지 기본 앱 문제인지 추가 분리해야 하며 무경고로 보고하지 않는다.
