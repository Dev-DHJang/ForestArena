# 대전 화면·터치 구현 전달

## 변경

- 모든 전투 표시 경로에 공통 `ForestlightMatchHud`를 사용한다. 기본 글자 16px, 얼굴 32px, 카드 높이 64px이며 글자 1.3배 설정에서는 높이 76px이다. 2명은 로컬 플레이어를 왼쪽에 표시하고 다인전은 최대 4열·2행으로 표시한다.
- 참가자 번호는 원래 snapshot 순서를 유지하며 Team은 팀끼리 묶는다. 캐릭터 이름·HP·기회를 표시하고 닉네임은 기존 미니맵에 유지한다. 탈락 표시는 글자와 투명도를 함께 사용한다. 기존 미니맵 240×150과 그 아래 일시정지/나가기 버튼 영역을 비워 둔다.
- 네 얼굴은 이미 승인된 콘셉트의 AtlasTexture와 `fa.character.minimap.<character-id>.face` 논리 ID를 재사용했다. 얼굴 자산·PNG·manifest·자산 목록 변경은 없다. 캐릭터 변경시에만 얼굴 Texture를 조회한다.
- 로컬 막기 내구도는 조이스틱 옆 116×8 막대와 숫자로 표시한다. 특수기 대기시간은 초로 바꾸어 해당 버튼 아래에 표시하고 궁극기는 백분율·준비·사용함을 해당 버튼 아래에 표시한다. 전투에서 받은 값을 표시하며 명령 실행 여부를 직접 판정하지 않는다.
- 오른쪽 행동 버튼은 약공격을 중심에 두고 강공격을 오른쪽 위, 점프·회피를 아래, 특수·궁극기를 위쪽 바깥 곡선에 배치한다. 약 96px, 강·특수·점프·회피 80px, 궁극기 64px이며 그림과 터치 판정을 같은 사각형에서 만든다. 궁극기에는 기존 승인 원형 특수 버튼 스킨과 네이티브 글자를 재사용한다. 빈 공간은 동작하지 않는다.
- 조이스틱의 손가락 소유, 행동 버튼 바깥에서 손을 뗄 때까지 유지, 두 손가락 동시 입력, 취소·포커스 손실·중단 해제는 보존한다. 화면 크기가 달라지면 누른 입력을 먼저 해제하고 버튼을 재배치한다.
- `CombatUiGeometry`가 실제 화면 픽셀 안전 영역을 viewport의 화면 변환 역행렬로 논리 좌표로 옮긴다. HUD·미니맵·조작이 같은 변환을 사용하며 HUD와 조작은 simulated override로 자동 확인할 수 있다.
- 고정 카메라 줌은 1.50이다. 플레이어 중심과 전투 snapshot 불변을 유지했다. 부분 노출 화살표 검사는 확대값에 따라 좌표를 계산하도록 수정했다. 위쪽 화살표 중심은 실제 HUD 아래끝에 화살표 길이 20px와 여유 8px를 더한 좌표 아래로 제한해 8명·큰 글자에서도 카드와 겹치지 않는다. 미니맵 아래 일시정지/나가기 예약 영역도 같은 방식으로 피한다.
- 숨긴 과거 HUD의 긴 문자열과 캐릭터 이름 하드코딩은 제거했다. 개발 상태 표시는 별도 라벨로 남긴다.

신규 검사에서는 참가자 2/4/8명, 16:9/20:9, 글자 1.0/1.3배, 상단·좌우·하단 안전 여백, 그림과 판정 일치, 버튼 간 겹침·빈 공간 무입력, LAN guest의 실제 로컬 ID, 팀 정렬 뒤 번호 유지, 입력 중 재배치 해제, 카메라·표시의 전투 데이터 불변을 확인한다.

화면 캡처는 오케스트레이터가 생성·검토한다. 기존 앱 검사 일부에는 종료 시 ObjectDB·Resource 정리 경고가 남아 있으며, 이 기록은 경고를 없는 것으로 취급하지 않는다. 물리 Android가 연결되지 않아 실제 기기의 조작감·안전 영역·글자 가독성·중단/복귀는 미실행이다.
