# 대전 UI 독립 확인 2회차

판정: `pass` — 1회차에서 발견한 라벨 돌출과 화면 밖 화살표 겹침을 수정한 뒤, 승인 계획의 자동 확인 범위를 다시 통과했다. Android 물리 기기 확인은 이 판정에 포함하지 않는다.

## 수정 재확인

- HP/남은 기회 라벨은 실제 폰트의 최소 높이를 읽어 아래쪽 2px 여백을 두고 배치한다. 글자 크기 1.3에서도 자식의 실제 표시 영역이 카드 안에 포함된다. 자동 검사에 얼굴·이름·HP 막대·HP 글자·남은 기회 영역의 실제 경계 확인이 추가됐다.
- 화면 밖 화살표의 상단은 현재 HUD 하단, 미니맵 하단, 앱의 일시정지/나가기 예약 높이 70px 아래에 화살표 길이 20px와 여유 8px를 더해 정한다. 확대된 8인 카드와 위/대각선 화살표가 겹치지 않는다.
- 앱 예약 높이 70px는 실제 `_place_match_button`의 간격 12px + 버튼 높이 58px와 일치한다. 앱 경로에서만 예약하며 개발용 장면에서는 미니맵/HUD 영역을 기준으로 한다.
- 기존 일부만 보이는 상대의 화살표 숨김과 종료한 상대의 화살표 숨김을 유지한다. 카메라·HUD·화살표 검사의 전후 전투 snapshot 값이 같다.

## 표시 경로와 남은 확인

- 오프라인·연습·Solo·Team·LAN의 앱 시작은 공통 HUD/터치를 사용한다. LAN 카메라·미니맵·HUD·버튼 상태는 `lan_host` 또는 `lan_guest` 중 실제 내 ID를 읽는다. UI는 전달받은 값과 논리 자산만 표시하고 피해·경직·승패를 변경하지 않는다.
- Android 물리 기기의 엄지 접근성·가독성·중단/복귀는 승인 계획에 따라 별도 수동 재검사로 남는다. 자동 검사 결과로 기기 통과를 기록하지 않는다.
