# 대전 UI 독립 확인 1회차

판정: `fix` — 글자 확대 시 HP/남은 기회 라벨이 카드 아래로 2px 돌출한다.

## 확인한 기준

- 승인 계획, `01_contract.md`, HUD/터치/카메라/미니맵과 앱의 LAN·오프라인 연결 경로를 교차 확인했다. UI는 복제된 snapshot의 표시값만 읽으며 전투 상태를 변경하지 않는다.
- LAN 양쪽은 `local_fighter_id`와 HUD `local_id`에 실제 `lan_host`/`lan_guest`를 연결한다. 카메라·화면 밖 화살표도 실제 로컬 참가자를 따라간다.
- 참가자 2명은 내 카드가 왼쪽이고 원래 참가자 번호를 보존한다. 다인전은 최대 4개씩 두 줄이며 팀별 정렬은 원래 번호와 분리된다. 얼굴은 기존 논리 ID의 AtlasTexture를 32px로 표시한다.
- 안전 영역은 실제 화면 변환의 역변환 후 논리 viewport와 겹치는 영역을 사용한다. 가로 16:9/20:9·화면 잘림을 흉내 낸 경우에 카드/그림/터치 영역이 안전 영역 안에 있다.
- 약공격 96px, 일반 80px, 궁극기 64px와 오른엄지 곡선 배치, 그림과 판정 일치, 버튼 사이 빈 공간 미입력, 동시에 이동·강공격, 크기 변경 때 해제를 확인했다.

## 남은 확인

Android 물리 기기의 엄지 접근성·가독성·중단/복귀는 사용자 계획에서 별도 확인 대상으로 정했다. 자동 검사 결과를 기기 통과로 기록하지 않는다.

## 추가 확인과 수정 전달

- 생산자가 실제 라벨 최소 높이를 반영해 수정했다. 같은 추가 실측에서 health/stocks y44,h30으로 카드 h76 안에 포함됐으며 `UI_REVIEW_LABEL_BOUNDS: PASS`를 확인했다. 기존 UI 검사에도 모든 자식 실제 global rect 포함 검사가 추가돼 PASS했다.
- 추가 발견: 화면 밖 화살표의 상단 기준은 720px 화면에서 0.21×720=151.2px이고, 위쪽 화살표 그림은 y131.2~167.2px다. 글자 1.3의 8인 HUD 두번째 줄은 y94~170px이므로 중앙 카드와 겹친다. 조율/생산 역할에 상단 화살표 영역 조정과 8인 겹침 자동 검사 추가를 전달했다. 이 항목이 해결되기 전에는 UI 전체를 pass로 바꾸지 않는다.
