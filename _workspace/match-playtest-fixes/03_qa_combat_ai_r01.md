# 전투·AI 독립 확인 1회차

## 판정

**pass — 코드와 macOS 자동 검사 범위.** 전투·AI 생산 코드는 수정하지 않았다. 요청, `01_contract.md`, 전투·AI 전달 기록, 실제 공격 데이터·입력 처리·snapshot 생성과 LAN 읽기, 자동 검사와 전체 검사 로그를 함께 확인했다. 수정이 필요한 전투·AI 결함은 발견하지 않았다. 수정 APK의 실제 Android 기기 결과는 이 판정에 포함하지 않는다.

## 전투 확인

- 네 캐릭터의 기본·방향·대시·공중 약공격 시간은 준비 8/활성 4/회복 18, 기본 연계 마지막 타격은 10/4/22다. 중간타 고정 경직 16을 무게에 적용한다. 피해·넉백·강공격 차지와 다른 기술은 이번 시간 변경으로 확대하지 않았다.
- 초기 공격 준비나 실제 맞힐 수 있는 단계에서는 일반 취소를 허용하지 않는다. 회복 단계에서 데이터가 정한 0~7 tick과 적중 조건을 검사한다. 마지막 타격의 취소 금지를 보존한다.
- 가드/회피로 공격을 끝낸 직후 같은 약공격을 다시 시작해 대기 시간을 줄이는 우회에는 `attack_restart_lock_ticks`가 필요하다. 남은 회복 시간만 기록하고 이동·방어·점프는 즉시 허용하면서 새 약·강·특수·궁극기 시작을 제한한다. 제한된 궁극기는 게이지와 사용 여부를 바꾸지 않는다.
- 값은 고정 계산마다 한 번 줄고, 가드·회피·피격 중에도 같은 위치에서 줄어든다. 피격으로 없애지 않으며 경기 초기화·조합 설정·기회 상실·복귀에서 0으로 만든다. 경기 일시정지에는 고정 계산 자체가 멈춘다.
- snapshot에 제한 시간이 포함되어 상태 해시에도 들어간다. `network_snapshot()`은 위치·속도만 JSON 좌표로 바꾸므로 이 정수 필드를 유지한다. LAN 클라이언트의 파이터 읽기 함수는 선택 필드가 없으면 0, 음수면 0으로 읽는다. 기존 메시지 버전·공격 데이터 형식은 그대로다.
- 실행할 수 없는 공중 가드/회피·점프, 방향 없는 회피, 대기 중인 특수기와 사용할 수 없는 궁극기는 기존 공격과 예약 입력을 지우지 않는다. 실제로 사용할 수 있는 적중 뒤 특수·궁극기 분기는 바로 시작하며 방어 취소용 제한을 적용하지 않는다.
- 위 강공격 적중 뒤 점프 추격은 기존 launcher 경로를 유지한다. 일반 약공격의 방어·점프 취소와 달리 승인된 띄우기 추격을 가로막지 않는다. 기존 `phase1_combat_behavior`에서 실제 경로를 재검사했다.

## AI 확인

- 기본 판단 간격 18 tick은 실제 `LocalMatchConfig`와 AI 생성자 양쪽에 반영됐다. 전술은 접근·간격 유지·짧은 후퇴·대기·방어를 36~72 tick 유지한다. 판단 사이에는 기존 이동 명령 유지 규칙을 사용한다.
- 유효한 적을 90 tick 유지하고 같은 거리면 ID 순서로 선택한다. 팀원, 탈락·경기 종료·링아웃·출전 준비 또는 기회 0인 참가자는 제외한다. 기존 목표가 유효하지 않으면 판단 간격을 기다리지 않고 다시 선택한다.
- 명령은 전달된 현재 snapshot과 고정 tick, 초기 난수 값만 읽는다. 파이터 직접 변경이나 숨은 입력·미래 상태 읽기는 없다. reset은 난수·전술·표적·강공격 해제 예약·중간 착지 목표를 모두 초기화한다.
- 상대가 없어도 낭떠러지 복귀를 먼저 판단한다. 예약한 강공격 해제는 상대 유무와 일반 전술보다 먼저 처리한다. 바닥에 착지하면 중간 발판 목표를 지워 다음 점프에 남기지 않는다.
- 짧은 후퇴는 지금 서 있는 발판의 안쪽 여유를 검사한다. 간격 유지 중 상대가 너무 가까우면 공격이 후퇴를 덮어쓰지 않는다. 준비/판정 단계에서 방어·회피, 회복 단계에서 반격을 고르되 실제 전투의 상태·자원 제한은 공통 입력 경로에서 적용한다.

## 실행 증거

독립 검토자가 최종 코드에서 직접 실행했다.

- `godot --headless --path . --script res://tests/match_playtest_combat.gd`: PASS. 캐릭터 4종 × 미장착/장신구 6종의 28개 공격 조합과 28개 피격 조합, **784쌍**. 가장 늦은 첫 적중과 다음 적중 사이 **최소 7 tick** 행동 기회. 같은 조합의 반복 상태 해시 일치.
- 위 검사에서 가드/회피 취소 후 반복 공격 각각 실제 후속 적중 7회를 확인했다. 행동 기회는 두 경로 모두 **[7, 10, 10, 10, 10, 10, 10] tick**이었다. 제한 시간의 피격·snapshot·구버전 읽기·기회 상실·복귀·재대전, 유효/무효 분기 검사가 포함된다.
- `godot --headless --path . --script res://tests/local_ai_behavior.gd`: PASS. 5개 전술·공격 다양성, 팀원 제외·목표 유지/교체, 준비 동작 대응·반격, 발판 안전 후퇴, 적 부재 복귀, 강공격 해제, reset 재현과 실제 물리 발판 도달.
- `godot --headless --path . --script res://tests/phase1_combat_behavior.gd`: PASS. 띄우기 뒤 점프 추격과 공중 공격 제한을 포함한 기존 행동 확인.
- 앞선 독립 실행 `tests/phase1_determinism.gd`: PASS. 같은 초기 상태·입력으로 같은 전투 해시.

이미 완료된 긴 검사도 원시 로그에서 확인했다. 같은 검사를 불필요하게 반복하지 않았다.

- `/tmp/match-ai-soak-latest.log`: `LOCAL_AI_SOAK: PASS`. 16개 캐릭터 조합과 전체 경기 재생, 30초 무진행 금지·5분 내 종료. 생산자 기록의 종료 범위는 6,018~9,512 tick.
- `/tmp/fa-match-full-verify.log`: `MATCH_PLAYTEST_COMBAT`, `LOCAL_AI_BEHAVIOR`, `LOCAL_AI_SOAK`, `LAN_CONTRACT`, `LAN_RUNTIME`, `LAN_APP_FLOW` 및 전체 검사 통과 문구 확인. `SCRIPT ERROR` 검색 결과 없음. 연결 검사의 가상 환경을 물리 Android 두 대 결과로 해석하지 않는다.

일부 기존 행동·AI 검사에는 종료 시 ObjectDB/Resource 미해제 경고가 있다. 새 전투 검사는 해당 경고가 없었다. 실제 Android 기기의 체감 공격 속도·AI 난이도·터치/중단 복귀는 미실행으로 남긴다. UI는 이 검토자가 생산했으므로 UI 독립 최종 판정은 다른 QA 회차의 기록을 따른다.
