# AI 대전 방식 변경

## 구현

- `LocalAICommandSource`와 실제 경기 구성 `LocalMatchConfig`의 기본 판단 간격을 18프레임으로 맞췄다. 접근·거리 유지·짧은 후퇴·공격 대기·방어 전술을 36~72프레임 유지한다.
- 가장 가까운 유효한 적을 90프레임 유지한다. 사망·링아웃·출전 준비·남은 기회 0은 즉시 다시 선택하고, 팀원은 선택하지 않는다. 같은 거리면 참가자 ID 순서로 정한다.
- 화면에 전달된 공격 준비/판정 상태에 가드·회피 비중을 높이고 공격 후 대기에는 반격한다. 약공격을 중심으로 점프·강공격 누름/해제·특수·궁극기를 섞는다. 숨은 입력·미래 상태를 읽지 않는다.
- 낭떠러지 복귀는 적이 모두 일시적으로 사라졌을 때도 실행한다. 중간 발판으로 뛰는 동안 착지 목표를 유지하며 최종 상대를 따라가다가 발판을 넘어가지 않게 했다. 후퇴는 현재 서 있는 발판 안에서 다음 판단까지의 이동 여유를 남긴다.
- 초기화는 난수·전술·적 선택·강공격 대기·착지 목표를 모두 초기화한다. 대상이 없어져도 예약한 강공격 해제는 보존한다.
- 전투 계산·공용 데이터 형식·LAN 메시지는 변경하지 않는다. 명령은 기존 사람 입력과 같은 처리 경로에서 상태/자원에 따라 허용된다.

## 자동 검사

- 기존 `tests/local_ai_behavior.gd`에 전술 5종과 공격 4종 다양성, 준비 동작에 가드/회피, 공격 후 반격, 90프레임 대상 유지와 즉시 재선택, 팀원 제외, 안전한 발판 후퇴, 적 부재 낭떠러지 복귀, 강공격 해제, 초기화 재현 검사를 통합했다.
- 기존 실제 물리 이동으로 모든 발판 도달 검사와 16개 캐릭터 조합의 `local_ai_soak.gd`를 유지한다. 30초간 피해/남은 기회 변화 없음 금지·5분 이내 종료·전체 경기 재현을 검사한다.
- 실행 결과는 통합 전 마지막 실행 이후 이 기록에 갱신한다. Android 실기기 난이도와 조작감은 별도 확인 대상이다.
