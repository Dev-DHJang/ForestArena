# 실제 서비스 개발 부족 항목 점검

- 요청: 실제 서비스에 필요한 개발 내용 중 부족한 부분을 점검하여 리스트업한다.
- 점검일: 2026-10-09.
- 범위: 현재 작업 폴더의 문서·코드·검사·기존 기기 기록을 비교하고 Android 출시와 운영에 필요한 후속 개발을 정리한다.
- 산출물: `docs/product/service-readiness-audit.md`. 항목마다 현재 상태, 근거, 우선순위, 담당 역할, 완료 조건을 남긴다.
- 제약: 신규 기능 구현이나 제품 결정 승인은 요청 범위에 포함하지 않는다. 기기 검사를 새로 수행하지 않으며 기존 기록과 이번 자동 검사 결과를 구분한다. 작업 시작 전에 있던 캐릭터·모션·문서·코드 변경은 보존한다.
- 검사: `./scripts/verify.sh`, `./scripts/verify-docs.sh`. 외부 스토어 준비 요건은 Google 공식 문서로 확인한다.
