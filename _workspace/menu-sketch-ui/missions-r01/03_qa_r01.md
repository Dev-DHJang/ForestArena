## 초기 발견과 해결

초기 명세에서 일일/주간 하단 새로고침·보조 문구의 안전여백 초과와 대전 업적 행을 압축하면서 생긴 본문/동작 영역 충돌 가능성을 발견해 전달했다. 네이티브 제작 전 하단 배치를 수정하고 대전 전용 행을 만들었다.

수정 명세의21보드를 별도로 검사해 중복 레이어명, 목적지 존재, 좌우96/상하48 안전여백,72px 조작 크기, 비활성 목적지, 로딩 배경 동작, 행 내부 범위에 문제0건임을 확인했다. 대전 행은 텍스트/막대128..1352와 동작 영역1424..1776으로 분리됐으며 모든 내용이 각 패널 안에 있다. 임시 문구도 정리됐다.

마지막 문구3개를 사용자 언어로 다듬은 뒤 해당 대전 목록·안내창의 실제 새 뷰어와 네이티브 PNG를 다시 확인했다. 내부 ID와 승인 절차 설명은 UI에서 제거됐고 개발 전달 문서의 ID 연결은 유지됐다. 배치·목적지는 그대로다.
