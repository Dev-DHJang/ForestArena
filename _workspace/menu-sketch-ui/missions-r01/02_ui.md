## 기존 기능 연결

근거는 `docs/ui/menu-features-v01.md`, `scripts/premium_menu/menu_feature_store.gd`와 기존 서버 집계다. 일일은 `daily-play`1회·`daily-win`1승, 주간은 `weekly-play`5회·`weekly-win`3승이다. 일일 한국 시간 자정, 주간 월요일 자정 기준을 그대로 표시한다.

대전 업적은 `first-play`1회·`ten-play`10회·`all-characters`4종 각각 완료다. 현재 활성 자현·나비2종과 구분해 호환 조건을 표시하며 캐릭터 해금/활성 범위를 늘리지 않는다. 정상 AI·Solo·Team·LAN 기록을 집계하고 연습·Story·포기 경기는 제외한다. 기존 기록에는 보상 지급이 없다. UI의 달성 상태는 수령 성공을 의미하지 않는다.

일일·주간·누적 진행은 기존 읽기 데이터에 연결 가능하다. 조회 실패는 빈 기록과 구분하고 재시도를 제공한다. 프로토타입의 새로고침·숫자는 예시이며 실제 조회를 호출하지 않는다.

## 제품 결정이 필요한 항목

- 출석 운영 기간·시작일, 연속/누적 집계, 초기화, 일자 변경과 오프라인 처리.
- 출석 보상 종류·수량·수령·중복 요청·실패 복구.28칸은 실제 운영 달력이나28일 상품 결정이 아니다.
- 수집·기술 업적 조건·집계 출처·기간·현재 보유/입력 기록의 활용 여부와 보상.
- 새 보상과 경제는 별도 승인 대상이다. 이번 시안은 성공 보상·현금 가격·가상의 재화 지급을 생성하지 않는다.

미정 항목의 확인창은 닫기와 배치만 검토한다. ‘보상 수령 · 미정’은 비활성이다. 확인창은 뒤 배경을 누를 수 없고 닫기 시 원래 탭·분류 문맥으로 복귀한다.

## 시각·상태·자산

기존 v08 어두운 숲과 금색 강조, Noto Sans KR·네이티브 텍스트·기존 표면 컴포넌트를 재사용한다.1920×1080,8px 간격,좌우96·상하48 여백,터치72 이상을 기준으로 한다.1280×720 축소와 대표3장의2400×1080 비교를 제공한다.

새 필수 이미지 슬롯은 없다. 기존 승인 `IMG/bg/character-room`과 복제 로비 원화를 재사용한다. 새로운 래스터 아이콘·보상 원화를 조용히 발명하지 않는다. `MISSING ASSETS`는 신규0개이며 기존 제작 묶음의 미수록 합집합28개는 유지한다. 미제작 생활·대전7종의 자산은 이 수에 포함하지 않는다.

일일·주간·출석의 선택 탭, 달성/진행중, 빈 목록, 전체 달성, 로딩, 조회 오류·재시도, 업적3분류와 비활성 보상, 필요한 안내창을 구성한다. 새 진입 로비는 복제본이므로 기존 승인 로비의 동선은 바꾸지 않는다.
