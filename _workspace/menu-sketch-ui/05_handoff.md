공통 기준은 1920×1080, 8px 간격, 좌우96·상하48 안전 여백, 주요 조작 영역72 이상이다. 한국어는 편집 가능한 Noto Sans KR 텍스트로 유지하고 v08의 어두운 숲과 금색 강조를 재사용한다. Godot 논리 해상도1280×720은 유지한다. 캐릭터 원화는 원본 비율을 유지해 영역 안에 맞춘다. 각 묶음에서1280 축소·20:9 비교와 선택·비활성·빈 목록·로딩·오류·확인창·뒤로 복귀 증거를 확인한다.

사용자 표시명은 신기, 재화명은 조약돌·무지개돌이다. 내부 장신구 ID와 데이터 형식은 유지하고 희귀도는 추가하지 않는다. 가격·출석 보상·시즌·자동 매칭·우편·계정·공지 운영은 예시 또는 미정 표시를 유지한다. UI 승인은 경제·결제·공용 인터넷 서비스·현재 게임 로스터 확대·새 캐릭터 원화 승인을 포함하지 않는다.

각 전달 명세에서 현재 기능과 추가 제품 결정을 구분한다. Story·Solo·Team·AI·Practice5개 모드, 전체 최대8명·팀당1~4명이라는 설계 계약을 유지한다. 현재 같은 네트워크의 LAN1:1·LAN5 초대 코드·LAN 승패 순위와 장래8인 방·시즌 티어·파티·자동 매칭을 구분한다. 현재 API를 미정 서비스의 승인으로 재해석하지 않는다.

현재 전체 미수록 기준은 [슬롯 합집합29종](match-r01/missing-assets-union.json)과 [새 랭크 문양 슬롯](match-r01/missing-assets.md)이다. 승인된 배경·캐릭터 원화·컴포넌트만 재사용하고 미수록은 정확한 슬롯명으로 표시한다. 개별 이미지 배치CSV, PNG 해시와 원본 JPEG 해시는 각 묶음과 참조 등록표에서 확인한다.

Penpot 감사·실제 뷰어·PNG·독립 QA와 Android 실기기는 별도로 기록한다. 실제 Android를 실행하지 않은 결과를 기기 통과로 표시하지 않는다. 개발을 시작할 때 승인 UI의 기능 연결, 전체 값 조합, 기기 저장·재실행, 한글 입력, 실제 실패 복구와 Android 터치·접근성을 별도 검증한다.
