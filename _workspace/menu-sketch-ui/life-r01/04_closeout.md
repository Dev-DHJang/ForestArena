## 재개와 연결 한계

작업은 사용량 한도 중단 뒤 저장된 시안·검사·PNG를 먼저 확인해 이어갔다. 중단된 goal은 없었다. 로컬 MCP가 종료됐지만 네이티브 제작·저장·내보내기·보존 검사는 이미 완료돼 시안을 재생성하지 않았다. 실제 뷰어의 남은 동선과 검토 자료를 마무리했다. 크레딧 구매나 초기화권을 사용하지 않았다.

선택 항목의 자기 화면 이동은 현재 Penpot에서 거부돼 의미에 맞게 제거했다. 새로 생성된 시작 흐름을 이름 붙여 사용했고,일반 ShapeProxy를 시작 보드로 재할당하는 버전 차이는 기존 흐름 재사용으로 해결했다. 초기 명세 일괄 요청이100KB 제한을 넘은 뒤에는 보드별로 나눠 보완했다. `construction-spec.json`·`refinements.json`은 단계별 제작 기록이며 최신 보드에 과거 명세를 재적용하지 않는다.

뷰어 일괄 검사120단계 뒤 도구 시간 제한으로 실행 환경이 재설정됐다. 각 단계의 체크포인트를 저장해 완료120개 전체를 반복하지 않았다. 새 탭에서 미완료 닫기 검사를 위해 미니맵 안내창만 다시 연 뒤 남은 검사를 이어167단계를 완료했다. 이 과정은 설계나 게임 데이터 변경이 아니다.
