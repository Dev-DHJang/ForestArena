## 재검사와 복구

`python3 _workspace/menu-sketch-ui/life-r01/check_spec.py`로75개 명세·우편8조합·버리기6문맥·여백·터치·목적지를 확인한다. 실제 뷰어는 `viewer-checks.json`을 따른다. 확인창은 원래 화면의 버튼에서 열어 닫기를 확인한다. 보드 선택창은 선택 후 오른쪽 위 닫기로 닫는다.

연결된 올바른 파일을 확인한 뒤 `setup.py`로 도우미·명세를 읽힌다. `create.py`는 완료 해시가 같은 보드를 재사용하고 새 요소를 작은 묶음으로 만든다. 불완전 보드는 소유·검토 대기·제작 해시가 일치하는지 검사한다. `construction-spec.json`과 `refine.py`는 초기 제작 후 슬라이더 시각 표시를 보완한 이력이다. 이미 완료된 최신 보드에 과거 명세를 다시 적용하지 않는다.

연결은 `wire.py`,검토 시작 선택은 `finish.js`다. 승인159보드·기존 원본은 재생성하거나 자동 덮어쓰지 않는다. 편집기에서 한글 배치를 표시하고 저장한 뒤 새 뷰어에서 다시 확인한다.

네이티브 PNG25개를 선별하고 전체75개 편집 요소 감사·실제 뷰어 증거와 함께 검토한다. 축소4개는 원본의 LANCZOS1280×720 결과이며 비교4개는2400×1080이다. 전체 파일의 크기·출처·해시는 `export-index.json`이다.

게임 코드는 이전 전체 검사93개 통과 기준과 같다. `verification-summary.json`의 Git 차이 근거에 따라 완료 검사를 재사용하고 이번 Penpot·문서·문법 검사를 별도 기록한다. 실제 Android 확인은 하지 않는다.
