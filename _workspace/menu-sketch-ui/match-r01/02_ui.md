## 진입과 게임 모드 대응

AI·자동 매칭·로비는 진입 방식이며 새 게임 모드3개가 아니다. 권위 모드는 Story·Solo·Team·AI·Practice5개다. AI 카드는 AI 준비방,일반 로비의 개인전은Solo,팀전은Team에 대응한다. Story와Practice는 앞서 승인한 메뉴에서 진입하며 이3종에서 새로 정의하지 않는다. 일반·랭킹 구분은 참가 경로의 구분이며 Rank라는 새 전투 모드 ID나 저장 형식을 추가하지 않는다.

현재 실제 LAN은 ADR-037과LAN5 계약의 같은 네트워크1:1이며 활성 전투 캐릭터는 자현·나비다. 설계의 장래8인 방과 묘령 승인 원화 재사용은 현재 런타임의 인원·로스터 확대 승인이 아니다. 개인전 전체 최대8명,Team은 팀당1~4명·전체 최대8명을 유지한다. 팀 예시방의 윗줄4슬롯은A팀,아랫줄4슬롯은B팀이며 각1명 표시와2/8 목록이 일치한다.

기존 대표 승인 일반·AI 대전방의8슬롯·설정·버튼 위계를 새 검토 페이지에서 재사용한다. 원본을 수정하지 않고 AI/개인전/개인전필터/팀전 진입 문맥의 준비·준비취소·시작안내·나가기 확인을 복제했다. 입력창과 방 상태는 진입한 화면 위에 전체 화면 오버레이로 표시한다. 다음 입력·개인/팀·준비·나가기 상태로 전환할 때 현재 오버레이를 닫고 다음 상태를 열어 한 층을 유지한다. 취소·뒤로·나가기 확인의 최종 실행은 오버레이를 닫으므로 원래 개인/팀 필터·선택·가득참·빈 목록 또는 AI 진입 선택을 보존한다. 중첩 오류·안내창은 안내 한 층만 닫는다. 개인전 필터에서 행을 골라도 필터·선택·가득참 표시를 유지한다.
