# MENU09 대표안 제작 기록

손그림21종 가운데 대표3장(메인 로비·캐릭터 스탯·일반/AI 대전방)을 Penpot 네이티브 요소로 제작했다. 지원상태11장·20:9비교3장과 전달안내1장을 추가했다. 나머지18장은 공통 방향 승인 뒤 제작한다.

## 실제 결과

- 파일 Forest_Arena_UI, 페이지23_MENU09_Review와24_MENU09_Handoff. 기존 프레임 이름·ID를 재정의하지 않고 새 MENU09 영역에서 대응한다.
- 대표1920×1080, 비교2400×1080, 축소1280×720. Noto Sans KR, 본문26–36px·제목44–56px, 8px 간격·72px 이상 조작.
- 텍스트524개·기존 컴포넌트 인스턴스212개. 배경1개·승인 원화4개를 재사용하고 자산/런타임 등록은 바꾸지 않았다.
- v08의 색상값을 새 Menu09 의미색7개에 연결했다. 기존 Menu07/Menu08 세트 활성 상태는 바꾸지 않았다.
- 로비는 중앙 묘령·상단 계정/재화·오른쪽 일반/랭킹·하단6메뉴다. 재화 잔액은 미정 기호로 표시한다.
- 캐릭터는 왼쪽 원화·세로3탭·오른쪽 기본능력치·아래4캐릭터다. 스탯은 묘령 Resource의 체력95·지상이동350·공중이동330·점프570·무게0.85다.
- 도표의 비교축 상한은 차례로120/400/400/650/1.2다. 항목별 값을 상한으로 나눈 표시용 비율이며 성장·등급·전투 밸런스 변경이 아니다.
- 대전방은 최대8칸·오른쪽 설정·준비/취소/나가기를 표현한다. 방에서 연 캐릭터 상세는 원래 방과 준비 상태로 복귀한다.

## 프로토타입과 개발 경계

일반대전 버튼은 대표안을 빠르게 검토하기 위해 AI방으로 바로 연결한다. 정식 일반대전 선택·자동매칭·방목록은 후속묶음이다. 미제작 항목은 다음 설계 안내로 연결하며 화면 전체를 완성한 것처럼 표시하지 않는다. 확인창 아래의 조작에는 이동 연결을 두지 않았다.

신기 표시는 기존 AccessoryData를 뜻한다. 내부 ID·API·저장 형식·전투/게임 규칙과 Godot 메뉴는 그대로다. 출석·우편함·재화상점·랭킹 자동매칭은 UI와 서비스 규칙을 별개로 승인받는다. 가격·보상·시즌·결제는 이번 작업에서 확정하지 않았다.
