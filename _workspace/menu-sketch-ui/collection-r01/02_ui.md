## 미디어와 상태

신기 아이콘 중 요요는 기존 승인 PNG를 실제 가져온다. 철갑옷 이미지는 `IMG/accessory/iron-armor` 슬롯이며 신규 설계 요청 이름이다. 기존CSV의 승인 슬롯이나 런타임 논리ID를 새로 등록한 것이 아니다. 영상7종은 별도 `VIDEO/...` 설계 슬롯이다. 목록은 `missing-assets.md`와 실제 Penpot 안내 보드에 표시한다.

영상 미수록 시에는 재생 버튼으로 “영상 준비 중” 안내를 열고 정확한 원래 탭·분류·장착 상태로 닫는다. 로딩과 연결 실패는 안내 보드에서 별도 검토한다. 미수록을 네트워크 오류로 표현하지 않는다. 오류의 다시 시도는 로딩 예시로 돌아가며 실제 영상을 재생하지 않는다.

Godot·API·데이터 스키마·저장·게임 규칙·승인 이미지 원본을 변경하지 않았다. Penpot 검증과 Android 기기 검증은 분리하며 실기기는 미실행이다.
