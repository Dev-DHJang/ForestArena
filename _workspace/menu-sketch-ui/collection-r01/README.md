## 재검사

`python3 _workspace/menu-sketch-ui/collection-r01/check_spec.py`로 명세·안전여백·동선·승인 경계를 검사한다. 실제 뷰어 검사는37단계이며 `viewer-checks.json`의 클릭과 도착 보드로 재현할 수 있다. Penpot의 보드 목록은 선택 후에도 열려 있을 수 있으므로 오른쪽 위 닫기 버튼으로 닫고 실제 화면을 검사한다.

플러그인이 초기화되면 먼저 부모 폴더의`rehydrate.py`로 보존된 원본 ID를 읽는다. 이후`bootstrap.py`는 기존 승인 이미지·컴포넌트와 새페이지ID를 복구하며, 대표 r01을 다시 제작하지 않는다. `sync.py`는 최신 새 묶음 명세만 읽힌다.

`render.js`의안전장치에 따라 기존 다른 버전 보드는 자동 덮어쓰지 않는다. `patch.js`는`patchKeys`를한 보드로 지정했을 때만 이번 검토 대기 보드를 수정한다. 한꺼번에 많은 보드를 갱신하면 공식 로컬MCP의30초 시간 제한을 넘으므로 보드별 호출 후 결과를 확인한다. 타임아웃을 받았을 때는 실제 완료 여부를 먼저 검사하고 같은 변경을 무조건 재실행하지 않는다.

PNG 생성은 Penpot의정식`board.export`이며 오류를 기록하고1회만 재시도한다. 원본/승인 보존, 네이티브 데이터 검사와 실제 표시 검사를 함께 유지한다. Android 실기기는 미실행이다.
