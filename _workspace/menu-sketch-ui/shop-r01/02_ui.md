2026-11-04. 캐릭터·신기 collection-r01의 사용자 승인을 기록한 뒤 상점5종을 `26_MENU09_Shop`에 글자·버튼·도형을 각각 편집하는 네이티브 요소로 제작했다. 이번 shop-r01은 **UI 검토 대기**다. 실제 개발·경제·결제 승인은 포함하지 않는다.

참조의 나뭇잎·다이아 표시는 사용자 지정 재화명 조약돌·무지개돌로 바꿨다. 캐릭터 손그림의 별점은 정식 난이도·공격력·방어력 별점 계약이 없어 기존 CharacterStats의 체력·이동·점프·무게 숫자로 표현했다. 새 별점 수치를 만들지 않았다.

캐릭터4종×기술5분류, 신기7종과 필터별 상세 복귀, 보유/비활성·미정 조건·획득 전 연습 안내, 재화 구성6종, 로딩·오류·빈 목록·잔액 부족과20:9 비교를 포함한다. 총73보드 중25개는 겹쳐 여는 확인창이다. 같은 문구의 창을 공유하고 Penpot의 `open-overlay`/`close-overlay`로 닫아 선택한 캐릭터·기술·분류를 그대로 유지한다. 오류 재시도는 정적인 로딩 보드로 이동해 확인창이 겹쳐 남지 않게 했다.

공통 탭·카드·버튼은 v08 컴포넌트와 MENU09 의미색, Noto Sans KR을 재사용한다. 1920×1080, 8px 간격, 좌우96/상하48 안전 여백과72px 이상 조작 크기를 따른다. 기술 영상은640×360, 미수록 신기 대표 이미지는1:1이다. 조약돌·무지개돌 상품 그림은 편집 가능한 단순 벡터다.

## 승인된 방향과 미정 조건

기준은 `docs/product/economy-pricing-v01.md`와 ADR-010이다. 현재0원 런타임과 미래 경제 UI를 구분한다.

| 항목 | 이번 표시 | 실제 개발 경계 |
| --- | --- | --- |
| 자현 | 보유 중·무료 기본 지급 | 유일한 무료 캐릭터라는 사용자 지정만 소비 |
| 묘령·나비·유란 | 조약돌 또는 무지개돌 택일 | 한 재화로 전액 구매, 합산 사용 미정 |
| 신기7종 | 무지개돌만·가격 미정 | 숫자 가격이나 판매 활성화를 승인하지 않음 |
| 조약돌 구성 | 100/500/1,000개 수량 예시 | 제공 방식·비용·두 재화 교환 미정 |
| 무지개돌 구성 | 100/500/1,000개 수량 예시 | 현금 가격·결제·환불·무료 지급 여부 미정 |
| 가격 미정 확인창 | 조건 확인 후 최종 구매 버튼 비활성 | 차감·지급·결제·영수증·중복 처리·저장을 연결하지 않음 |
| 잔액 부족 | 안내 보드에서만 보는 상태 예시, 필요/보유 — | 미정 가격으로 부족 여부를 계산하지 않음 |
| 획득 전 연습 | 진입 버튼과 후속 연결 안내 | 이 프로토타입에서 실제 경기를 시작하지 않음 |

기존 조약돌3,000 제안도 확정 가격으로 표시하지 않았다. 현재 `LocalPlayCatalog`의0원 가격, 기존 보유·프로필·DB와 Resource를 변경하지 않는다. 현재 정식 활성 캐릭터는 자현·나비, 활성 신기는 조약돌 요요다. 묘령·유란과 기존6신기의 판매·정식 활성화는 이 UI 승인으로 확대하지 않는다. 유료 전투 옵션의 공정성 등 경제 문서의 미결정 사항도 그대로다.

## ID와 미디어

`data-id-mapping.csv`에 현재7개 Resource ID와 UI 이름·설계 분류를 명시했다. `fixture-thorns`는 균형 신기, `fixture-ultimate-charm`은 집중 신기, `fixture-phoenix-revive`는 활공 신기로 표시한다. 옛 내부 ID의 revive를 부활 효과로 해석하지 않는다. UI 필터 분류는 설계 예시이며 저장 형식을 추가하지 않는다.

기존 배경·승인 캐릭터4종·요요 미디어6종을162곳에 배치했다. 원본 경로와 SHA-256은 `image-mapping.csv`에 있다. 신기6종 이미지·기술 영상20종은 미수록이다. 작은 목록에는 “이미지 준비 중”, 상세와 실제 `shop-missing` 보드에는 정확한 슬롯 이름을 표시한다. 다른 장비의 기존 이미지를 임의로 대응시키지 않았다.

상점 자체 미수록은26개다. 이전 캐릭터·신기 묶음과 합친 현재 제작11종의 미수록은28개이며, 나머지10개 참조 화면의 자산은 아직 전체 평가하지 않았다.

## 실제 검증과 전달

- 네이티브 보드73개, 텍스트1,453개, 컴포넌트 인스턴스659개와481개 연결을 감사해 문제0건이다.
- 새 뷰어에서109단계와23개 실제 화면을 확인했다. 확인창 닫기·선택 유지·배경 포인터 차단·가격/보유 비활성·필터 복귀·구성6종·오류 재시도·빈 목록·잔액 부족·로비 왕복을 포함한다.
- PNG48개는 네이티브19,1280×720 축소5,연락표1,실제 뷰어23개다. 유사한 모든 상태를 중복 PNG로 출력하지 않고 전체73개 편집 원본과 네이티브 검사를 유지했다. 비교3종은2400×1080이다.
- 승인된 이전63보드의 재귀 해시 변화0건, 기존700개 조작 요소/231개 이동 연결도 기존 명세와 같다. 원래24페이지·1,586루트·라이브러리586개 정의를 보존했다. 이전 승인 원본을 새 링크로 덮지 않고 별도 로비 복제본에서 이번 묶음에 진입한다.
- Penpot 저장 버전은 `MENU09 캐릭터·신기 r01 승인 · 상점5종 r01 검토대기`다. 독립 QA와 검사 원본은 각각 `03_qa_r01.md`, `native-audit.json`, `viewer-checks.json`, `export-index.json`, `preservation-summary.json`, `protected-navigation.json`을 따른다.

Penpot 검증과 Android 실기기 검증은 별도다. Android에서 새 메뉴를 실행하지 않았다. Godot·API·저장·게임 규칙·런타임 리소스 등록을 변경하지 않았다.
