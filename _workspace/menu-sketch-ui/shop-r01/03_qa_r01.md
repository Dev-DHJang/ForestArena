# 상점 묶음 독립 QA r01

2026-11-04. 독립 검토 역할 `shop_qa`. 최종 판정은 **pass — 상점 5종 사용자 검토 준비 완료**다. 새 상점 화면의 사용자 승인은 대기이며 실제 개발·결제·경제·API·저장과 Android 실기기 검사는 이 판정에 포함하지 않는다.

## 범위와 검토 방법

참조10 캐릭터,08 신기 목록,09 신기 상세,06 조약돌,07 무지개돌의5종을 검토했다. `forest-arena-qa/SKILL.md`, 요청·승인 기록, 비전투 UI 계약, v08 기준, `LocalPlayCatalog`, 현재 요요 규칙, ADR-010·037, 재화와 구매 가격 제안, 각 캐릭터/신기 Resource와 제작 산출물을 함께 읽었다. 참조5장, 네이티브 PNG19장, 실제 새 뷰어 캡처23장, 축소5장과20:9비교3장을 직접 시각 검토했다.

브라우저·Penpot 조작은 제작자가 단독 담당했다. 독립 QA는 제작자가 실제 새 뷰어에서 수행한109단계 기록과23개 화면 증거, 네이티브 감사 도구·결과, 원본 보존과 실제 전달 파일을 대조했다. 데이터 존재만으로 실제 한글 표시를 통과 처리하지 않았다.

## 제품·데이터 경계

- 사용자 지정대로 자현만 무료이며 다른 캐릭터는 조약돌 또는 무지개돌 한 재화로 전액 구매한다. 합산 사용은 미정이다. 캐릭터 외 상품은 무지개돌 전용이다.
- 수치 가격은 미정, 재화 패키지 수량은 설계용 예시다. 교환·제공 조건·현금 가격·결제·환불을 채택한 것처럼 표시하지 않는다. 실제 구매 버튼은 조건 확정 전 비활성이고 현재0원 상점/기존 보유를 변경하지 않는다.
- 활성 캐릭터 자현·나비와 활성 신기 조약돌 요요의 경계를 명시한다. 기존6신기는 현재 경기에서 비활성이며 분류·판매 여부도 설계 예시다.
- 손그림의 별점 대신 기존 CharacterStats의5개 수치를 사용했다. 생략된 자현의300/280/520은 기본값과 일치한다. 나머지 캐릭터 값도 각 Resource와 일치한다.
- `item_data` 및 `data-id-mapping.csv`의7개 실제 AccessoryData ID를 원본 파일과 일일이 비교해 모두 일치했다. 균형·집중·활공 신기는 사용자 표시명이며 내부 ID는 유지한다. 기존6신기 설명은 실제 수치·기술 교체·게이지 설정과 맞고 추가 피해·반사·부활을 넣지 않았다.
- 획득 전 연습은 버튼과 정확한 후속 연결 안내를 제공한다. 현재 시안에서 실제 경기를 시작한 것으로 표현하지 않는다.

## 화면과 동선

- `scene-spec.json`의73보드와25개 공유 확인창 구조를 독립 순회했다. 좌표·안전여백·72px 이상 조작·목적지·비활성 버튼·확인창 아래 링크 차단에서 정적 오류0건이었다. 네이티브 감사는 텍스트1,453개, 컴포넌트 인스턴스659개, 문제0건이다.
- 캐릭터4종의 기술5분류, 무료 보유 상태, 재화 택일 구매 안내, 영상 미수록·연습 안내를 확인했다. 공유 확인창은 close-overlay로 실제 진입한 캐릭터·기술을 유지하며 닫힌다.
- 실제109단계 기록에는 확인창 뒤 조약돌 탭의 포인터 클릭 차단, 구매 조건 미확정·보유 버튼의 비활성,7신기의 이름/구매 재화 확인,3필터의 상세 왕복, 재화6패키지의 구성/닫기, 오류/재시도/로딩/빈 목록/잔액 부족과 로비 왕복이 포함된다. 모두 pass다.
- 오류 재시도는 정적 전체 로딩 보드로 이동해 확인창이 겹치지 않는다. `viewer-checks.json`의 dialog visibility 필드가 이 정적 로딩 창에도 true임을 명시한 것을 확인했다.
- 새 뷰어 캡처23개에서 한글·이미지·선택·확인창·배경 어둡게 처리와 버튼 위계가 정상이다. 네이티브19장 전체와 축소5장·20:9비교3장에서도 잘림·겹침을 발견하지 않았다. 20:9는 중앙 정보 배치와 안전여백을 유지한다.

## 자산·파일·원본 보존

- 미수록은 이미지6종·기술 영상20종, 총26개다. 작은 목록 아이콘은 짧게 표시하고 상세 및 가시 `MISSING ASSETS` 보드에서 정확한 슬롯명을 유지한다. 이전 캐릭터·신기 묶음과의 합집합은28개다. 이는 실제 등록 자산의 누락을 숨기거나 기존의 다른 신기로 임의 대체한 결과가 아니다.
- 기존 승인 미디어6종의 실제 원본 SHA-256을 확인했고162개 배치 매핑과 일치한다. 요요 승인 이미지를 재사용했다. 재화 상품의 도형은 편집 가능한 벡터이며 새 게임 자산 등록은 없다.
- `export-index.json`의 PNG48개 전부에서 SHA-256·크기·바이트 수가 실제 파일과 일치했다. 구성은 네이티브19,1280축소5,연락표1,실제 뷰어23이다. 모든 확인창을 중복 PNG로 내보내지는 않았다. 전체73보드는 네이티브 감사로 확인하고 실제 뷰어에서는 기록된109단계 흐름을 검증했다.
- 축소5개는 최신1920 원본의 RGB/LANCZOS1280×720 결과와 픽셀이 정확히 같다. 직접 시각 검토에서도 읽기·간격·버튼이 유지된다.
- `before.json`과 `preservation-after.json`의 승인63보드 해시를 독립 비교해 차이0건이었다. 기존24페이지의1,586루트 수가 같고 라이브러리586개 정의의 ID·이름·경로가 초기 기준과 정확히 같다. 화면/링크를 새 상점 페이지에만 작성하는 코드 경계도 확인했다.

## 초기 검토에서 해결한 항목

초기 제작 중155보드는 문맥별 확인창 배경을 중복했다. 정식 open-overlay/close-overlay 공유 방식으로73보드로 정리했고 현재 진입 상태 복귀를 실제 뷰어에서 확인했다. 현재 Penpot에서 close-overlay의 선택 인자 destination을 생략해야 동작하는 점도 제작자가 실제 검증했다.

작은112px 이미지 영역의 긴 슬롯명 줄바꿈 후보는 짧은 준비 중 표시와 상세·누락 목록으로 해결했다. 사용자 표시 용어, 실제 ID 매핑, 자현의 명시적인 보유 중·무료 기본 지급 상태도 반영했다. 이들은 최종 시각·데이터 검토에서 해결 확인했다.

## 별도 검증과 남은 승인
