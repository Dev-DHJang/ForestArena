## 친구의 현재 기능

기준은 `docs/ui/menu-features-v01.md`와 `premium_menu_view.gd`의 기존 친구/초대 조건이다. 정확한 닉네임1~12자를 검색한다. 본인·이미 친구·중복 요청을 막고 반대 방향 신청을 자동 수락하지 않는다. 신청·수락·거절·보낸 신청 취소·친구 삭제를 각각 확인할 수 있다. 채팅은 제공하지 않는다. 최근 상대는 LAN 기록이다.

대기 중인 LAN 방의 방장만 친구에게 초대한다. 상대가 오프라인이라는 이유로 새 초대 제한을 추가하지 않는다. 받은 초대는120초 만료·닫힌 방을 구분하고 대전 중/이미 LAN 방 참가 중에는 참가를 막는다. 연결 실패는 친구 없음과 구분하고 마지막 확인 정보의 한계를 표시한다. 조회/초대 기능은 기존 기능과 연결 가능하며 시안의 이름·상태는 예시다.

Penpot 입력은 편집 가능한 네이티브 텍스트와 대표 입력 예시(새솔)로 구성한다. 실제 키보드·한글 조합·검색 API를 실행하지 않는다. 모든 확인창은 원래 탭으로 닫히며 실제 친구 관계나 초대를 변경하지 않는다. 문자 아바타는 이름 첫 글자를 사용하는 기본 대체 표시이며,프로필 사진 기능/새 원화를 발명하지 않는다.

## 우편과 공지의 미정 경계

우편 체크3개는8개 선택 조합으로 정확히 이동한다. 제목별3개 상세는 오버레이(원래 목록 위에 겹쳐 표시하는 창)로 열려 닫으면 선택 문맥을 유지한다. 선택0개는 지우기 비활성이고 수령/삭제는 각각 확인한다. 실제 발송·만료·보상·중복 수령·미수령 우편 삭제·전체 삭제 범위·복구는 추가 제품 결정이 필요하다. 실제 우편이나 보상 성공을 만들지 않는다. 조회 오류와 빈 우편함을 구분한다.

공지 A/B 본문과 진행/지난 이벤트 분류를 제공한다. 모든 게시 내용·일정은 예시이며 실제 점검/이벤트 소식이 아니다. 게시 출처·노출 기간·외부 링크·참가와 보상은 미정이다. 공지는 본문·분류·닫기,오류와 재시도를 검토한다.

## 설정과 대표 상호작용

손그림의 그래픽·사운드·알림·계정·정보5개 주분류를 유지하고 그래픽 분류 안에 기존 화면 효과·접근성·미니맵·조작·임시 디버깅을 포함한다.

- 사운드: 음악/효과음0~100%·5% 간격,기본60/80%,음소거 꺼짐.
- 효과: 피격 번쩍임 줄이기. 접근성: 글자100/115/130%,진동 기본 켜짐.
- 미니맵: 투명0~90%·기본30%,얼굴/점·기본 얼굴,이름 기본 켜짐.
- 조작: 고정/플로팅,버튼100~120%·5% 간격,투명0~50%·5% 간격,기본 고정100/0.
- 임시 디버깅: 타격 빨강·피격 파랑,재실행 꺼짐,기기/계정에 저장하지 않음.

값 버튼·슬라이더와 체크 표시는 네이티브 편집 요소다. 작은 슬라이더 손잡이는 시각 표시이고 실제 프로토타입 조작은72px 이상 값 버튼을 사용한다. 대표 프로토타입은 음악60→65%,취소→60%,적용→65% 표시다. 적용 화면을 다시 눌러 같은 값인데 변경 상태가 되지 않게 한다. 미적용 상태에서 각 분류/뒤로로 이동하면 목적지별5개 버리기 확인을 연다. 계속 편집은65% 초안으로 복귀하고 버리기는 의도한 분류/로비로 이동한다. 저장 오류는 변경 전 값 유지와 편집 복귀를 표시한다.

다른 값의 연속 조절·기기 저장은 Penpot에서 실행하지 않고 범위 안내로 검토한다. 이 대표 상호작용을 실제 설정 기능 전체 구현으로 기록하지 않는다. 기존 분류별 적용·취소·기본값 기능을 후속 개발에서 연결하며 전체 값 조합·실제 저장/재실행·입력 해제는 별도 검증 대상이다. 검토용 ‘시안/설계 예시’ 문구와 안내창은 실제 구현의 성공 메시지를 대신하지 않는다.

프로필 관리는 계정 아래 정보 화면으로 이동하고 뒤로는 계정으로 돌아온다. 기존 프로필 메뉴 연결 대상으로 둔다. 알림 종류·기기 권한,로그아웃과 계정 운영 조건은 미정이며 실제 계정/기기 권한/종료를 변경하지 않는다. 종료·로그아웃 확인창은 닫기와 비활성 최종 버튼만 검토한다.
