# MENU09 미디어 독립 QA r01

2026-11-05 독립 검토 `pass`. 신규 미디어의 사용자 검토 상태는 대기다. Android 실기기 확인은 미실행으로 기록한다.

## 검토 기준

원 요청과 제작 계약을 기준으로 기존 29개 슬롯의 파일, 원본 보존, 영상의 동작 표현과 Penpot 배치를 확인했다. 검토 범위는 편집 영상과 Penpot 시안이며, 승인된 게임 개발 범위는 기존 전달 명세를 따른다. [요청](00_request.md) · [제작 계약](01_contract.md) · [29슬롯 기준](qa/expected-slots.json)

- 신규 신기 이미지의 정사각형 투명 PNG와 96px 실루엣, 표시명, 희귀도 표현 확인.
- 기존 실버 원본의 바이트 일치와 실버3 예시 표시 확인.
- 영상 22개 실제 디코드, 1280×720·무음, 전체 원화 프레임과 최종 MP4의 시간별 화면 확인.
- 기존 SpriteFrames의 프레임 순서, 가중치, FPS 및 실제 연결 경로 대조.
- Penpot의 29슬롯 배치와 재생 연결, 승인 원본 284보드 보존, 새 미디어 검토 상태 확인.

## 이미지 7종

신규 6종은 모두 1254×1254 RGBA다. 256px와 96px 축소, 어두운 숲 색과 체크무늬 배경에서 직접 봤다. 복싱 글러브의 두 주먹, 도약 장갑의 스프링, 철갑옷의 흉갑, 활공 신기의 깃 장식, 균형 신기의 저울, 집중 신기의 수정 펜던트가 구별된다. 형태와 장식은 현재 표시명에 맞으며 희귀도 단서는 0개다. 투명도 값이 8 이상인 실루엣은 여백 안에 들어간다. 가장자리에 닿는 일부 값 1~7의 미세점은 실제 크기에서 눈에 띄지 않았다. [크기·투명도 측정](qa/image-metrics.json) · [96px 비교](qa/icons-reviewed.png)

실버 복제와 기존 PNG의 바이트가 일치한다. SHA256은 `d5613f51644c9a517714fa75b0a6d8e37b81dbfaff9f200231101e32ec05092b`다. 요청대로 재사용한 원본의 흰 배경 흔적과 거친 경계가 랭킹 화면에도 보인다. 실버3 표기는 편집 가능한 예시 텍스트다. [랭킹 화면](exports/rank-lobby.png)

## 영상 22종

독립 검사로 MP4 22개의 해시, 스트림과 전체 디코드를 확인했다. 모두 1280×720, H.264/yuv420p, 60fps, 무음이다. 원본 `.tres`의 프레임 순서·가중치·FPS와 참조 PNG의 해시를 별도로 대조했다. 12fps 원화는 출력 5프레임씩 표시하고, 24fps 원화는 60fps 출력에서 2·3프레임씩 교대로 표시해 전체 원화 재생 시간을 보존한다. 기존 캐릭터·공용 자료·신기 데이터 684개가 기준 SHA256과 일치한다. [독립 검사](qa/automated-audit.json) · [원본 기준](qa/source-baseline.json)

4캐릭터의 기술 20종과 요요 4모션을 전체 원화 시트에서 직접 확인했다. 콤보에 다시 사용하는 프레임을 포함해 총 576개를 봤다. 최종 MP4에서 따로 추출한 8시점씩 총 176개 화면의 순서, 배치, 글자와 잘림도 확인했다. Chrome 로컬 검토 페이지에서 자현 약공격과 특수, 나비 특수, 묘령 공중 강공격, 요요까지 5개 표본을 1배속으로 끝까지 재생했고 이미지 7개가 모두 로드됐다. [브라우저 재생 결과](qa/browser-playback.json) · [요요 시간별 화면](qa/accessory-pebble-yoyo-decoded-timeline.png)

자현의 약연계는 손 뻗기와 마지막 발차기, 공중 강공격은 목도리의 위에서 아래로 이어지는 동작, 특수는 32프레임의 연속 휘두르기와 회복이 읽힌다. 나비의 강공격은 위로 뻗는 발톱이 보이고, 공중 약공격은 전방, 공중 강공격은 위로 향한다. 나비 특수는 돌진 자세에서 발톱 타격과 회복으로 이어진다. 묘령은 주먹·발차기·공중 다리 동작이 구분되고 특수는 반복 발차기다. 유란의 주먹과 큰 꼬리로 하는 가로·공중 휘두르기도 구분된다. 영상은 기존 원화 재생 속도로 편집한 기술 소개다.

요요는 자현·나비의 지상·공중 64프레임을 사용한다. 발사와 회수 구간의 실이 손에 이어지고 요요가 화면 안에 남는다. 철갑옷 4초 정보 영상에는 현재 경기 비활성, 무게 +5%, 지상 속도 -5%와 능동 기술 여부가 읽힌다. 갤러리 카드의 중복 비활성 문구는 한 번만 표시하도록 정리했다. [철갑옷 시간별 화면](qa/accessory-iron-armor-decoded-timeline.png) · [로컬 갤러리](index.html)

초기 영상의 자현 특수·나비 강공격·나비 특수에서 과거 원화 선택을 찾아 `fix`로 반환했다. 현재 moveset이 쓰는 `special_scarf_sweep`, `attack_heavy_up`, `special_side`로 교체했다. 약공격 4개 영상은 각 캐릭터가 보유한 원화의 연계 순서로 확장했다. 수정된 7개 영상의 전체 프레임과 최종 MP4를 다시 확인했고 독립 검사에 최종 해시를 기록했다. [영상 제작 기록](02_video.md)

## Penpot 반영

승인 원본 6페이지 284보드의 형상·동선·승인 스냅샷이 전후 일치했다. 미디어 검토용 4페이지 190보드는 내용이 바뀐 검토 대기 79개와 기존 레이아웃 복제 111개로 구분된다. 이미지 43곳과 포스터 55곳에서 실제 이미지 채우기 ID 98개가 업로드한 미디어와 정확히 일치한다. 29슬롯 전체가 포함된다. 초기 확인에서 이미지 채우기가 빠진 Collection 포스터 26곳을 발견했고, 복구 뒤 98곳을 다시 대조했다. [독립 배치 대조](qa/penpot-check.json) · [초기 포스터 수정 근거](qa/penpot-media-discrepancies.json)

일반 포스터의 재생 버튼 53개가 올바른 로컬 URL과 영상 슬롯을 가리킨다. 로딩과 오류 상태는 각각 별도 시안으로 확인했다. 상점 묘령 약공격 모달에서 해당 영상으로 직접 연결되는 버튼과 닫기 동작을 대조했다. 제작자가 실제 뷰어에서 묘령 강공격 버튼으로 해당 MP4를 열어 4.066667초를 1배속 재생했다. 상점 신기 목록에서 철갑옷 상세를 열고 돌아온 뒤, 캐릭터 목록에서 자현 상세를 열고 복귀하는 동선도 확인했다. 영상은 Penpot 포스터에서 이 컴퓨터의 검토 페이지로 연결된다.
