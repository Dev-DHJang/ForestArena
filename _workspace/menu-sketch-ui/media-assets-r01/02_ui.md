# MENU09 미디어 반영 명세

2026-11-05. `media-assets-r01`에 누락 목록 29개 슬롯을 공급했다. 신기 원화 6종을 제작하고 실버 문양 1종을 기존 PNG 그대로 사용했다. 기술 영상 20종과 신기 소개 영상 2종은 기존 모션과 규칙 자료를 읽어 제작했다. 새 미디어 반영 보드는 사용자 검토 대기다.

복제 페이지 4개에 보드 190개가 있다. 변경 보드 79개는 미디어 검토 대기다. 나머지 111개는 기존 동선을 제공하는 레이아웃 복제다. 기존 승인본 1039의 284개 보드와 새 미디어 반영본 1055는 별도로 보관한다. 원본 전후 비교는 [preservation.json](preservation.json), 보드별 표시와 상태는 [penpot-audit.json](penpot-audit.json), 이름 있는 저장본은 [saved-version.json](saved-version.json)을 따른다.

이미지와 포스터는 실제 Penpot 이미지 채우기로 연결했다. 화면 안 한국어 문구는 편집 가능한 텍스트를 사용한다. 29슬롯을 이미지 43곳과 포스터 55곳에 연결했다. 동일 슬롯의 자료는 공유한다. 상점 캐릭터는 목록에서 캐릭터를 선택해 상세 화면을 보고 뒤로 목록으로 돌아온다. 가격과 실버 3은 설계 예시이며 기존 배치와 별도 텍스트로 표시한다. 실버 PNG의 흰 배경 흔적은 원본 상태 그대로 보인다.

현재 Penpot 플러그인의 재생 버튼은 현재 컴퓨터의 검토 페이지에서 해당 영상을 새 탭으로 연다. 동영상 영역에는 포스터와 안내 문구를 표시하고, 기존 로딩·오류 상태는 비교할 수 있도록 남겼다. 다른 컴퓨터에서 검토할 때는 전달 폴더에서 `python3 serve_preview.py`를 실행하거나 MP4를 직접 연다. 경로와 파일 확인값은 [29슬롯 대응표](asset-map.json), 실제 Penpot 연결 위치는 [배치 기록](placements.json)을 따른다.

기존 게임과 연결 가능한 정보는 승인 캐릭터와 모션, 장신구 효과, 기존 실버 리소스 ID다. UI 표기용 영상은 기존 동작을 편집한 소개 자료이며 실제 전투의 이동·적중을 시뮬레이션하지 않는다. 비활성 캐릭터와 철갑옷은 도감·정보 소개용이다. 새 신기 원화 등록과 앱 재생 방식, 시즌·경제·온라인 운영은 후속 개발 결정으로 분리한다. Android 실기기 확인은 미실행으로 기록한다.
