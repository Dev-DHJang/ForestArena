# MENU09 소개 영상 제작

2026-11-05. 22개 슬롯을 MP4·포스터·검토 자료로 공급했다. 기존 모션·게임 데이터·등록 파일은 수정하지 않았다. 영상은 새 미디어 검토 대상이며 기존 캐릭터 모션의 승인과 구분한다.

## 전달 파일

- `video/manifest.json`: 22개 영상의 정확한 슬롯, MP4·포스터·검토 시트, SHA256, 소스 SpriteFrames/PNG, 프레임 순서·영역·가중치, 원본 FPS와 표시 배율, 인코딩 확인 자료.
- `video/<character>-<light|heavy|jump-light|jump-heavy|special>.mp4`: 자현·나비·묘령·유란 각5개.
- `video/accessory-pebble-yoyo.mp4`, `video/accessory-iron-armor.mp4`.
- 각 영상 옆 `-poster.png`와 `-timeline.png`. 캐릭터 영상의 `-frames.png`는 해당 영상에 사용한 원본16/32프레임과 연계48/64프레임 전부를 보여 주며 요요 시트는4개 모션64프레임 전부를 보여 준다.
- `video/all-video-posters.png`: 22종 미리보기. `render_videos.py`: 재현 스크립트.

## 재사용과 표현 경계

캐릭터 기술20종은 현재 manifest가 연결한 `.tres`를 읽어 실제 참조 PNG의128px 셀·프레임 순서·가중치를 그대로 사용했다. 현재 경기 자현·나비는 `two_fighter_*_moveset.tres`의 실제 `visual_state_id`도 대조했다. 강공격은 자현/묘령/유란 가로·나비 상향 원화다. 특수공격은 자현 `special_scarf_sweep`32프레임·나비 `special_side`32프레임이며 비활성 묘령/유란은 기존 중립 특수 원화다. 게임 규칙을 바꾸지 않고 현재 연결을 따랐다.

약공격 영상4개는 각 단계 원화를 순서대로 연결했다. 자현4타는 현재 연결 그대로01→02→01→04, 나비3타는01→상향 약공격→02다. 비활성 묘령은 기존01~04의4타 자료, 유란은01~03의3타 자료다. 영상 안에 총 타수와 현재 단계 표시를 넣었다. 각 연계를2회 보여 주므로 자현·묘령12.067초, 나비·유란9.4초다. 나머지 캐릭터 기술16개는 각4.067초다. 공격 사이 원화 순서는 소개 편집이며 실제 연계 입력창이나 적중을 시뮬레이션하지 않는다.

원본12fps는60fps 출력에서 원화 한 프레임을5프레임씩 표시했다. 원본24fps의32프레임 특수2종은60fps 출력에서 각 원화를2/3프레임으로 교대 표시해 총 재생 시간을 보존했다(시각 보간·새 중간 그림 없음, 시각 경계 반올림 오차 최대1/120초). 각 원화 시연은2회이며 시연 사이와 앞뒤에 정지 시간을 둔다. 영상은 실제 게임의 공격 단계 시간, 이동·피해·적중·절차 효과의 녹화가 아니다. 화면 확대3.35배에 현재 해시와 일치하는 표시 보정 배율을 곱하고 발 기준점을 고정해 프레임마다 외곽에 맞춘 확대를 하지 않았다. 공중 모션은 지상보다60px 위에 고정해 공중 자세임을 보여 준다. 묘령·유란은 현재 경기 비활성·설계 도감용임을 영상에 표시했다.

나비 약공격·공중 약·공중 강3종은 manifest에 `unapproved-workspace-only`라는 과거 문자열이 남아 있다. 이 문자열을 임의 수정하지 않았다. 현재 `.tres`가 가리키는 PNG의 SHA256이 `motion_registration`의 `_workspace/fighter-presentation-fixes/user-motion-approval-r03.json`에 있는 `png_sha256`와3종 모두 일치함을 대조했다. 현재 연결·승인 해시 근거를 함께 기록해 재사용했으며 신규 모션을 생성하거나 등록하지 않았다.

조약돌 요요는 자현·나비 지상/공중4개 기존 원화를 순서대로 소개한다. 이 SpriteFrames의 명목 FPS는60이지만 실제 장비 표현은 별도의4구간 시간으로 재생된다. 기존 `pebble_yoyo_accessory.tres`의 준비6·발사18·회수18·회복6틱(60틱/초)과 manifest의 구간별 프레임·손 앵커를 읽어 사용했다. 기존 요요 PNG와 `equipment_visual.gd`의 실·회전 표현을 참고한 무충돌 소개 합성이며 실제 경기 녹화로 주장하지 않는다. 각 구간 전후 정지를 포함해7.2초다. 경기에서 쿨다운 없이 연속 사용할 수 있다는 뜻도 아니다. 장비 이미지와 원화는 그대로 재사용했다.

철갑옷은 새 아이콘을 정지 정보 카드로4초 소개한다. 기존 비활성 fixture의 무게1.05·지상속도0.95만 읽어 무게+5%·지상속도-5%를 표시했다. 현재 경기 비활성과 능동 사용 기술 없음을 표시하고, 슈퍼아머·새 공격을 연출하지 않았다. 신기 아이콘 생성 출처는 부모 제작 기록에 둔다.

배경은 기존 `forest_arena/assets/quality/high/background/bg_splash_forest.png`를 읽어 영상 캔버스에 맞추고 어두운 색을 덧씌웠다. 원본 PNG 바이트는 유지했다. 모든 표현 원본의 출처·권리 근거는 기존 manifest를 따른다. 새 외부 이미지·음악·폰트 파일을 게임에 도입하지 않았다. 한국어 레이블은 로컬 시스템 AppleSDGothicNeo로 영상에 렌더했으며 이 시스템 폰트를 배포 파일로 복사하지 않았다.

## 제작 검사

- 22개 전부1280×720,16:9,60fps,H.264/yuv420p,무음,faststart.
- `ffprobe`로 파일·스트림·길이 확인. `ffmpeg -v error -i <file> -f null -` 전체 디코드22개 통과.
- MP4 총9,647,930바이트. 원화 PNG·SpriteFrames는 읽기 전용으로 취급하고 원본 SHA를 manifest에 기록했다.
- 대표 자현 강공격 포스터와22종 모음, 요요 시간 시트, 철갑옷 포스터를 직접 열어 확인했다. 철갑옷에서 시스템 폰트의 유니코드 마이너스 글리프 누락을 발견해 ASCII 하이픈으로 교정·재렌더했다.
- 독립 QA에서 현재 moveset과 자현 특수·나비 강·나비 특수의 초기 선택 차이를 발견했다. 기존 승인 소스의 실제 연결로 교정했고 약공격4개를 전체 연계로 확장했다. 변경된7개와 나머지15개 전체 디코드를 확인한 뒤 독립 QA에22개 영상·전체 원화 프레임·시간 시트·소스 근거를 전달했다. 독립 QA 판정은 `03_qa_r01.md`에서 별도로 확인한다.
- Android 디코딩·기기 성능·Godot 동영상 재생은 실행하지 않았다. 실제 게임 연결과 미디어 코덱 선택은 후속 개발 항목이다.
