# Android 미디어 검토 페이지 확인

2026-11-05. Galaxy S23 Ultra, Android 16, Chrome 156에서 USB 연결과 로컬 미디어 검토 페이지를 사용했다. 가로 화면에서 이미지 7종 로드, 이미지·영상 필터 터치와 22개 영상 카드 표시를 확인했다. 자현 약공격 12.067초, 조약돌 요요 7.2초, 철갑옷 4초를 각각 시작부터 끝까지 정상 속도로 재생했고 디코드 오류가 없었다. 확인값과 캡처는 이 폴더의 device-results.json과 PNG에 기록했다.

실기기에서 이미지가 카드보다 크게 그려지는 문제를 발견해 검토 페이지 이미지의 크기를 카드 안에 맞췄다. 수정 뒤 같은 기기에서 이미지 7종의 경계와 가로 스크롤 없음을 확인했다. 이 결과는 브라우저 검토 페이지에 대한 표본 검사다.

실제 Godot 앱에 메뉴와 영상을 연결한 후의 Android 실기기 검사는 별도다. 2026-11-11 재개 시 ADB 연결 목록이 비어 있다.
