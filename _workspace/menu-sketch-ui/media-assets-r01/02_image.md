# 이미지 제작·재사용 기록

2026-11-05. Phase6 기반 MENU09 Penpot 설계용. 현재 UI 표시명과 29슬롯 목록을 기준으로 신규 신기 이미지6종과 기존 실버 문양1종을 공급했다.

신규 원화는 imagegen 기본 내장 도구로 각 자산을 개별 생성했다. 최종 프롬프트·원본 생성 경로는 [image-prompts.json](image-prompts.json), 슬롯·최종 파일·SHA256·alpha·해상도는 [images/manifest.json](images/manifest.json)에 기록했다. 프로젝트 안으로 최종 원본을 복사했으며 비트맵 후편집·기존 자산 교체는 없다. 생성 결과는1254×1254 RGBA PNG이고 각 슬롯은1:1이다. 독창적 판타지 도구·가죽·금속·민트/코발트/금색으로 구성하고 제3자 IP·상표·특정 작가 모방은 사용하지 않았다. 외부 참조 이미지를 생성 입력에 전송하지 않았다.

철갑옷·복싱 글러브·균형 신기·도약 장갑·집중 신기·활공 신기의 정확한 내부 ID는 기존 슬롯을 유지한다. 옛 이름 thorns/explosive-gloves/phoenix-revive를 가시 반사·폭발·부활 능력으로 바꾸지 않았다. 희귀도 별·티어 테두리·문자·등급 단서를 넣지 않았다. 현재 경기 비활성 상태는 유지한다.

실버 문양은 `forest_arena/assets/common/rank/rank_silver.png`의 기존 바이트를 `images/rank-silver.png`로 복사했다. 리소스 ID `fa.rank.rank.silver`는 그대로다. 기존 배경 잔여도 수정하지 않았다. UI의 “실버3 · 예시”는 편집 가능한 별도 텍스트이며 시즌·티어 운영을 확정하지 않는다.

6아이콘을256px·96px로 배치한 [미리보기](images/contact-sheet.png)와 독립 QA를 확인한다. 실제 실루엣(alpha≥8)에는 여백이 있고 눈에 띄는 잘림이 없다. 생성 원본의 극저alpha 가장자리 픽셀은 원본대로 보존했다. Penpot에는 PNG를 직접 업로드해 이미지 레이어로 연결하고 한국어 UI 문구는 네이티브 텍스트로 유지한다.

상태는 제작·배치 완료/새 미디어 검토 대기다. 기존 공식 자산 CSV의 다른 슬롯·구버전 승인 상태나 Godot 자산 등록은 바꾸지 않는다.
