# 상점 캐릭터 목록 수정과 전달

2026-11-04. 참조10 `상점-캐릭터.jpeg`의 상세를 유지하고, 사용자가 추가 요청한 목록 단계를 그 앞에 둔다. 공식 대응 ID `SCR_19_Shop`와 기존 상세 ID·데이터 형식은 유지한다. 나머지 참조08·09·06·07은 주요 본문을 재사용하고 캐릭터 카테고리 목적지만 새 목록으로 연결한다.

## 실제 Penpot 변경

- 1920×1080 목록과2400×1080 비교를 추가해 전체75보드다. 목록 카드4개는 자현·묘령·나비·유란 순서다. 카드 전체408×504 영역에 원화·이름·역할·가격 표시를 편집 가능한 요소로 구성했다. 초상화는 승인 원본이다.
- 로비 상점·검토 시작·모든 상점의 캐릭터 탭은 목록을 먼저 연다. 각각의 카드는 해당 캐릭터 약공격 상세를 연다. 기존 상세20상태의 뒤로/캐릭터 카테고리는 목록으로 복귀한다.
- 상세의 기술 탭과 캐릭터 빠른 전환180개는 기존 목적지를 유지한다. 목록 진입으로 무관한 상세 전환을 치환하지 않는다. 로딩 검토는 목록 배경으로 변경했고 닫으면 목록으로 복귀한다.
- 좌우96·상하48 여백과72 이상 터치 영역을 유지한다. 비교 보드는 가운데 배치한다. 한국어 텍스트·버튼·초상화 슬롯은 네이티브 편집 요소다.
- 변경 전73개 ID를 유지하고2개만 추가했다. 변경한 기존45보드와 신규2보드에 연결을 적용했다. `revision-changes.json`과 `patch-report.json`에는 로딩의 두 단계 변경이 중복 기록돼46항목이지만45개 고유 기존 보드다. 전체75개 감사에는 중복이 없다.

## 가격·자산·기능 경계

가격·보유 표시는 설계 예시다. 자현 무료·나머지 캐릭터는 한 재화로 전액 구매·합산 사용 미정의 기존 방향만 표현한다. 신기는 무지개돌 전용이며 가격·현금/교환·결제·환불은 확정하지 않았다. 신규 경제 승인은 없다.

원화6종·현재7신기의 ID·기존 미수록26개 목록과 이미지 대응표는 `../shop-r01/`을 그대로 따른다. 새 누락 자산은 없다. 묘령·유란의 디자인 표시와 기존6신기 표시를 현재 런타임 활성화로 확대하지 않는다.

기존 `SCR_19_Shop`의 캐릭터 데이터와 상세 상태를 소비할 수 있다. 후속 개발에서는 목록 선택 캐릭터 ID 전달·상세 진입·뒤로 복귀를 연결하고 실제 보유 상태는 기존 계약을 사용한다. 획득 전 연습·판매 가능 범위·가격/재화·온라인 조회/결제는 추가 제품 결정과 개발이 필요하다. API·저장 형식·Resource·게임 규칙·런타임 코드를 바꾸지 않았다.

## 검토 기준

카드4개→정확한 상세, 상세→목록, 타 상점 카테고리→목록, 로비→목록과 기존 기술/빠른 캐릭터 전환 보존을 확인한다. 변경 상태는 shop-r02 검토 대기이며 기존 승인63보드는 보호한다. Penpot 검사와 Android 실기기 결과는 별도다. 이번에는 실제 Android에서 새 UI를 실행하지 않았다.
