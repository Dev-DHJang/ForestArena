# 상점 캐릭터 목록 수정 독립 QA r01

2026-11-04. 독립 검토 역할 `shop_qa`. 현재 상태는 **초기 회귀 수정 확인 / 실제 표시 증거 대기**다. 아래 초기 동선 회귀의 수정을 확인했으며 새 명세·네이티브·PNG·새 뷰어 증거를 확인한 뒤 최종 판정을 갱신한다.

## 요청과 범위

사용자는 “상점에서 캐릭터도 신기처럼 캐릭터 목록을 먼저 나열하고 캐릭터 클릭 시 상점 캐릭터 디테일을 보여준다.”라고 수정 요청했다. 목록4카드 → 해당 캐릭터 기존 상세, 상세 뒤로/캐릭터 카테고리 → 목록, 로비 상점/다른 상점 탭/검토 시작 → 목록을 검토한다. 기존 상세의 기술·캐릭터 빠른 전환과 구매/연습 확인창 복귀는 유지한다.

기존 승인6종의63보드는 보존한다. 상점 r01은 사용자 승인 대기였으며 이번 변경은 shop-r02로 다시 검토한다. 가격·실제 결제·경제·API·저장·Godot 개발·Android 기기 검사는 범위 밖이다.

## 초기 명세 검토

기존 r01의 제품·데이터·자산 검토 기록과 r02 요청, `build_spec.py`, `scene-spec.json`, `revision-changes.json`을 읽었다. 새4카드 목록과20:9 비교를 추가한75보드 구성이며 자현 무료·타 캐릭터 재화 택일·가격 미정과 기존 원화를 유지한다.

**발견:** 기존 기본 묘령 상세를 목적지로 가진 모든 컨트롤을 일괄 치환하면서, 묘령 상세의 약공격 탭과 다른 캐릭터 상세의 묘령 빠른 선택도 목록으로 가게 되었다. 카테고리 진입·뒤로만 목록으로 바꾸고 기술 분류/캐릭터 상세 빠른 전환의 목적지는 보존해야 한다. 제작자에게 전달했다.

## 회귀 수정 후 명세 재확인

목적지 치환을 실제 카테고리 진입 컨트롤에 한정한 것을 확인했다. 캐릭터 상세20상태의 기술/로스터 빠른 전환180개는 r01과 정확히 같다. 상세 뒤로·캐릭터 탭, 다른 상점의 캐릭터 탭, 로비 상점·검토 시작·로딩 복귀는 목록으로 연결된다. 목록4카드는 정확한 각각의 캐릭터 상세를 연다. 전체75보드의 목적지 존재도 확인했다.

`colors`, `characters`, `item_data`, `missing_assets`는 r01과 같아 기존 가격·효과·캐릭터·실제 ID·미수록 자산 경계가 유지된다.
