# 상점 캐릭터 목록 수정 독립 QA r01

2026-11-04. 독립 검토 역할 `shop_qa`. 최종 판정은 **pass — 캐릭터 목록 우선 수정안 검토 준비 완료**다. 상점5종 shop-r02의 사용자 승인은 대기이며 실제 개발·결제·경제·API·저장·Android 기기 검사는 이 판정에 포함하지 않는다.

## 요청과 범위

사용자는 “상점에서 캐릭터도 신기처럼 캐릭터 목록을 먼저 나열하고 캐릭터 클릭 시 상점 캐릭터 디테일을 보여준다.”라고 수정 요청했다. 목록4카드 → 해당 캐릭터 기존 상세, 상세 뒤로/캐릭터 카테고리 → 목록, 로비 상점/다른 상점 탭/검토 시작 → 목록을 검토했다. 기존 상세의 기술·캐릭터 빠른 전환과 구매/연습 확인창 복귀는 유지한다.

기존 상점 r01의 제품·데이터·자산 검토, r02 요청, 명세·수정 코드·변경표·네이티브 감사·실제 화면 증거와 승인 기록을 함께 읽었다. 브라우저와 Penpot 조작은 제작자가 단독 수행했으며, 독립 QA는 실제 새 뷰어 기록/캡처와 제작 데이터·현재 네이티브 결과를 대조했다.

## 초기 발견과 해결

초기 일괄 치환은 기본 묘령 상세를 목적지로 가진 모든 컨트롤을 목록으로 바꿨다. 이때 묘령의 약공격 탭과 다른 캐릭터 상세의 묘령 빠른 선택까지 목록으로 가는 회귀를 발견해 제작자에게 전달했다.

치환을 실제 카테고리 진입 컨트롤에 한정한 후 재확인했다. 캐릭터 상세20상태의 기술/로스터 빠른 전환180개가 r01과 정확히 같다. 상세 뒤로·캐릭터 탭과 다른 상점의 캐릭터 진입은 목록으로 연결된다. 목록4카드는 각각의 정확한 캐릭터 상세를 연다. 모든75보드의 목적지 존재도 확인했다. 초기 회귀는 **해결 완료**다.

## 최종 화면·동선

- 캐릭터4종을 자현·묘령·나비·유란 순으로 먼저 나열한다. 카드408×504 전체에 상세 진입 연결이 있으며 원화·이름·역할·가격 조건은 편집 가능하다. 각 카드의 이미지와 이름이 해당 캐릭터/슬롯과 일치한다.
- `native-audit.json`:75보드, 텍스트1,493개, 기존 컴포넌트 인스턴스668개, 이동509개, 문제0건이다. 카드 내부 문자·원화와 넘침, 좌표·크기·순서·서체·터치/안전여백·기존 확인창 동작을 검사하는 감사 코드를 읽었다.
- 제작자가 실제 새 뷰어에서 수행한26단계는 모두 pass다. 4카드 원화/이름 선택, 상세 뒤로·캐릭터 탭 복귀, 묘령 기술 및 빠른 캐릭터 전환 회귀, 유란 구매 안내 닫기, 신기·조약돌·무지개돌에서 캐릭터 목록 복귀, 로비 상점 진입을 확인했다. 검토 시작·정적 로딩의 복귀 목적지는 네이티브 전수 검사로 확인했다.
- 네이티브 PNG8개와 실제 뷰어 캡처5개를 직접 보았다. 목록/상세 제목 구분,4카드·역할/가격 문구·이미지·구매 확인창에 잘림·겹침이 없다. 목록 및 상세20:9 비교에서도 중앙 배치·안전여백을 유지한다.
- 1280축소4개는 최신 원본의 RGB/LANCZOS1280×720 결과와 픽셀이 정확히 같다. 목록 축소본을 직접 보았고, 상세 축소본은 앞서 검토한 동일 배치의 원본/실제 뷰어와 함께 확인했다. 글자·간격·조작 영역이 유지된다.

## 데이터·파일·승인 원본 보존

- `colors`, `characters`, `item_data`, `missing_assets`는 r01과 정확히 같다. 자현 무료, 다른 캐릭터의 재화 택일, 가격 미정,7신기 실제 ID와 비활성 범위, 미수록26개(이미지6·영상20)는 변경하지 않았다. 신규 캐릭터·미디어·경제·저장 규칙은 없다.
- `export-index.json`의 PNG18개 전부 SHA-256·크기·바이트 수를 실제 파일과 비교해 일치했다. 네이티브8, 축소4, 연락표1, 실제 뷰어5개다.
- r01/r02 보존 스냅샷을 독립 비교해 승인63보드의 내용·배치 해시 차이가0건임을 확인했다. 기존24페이지의1,586루트 수와 라이브러리586개 정의의 ID·이름·경로도 초기 기준과 정확히 같다.
- `protected_navigation.py`와 결과를 읽었다. 승인63보드의700개 버튼과231개 이동을 원래 명세의 실제 목적지와 비교해 모두 보존됐다.
- 저장 버전은 `MENU09 상점 r02 · 캐릭터 목록 우선 · 검토대기`이며 리비전1012가 실제 기록에 있다. 화면 등록표의 상점5종은 shop-r02/승인 대기이고, 캐릭터 참조는 새 목록 보드 ID를 가리킨다. 실제 개발 승인 플래그는 모두 false다.

## 검증 범위와 한계

이번 변경 동선의 실제 검증은 위26단계다. r01의109단계 확인창/상점 검토는 바뀌지 않은 화면·동작의 과거 근거로만 사용하며 이번 변경을109단계로 새로 검사했다고 기록하지 않는다. 전체 게임 회귀는 제작자의 기존 통과 결과와 구분하고 실제 Android는 미실행이다.

사용자 목록 우선 요청은 Penpot에서 반영됐다. 새 상점 화면 승인과 미수록 자산, 가격·재화 상품·교환·실제 결제·개발 승인은 계속 별도다.
