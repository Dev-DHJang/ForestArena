# MENU09 능력치 표시 독립 QA r02

2026-11-16. 능력치 숫자의 줄바꿈과 잘림 수정은 macOS Godot 실제 렌더에서 `pass`다. Android의 수정 전 화면에서 체력 105와 지상 이동 300 등이 한 자리씩 줄바꿈되고 스크롤바 쪽에서 잘린 것을 확인했다. 값 레이블의 최소 폭 88px, 줄바꿈 끄기, 오른쪽 정렬을 적용한 화면을 검증했다. [수정 전 Android 화면](android-device-r02/04-shop-detail.png)

상점 목록에서 자현 상세를 열고 빠른 전환으로 묘령·나비·유란을 확인했다. 캐릭터 메뉴의 스탯에서도 네 캐릭터를 골랐다. 양쪽 화면을 실제 1280×720 창에서 글자 배율 1.0과 1.3으로 각각 검사했다. 16개 화면의 체력·지상 이동·공중 이동·점프·무게 80개 값과 화면 캡처를 포함해 총 446개 검사에서 실패는 0개다. [독립 검사 결과](qa/stats-r02/stats-report.json) · [재현 스크립트](qa/native_stats_probe.gd)

모든 값이 데이터의 정수 또는 소수점 두 자리와 일치하고 한 줄로 오른쪽 정렬됐다. 값 레이블의 최소 폭은 88px, 가장 넓은 글자는 58px이었다. 제목과 값의 최소 간격은 12px였으며 가로 겹침이나 잘림은 없었다. 기본 배율에서는 8개 화면의 값 40개가 처음부터 모두 보였다. 1.3배에서는 하단 12개 행을 스크롤한 뒤 제목과 값이 모두 표시됐다. 실제 PNG에서 기본 배율의 다섯 값과 확대 배율의 하단 소수점 값을 직접 읽었다.
