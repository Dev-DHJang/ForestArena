# 미션과 생활 화면 앱 반영

2026-11-11. 승인된 미션·출석·업적과 생활 화면 4종을 실제 Godot 메뉴에 연결했다. 탭, 진행 막대, 입력, 목록, 버튼, 안내창은 네이티브 Control이다. 공통 메뉴의 1280×720 논리 화면, 안전 영역과 기존 글자 크기 설정을 사용한다. [승인된 미션 설계](../missions-r01/02_ui.md) · [승인된 생활 설계](../life-r02/02_ui.md)

| 화면 | 앱 진입 | 연결 |
|---|---|---|
| 일일 미션 | 로비 미션 → 일일 | 현재 일일·주간 경기 기록, 완료·진행 상태, 상세, 집계 안내, 조회 오류와 새로고침 |
| 출석 | 미션 → 출석 | 28칸 배치 예시, 운영 안내, 출석 확인 비활성 |
| 업적 | 로비 업적 또는 미션 우측 업적 | 대전·수집·기술 분류. 대전은 기존 누적 경기 기록, 수집·기술은 운영 안내와 보상 비활성 |
| 친구 | 로비 친구 | 정확한 닉네임 검색, 친구·받은/보낸 신청·최근 상대·받은 초대. 기존 서비스 인증·작업과 LAN 초대 조건 적용 |
| 우편함 | 로비 우편 | 선택·내용·남은 시간 열과 빈 목록, 받기·삭제 작업 비활성 |
| 공지사항 | 로비 공지 또는 설정 정보 → 공지사항 | 공지·진행/지난 이벤트 탭과 각각의 빈 목록, 뒤로 복귀 |
| 설정 | 로비 설정 | 그래픽 기본 탭과 사운드·알림·계정·정보. 기존 효과·접근성·미니맵·조작·디버깅 및 음량 초안·적용 연결. 계정 → 기존 프로필 → 계정 복귀 |

미션과 대전 업적은 기존 기록과 기간 계산을 읽는다. 출석 운영, 수집·기술 업적 조건, 우편 수령, 공지 게시, 알림과 로그아웃은 제품 결정 이후 연결할 상태로 표시한다. 친구의 작업은 기존 인증과 서비스 코드에 전달한다. 앱 설정에서 그래픽의 하위 탭을 선택할 수 있으며, 사운드나 그래픽에서 편집 중인 값이 있으면 분류 이동 전에 기존 버리기 확인이 열린다. [미션·생활 화면 코드](../../../scripts/premium_menu/menu09_life.gd)

전용 검사는 별도 로컬 프로필로 미션 기록·출석·업적 상세와 복귀, 친구 검색 입력·신청·초대 탭, 우편 비활성 작업, 공지 탭과 닫기, 그래픽 기본·사운드 변경 확인·계정 프로필 복귀를 실행한다. `godot --headless --path . --script res://tests/menu09_life_runtime.gd` 명령으로 재현한다. `--resolution 1280x720`와 사용자 인자 `--ui-capture`를 사용한 렌더 실행에서 대표 7개 화면의 글자·컨트롤·표시 영역을 직접 확인했다. 로그와 화면 캡처는 `build/menu09-life/`에 있다. 연결된 Android에서 실제로 실행한 항목은 통합 작업의 별도 기록을 따른다.
