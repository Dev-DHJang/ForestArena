# 로비와 대전 화면 구현

2026-11-11. 승인된 MENU09 로비·대전 화면을 Godot 네이티브 UI로 연결했다. 1280×720 기준의 터치 영역과 안전 여백을 `Menu09MatchView`에서 배치한다. 숲 배경, 캐릭터 원화, 실버 문양, 한글 서체는 기존 리소스 ID를 사용한다.

| 승인 화면 | 실제 화면과 동선 |
|---|---|
| 메인 로비 | `home`에서 현재 캐릭터와 신기, 일반대전, 랭킹대전, 상점·캐릭터·신기·미션·업적·친구, 공지·우편·설정을 연다. 조약돌과 무지개돌 잔액은 `—`로 표시한다. |
| 일반대전 선택 | `mode_select`에서 AI 준비방과 방 목록을 연다. 자동 매칭은 운영 준비 상태를 안내한다. |
| 일반대전 방 목록 | `lan_menu`에 전체·개인전·팀전 필터, 공개 목록 준비 상태, FA5 전체 코드 참가, FAH5 호스트 연결, 오프라인 개인전·팀전 준비가 있다. 입력 오류나 방에서 나오면 선택한 필터로 돌아온다. |
| 일반·AI 대전방 | `prepare`에서 실제 오프라인 참가자를 8칸에 표시하고, 팀전은 4칸씩 두 줄로 배치한다. 준비·취소·나가기와 기존 경기 시작 경로를 연결한다. `lan_waiting`은 실제 LAN 1:1의 방장과 대기 자리, 기존 초대 코드 복사와 친구 초대를 표시한다. |
| 랭킹대전 로비 | `rank_lobby`에 기존 실버 문양과 `실버 3 · 예시`를 표시한다. 파티·친구 초대·자동 매칭은 현재 운영 상태를 안내한다. `LAN 순위 보기`에서 기존 승패 순위를 연다. |

로비의 오프라인 대전과 LAN 바로가기는 기존 경로를 유지한다. 일반대전 메뉴에서 연 방은 준비 상태를 거쳐 시작하며 나가기 확인으로 목록에 복귀한다. 스토리 버튼은 기존 스토리 프롤로그 준비 화면을 연다.

`tests/menu09_match_runtime.gd`에서 1280×720·20:9 로비 터치 영역, AI 준비·취소·시작과 실제 선택 캐릭터, 팀 최대 8인, LAN 잘못된 초대 코드 오류와 필터 복귀, 방 나가기 확인, 실버 표시와 실제 LAN 순위 진입·복귀를 확인했다. 선택한 캐릭터 이름과 AI 셀렉터의 표시값이 같을 때 직접 선택 버튼을 먼저 찾도록 노드 순서를 맞춘 뒤 `tests/local_ai_app_flow.gd`를 통과했다. 리소스 등록 검사도 통과했다.

기기 확인은 최종 통합 기록에서 확인한다. 두 대의 LAN 연결은 위 자동 검사의 범위 밖이다.

`godot --path . --script res://tests/menu09_match_runtime.gd -- --ui-capture`로 실제 로비 1280×720·20:9, 일반대전 선택, AI·팀 대전방, 방 목록, 초대 코드, 랭킹 로비를 `build/menu09-match-preview/`에 캡처했다. 로비의 오프라인 대전 글자색을 어두운 버튼에 맞춘 뒤 같은 검사를 통과했다.
