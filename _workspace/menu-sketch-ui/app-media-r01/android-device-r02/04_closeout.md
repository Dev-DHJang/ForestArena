# 실기기 검사 진행 상태

2026-11-16. 검사 대기. `adb devices -l`에서 연결된 기기가 없었고 ADB 무선 서비스 탐색에도 기기가 나타나지 않았다. 따라서 APK 설치·앱 실행·터치·영상 재생은 수행하지 않았다.

검사 대상으로 준비된 `build/android/ForestArena-debug.apk`의 SHA256은 `e8f2c2ca718acd8b76e97c1c33687bdcc85aac7e62a178757dd3179191f1d295`이며, 작업 브랜치 `codex/menu09-runtime`의 초안 PR #145에 해당한다. USB 또는 승인된 무선 디버깅으로 실제 기기를 연결한 뒤 기기 상태를 재확인하고 필요한 화면과 영상 동작만 검사한다. 이전 브라우저 기기 검사나 Mac의 Godot 검사를 앱 실기기 통과로 취급하지 않는다.
