# MENU09 앱 반영과 검증 기록

2026-11-11. 사용자 요청에 따라 승인된 손그림 21종의 화면과 상태를 실제 Godot 메뉴에 연결했다. 캐릭터·신기·상점, 로비·대전, 미션과 생활 화면의 동작은 [앱 메뉴 명세](../../../docs/ui/menu09-runtime-v01.md)와 역할 기록을 따른다.

신기 이미지 6개, 포스터 22개, Ogg Theora 영상 22개를 논리 ID로 등록했다. 실버 문양과 요요 이미지는 기존 파일을 사용한다. 제품 가격·시즌·공개 매칭·출석/우편 보상은 미정으로 표시하고 활성 로스터와 저장·서비스 계약을 유지한다. 이전 브라우저 검토에서 발견한 가로 화면 이미지 크기도 수정했다.

독립 QA에서 상점 카드·상세와 필터 92개, 실제 Godot 영상 재생·일시정지·재시작·복귀 32개를 통과했다. 영상 22개의 전체 디코드와 원본 이미지 해시, 생활·대전 화면 캡처를 확인했다. 자세한 판정과 Android 미실행 항목은 [독립 QA](03_qa_r01.md)에 있다.

전체 회귀 93개와 Godot 가져오기 1단계는 `build/verification/20261111-135207-ada6cfee/result.json`에서 통과했다. 실행 도중 상점 카드 높이와 문구, 로비 상점 문구를 수정해 변경 관련 UI 15개를 `build/verification/20261111-191726-4d359832/result.json`으로 다시 검사했다. 변경 뒤 기존 앱 흐름 및 Android 검사 도구 단위 검사도 통과했다. 생활·대전 개별 검사는 각 역할 기록에 있다.

최신 debug APK는 `build/android/ForestArena-debug.apk`, SHA256 `e8f2c2ca718acd8b76e97c1c33687bdcc85aac7e62a178757dd3179191f1d295`다. APK 패키지·브랜딩 검사와 미디어 50개 포함을 확인했다. 이 APK의 Android 실기기 재생·복귀는 기기 연결이 없어 미실행이다. 이전 Chrome 검토 페이지의 물리 기기 결과는 [별도 기록](../media-assets-r01/android-device-r01/02_mobile.md)을 따른다.

작업 브랜치는 `codex/menu09-runtime`, 기준 커밋은 `f116eb3f2dc7515bcc896ba302dc9ef507d51cbf`다. 실기기 검증 결과, PR·병합과 되돌리기 정보를 이어 기록한다.

2026-11-11. 구현과 증적은 [초안 PR #145](https://github.com/Dev-DHJang/ForestArena/pull/145)에 올렸다. 구현 커밋은 `2e91615bb20ee503acc72a77e2d914f57aaa1f14`이다. Galaxy S23 Ultra가 ADB 목록에 다시 나타나면 위 APK의 재생·일시정지·복귀와 대표 화면 터치를 확인한다. 이후 QA 결과와 변경 없는 APK 해시를 대조하고 PR 상태와 병합 기록을 갱신한다.
