## 자산과 네이티브 재생

검토 자산 29슬롯과 앱 미디어 목록을 독립 대조했다. 신규 등록 50개를 포함해 리소스 목록의 고유 ID가 571개이며, 기존 521개 항목은 기준 커밋의 내용과 일치한다. 신기 PNG 6개·포스터 PNG 22개는 원본 SHA256과 일치한다. 기존 실버·요요 PNG도 각 기존 ID와 파일로 연결된다. Ogg Theora 22개는 전부 독립 디코드에 성공했고 960×540, 30fps, 무음과 MP4 원본 길이를 확인했다. [자산 검사 결과](qa/app-media-integrity.json)

OGV에서 나비 상향 강공격, 자현 목도리 특수, 묘령의 4타, 요요 발사, 철갑옷 정보를 추출해 직접 확인했다. 나비의 위를 향한 발톱과 자현의 위로 든 목도리, 묘령의 마지막 발차기, 요요의 손과 실 연결, 철갑옷의 무게 +5%·지상 속도 -5%와 비활성 상태가 읽혔다. [나비 강공격](qa/nabi-heavy-ogg.png) · [자현 특수](qa/ja-hyun-special-ogg.png) · [묘령 약공격](qa/myo-ryung-light-ogg.png) · [요요](qa/accessory-pebble-yoyo-ogg.png) · [철갑옷](qa/accessory-iron-armor-ogg.png)

실제 macOS Godot 앱에서 네이티브 재생 표본 3종, 32개 검사가 통과했다. 캐릭터 기술에서 자현 약공격, 신기 방어 분류에서 철갑옷, 상점 나비 상세에서 강공격을 열었다. `ForestArenaResources.load_video()`의 논리 ID와 앱 플레이어가 같은 Theora 경로를 사용했고, 재생 위치가 진행하며 960×540 텍스처가 렌더됐다. 일시정지 동안 같은 위치가 유지됐고 이어서 재생했을 때 진행했다. 철갑옷의 재생 완료·다시 재생, 버튼 닫기와 앱 뒤로 처리의 플레이어 해제, 선택 화면 복귀, 앱 중단 알림의 일시정지를 확인했다. ## 상점과 선택 경계

상점 카드의 원화 영역을 좌표 입력으로 눌러 자현 상세를 열고, 상세의 나비 버튼으로 항목을 바꾼 뒤 캐릭터 목록으로 복귀했다. 신기 방어 분류는 철갑옷을 선택하고, 방어를 마지막으로 본 뒤 프리셋 편집으로 들어가면 전체 또는 공격 분류로 복구돼 요요를 고를 수 있다. 도감 상세에는 읽기 전용 안내와 뒤로 동선이 있다. 기존 무료 구매 경로는 활성 항목과 현재 보유 상태를 확인하고, 확인 후 기존 프로필 저장을 사용한다. 묘령·유란과 기존 신기 6종은 소개 상태로 표시하며, 조약돌과 무지개돌은 상품·조건 미정 표시를 확인했다. [상점 검사](qa/native-shop-report.json) · [상점 검사 스크립트](qa/native_shop_probe.gd)

초기 카드의 글자 37개가 카드 밖에 배치됐고 최대 97px가 초과됐다. 긴 설명을 상세에 배치한 뒤 큰 글자에서 상세 안내 8개가 16px씩 초과됐다. 카드 최소 높이를 312px로 맞춘 뒤 1280×720, 글자 배율 1.0·1.3의 레이블 경계와 위 동선을 합한 92개 검사가 통과했고 초과는 0px였다. 상점 가격 안내는 현재 판매 가능한 항목으로 범위를 좁혔고 로비 버튼명은 `상점`으로 확인했다. [초기 카드 문제 기록](qa/native-shop-initial-fix.json) · [최종 상점 결과](qa/native-shop-report.json)

출석·우편 등 운영이 미정인 기능의 비활성 표시, 공지와 친구의 실제 빈 상태, 그래픽 설정의 기본 진입을 생활 화면에서 확인했다. 방 목록은 공개 검색 준비 상태와 실제 코드 입력을 표시하고, 랭킹은 예시 시즌 등급과 기존 LAN 순위 진입을 구분한다. 현재 제품에서 운영하는 실제 구매·설정·기기 저장·LAN 계약은 기존 기능 연결을 기준으로 확인했다. 앱 전환 중단 검사는 macOS 앱의 중단 알림을 직접 발생시킨 표본이다. 물리 Android 재생, 홈 복귀, 실제 두 기기 LAN은 이번 독립 검사에서 미실행이다.

Android가 다시 연결되면 최종 APK로 로비→캐릭터 기술→재생·일시정지·닫기, 상점→신기 상세→복귀, 랭킹 로비와 앱 홈 중단·복귀를 확인한다. 당시 기기 모델, APK 해시와 캡처를 통합 기록에 남긴다.
