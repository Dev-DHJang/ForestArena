# 추가 개발 내용 실기기 간단 검사

2026-10-17 사용자 요청: 추가 개발 내용을 간단히 실기기에서 테스트한다.

- 최신 승인 모션90종이 포함된 Android debug APK를 생성하고 연결된 Galaxy S23 Ultra 한 대에서 확인한다.
- 저장 데이터를 삭제하지 않고 기존 앱을 업데이트한다. 묘령·나비·유란 선택과 전투 표시, 기본 터치 입력·점프·공격, 일시정지·백그라운드 복귀를 짧게 점검한다.
- 화면·앱 로그·빌드 결과를 증거로 남기며 기기 주소·포트·페어링 코드·ADB 키는 기록하지 않는다.
- 90종 전체 개별 재생·모든 장신구 조합·LAN 두 실기기·장시간 성능·오디오 청취는 이번 간단 검사에 포함하지 않는다.
- 게임 코드·판정·승인 자산을 고치지 않고 결과와 미확인 항목을 구분한다.
