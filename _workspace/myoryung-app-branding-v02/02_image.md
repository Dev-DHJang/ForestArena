# 묘령 상반신 아이콘 v02 이미지 기록

2026-10-20. 사용자 첨부 원본을 일반 아이콘의 구도로 확정했다. 얼굴만 분리했던 v01을 보존하고, 목·어깨·분홍/흰 상의가 자연스럽게 이어지는 v02를 별도 제작했다. 승인 캐릭터 원본은 변경하지 않았다.

## 원본과 제작

- `source/concept-icon.png`: 사용자가 선택한 첨부 이미지. 일반 아이콘은 이 정사각형 원본을 그대로 1024px와 192px로 축소한다.
- `source/foreground-source.png`: 이전 중단 세션의 built-in image_gen 투명 상반신 결과. 실제 알파를 보존하고 재생성하지 않았다.
- `source/forest-source.png`: v01의 단순 숲 배경을 재사용한다.
- 원본 출처·SHA-256·생성 요구사항은 `input-provenance.json`에 기록한다. 이전 세션 생성 프롬프트 원문은 회수 여부를 구분해서 기록한다.
- Godot `Image` API로 결정적인 크기 조정·층 배치·마스크 미리보기만 수행했다. 이미지 편집을 위한 Python 대체 생성은 하지 않았다.

## Android 사용 규격

일반 아이콘은 1024px 원본과 192px 출력이다. 적응형은 432px 배경과 투명 전경으로 분리했다. 상반신 전경은 360×360px로 축소해 (36,10)에 놓았다. Android의 중앙 288×288px 보이는 영역에서 얼굴·눈·입이 유지되고 목·어깨·옷이 아래쪽 경계까지 이어진다. 귀 끝은 런처 마스크에 따라 잘릴 수 있다.

`previews/contact-sheet.png`는 일반/적응형 × 원형/둥근 사각형 × 48/72/192px의 12개 결과다. 실제 축소 이미지에서 얼굴이 떠 있는 빈 공간과 분리된 목이 없고, 분홍 의상과 어깨가 연속되는 것을 확인했다. 문자·로고·추가 장식은 넣지 않았다.

사용 자산은 `assets/branding/myo-ryung-v02/manifest.json`에 크기·알파·해시·사용 위치를 기록한다. 이는 기존 사용자 제공 승인 캐릭터의 AI 파생 이미지이며 제3자 권리 확인을 새로 보증하지 않는다.
