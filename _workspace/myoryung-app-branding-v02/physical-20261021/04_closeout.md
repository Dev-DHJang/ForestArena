# 묘령 아이콘 v02 실기기 확인 마무리

2026-10-21. Galaxy S23 Ultra(SM-S918N), Android16에서 지정된6개 검사를 수행했고 독립 품질 확인을 통과했다. 기존 데이터를 유지한 업데이트 설치이며 설치된 APK SHA-256은 빌드의 `5050b0021cc72159852275ce8024c0f04603f1fd662d70ad41a7db82dd632763`와 일치한다.

실제 런처 아이콘의 상반신 연결, 런처 첫 실행, 강제 종료 뒤 새 프로세스 재실행, Godot 시작 로고 미표시, 게임 시작 터치, HOME 중단·복귀를 확인했다. 복귀 전후 로비는 RGBA 픽셀이 동일하다. Android activity 시작821ms를 전체 로딩 시간으로 기록하지 않는다.

화면·앱 전용 녹화·해시는 `qa-evidence.json`, 실행 결과는 `device-test-results.json`, 독립 판정은 `03_qa_r01.md`를 참고한다. 개인 런처 UI가 섞인 임시 원본·모음은 .gitignore로 제외했다.

새 기기 최초 설치·오디오 청취·장시간 전투 성능·다른 Android 기기는 검사하지 않았다. 이 APK의 기존 Godot 로비를 검사했으며 메뉴 v08은 Penpot 작업으로 계속 진행한다. 커밋·PR·전체 병합과 롤백은 상위 메뉴 v08의 04_closeout.md에서 관리한다.
