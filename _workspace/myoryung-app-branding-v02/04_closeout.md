# 묘령 상반신 아이콘 v02 마무리

2026-10-20. 첨부 이미지의 얼굴·목·어깨·몸이 이어지는 구도로 일반·적응형 앱 아이콘을 적용했다. 일반 아이콘은 사용자 선택 원본을 그대로 사용했고, 적응형은 이전 중단 작업의 투명 상반신 생성 결과를 회수해 사용했다. v01과 승인 캐릭터 원본은 보존했다.

## 완료

- v02 자산 4종, 원본·출처·해시 manifest, 12개 크기/마스크 미리보기와 비교 시트.
- 프로젝트 아이콘 및 Android Debug·Demo 두 내보내기 설정 갱신. Godot 시작 로고 숨김과 시작 장면 보존.
- 실제 새 APK 생성, 네이티브 아이콘과 시스템 시작 아이콘 픽셀 비교, 패키지 프로젝트 설정 검사 통과.
- 목·어깨·옷이 연결되는 구도를 48/72/192px 원형·둥근 사각형 출력에서 수동 확인.

## 미검증과 한계

- 2026-10-21 Galaxy S23 Ultra·Android16 실기기에서 설치·런처·첫 실행·재실행·Godot 로고 숨김·HOME 복귀를 실제 확인하고 독립 QA 통과했다. 세부 증적은 `physical-20261021/04_closeout.md`에 있다.
- 새 기기 최초 설치·오디오 청취·장시간 전투 성능·다른 Android 기기는 미검증이다.
- 회수한 투명 상반신의 실제 생성 파일과 SHA-256은 확보했다. 생성 프롬프트 원문 회수 여부는 `input-provenance.json`에 별도로 명시한다.
- 메뉴 v08 작업과 저장소 전체 검사는 주 작업에서 별도 통합한다. 이 하위 작업은 Godot 메뉴 배치·공개 API·저장 형식을 변경하지 않았다.

검사 명령과 증적은 `02_mobile.md`와 `branding-checks.json`, 이미지 규격은 `02_image.md`와 자산 manifest를 참고한다. 전체 통합·독립 품질 확인·커밋은 주 작업 담당자에게 인계한다.
