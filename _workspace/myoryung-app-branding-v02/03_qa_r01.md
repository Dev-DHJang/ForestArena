# 묘령 상반신 아이콘 v02 독립 품질 확인 r01

2026-10-20. 생산 코드와 자산은 수정하지 않고 요청·이미지·Android·마무리 기록, manifest와 출처, 실제 PNG 및 새 APK를 독립 확인했다.

## 판정

**PASS — 이미지·설정·새 APK 검사. Android 실기기 설치·런처·첫 실행·재실행은 미검증.** 연결 가능한 기기가 있을 때 수행하는 조건부 검사이므로 이 미검증을 이미지·패키지 통과와 분리했다. 전체 저장소 검사는 주 작업에서 별도로 통합한다.

## 시각 확인

`previews/contact-sheet.png`의 일반/적응형 × 원형/둥근 사각형 × 48/72/192px 12개를 직접 확인했다. 목·어깨·분홍/흰 상의가 이어지고 하단 경계까지 몸이 연결된다. v01의 분리된 머리 구도를 사용하지 않았다. 일반 아이콘은 사용자 첨부 구도를 유지하고 적응형은 얼굴을 더 크게 배치했다. 원형의 귀 끝 잘림은 계획에 명시된 허용 범위이며 얼굴·눈·입은 읽힌다. 작은 48px에서도 얼굴과 분홍 의상이 구분된다.

`source/concept-icon.png`와 사용자의 실제 첨부 `exec-acd48f1a-398f-4227-afb9-b626fa40da60.png`의 바이트 동일을 독립 확인했다. 원본 추출·출처와 회수한 전경 프롬프트 미회수 사실을 구분해 기록했다.

## 자동·정적 검사

생산자의 검사 결과를 읽은 뒤 별도 Python/Pillow/NumPy 코드로 실제 APK를 다시 열고 비교했다. 원본 자산 4종의 manifest SHA-256과 크기를 확인했다.

- APK SHA-256: `5050b0021cc72159852275ce8024c0f04603f1fd662d70ad41a7db82dd632763` — 이전 v01 APK와 다른 새 파일이다.
- 일반 아이콘과 적응형 배경: RGBA 픽셀 동일.
- 적응형 전경과 시스템 시작 아이콘: 알파·불투명 RGB 동일. 알파를 곱한 평균 RGB 차이 `0.0102829666/255`이며 WebP 변환의 투명 경계 차이를 가시적인 큰 변경으로 오판하지 않았다. 생산자의 int16 계산은 RGB 차이 계산에서 overflow가 없고 전경의 실제 알파도 보존한다.
- 시스템 하단 브랜드 이미지: 모든 알파 0.
- APK에 들어간 프로젝트 아이콘 PNG: 원본 파일과 바이트 동일.
- 실제 `project.binary`를 임시 폴더로 읽어 Godot `ProjectSettings` 확인: `show_image=false`, `minimum_display_time=0`, `main_scene=res://scenes/startup_title.tscn`, 아이콘 v02.
- Git diff의 프로젝트 변경은 아이콘 경로 한 줄이며 기존 시작 화면과 로고 숨김 설정을 보존했다. Android Debug·Demo 두 내보내기 설정 모두 일반·적응형 전경·배경 3개 경로가 v02다.

## 미확인

새 APK가 실제 기기에 설치되어 런처·첫 실행·재실행에서 보이는 모습은 확인하지 않았다. 생산자의 연결 기기 없음 기록과 마무리 문구는 이를 통과로 표현하지 않는다. APK 검사와 시각 미리보기를 실제 Android 기기 증거로 대체하지 않았다.

차단 결함 없음. 별도 메뉴 v08의 최종 PNG·클릭 경로 검토는 이 아이콘 통과에 포함하지 않는다.
