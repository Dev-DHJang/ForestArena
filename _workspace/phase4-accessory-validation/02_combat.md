# 장신구 검증 구현

## 검사 경계

- `CombatEffectData.tags`는 공격 태그 중 하나가 맞을 때만 조건 효과를 실행한다. 맞는
  태그와 맞지 않는 태그를 모두 실제 효과 전달 경로에서 검사한다.
- `Character → 부모 직업 → 현재 직업 → 장신구` 순서에서 같은 수치에
  `ADD → MULTIPLY → OVERRIDE`를 적용해 마지막 장신구 값이 최종값이 되는지 검사한다.
- 한 데이터 층에서 같은 수치를 두 번 쓰는 모호한 장신구는 거부한다.
- 복싱 글러브의 전체 `MoveSet` 교체를 네 캐릭터 모두에서 만들고, 기술·연계가 원본의
  변경 없는 복사본인지 검사한다.
- 중복 공격 ID, 중복 연계와 존재하지 않는 다음 공격을 가진 `MoveSetData`는 거부한다.
- 장신구 아이콘과 애니메이션의 속도·프레임·색·표시 여부를 바꾼 뒤에도 파이터 전투
  snapshot이 같아야 한다.

## 계약 보강

`MoveSetData.is_valid_definition()`은 공격 ID, 시작 공격 ID, 연계 정의와 취소 정의의
완전 중복을 명시적으로 거부한다. `CombatEffectData`와 `CombatRuleData`의 조건 태그도
`AttackData.VALID_TAGS`에 있는 태그만 허용한다. 구버전을 추정하거나 알 수 없는 태그를
조용히 받아들이지 않는다.
