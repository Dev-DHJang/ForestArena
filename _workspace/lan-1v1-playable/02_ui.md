# 화면과 조작 적용

- 홈에 `LAN 1:1 · 같은 Wi-Fi`를 추가하고 코드 붙여넣기, 방 만들기·참가·초대 코드 복사·대기·전투·결과·재대전을 연결했다.
- 화면에는 로그인·결제·랭크·친구·채팅을 표시하지 않는다.
- Story는 `스토리 프롤로그 · 첫 기록인장`으로 표시해 보상·성장 없는 현재 범위를 밝힌다.
- LAN 카메라는 자기 캐릭터를 따라가며 화면 밖 상대 화살표와 기존 HUD·터치 조작을 재사용한다.
- 임시 전투 D-pad와 행동 버튼은 승인 Forestlight SVG로 교체했다. 행동 글자는 SVG와 분리해
  런타임이 약·강·특수·궁극기 의미를 올바르게 표시한다.
