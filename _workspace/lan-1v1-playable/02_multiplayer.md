# LAN 대전 의미

- 방장 `lan_host`와 참가자 `lan_guest` 두 슬롯만 존재한다.
- macOS 서버가 기존 3 stock·HP·링아웃 전투를 60Hz로 계산한다.
- Android는 입력만 전송하고 20Hz 상태와 전투 표현 이벤트를 표시한다.
- 연결 해제 즉시 해당 슬롯 입력을 풀고 60초 안에는 회전형 토큰으로 같은 슬롯에 복귀한다.
- 60초가 지나면 이탈 패배, 결과 뒤 두 사용자가 20초 안에 동의하면 새 seed로 재대전한다.
- 세 번째 참가자, 잘못된 캐릭터·장신구, 중복 입력 순번은 서버가 거부한다.
