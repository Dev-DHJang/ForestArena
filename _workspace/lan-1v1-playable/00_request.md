# 요청

macOS 호스트 PC 한 대와 같은 Wi-Fi의 Android APK 두 대가 로그인·결제·인터넷 없이 실제 1대1 대전을 끝내고 재대전할 수 있게 한다.

## 확정 범위

- 한 호스트에서 한 경기만 운영하며 방장과 참가자는 한 줄 연결 코드로 만난다.
- 자현·묘령·나비·유란, 미장착과 무료 장신구 6종을 지원한다.
- 서버가 60Hz 전투 결과를 정하고 20Hz snapshot을 보낸다.
- AI·연습·Solo·Team 오프라인 흐름을 보존하고 Story는 보상·성장 없는 프롤로그로 표시한다.
- Android debug APK와 macOS 호스트 도구를 실제 두 기기에서 검증한다.

## 후속 범위 조정

- 2026-10-08 사용자 결정으로 물리 Android 두 대 검증은 다음 계획으로 옮겼다.
- 이번 작업은 자동 두 클라이언트와 Android 에뮬레이터의 실제 macOS LAN 접속·결과·재대전,
  debug APK 설치까지를 완료 조건으로 사용한다.

## 제외

- 정식 로그인, 결제, 인터넷 매칭, 중앙 서버, 랭크, 채팅, 음성, 클라우드와 Google Play 출시.
- release AAB, 출시 서명, 스토어 등록정보와 운영 서버 배포.
