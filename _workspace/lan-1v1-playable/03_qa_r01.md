# 품질 확인 r01

## 통과

- `./scripts/verify.sh`: 전투, 16개 AI 대진 장시간 경기, 터치, 저장, 장신구 6종,
  LAN 계약·실제 WebSocket 두 클라이언트, 기존 개발 온라인, 346개 논리 자산, 문서와
  하네스 전체 통과.
- `./scripts/verify-lan-runtime.sh`: 방 생성·참가, 네 캐릭터·장신구 로드아웃, protocol 오류,
  없는 로드아웃, 잘못된 입력, 8KiB 초과 메시지, 중복 입력, 세 번째 참가, 연결 해제·복귀,
  이탈 결과, 재대전과 방 닫기 통과.
- `./scripts/lan-host.sh start|status|stop`: macOS Wi-Fi `192.168.45.135:7777`에서 실제 시작,
  한 줄 호스트 코드 출력, 상태 확인과 종료 통과.
- `./scripts/export-debug-android.sh`와 `./scripts/verify-android-package.sh`: debug APK 생성,
  arm64·x86_64, API 29~36, 가로 화면과 `INTERNET` 권한 계약 통과.
- `./scripts/verify-android-emulator.sh`: `emulator-5554`에 최종 APK 설치, COLD 시작, 가로 화면,
  경기 진입·터치, Home 중단, HOT 복귀, 일시정지와 로비 복귀 통과.
- 최종 APK SHA-256:

- 최종 화면: [Android 에뮬레이터 경기](evidence/android-emulator-stage.png), 2400×1080,

## 관찰

- Godot의 일부 기존 headless 검사는 종료 시 `ObjectDB instance was leaked` 경고를 출력한다.
  검사 종료 코드는 0이고 동일 경고가 LAN 변경 밖의 기존 전투 검사에도 있다. Android 실행 중
  오류 로그나 진행을 막는 증상은 확인되지 않았다.

## 미확인

- ADB에는 에뮬레이터 한 대만 보였다. 이전 실기기 주소 `192.168.45.109:42313` 재접속은
  `Connection refused`였으므로 물리 Android 두 대의 LAN 한 판·재대전은 통과로 기록하지 않는다.
- 물리 기기 두 대에서 Wi-Fi 단절·60초 복귀, 앱 중단·복귀, 서로 다른 화면 비율의 터치,
  진동·사운드와 장시간 성능 측정은 미확인이다.
- 패키징·출시 서명·AAB·스토어 등록은 사용자가 이후로 미룬 범위다.
