# 품질 확인 r02

## Android에서 실제 macOS LAN 접속

- macOS 서버: `ws://192.168.45.135:7777`, Godot headless 60Hz 한 경기 서버.
- Android: `emulator-5554`, 최종 debug APK, Android 15.
- 두 번째 참가자: Godot `tests/lan_android_guest.tscn`, 유란·복싱 글러브.
- Android 앱에서 `FAH1|ws://192.168.45.135:7777|1`을 입력해 방 생성 성공.
- 실제 초대 코드가 표시된 화면: [LAN 참가자 대기](evidence/android-emulator-lan-waiting.png),
  SHA-256 `c71e2d43ea82c1671286e0afd4c62dee58a03ebaca56f40a5d8759e727015107`.
- 두 번째 클라이언트가 참가해 Android가 `lan_match`로 전환했고, 서버 결과 뒤
  `lan_result` 화면과 재대전 버튼이 나타났다.
- Android에서 20초 안에 재대전을 요청해 두 번째 `match_start`를 받았고, 두 번째 결과와
  방 닫기까지 완료했다.

관찰 로그:

```text
LAN_ANDROID_GUEST: JOINED
LAN_ANDROID_GUEST: ROUND_1_READY
LAN_ANDROID_GUEST: ROUND_1_END
LAN_ANDROID_GUEST: WAITING_FOR_ANDROID_REMATCH
LAN_ANDROID_GUEST: ROUND_2_READY
LAN_ANDROID_GUEST: ROUND_2_END
LAN_ANDROID_GUEST: PASS
```

## 판정

- pass: Android APK의 `INTERNET` 권한, 사설 Wi-Fi WebSocket, 한 줄 코드, 방 생성·참가,
  서버 상태 표시, 결과와 재대전이 실제 Android 런타임에서 연결됐다.
- 다음 계획: 물리 Android 두 대의 사용자 플레이, Wi-Fi 단절·60초 복귀, 진동·사운드와
  장시간 성능. 사용자가 명시적으로 다음 계획으로 옮겼으므로 이번 작업의 실패나 미완료로
  처리하지 않는다.
