# Android 적용

- 같은 Wi-Fi WebSocket에 필요한 `android.permission.INTERNET`만 export preset에 추가했다.
- 앱 중단·초점 손실 때 눌린 입력을 풀고 연결이 끊어졌으면 60초 재접속 흐름으로 들어간다.
- LAN 클라이언트는 오프라인 전투 코드를 실행하지 않고 서버 snapshot만 표시한다.
- Android 에뮬레이터에서 최종 APK 설치·터치·중단/복귀와 macOS 실제 Wi-Fi 주소의 LAN
  방 생성·결과·재대전을 확인한다. 물리 Android 두 대 검증은 사용자 결정에 따라 다음 계획의
  별도 품질 확인으로 남긴다.
