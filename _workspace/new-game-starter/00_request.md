# 새 게임 기본 뼈대 압축 파일 요청

- 날짜: 2026-10-09
- 목표: 앞으로 새 게임마다 재사용할 문서·작업 절차·최소 스킬·실행 가능한 구조 검사를 ZIP 하나에 담는다.
- 기준: `docs/operations/new-game-bootstrap.md`와 사용자의 이전 확정 범위.
- 기본: 엔진 공통 구성, 단일 에이전트, 엔진·플랫폼 미정, 외부 도구 없음. Godot·Android는 선택 문서만 포함한다.
- 산출물: `artifacts/new-game-starter-v1.zip`, 재생성 도구·검사·사용 안내, 요청·마무리 기록.
- 제외: 게임 코드, Forest Arena 자산·고유 규칙·패키지·DB·LAN·원격 병합 정책 복사, 설치·계정 연결.
- 완료 조건: ZIP을 임시 폴더에 풀어 기본 구조 검사, 실제 새 이름·ID 설정, 재실행, Godot·Android 선택 구성과 실패 상황을 확인한다. 기존 사용자 파일을 덮어쓰지 않는다.
- 작업 구조: 단일 에이전트가 작성·검토·패키징을 순서대로 수행한다. 역할 구분은 에이전트 실행 수를 뜻하지 않는다.
- 검사: 패키지 시나리오 자동 검사, ZIP 내용·출처 식별자·빠진 파일 검사, 프로젝트 문서·역할·기본 검사.
