## 관찰과 판단

- 은백색 머리와 파란 눈, 흰색·검정·코발트 의상, 인간형 얼굴·손·발, 두 둥근 귀와 한 가는 꼬리, 긴 파란 리본이 유지된다. 동물 주둥이·발바닥형 손발·추가 꼬리를 보지 못했다.
- combat는 오른쪽 3/4 낮은 가드이며 양발을 벌리고 무릎을 굽힌다. front는 정면 중립, side는 한 눈·겹친 어깨/골반/신발이 보이는 오른쪽 측면, rear는 얼굴이 보이지 않는 후면이다. 측면 반대 귀는 겹침으로 가려지며 추가 귀를 만들지 않았다.
- 같은 머리 기준에서 combat 몸 높이627.1px가 중립640px보다 낮다. 정면·측면 머리 높이의 약5.7% 차이는 각도와 기준점 추정 범위 안에서 보이며 체형이 다른 인물로 바뀌는 문제는 보지 못했다.
- 128px와 반전에서 둥근 귀·가는 꼬리·파란 리본이 읽히고 전체 외곽이 잘리지 않는다. 384px 비교에서도 얼굴·머리·의상 재질의 공통 작화가 유지된다.
- rear 턱은 앞모델에서 투영한 가려진 점이며, 실제 목/머리카락 경계와 다르다. side 반대발 중심도 가려져 추정했다. 두 항목은 notes/estimated로 남아 있어 실측과 구별된다.

## 최종 코드·문서 독립 검토

- `combat_reference.py`의 초안 전용 배치 경로, PNG/원본/외형 계약 해시 확인, 균일 배치 재현, 중립640px·발기준896·정면/측면2.6~3.4 및 각도별 머리8% 재검토 기준을 읽었다. 구조 검사가 실제 머리/턱의 의미를 자동 증명하지 않는다는 한계를 확인했고, 나비 기준점 표시판도 직접 보았다. 귀와 묶은 머리를 제외한 머리 본체 위의 중심점으로 표시돼 있다.
- 앞선 독립 검토에서 찾은 4등신 세트 통과와 다른 캐릭터 승인 기록 연결 문제에 대해 비율 검사 및 구조화된 승인/QA의 캐릭터·버전·대상 이미지 해시·관찰 근거 대조가 추가됐다. 해당 회귀 코드와 검사 선택 등록을 읽었으며 정식 승인 판정을 단순 파일 존재로 대신하는 문제는 해소됐다. 자동 검사의 pass가 실제 사용자 발언·시각 판단을 자동 증명하지 않는다는 출력과 문서도 확인했다.
- 새 제작 기준 문서와 image-design/2d-animation/qa 스킬 연결은 정면 구성 모델 우선·참조 PNG 직접 첨부·해시 기록·표정과 후속 움직임의 허용·기존 모션 유지·사용자 승인 전 등록 금지를 설명한다. 게임 전투/저장/통신 형식이나 현재 리소스 연결을 바꾸는 변경은 보지 못했다.
- 생성 이력은 실제 입력·프롬프트·해시를 기록하고, 등록 계획은 installation_allowed=false이다. 실제 `assets/character`와 manifest·런타임은 변경되지 않았다. 승인 대기 자료로 제시하는 데 막는 문제는 찾지 못했다. 91항목 전체 검사와 이후 문서 재검사 pass는 제작 담당의 실행 결과이며 본 검토는 같은 전체 검사를 이유 없이 반복하지 않았다.
- PNG를 직접 보는 정지 검토로 수행했다. 브라우저 미리보기 자동 열기·실제 모션·Android 기기·사용자 채택 승인을 수행했다고 기록하지 않는다.
