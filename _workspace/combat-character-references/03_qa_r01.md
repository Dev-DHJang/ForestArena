# 대표 이미지 독립 QA — 초기 접근 검토

- 검토자: reference_qa. 2026-10-29. 제작 담당과 분리해 PNG와 승인 콘셉트를 직접 비교했다.
- 초기 자현 중립 정면·측면과 묘령 정면은 머리가 작아 약3.7~4.5등신으로 읽혀 fix였다. 초기 자현 측면도 3/4에 가까웠다.
- 자현 front-r02는 큰 머리·짧은 몸으로 개선됐지만 초기 생성 combat와 구성 비율이 달라 그대로 한 세트로 채택할 수 없었다.
- 같은 원인이 두 회차 반복돼, 초기 combat를 고정한 채 중립을 맞추는 접근을 중단했다. 승인 콘셉트의 정체성을 유지한 새 neutral front를 먼저 구성 모델로 정하고 combat/side/rear를 다시 만드는 접근으로 재분류했다. 구버전은 원본 r01 폴더에 보존한다.
- 후면 턱은 직접 보이지 않으므로 추정 표시를 요구했고, 가려진 반대발도 실측으로 취급하지 않도록 했다.
- 이 기록은 초기 문제와 접근 변경의 증거다. 교체된 이미지에 초기 pass를 재사용하지 않으며, 최종 세트는 r03 이후의 해시별 QA를 따른다.
