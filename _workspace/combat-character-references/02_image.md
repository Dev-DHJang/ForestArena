# 대표 이미지 제작과 접근 변경

## 사용 도구와 원본

내장 imagegen을 사용한다. 기존 승인 콘셉트 PNG와 외형 계약을 입력한다. 생성마다 실제 프롬프트는 01_sources/<character-id>/에 보존한다. 생성 원본은 변경하지 않고 공통 캔버스 배치본을 별도로 만든다.

## r01 → r02 접근 재분류

최초에는 대전 기본 자세를 만들고 정면·측면·후면으로 바꿨다. 독립 QA가 자현 r01 정면·측면, 묘령 r01 정면에서4등신에 가까운 길쭉한 체형을 확인했다. 자현 r02 정면은 큰 머리·짧은 몸을 회복했으나 초기 combat와 비율이 달랐다. 같은 원인2회로 접근을 재분류했다.

승인 콘셉트에서 중립 정면 구성 모델을 먼저 맞추고, 이 모델을 직접 첨부해 combat/side/rear를 다시 만든다. 초기 combat를 최종 기준으로 강제하지 않는다. QA는 자현 r02 정면이 승인 콘셉트와 약3등신 작화 범위에서 시범 모델로 사용 가능함을 확인했으며, 최종 세트 pass는 아직 아니다. 거부된 r01은 해당 원본의 r01/에 보존한다.

기준점을 옮기거나 신체를 부분 확대해 수치를 맞추지 않는다. 후면의 가려진 턱은 추정임을 표시한다. 승인·QA 기록은 검토한 실제 이미지 해시에 연결한다.

## 선택 이미지의 실제 입력 이력

generation-index.json이 선택16장의 원본·실제 프롬프트·첨부 이미지와 해시를 연결한다. 자현 front-r02는 r01 combat와 거부된 r01 front 두 파생 이미지를 수정 입력으로 사용했다. 승인 콘셉트는 이 호출에 직접 첨부하지 않았고, 최종 독립 QA에서 승인 콘셉트와 직접 비교했다. 나머지 정면은 승인 콘셉트와 초기 combat, 최종 combat/side/rear는 새 정면 모델과 승인 콘셉트를 첨부했다. 모든 선택 호출이 승인 콘셉트를 직접 첨부했다고 기록하지 않는다.

## 배치와 검토 자료

combat_reference.py layout이 원본 전체에 균일 배율·이동만 적용한다. 신체 부위를 따로 편집하거나 원본 픽셀을 덮지 않는다. 기준점은 QA가 원본을 직접 보고 권고한 시각 추정값이며 숨은 반대발·후면 턱은 notes와 추정 표시로 구분했다. 02_candidates/의 PNG16장은1024×1024 실제 RGBA, 중립 몸640px·발y896이다.

03_review/의 캐릭터별 review.png는384px/128px·반전 비교판, landmarks.png는 정수리·턱·발과 기준선 표시 자료다. overview.png는16장 전체 비교판이다. 검토용 합성 자료는 Pillow로 조립했으며 정식 PNG의 그림을 바꾸지 않는다. index.html은 배경·크기·반전·기준점 확인용 로컬 정지 이미지 화면이다. Work 설정에서 로컬 브라우저 자동 사용이 비활성화되어 자동 화면 조작 검증은 수행하지 않았고 PNG는 직접 시각 검토했다.
