# 전투 변경과 검사

현재 자현·나비 CombatRules에만 피격 계산 결과2배·착지 다운36·가드 붕괴60·낙하 장외를 켰다. 기존 기반 규칙의 기본값과 승인 PNG·SpriteFrames·manifest는 보존했다. 콤보 예약 구간은 회복 시작 기준 -12..17이며, 준비 중 예약도 회복 종료 후 실행한다.

가드 해제 함수를 방향 변경·일시정지·LAN 입력 해제에 함께 사용하며 붕괴 때 실제 가드도 끈다. 기존 승인 hold frame11에서 멈추는 표시 분기를 명시했다. 다운 표시 시간은 상태가 전달한 전체 길이를 읽는다.

FALLING_OUT은 기존 상태 번호 뒤에 추가했다. 입력 전 및 이동 뒤 타격/몸 충돌 전에 아래 경계를 검사해 낙하로 전이한다. 비표시선 뒤60 tick은 MatchController가 한 번씩 계산하고 같은 tick의 전체 기회 상실 뒤 승패를 확정한다. 기존 RING_OUT은 부활 대기로 유지한다. 카메라·표시는 이 계산에 관여하지 않는다.

LAN snapshot에 남은 경직·다운 전체 길이·낙하 비표시/남은대기·실제사각형을 전달한다. 로컬 debug getter는 공격 resolver와 같은 영역을 읽고 LAN은 수신한 사각형을 표시한다.

회귀 검사 중 Godot StringName의 비교가 문자열 순서와 다른 것을 실제 확인했다(name_order=false/string_order=true). 거리 동률의 대상/몸 충돌 정렬을 String으로 명시해 기존 기대와 결정론을 보장했다.

새 tests/combat_input_ringout.gd는 두 캐릭터 전체 조합·무게/상하한·실제 경직 종료·가드 붕괴·각 공격단계 입력경계·예약중복/HOLD/중단·전투도중경계통과·낙하/비표시/60tick·기회중복차감·동시최종탈락·부활/재시작·HP사망·LAN기하/시간을 검사한다. 2026-10-29 최신 단독 실행 PASS, 원 전투v2 검사도 새 시간 기준으로 갱신 후 PASS. 최종 전체 검사와 독립 QA는 closeout에 기록한다.

실제 Android 검사는 사용자 요청에 따라 별도 진행한다.
