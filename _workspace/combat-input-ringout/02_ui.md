# 임시 디버깅 설정과 판정 표시

- 설정의 디버깅 분류에 실제 CheckButton과 적용·취소·기본값을 연결했다. 앱 메모리에서만 유지하며 profile·기기·DB 저장에는 넣지 않는다.
- 로비와 일시정지의 조작 설정에서 접근할 수 있다. 적용 시 현재 경기와 이후 local/LAN 경기에 반영한다.
- 별도 Node2D가 모든 참가자의 get_debug_geometry()를 읽어 반투명 빨강 타격·파랑 피격 사각형을 그린다. 다단 공격의 모든 활성 영역과 LAN 서버 사각형을 그대로 사용한다. 표시 코드는 전투·충돌 상태를 쓰지 않는다.
- 색상 외 텍스트 범례를 HUD에 표시한다. 별도 이미지나 승인 캐릭터 자산은 수정하지 않았다.
- tests/combat_debug_settings.gd: 기본값·초안취소·적용·복원·세션 한정·추가 참가자·다단 영역·LAN 사각형·동일 입력 결과·일시정지 연결과16:9/20:9 범례/체크 영역 검사. --ui-capture로 실제 렌더 캡처를 지원한다.
- 검사 실행과 화면 결과는 최종 QA/closeout 기록에서 확인한다. 실제 Android 검사는 사용자가 별도 진행하도록 이연했다.

## 수행 결과

- headless 자동 검사: PASS (`build/verification/combat-input-ringout/debug-headless.log`). 이 실행에는 종료 정리 진단4 ObjectDB/2 resources가 별도 출력됐다.
- 실제 macOS 네이티브 렌더 자동 검사: PASS, 종료코드0, 엔진 오류·정리 진단 없음 (`build/verification/combat-input-ringout/debug-capture.log`).
- 설정·경기의1280×720과1600×720 캡처4장을 직접 읽었다. 디버깅 분류·체크·설명·적용/취소/기본값이 잘리지 않고, 빨강3방향 공격 영역·파랑 피격 영역·색상별 텍스트 범례가 표시된다. HUD와 터치 버튼을 가리지 않는다.
- 첫 화면 확인에서6번째 설정 분류가 스크롤 아래에 일부 잘리는 것을 발견했다. 해당 목록 간격을4px로 줄이고72px 터치 크기를 유지해 여섯 분류가 모두 보이도록 고친 뒤 재검사했다.
