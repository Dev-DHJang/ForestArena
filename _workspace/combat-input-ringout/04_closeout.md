# 전투 조작·가드·장외 처리 개선

2026-10-29. 요청한 다섯 개선과 LAN4 연결을 구현하고 독립 QA·최종 전체 검사를 통과했다. PR116을 develop에 병합했다. 실제 Android 검사는 사용자 요청대로 별도 진행한다.

## 구현

- 무게·기존 상하한 계산 뒤 피격 경직을 정확히2배로 늘렸다. 현재 규칙은 착지 다운36·가드 붕괴60 tick이다. 기상 보호12·공중 제한120·특수 대기300 tick은 유지한다.
- 약 중간타의 준비·판정·회복 전체30 tick에서 다음 누름 하나만 예약하며 기존 회복 뒤 실행한다. HOLD·마지막 타격·피격 중단 규칙을 검사했다.
- 승인 가드 고정 frame11을 유지하고 아래 해제·방향 변경·중단·LAN 입력 손실 때 실제 방어와 표시를 함께 해제한다.
- 설정의 임시 디버깅은 실행 중에만 유지한다. 모든 local/LAN 참가자의 실제 판정 사각형을 빨강 공격·파랑 피격으로 표시하며 전투 상태를 바꾸지 않는다.
- 아래 경계만 낙하 전이를 시작하고 타격·몸 충돌 전에 행동을 제외한다. 비표시선 뒤60 tick에 기회를 한 번 차감하고 승패를 결정한다. 카메라 아래 추적을 제한하며 HP 사망·부활 흐름은 보존했다. 낙하 중 공통 대기·내구 회복 시계도 계속 흐른다.
- LAN4·FAH4/FA4와 공용 상태를 서버·클라이언트·검사 도구에 함께 적용했다. 이전 버전은 거부한다. 프로필·DB 형식과 승인 캐릭터 원본은 바꾸지 않았다.
