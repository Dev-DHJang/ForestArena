# Android 통합본 확인

기기는 Galaxy S23 Ultra(SM-S918N), Android16/API36 실제1대다. 물리 화면3088×1440, 앱 논리 화면1544×720에서 가로 UI를 확인한다. 동일 기기의 여러 ADB 연결을 여러 대로 세지 않았다. 연결 주소·serial·인증 값은 Git용 증거에서 가린다.

기존 앱을 `install -r`로 업데이트했고 저장 삭제를 수행하지 않았다. `--qa-run`의 별도 실행 ID와 저장 경로를 사용한다. 기존 원본 저장13경로(메뉴4종의 파일·백업 포함)는 전후 존재 여부와 해시만 비교하고 내용은 수집하지 않는다. 이번 실행은 전후 모두 파일이 없어 before/after가 빈 객체이고 unchanged=true다. 존재하는 저장 파일13개를 검증한 결과로 표현하지 않는다.

최종 APK는 `build/android/ForestArena-integrated-device.apk`, SHA-256 `ae579f8ed372c32f79c479edebb1a671047e7b4d1467ce9f0f06997fd55df6df`다. 원본 APK와 중간 실패 APK는 로컬에 유지한다. 기기에 실제 설치된 base.apk 해시도 최종 APK와 비교한다.

기기 조작은 실제 ADB touch/swipe/keyevent로 수행한다. 모드·대전 조건 설정과 결과까지의 자동 전투에는 debug QA 명령을 사용한다. 자동 전투는 정상 전투 규칙을 거치며 피해·게이지·승패를 직접 설정하지 않는다. 따라서 사람이 전체 경기를 직접 조작한 품질 검사로 표현하지 않는다.

타이틀 반복 시작 영상, 메뉴 화면, 네 캐릭터의 새 전투·점프 상태를 별도 검사한다. 설치 아이콘 화면은 Android 앱 정보 화면이며 개인 홈 화면의 런처 배치·마스크를 검사한 것으로 표현하지 않는다. 최종 통과·실패·미실행 범위와 원본 저장 해시 결과는 `04_closeout.md` 및 실제 실행 결과에 기록한다.

사람의 오디오 청취, 전체90모션의 개별 시각 품질, 두 실기기 LAN, 장시간 발열·성능·배터리는 이번 간단 통합 검사에서 완료로 주장하지 않는다.
