# 음악·효과음 v02 청취 시안 r03

2026-10-09 추가 피드백을 반영했다. 전투 긴장감은 적절하다는 사용자 의견을 유지하면서 두 음악의 반복감과 로비 피아노의 단조로움을 개선했다. 강한 타격 ‘퍽’은 유지하고 약한 타격 ‘파악’을 추가했으며 가드 파괴는 ‘채앵’으로 바꿨다. 이전 r02는 Git `54b526a`에 보존한다. 비교 A는 최초 v01이고 B는 최신 r03이다.

## 최종 9개 선택 — 게임에 적용

사용자가 아래 9개 조합을 확정했다. 이 선택 조합을 게임에 적용하고 나머지 38개는 기존 v01을 유지한다. 묘령의 선택은 미리 들은 위 특수기에만 해당한다.

| 소리 | 확정 버전 |
| --- | --- |
| 로비·전투 음악 | A · 최초 v01 전체 반복 음악 |
| 점프·강한 타격·묘령 위 특수기 | A · 최초 v01 |
| 버튼 클릭·약한 타격·가드 파괴·자현 필살기 | B · v02 r03 |

[선택 조합 미리듣기](preview.html?selection=approved)에서 9개 모두 **확정·게임에 적용** 표시를 확인한다. 두 음악의 B·r03 재편곡을 비롯한 미선택 시안은 비교용으로 보존한다. 음악 A/B 비교는 60초지만 게임은 승인된 v01의 원래 80/90초 반복 음악이다. 모든 47개를 v02로 완성·교체했다는 뜻은 아니다.

`manifest.json`의 `candidate_selection`은 9개 모두 `preference_confirmed: true`, `selection_feedback.whole_set_approved`는 이 **선택 조합**의 확정, `selection_runtime_applied: true`는 조합의 게임 적용을 기록한다. 본체의 `runtime_connected: false`와 `human_listening_approved: false`는 보존된 **A/B 비교 묶음 전체**가 게임에 연결·승인된 것이 아니라는 뜻으로 유지한다. 실제 Android 기기의 청취·출력 전환·중단/복귀는 여전히 미확인이다.

[비교 미리듣기](preview.html)를 브라우저로 연다. 파일을 직접 열어 재생할 수 없으면 이 폴더만 로컬 서버로 제공한다.

```sh
python3 tools/forest_arena/serve_audio_v02_preview.py
```

이 서버는 음원 위치 탐색에 필요한 HTTP byte range(파일의 일부만 요청하는 기능)를 지원하며 시안 폴더만 127.0.0.1에서 제공한다.

`http://127.0.0.1:8875/preview.html?revision=3`에서 같은 소리를 A·이전 / B·새 시안으로 바꿔 듣는다. 자동 재생이나 외부 업로드는 없다. 음악 비교는 위치를 이어 듣고, 효과음은 처음부터 듣는다.

## 무엇이 달라졌는가

- 음악을 60초로 늘리고 도입·주제·대조·변형 재현을 구성했다. 기존 30초를 두 번 복제하거나 템포만 바꾸지 않았다. 두 음악 모두 0–15초 도입, 15–30초 주제, 30–45초 대조, 45–60초 변형 재현이다. 전투는 마지막 구간에 절정을 포함한다. 구간 경계는 각 `score.json`의 `sections`와 비교 화면에 남겼다.
- 로비는 피아노를 주선율로 유지하면서 음역·쉼·화성과 왼손 반주 형태를 바꿨다. 구간별 악기 출입과 대화하는 선율로 전개를 넓혔다.
- 전투는 단조·감화음·E7의 긴장과 호른·현악을 유지하면서 첼로·타악 패턴, 악기 밀도와 완급을 구간별로 바꿨다.
- 약한 타격 ‘파악’은 밝고 넓은 접촉과 짧은 공기층으로 강한 타격의 낮은 몸통과 구분했다. 가드 파괴 ‘채앵’은 날카로운 접촉 뒤 음정 간격이 불규칙한 금속 울림이 감소하도록 합성했다. 상승 음계나 경쾌한 종 선율은 쓰지 않았다.
- 강한 타격·버튼·점프·묘령 위 특수기·자현 필살기 5개는 r02 원본과 비교 파일을 그대로 유지했다.
- 음악은 EBU R128의 전체 청감 음량(LUFS-I)을 맞췄다. 아주 짧은 효과음은 250ms 간격으로 같은 횟수 반복한 신호를 측정했다. 목표는 음악 -18 / 효과음 -22 LUFS이며 두 버전 모두 true peak(샘플 사이까지 추정한 최대 크기) -2dB를 넘지 않도록 필요하면 공통 목표를 낮춘다. 수치·방법은 manifest에 남긴다. 수치 일치가 모든 사람이 같은 크기로 느낀다는 뜻은 아니다.

이 60초 파일은 끝에 0.65초 사라지는 구간이 있는 **비반복 청취 시안**이다. 게임용 전체 반복 경계가 검증됐다는 뜻이 아니다. 참고 영상은 사용자가 제시한 MapleStory Title Theme의 제작 완성도 기준이며 녹음·음표·선율을 추출하거나 복사하지 않았다. 악보는 프로젝트 코드에서 별도로 작성했다. 참고 수준의 청감 품질이나 반복감의 해소 여부를 자동 검사만으로 판정하지 않는다.

## 파일과 권리

- `source/music/`: 렌더링한 두 음악과 각각의 악기별 WAV 9개, MIDI와 음표·강약·배치 JSON. 악기별 파일은 잔향 확인용 2초 여유를 포함한다. 최종 60초 비교음원과 길이가 다르다.
- `source/sfx/`: 직접 합성한 대표 효과음 7개. 외부 녹음·음성 없음.
- `comparison/`: v01/v02의 음량을 맞춘 18개 비교 WAV. 44100Hz PCM16, 음악 스테레오/효과음 모노.
- `manifest.json`: 제작기 확인값(SHA256), 악기 라이브러리·도구 버전·설정·출처·전체 파일 확인값과 음량 측정값.
- `licenses/FluidR3-COPYRIGHT.txt`: FluidR3 GM의 MIT 허가문·저작자·기여자 표시. Frank Wen ©2000–2002,2008와 기여자에게 악기 샘플 권리가 있다. 프로젝트가 모든 악기 녹음까지 직접 만들었다고 주장하지 않는다.

FluidR3_GM.sf2와 FluidSynth는 제작에만 사용한다. 악기 라이브러리를 저장소나 APK에 넣지 않으며 `assets/audio/.gdignore`가 제작용 파일을 Godot에서 제외한다. 기존 `fa.audio.*` 논리 ID와 재생 정책을 유지하면서 확정한 B 효과음 4개만 새 게임 자산에 연결한다. 악기 라이브러리와 음악 B 시안은 게임에 넣지 않는다.

## 다시 생성

Python 3+NumPy, ffmpeg, FluidSynth 2.6.0이 필요하다. macOS에서는 공식 Homebrew의 `brew install fluidsynth`로 설치할 수 있다. 도구 버전이 다르면 결과 파일의 확인값이 달라질 수 있으므로 manifest의 버전을 함께 확인한다.

악기는 Debian 공식 배포의 `fluid-soundfont-gm_3.1-5.3_all.deb`를 받아 **실행하거나 설치하지 않고** 압축을 풀어 사용한다.

- 배포: https://deb.debian.org/debian/pool/main/f/fluid-soundfont/fluid-soundfont-gm_3.1-5.3_all.deb
- 패키지 SHA256: `6f531493ac4e4d9772fd96b2488ea1790af81c196135fbdd25997da0781fc60e`
- `ar -x <package.deb> data.tar.xz` 뒤 `tar -xf data.tar.xz`로 추출한다. `usr/share/sounds/sf2/FluidR3_GM.sf2` 확인값은 `74594e8f4250680adf590507a306655a299935343583256f3b722c48a1bc1cb0`이다.

저장소 루트에서 실행한다. `--soundfont`에는 추출한 파일 경로를 지정한다. macOS에서 라이브러리 검색이 안 되면 `--fluidsynth-library /opt/homebrew/lib/libfluidsynth.dylib`를 추가한다.

```sh
python3 tools/forest_arena/generate_audio_v02_preview.py --soundfont /path/to/FluidR3_GM.sf2
python3 tools/forest_arena/verify_audio_v02_preview.py
```

`--output /tmp/audio-preview-rebuild`를 주면 저장된 시안을 덮지 않고 다시 만들 수 있다. `--skip-music`은 이미 렌더링한 음악을 재사용하여 비교음량만 갱신하는 선택 사항이며, 음악을 다시 제작하거나 렌더링한 것으로 기록하지 않는다. 필요한 악기 파일이 없거나 확인값이 다르면 단순 파형 음원으로 대체하지 않고 실패한다.
