# Forest Arena 사운드 v01

밝은 숲 판타지 분위기의 독창적인 작곡·합성 음원이다. 외부 녹음·샘플·음성·기존 곡의 선율은 사용하지 않는다. 합성 악기의 음색과 실제 게임에서 여러 소리가 겹칠 때의 균형은 사람이 추가 청취해야 한다. 자동 검사는 Android 실기기 청취를 대신하지 않는다.

## 구성과 교체

- `lobby.ogg`: D장조, 96 BPM, 4/4박자, 32마디, 80초. 부드러운 목관·뜯는 현악·나무 건반·가벼운 타악.
- `battle.ogg`: 같은 8마디 주제의 변주, 128 BPM, 48마디, 90초. 촘촘한 타악·저음·높은 응답 선율.
- 메뉴 5개, 이동 5개, 일반 전투 8개, 경기 흐름 5개, 특수·필살기 적중 2개, 네 캐릭터별 주요 기술 20개: 총 45개 효과음.
- 자현은 빠르고 나무 같은 타격, 묘령은 밝고 가벼운 종, 나비는 날카로운 긁힘, 유란은 낮고 굴러가는 바람을 기본 음색으로 한다. 기술 방향마다 음높이 움직임을 달리하고 필살기는 더 긴 음색 층을 쓴다. 이는 소리 표현이며 전투 판정을 만들지 않는다.

실행 음원은 `forest_arena/assets/audio/v01/`에 있으며 원본 WAV는 이 폴더의 `source/`에 있다. 음악은 스테레오 Vorbis OGG, 효과음은 모노 16비트 PCM WAV다. 모두 44,100 Hz다. 효과음 원본과 실행 음원은 동일하다. 파일명에 대응하는 논리 ID는 `fa.audio.<파일명에서 확장자를 뺀 이름>`이다.

`preview.html`을 브라우저로 열면 이름별로 미리 들을 수 있다. 음악 재생기는 반복을 켜 두었다. 소리를 교체하면 파일명·논리 ID를 유지하고 `manifest.json`의 출처·권리 근거·파일 확인값을 다시 기록해야 한다.

## 다시 생성하기

프로젝트 루트에서 아래 명령을 실행한다. Python 3, NumPy와 ffmpeg/ffprobe가 필요하다. 사용한 버전은 `manifest.json`에 기록한다.

```sh
python3 tools/forest_arena/generate_audio_v01.py
python3 tools/forest_arena/verify_audio_v01.py
```

고정 난수값 `20261008`을 사용한다. 동일한 NumPy·ffmpeg 버전에서 두 번 생성해 모든 WAV·OGG 파일 확인값이 같은지 검사한다. 음악 끝에 걸친 악기 잔향과 반사음은 시작 지점으로 연결해 반복 경계를 만든다. OGG 컨테이너의 난수 일련번호도 고정되도록 `bitexact` 옵션을 쓴다. 도구 버전이 바뀌면 인코더 차이로 확인값이 달라질 수 있다.

검사는 필수 47개 음원과 중복, 원본·실행 파일 확인값, 미리듣기 링크, 길이·채널·형식, 지나친 음량·무음·직류 성분, 효과음 시작·끝의 완만한 음량 변화, 실제 OGG를 해독한 반복 경계의 급격한 변화와 무음 구간을 확인한다. 사람의 청취·Android 출력·게임 연결은 별도 확인 항목이다.
