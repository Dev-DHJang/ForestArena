# 사용자가 확정한 음원 조합

2026-10-09 사용자가 아홉 항목의 버전을 최종 결정했다. 최종 선택은 실제 게임에 적용했다.

| 소리 | 선택 |
| --- | --- |
| 로비 | v01, 기존 80초 반복곡 |
| 전투 | v01, 기존 90초 반복곡 |
| 버튼 클릭 | v02 r03 |
| 점프 | v01 |
| 약한 타격 | v02 r03 |
| 강한 타격 | v01 |
| 가드 파괴 | v02 r03 |
| 묘령 위 특수기 | v01 |
| 자현 필살기 | v02 r03 |

네 v02 효과음만 `forest_arena/assets/audio/v02-selected/`에 원본 PCM과 같은 바이트로 복사했다. 기존 논리 ID의 경로를 바꿨으며 재생 이벤트·오디오 버스·음량·동시 재생 한도·중단 복귀 정책은 유지한다. 비교 시안의 음량 보정본은 이 원본의 배율만 바꾼 신호다. 다른 38개 게임 음원과 v01 원본·실행 파일은 유지한다. v02 음악과 묘령의 다른 기술을 새로 승인한 것으로 간주하지 않는다.

`manifest.json`은 선택 아홉 개, 원본·미리듣기·실행 파일 경로와 확인값, 사용자 결정 범위·출처·적용 도구를 기록한다. 선택된 음악과 효과음은 프로젝트 독창적 작곡·합성이며 새 v02 효과음에는 외부 녹음·샘플·음성이 없다. 선택되지 않은 B 음악 제작에는 별도 FluidR3 샘플 라이선스가 있으며 그 자료는 기존 시안 폴더에 보존한다.

```sh
python3 tools/forest_arena/apply_approved_audio_v02.py
./scripts/verify-audio.sh
python3 tools/forest_arena/verify_godot_resources.py --project-root .
```

[확정 조합 미리듣기](../v02-preview/preview.html?selection=approved)에서 선택 표시된 음원을 듣는다. 비교 A 음악은 60초 발췌이며 게임에서는 원래 80/90초 반복곡을 사용한다. 사용자 청취 선택과 실제 Android 출력·중단/복귀 검증은 별개다. 실제 Android 청취는 후속 미확인이다.
